Machine Learning Guideline

English 中文

Hexo Home

Machine learning studies how a system can improve its behavior from data or interaction while continuing to perform well on experience it has not seen before. A complete treatment therefore needs more than a catalogue of algorithms: it must connect problem formulation, data, mathematical assumptions, learning objectives, optimization, experimental evidence, reliability, and deployment.

This series follows those dependencies. Parts I-III build the classical core, Part IV introduces advanced learning settings, and Part V addresses trustworthy systems and research practice. Neural-network fundamentals are included as a bridge, while architecture-specific material remains in the separate Deep Learning series.

Supervised Learning

These chapters organize supervised methods by the assumptions they make about geometry, probability, partitioning, structure, and representation.

  1. Linear Regression and Generalized Linear Models
  2. Instance-Based, Geometric, and Kernel Methods
  3. Rule Learning, Decision Trees, and Ensembles
  4. Probabilistic Models and Bayesian Learning
  5. Graphical Models and Sequential Prediction
  6. Neural Networks: A Bridge to Deep Learning

Unsupervised and Representation Learning

These chapters explain how models discover groups, densities, anomalies, latent factors, manifolds, and sparse representations without direct target labels.

  1. Clustering, Density Estimation, and Anomaly Detection
  2. Dimensionality Reduction and Sparse Representation

Advanced Learning Paradigms

These chapters move beyond independent and identically distributed labeled examples to limited supervision, transfer, sequential decisions, and causal questions.

  1. Learning with Limited, Weak, and Noisy Supervision
  2. Transfer, Domain Adaptation, and Multi-Task Learning
  3. Online Learning, Bandits, and Reinforcement Learning
  4. Causal Machine Learning

Reliable and Practical Machine Learning

These chapters evaluate whether a model is understandable, robust, fair, private, reproducible, deployable, and scientifically credible.

  1. Interpretability, Robustness, Fairness, and Privacy
  2. Machine Learning Systems and Research Practice

Scope and Boundaries

The classical and advanced chapters cover the main learning outcomes associated with Machine Learning and Advanced Machine Learning courses. Detailed CNN, RNN, Transformer, and modern deep-learning architectures remain in the Deep Learning guideline. The original combined notebook is preserved as Machine Learning-full.ipynb for historical reference.
