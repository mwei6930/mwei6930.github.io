NLP 建模

NLP 建模把任务合同转化为一个可学习的条件分布、结构预测问题或生成过程。输入表示、上下文编码、预测头和解码算法共同决定可表达的输出。英文输入输出案例保持原文，以免改变标签边界、长度和语义关系。

Raw Text -> Tokenisation -> Representation -> Model -> Prediction / Generation

NLP 中的建模意味着什么

建模不是简单选择神经网络名称，而是明确 \(x\) 是什么、\(y\) 的结构是什么、要估计 \(p(y\mid x)\) 还是联合分布，以及推断时如何从分数得到输出。同一架构可配不同任务头，同一任务也可用规则、概率模型或深度模型解决。

\[ P(y \mid x) \]

\[ P(y_1, y_2, ..., y_T \mid x) \]

Part Role Example
Input representation Turns text into vectors BoW, TF-IDF, embeddings, contextual embeddings
Context modeling architecture Combines information across tokens Linear model, CNN, RNN, Transformer
Prediction head Converts hidden representation into output Classification head, token classifier, LM head 
Representation answers: what does each token/document look like numerically?
Architecture answers: how does information move between tokens?
Prediction head answers: what kind of output do we want?

NLP 的输入输出形式

先按输入与输出结构分类问题，可以在选择模型前识别所需上下文和损失。常见形式包括序列到标签、序列到标签序列、序列到序列、语言模型以及 pairwise matching。形式决定数据标注、张量形状、解码和指标。

序列到标签建模

模型读取一个 token 序列并输出固定标签或连续值，例如 sentiment、topic、intent。编码器先聚合序列，分类头再产生 logits。池化策略必须保留任务所需证据，并注意长文截断可能删除决定性片段。

Input:  "This movie was surprisingly good"
Output: Positive
Task Input Label
Sentiment classification review text positive / negative
Spam detection email text spam / not spam
Topic classification news article politics / sport / finance
Intent detection user utterance book_flight / cancel_order

\[ \hat{y} = \arg\max_y P(y \mid x) \]

代码与案例 
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

texts = [
    "the movie was excellent",
    "great story and acting",
    "the film was boring",
    "terrible pacing and weak plot"
]
labels = [1, 1, 0, 0]

model = Pipeline([
    ("tfidf", TfidfVectorizer()),
    ("clf", LogisticRegression())
])

model.fit(texts, labels)
print(model.predict(["excellent acting"]))

输出与输入 token 或 span 对齐，例如 POS、NER 与 slot filling。模型需要同时判断标签类别和边界；独立 token softmax 简单，CRF 等结构层可约束合法转移。子词拆分后还要规定标签投影与聚合规则。

序列到序列建模

输入和输出都是可变长序列，常见于翻译、摘要与问答。encoder-decoder 先编码 \(x\)，decoder 自回归建模 \(p(y\mid x)=\prod_t p(y_t\mid y_{<t},x)\)。训练可并行，推断却依赖已生成前缀。

\[ P(y \mid x) = \prod_{t=1}^{m} P(y_t \mid y_{<t}, x) \]

语言建模

语言模型为 token 序列分配概率。自回归模型预测下一 token，masked model 根据双向上下文恢复被遮蔽 token。它们学习通用语言统计，但低 perplexity 不自动意味着事实正确、指令遵循或安全。

Input:  Natural language processing is
Output: [fun, difficult, useful, ...]

\[ P(w_1, w_2, ..., w_n) \]

\[ P(w_1, ..., w_n) = \prod_{i=1}^{n} P(w_i \mid w_1, ..., w_{i-1}) \]

\[ P(w_i \mid w_{<i}) \]

from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

model = AutoModelForCausalLM.from_pretrained(model_name)

    outputs = model(**inputs)

next_token_logits = outputs.logits[0, -1]
next_token_id = next_token_logits.argmax().item()

print(tokenizer.decode([next_token_id]))

成对与匹配建模

匹配任务比较 query-document、premise-hypothesis 或两句是否等价。cross-encoder 联合编码 pair，交互充分但成本高；bi-encoder 分别编码并用相似度比较，便于大规模索引。负例选择往往比单纯扩大模型更关键。

NLP 建模的概率视角

概率视角明确模型在估计什么分布以及不确定性来自哪里。分类常直接估计条件分布，生成模型可描述数据生成过程，条件生成则在给定输入下生成输出。概率需要校准与任务约束，不能把 softmax 数值直接当作事实可信度。

判别式建模

判别模型直接学习 \(p(y\mid x)\) 或决策边界，重点区分目标类别。逻辑回归、CRF 和大多数微调分类器都属此类。它们通常在有标签任务上高效，但不会完整解释输入如何产生，也难自然生成新文本。

\[ P(y \mid x) \]

Model Task
Logistic Regression sentiment classification
Linear SVM document classification
BERT classifier intent detection
CRF tagger sequence labeling

生成式建模

生成模型学习 \(p(x)\) 或 \(p(x,y)\)，可采样、补全或通过 Bayes 规则分类。n-gram、HMM 和自回归语言模型体现不同形式。它们能利用无标签数据，但对分布假设、解码与生成错误更敏感。

\[ P(x, y) = P(y)P(x \mid y) \]

\[ P(y \mid x) = \frac{P(x \mid y)P(y)}{P(x)} \]

\[ P(c \mid d) \propto P(c) \prod_i P(w_i \mid c) \]

\[ P(w_1, ..., w_n) \]

条件生成

条件生成估计 \(p(y\mid x)\)，但 \(y\) 是开放序列而非固定类别。翻译、摘要和基于证据的回答都属于此类。模型必须同时满足内容条件与语言流畅性，评估也要区分事实支持、覆盖、风格和多解问题。

\[ P(y \mid x) \]

Task Conditional Probability
Translation \(P(\text{target sentence} \mid \text{source sentence})\)
Summarisation \(P(\text{summary} \mid \text{document})\)
Dialogue \(P(\text{response} \mid \text{conversation})\)

把架构理解为上下文建模方式

不同架构的核心差异是信息如何在 token 之间传播：线性模型使用局部人工特征，CNN 聚合固定窗口，RNN 顺序传递状态，Transformer 用注意力直接连接位置。选择架构就是选择归纳偏置、并行方式、上下文长度与成本。

CNN-Based Models local n-gram windows local phrase patterns limited long-range context
RNN / LSTM / GRU recurrent hidden state sequential context hard to parallelise

传统概率序列模型

HMM 用隐状态和生成假设建模序列，MEMM 直接建模局部条件分布，CRF 对整条标签序列归一化并加入转移约束。它们在小数据、可解释标注和结构约束场景仍有价值，也为理解神经序列模型提供清晰基线。

\[ y^* = \arg\max_{y \in \mathcal{Y}(x)} \operatorname{score}(x,y) \]

Observed words:    The       bank      raised     rates
Hidden POS tags:   DET  ->   NOUN  ->  VERB  ->   NOUN

\[ P(x,y) =P(y_1) \prod_{t=2}^{T}P(y_t\mid y_{t-1}) \prod_{t=1}^{T}P(x_t\mid y_t) \]

\[ y^*=\arg\max_y P(y\mid x) =\arg\max_y P(x,y) \]

\[ \delta_t(j) = \max_i\left[\delta_{t-1}(i)a_{ij}\right]b_j(x_t) \]

代码与案例 
import math

words = ["the", "bank", "closed"]
tags = ["DET", "NOUN", "VERB"]

# Probabilities are deliberately small and illustrative rather than learned
# from a full corpus. In practice, estimate them from tagged training data.
start = {"DET": 0.60, "NOUN": 0.25, "VERB": 0.15}
transition = {
    "DET":  {"DET": 0.05, "NOUN": 0.85, "VERB": 0.10},
    "NOUN": {"DET": 0.10, "NOUN": 0.20, "VERB": 0.70},
    "VERB": {"DET": 0.40, "NOUN": 0.40, "VERB": 0.20},
}
emission = {
    "DET":  {"the": 0.90, "bank": 0.01, "closed": 0.01},
    "NOUN": {"the": 0.01, "bank": 0.70, "closed": 0.10},
    "VERB": {"the": 0.01, "bank": 0.20, "closed": 0.80},
}

# Log probabilities turn products into sums and prevent numerical underflow.
def safe_log(probability):
    return math.log(max(probability, 1e-12))

scores = []       # scores[t][tag] = best log-score ending in tag at t
backpointers = [] # backpointers[t][tag] = best previous tag

# Step 1: initialize paths using the start and first-word probabilities.
first_scores = {
    tag: safe_log(start[tag]) + safe_log(emission[tag].get(words[0], 1e-6))
    for tag in tags
}
scores.append(first_scores)
backpointers.append({tag: None for tag in tags})

# Step 2: extend only the best path into each current tag.
for position in range(1, len(words)):
    current_scores = {}
    current_backpointers = {}

    for current_tag in tags:
        candidates = {
            previous_tag: (
                scores[position - 1][previous_tag]
                + safe_log(transition[previous_tag][current_tag])
                + safe_log(emission[current_tag].get(words[position], 1e-6))
            )
            for previous_tag in tags
        }
        best_previous = max(candidates, key=candidates.get)
        current_scores[current_tag] = candidates[best_previous]
        current_backpointers[current_tag] = best_previous

    scores.append(current_scores)
    backpointers.append(current_backpointers)

# Step 3: start from the best final tag and follow pointers backward.
best_final_tag = max(scores[-1], key=scores[-1].get)
best_path = [best_final_tag]

for position in range(len(words) - 1, 0, -1):
    best_path.append(backpointers[position][best_path[-1]])

best_path.reverse()
print(list(zip(words, best_path)))
# [('the', 'DET'), ('bank', 'NOUN'), ('closed', 'VERB')]

\[ P(y\mid x) =\prod_{t=1}^{T}P(y_t\mid y_{t-1},x,t) \]

\[ \operatorname{score}(x,y) =\sum_{t=1}^{T}s_t(y_t,x) +\sum_{t=2}^{T}A_{y_{t-1},y_t} \]

\[ P(y\mid x) =\frac{\exp(\operatorname{score}(x,y))}{Z(x)}, \qquad Z(x)=\sum_{y'\in\mathcal{Y}(x)}\exp(\operatorname{score}(x,y')) \]

线性模型

线性模型对 BoW、TF-IDF 或人工特征加权，再通过 sigmoid/softmax 预测。训练快速、系数可解释、对小数据稳定，但除非显式构造 n-gram 或交互特征，否则难表达词序和复杂组合。

\[ f(x)=w^Tx+b \]

Input sentence: "not very good"
Features: not=1, very=1, good=1, not_good=1
Model score: sum(feature value * feature weight)

基于 CNN 的模型

文本 CNN 用卷积核检测局部 n-gram 模式，再通过 pooling 得到固定表示。它能并行训练并捕获关键短语，适合分类；更深或空洞卷积可扩大感受野，但长距离依赖仍需多层传播。

Embeddings -> Convolution Filters -> Max Pooling -> Classifier
not very good
really loved this
waste of time
Component NLP Interpretation
Embedding matrix sentence represented as token vectors
Convolution filter detects local phrase pattern
Feature map where the pattern appears
Max pooling keeps the strongest signal
Classifier predicts the final label
代码与案例 
import torch
import torch.nn as nn
import torch.nn.functional as F

class TextCNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.conv = nn.Conv1d(
            in_channels=embed_dim,
            out_channels=100,
            kernel_size=3
        )
        self.fc = nn.Linear(100, num_classes)

    def forward(self, token_ids):
        x = self.embedding(token_ids)      # [batch, seq_len, embed_dim]
        x = x.transpose(1, 2)              # [batch, embed_dim, seq_len]
        x = F.relu(self.conv(x))           # [batch, channels, new_seq_len]
        x = F.max_pool1d(x, kernel_size=x.size(2)).squeeze(2)
        return self.fc(x)

RNN、LSTM 与 GRU

RNN 按顺序更新隐藏状态，天然表示前缀；LSTM/GRU 通过门控缓解梯度消失并控制记忆。双向模型适合理解任务，单向模型适合生成。顺序依赖限制并行，超长上下文中的信息仍可能衰减。

\[ h_t = \tanh(Wx_t + Uh_{t-1} + b) \]

Pattern Input Output Example
many-to-one token sequence one label sentiment classification
many-to-many token sequence token label sequence NER, POS tagging
encoder-decoder source sequence generated target sequence translation
Model Main Mechanism Intuition
RNN one hidden state simple sequential memory
LSTM cell state + input/forget/output gates stronger long-term memory
GRU update/reset gates simpler gated memory
代码与案例 
import torch
import torch.nn as nn

class BiLSTMTagger(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_tags):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(
            embed_dim,
            hidden_dim,
            batch_first=True,
            bidirectional=True
        )
        self.classifier = nn.Linear(hidden_dim * 2, num_tags)

    def forward(self, token_ids):
        embeddings = self.embedding(token_ids)
        outputs, _ = self.lstm(embeddings)
        return self.classifier(outputs)

model = BiLSTMTagger(10000, 128, 64, 5)
batch = torch.tensor([[11, 22, 33, 44]])
print(model(batch).shape)  # [batch, seq_len, num_tags]

基于 Transformer 的模型

Transformer 用 self-attention 让每个 token 根据其他位置加权聚合信息，并结合位置编码与前馈层。encoder、decoder 和 encoder-decoder 分别适合理解、生成与条件生成。全局交互能力强，但注意力成本、上下文管理和位置泛化仍需权衡。

\[ q_i = W_Qx_i, \quad k_i = W_Kx_i, \quad v_i = W_Vx_i \]

\[ \text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \]

Component Role
Multi-head self-attention lets tokens exchange contextual information
Feed-forward network applies non-linear transformation at each position
Residual connection stabilizes deep networks
Layer normalization normalizes hidden activations
Positional encoding injects word order information
Family Attention Pattern Suitable Tasks
Encoder-only bidirectional attention classification, NER, embeddings
Decoder-only causal attention text generation, chat, completion
Encoder-decoder encoder attention + decoder cross-attention translation, summarisation

import torch
import torch.nn as nn

attention = nn.MultiheadAttention(
    embed_dim=128,
    num_heads=8,
    batch_first=True

x = torch.randn(2, 10, 128)
output, weights = attention(x, x, x)

print(output.shape)   # [2, 10, 128]

预测头与输出结构

共享编码器的隐藏状态必须通过与任务相匹配的输出头转成预测。头部规定 logits 的维度、参数共享方式和损失位置；输出结构不匹配时，再强的编码器也无法自然表达任务约束。

Backbone hidden states -> Prediction Head -> Task-specific Output

分类头

分类头从 pooled 表示或指定 token 隐藏状态计算类别 logits，随后用 softmax 或 sigmoid。单标签任务通常使用 softmax，多标签任务逐类使用 sigmoid。阈值、类别权重和校准属于最终决策的一部分。

\[ z = W h_{CLS} + b \]

\[ P(y \mid x)=\text{softmax}(z) \]

代码与案例 
import torch
import torch.nn as nn

hidden_size = 768
num_classes = 3

cls_vector = torch.randn(4, hidden_size)  # [batch, hidden]
head = nn.Linear(hidden_size, num_classes)

logits = head(cls_vector)
print(logits.shape)  # [4, 3]

Token 分类头

Token 分类头在每个位置共享同一个线性层，输出形状通常为 [batch, length, labels]。训练时应屏蔽 padding，并规定首子词或全子词的标签策略。需要全局合法性时可在 logits 之上增加 CRF。

\[ z_t = W h_t + b \]

Input hidden states: [h_1, h_2, ..., h_n]
Output logits:       [z_1, z_2, ..., z_n]

语言模型头

语言模型头把隐藏状态投影到词表维度，常与输入 embedding 权重绑定。自回归模型在每个位置预测下一 token，masked model 只在被选位置计算主要损失。大词表投影会占用显著参数和计算。

\[ z_t = W h_t + b \]

\[ P(w_{t+1} \mid w_{\le t})=\text{softmax}(z_t) \]

hidden state -> vocabulary logits -> probability over all tokens

Encoder-Decoder 输出层

decoder 根据已生成前缀和 encoder 表示产生下一 token logits，并重复直到 EOS 或长度上限。cross-attention 提供输入条件，输出层负责词表概率。训练中的 teacher forcing 与推断中的自回归前缀不同，会产生 exposure bias。

encoder input -> encoder states
previous output tokens -> decoder states -> vocabulary distribution

解码与推断

解码在巨大输出空间中搜索或采样序列。它会改变重复、长度、多样性和延迟，因此必须与任务目标共同调参。生成分数通常累加 log-probability，并需要长度归一化、停止条件和非法 token 约束。

\[ P(y_t \mid y_{<t}, x) \]

贪心解码

贪心解码每一步选择概率最高的 token，速度快、确定性强，但局部最优不保证整句概率最高。一旦早期选择错误，后续只能在错误前缀上继续。适合低延迟或输出较受约束的任务。

\[ y_t = \arg\max_w P(w \mid y_{<t}, x) \]

def greedy_decode(next_token_fn, start_token, end_token, max_len=20):
    output = [start_token]

    for _ in range(max_len):
        probs = next_token_fn(output)
        next_token = max(probs, key=probs.get)
        output.append(next_token)

        if next_token == end_token:
            break

    return output

Beam Search

Beam search 同时保留 \(k\) 个得分最高前缀，每步扩展并裁剪。较大 beam 可改善搜索，却增加计算，并可能偏向短、保守或重复输出。长度惩罚、覆盖约束和结束序列处理决定实际效果。

基于采样的解码

采样按模型分布选择 token，可用 temperature、top-k 或 top-p 控制随机性和长尾。它适合开放生成与多样候选，但不保证稳定或事实正确。应记录随机种子与参数，并对高风险输出增加验证。

\[ y_t \sim P(\cdot \mid y_{<t}, x) \]

Method Idea Effect
Temperature divide logits by temperature controls randomness
Top-k Sampling sample only from top k tokens removes very unlikely tokens
Top-p Sampling sample from smallest set with cumulative probability p adapts candidate set size

\[ P(w)=\text{softmax}(z_w / T) \]

Temperature Behavior
Low temperature safer, more deterministic
High temperature more diverse, more risky

选择建模策略

先确定输出结构、数据量、错误代价和部署预算，再建立从简单基线到复杂模型的阶梯。比较时保持数据、指标和调参预算一致，同时观察准确率、延迟、内存、校准和关键切片。最小且满足任务合同的模型通常更容易维护。
