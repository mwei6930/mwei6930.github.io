文本表示

文本表示把离散语言符号转换成可计算对象。频率表示强调词是否出现及出现多少，分布式表示学习稠密语义空间，上下文化表示则让同一词在不同句子中获得不同向量。方法选择取决于任务、数据、解释需求和计算预算。

离散表示（基于频率）

离散方法以固定词表为坐标，将文档表示为独立维度上的计数或权重。它们通常稀疏、可解释且训练快速，适合检索、线性分类与强基线；但词序、同义关系和上下文词义大多被忽略。

One-Hot 编码

One-Hot 为词表中的每个 token 分配一个维度，目标词位置为 1，其余为 0。向量不会表达 cat 与 dog 比 cat 与 table 更接近，维度也随词表增长。英文词表与编码矩阵保持原文，保证索引可核对。

代码与案例 
def one_hot_encode(text):
    words = text.split() # Split the text by whitespace
    vocabulary = set(words) # Keep the elements unique in the set
    word_to_index = {word: i for i, word in enumerate(vocabulary)} # Assign index for each word in vocabulary, output will be like {word0 : 0, word1: 1, ...}
    one_hot_encoded = []
    for word in words: # For every word, create the vector with 0 and lenght of vocabulary firstly, then set the corresponding position to 1 according to the word index
        one_hot_vector = [0] * len(vocabulary) 
        one_hot_vector[word_to_index[word]] = 1
        one_hot_encoded.append(one_hot_vector)
    return one_hot_encoded, word_to_index, vocabulary

词袋模型（BoW）

BoW 把文档表示为词频向量，忽略词序但保留出现次数。构建过程是确定词表、统计每个文档的 token、形成文档-词矩阵。它可直接解释分类权重，却无法区分 dog bites man 与 man bites dog 这类词集合相同的句子。

代码与案例 
"""
Document
   ↓
Tokenization
   ↓
Count word frequency
   ↓
Map to vocabulary index
   ↓
Vector representation
"""
import numpy as np

# vocabulary (normally built from a corpus)
vocab = ["cat", "dog", "fish"]

# word -> index
word_to_index = {word: i for i, word in enumerate(vocab)}

def bow_encode(document):
    vector = np.zeros(len(vocab))
    
    words = document.split()
    
    for word in words:
        if word in word_to_index:
            vector[word_to_index[word]] += 1
    
    return vector

doc = "cat dog cat"

print(bow_encode(doc))

TF-IDF

TF-IDF 用文档内词频乘以逆文档频率，使在当前文档常见但在语料中稀有的词获得高权重。常见形式为 \(w_{t,d}=tf_{t,d}\times\log(N/df_t)\)，实现中通常加入平滑、子线性 TF 和向量归一化。它仍不建模词序，但检索与分类效果很强。

\(\text{TF-IDF: } w_{t,d} = tf_{t,d} \times idf_{t}\)

\(idf(t) = \log\left(\frac{N}{df_t} \right)\)

\[ tf(t,d) = \begin{cases} 1 + \log_{10}(count(t,d)) & \text{if } count(t,d) > 0 \\ 0 & \text{otherwise} \end{cases} \]

\[ tf(data, D2) = 1 + \log_{10}(2) \approx 1.301 \]

\[ idf(t) = \log_{10}\left(\frac{N}{df_t}\right) \]

\[ idf(data) = \log_{10}\left(\frac{3}{2}\right) \approx 0.176 \]

\[ tfidf(data, D2) = tf(data, D2) \times idf(data) \]

\[ tfidf(data, D2) = 1.301 \times 0.176 \approx 0.229 \]

代码与案例 
import math
from collections import Counter

def compute_tfidf(documents):
    """
    Compute TF-IDF vectors for a list of documents.
    
    Parameters:
        documents (list[str]): A list of input documents.
        
    Returns:
        tfidf_vectors (list[dict]): TF-IDF vector for each document.
        vocabulary (list[str]): Sorted list of all unique terms.
        idf (dict): IDF value for each term.
    """
    
    # Step 1: Tokenize documents
    tokenized_docs = [doc.lower().split() for doc in documents]
    
    # Step 2: Build vocabulary
    vocabulary = sorted(set(word for doc in tokenized_docs for word in doc))
    
    # Step 3: Compute document frequency (df)
    N = len(documents)
    df = {}
    for term in vocabulary:
        df[term] = sum(1 for doc in tokenized_docs if term in doc)
    
    # Step 4: Compute IDF
    idf = {}
    for term in vocabulary:
        idf[term] = math.log10(N / df[term])
    
    # Step 5: Compute TF-IDF for each document
    tfidf_vectors = []
    
    for doc in tokenized_docs:
        term_counts = Counter(doc)
        tfidf = {}
        
        for term in vocabulary:
            count = term_counts.get(term, 0)
            
            # Log-scaled TF
            if count > 0:
                tf = 1 + math.log10(count)
            else:
                tf = 0
            
            tfidf[term] = tf * idf[term]
        
        tfidf_vectors.append(tfidf)
        
    return tfidf_vectors, vocabulary, idf


# Example usage
documents = [
    "data science is fun",
    "data science uses data",
    "machine learning is fun"
]

tfidf_vectors, vocabulary, idf = compute_tfidf(documents)

print("Vocabulary:")
print(vocabulary)

print("\nIDF values:")
for term, value in idf.items():
    print(f"{term}: {value:.3f}")

print("\nTF-IDF vectors:")
for i, vec in enumerate(tfidf_vectors, start=1):
    print(f"\nDocument D{i}:")
    for term in vocabulary:
        print(f"{term}: {vec[term]:.3f}")

BM25（Okapi Best Matching 25）

BM25 是概率检索排序函数，对词频采用饱和增长，并用参数 \(b\) 校正文档长度。\(k_1\) 控制重复词的边际收益，\(b\) 控制长度归一化。与普通 TF-IDF 相比，它避免超长文档仅因词多而占优，是搜索与 RAG 稀疏检索的重要基线。

\(\text{BM25}(D, Q) = \sum_{i=1}^{n}\text{IDF}(q_i)\cdot\frac{f(q_i, D)\cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot \left(1 - b + b \cdot \frac{|D|}{\text{avgdl}}\right)}\)

Aspect TF-IDF BM25
TF behavior Linear growth Saturation (diminishing returns)
Length handling Weak/simple Explicit normalization
IDF Standard Smoothed
Performance Baseline Stronger retrieval model
Usage Simple tasks Industrial search systems

下面给出 BM25 的完整 Python 实现。查询、文档 token 与输出保持英文原文，从而使分词、词频和排名结果与英文版一致。

代码与案例 
import math
from collections import Counter, defaultdict


class BM25:
    def __init__(self, corpus, k1=1.5, b=0.75):
        """
        corpus: list[list[str]]
        Example:
        [
            ["this", "is", "a", "document"],
            ["this", "document", "is", "about", "nlp"]
        ]
        """
        self.corpus = corpus
        self.k1 = k1
        self.b = b
        self.N = len(corpus)
        self.doc_len = [len(doc) for doc in corpus]
        self.avgdl = sum(self.doc_len) / self.N

        self.doc_freq = defaultdict(int)
        self.term_freqs = []

        for doc in corpus:
            tf = Counter(doc)
            self.term_freqs.append(tf)

            for term in tf:
                self.doc_freq[term] += 1

    def idf(self, term):
        n_i = self.doc_freq.get(term, 0)

        return math.log((self.N - n_i + 0.5) / (n_i + 0.5) + 1)

    def score(self, query, doc_index):
        score = 0.0
        doc_tf = self.term_freqs[doc_index]
        doc_len = self.doc_len[doc_index]

        for term in query:
            f = doc_tf.get(term, 0)
            if f == 0:
                continue

            numerator = f * (self.k1 + 1)
            denominator = f + self.k1 * (
                1 - self.b + self.b * doc_len / self.avgdl
            )

            score += self.idf(term) * numerator / denominator

        return score

    def rank(self, query):
        scores = []

        for i in range(self.N):
            scores.append((i, self.score(query, i)))

        return sorted(scores, key=lambda x: x[1], reverse=True)

corpus = [
    "machine learning is useful",
    "deep learning is a part of machine learning",
    "natural language processing uses machine learning",
    "cooking recipes and food"
]

tokenized_corpus = [doc.lower().split() for doc in corpus]

bm25 = BM25(tokenized_corpus)

query = "machine learning"
tokenized_query = query.lower().split()

results = bm25.rank(tokenized_query)

for doc_id, score in results:
    print(score, corpus[doc_id])

向量相似度

得到 BoW、TF-IDF 或 embedding 后，需要定义向量间接近程度。余弦相似度关注方向，适合长度不同文档；点积同时受向量范数影响；欧氏距离则依赖尺度。选择度量时必须与训练目标和索引系统一致，并处理零向量。

\[ \mathbf{A} = (a_1, a_2, ..., a_n) \]

\[ \mathbf{B} = (b_1, b_2, ..., b_n) \]

\[ A \cdot B = \sum_{i=1}^{n} a_i b_i \]

\[ \cos(\theta) = \frac{A \cdot B}{||A|| \, ||B||} \]

代码与案例 
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

# Example TF-IDF-like document vectors
A = np.array([1, 2, 0, 1])
B = np.array([0, 1, 1, 1])

# Dot product
dot_product = np.dot(A, B)
print("Dot product:", dot_product)

# Cosine similarity from scratch
cosine = np.dot(A, B) / (np.linalg.norm(A) * np.linalg.norm(B))
print("Cosine similarity:", cosine)

# Cosine similarity using scikit-learn
cosine_sklearn = cosine_similarity([A], [B])[0][0]
print("Cosine similarity (sklearn):", cosine_sklearn)

分布式表示（词嵌入与预测式表示）

分布式表示用低维稠密向量编码词的使用模式。分布假设认为出现在相似上下文中的词具有相近意义，因此相似关系来自数据而非人工维度。静态 embedding 每个词只有一个向量，无法充分表达多义词。

Representation Vector Type Captures Semantics Captures Context Typical Use
One-Hot Sparse No No Basic encoding
BoW / TF-IDF Sparse Weak No Classification, retrieval
Word2Vec / GloVe / FastText Dense Yes No Word similarity, feature initialization
ELMo / BERT / GPT Dense Yes Yes Modern NLP systems

Word2Vec

Word2Vec 通过局部上下文预测学习词向量。CBOW 用上下文预测中心词，Skip-gram 用中心词预测上下文；negative sampling 用少量负例近似完整 softmax。训练窗口、最小词频和负采样分布会显著影响语义与句法关系。

I love natural language processing
context = [I, love, language, processing]
center  = natural

\[ score(w, c) = v_w \cdot v_c \]

\[ P(w_t \mid w_{t-m}, ..., w_{t-1}, w_{t+1}, ..., w_{t+m}) \]

Sentence: I love natural language processing
Input context: I, love, language, processing
Target word: natural

\[ P(w_{t-m}, ..., w_{t-1}, w_{t+1}, ..., w_{t+m} \mid w_t) \]

Sentence: I love natural language processing
Input word: natural
Target context: I, love, language, processing
(natural, language)
(natural, banana)
(natural, table)
(natural, window)

\[ \log \sigma(v_w \cdot v_c) + \sum_{i=1}^{k} \log \sigma(-v_w \cdot v_{n_i}) \]

Model Input Output Strength Weakness
CBOW Context words Center word Fast, good for frequent words Weaker for rare words
Skip-gram Center word Context words Good for rare words, high-quality embeddings Slower training

GloVe

GloVe 从全局词共现矩阵学习向量，使向量点积逼近共现概率的对数。它把矩阵统计与预测式 embedding 的优点结合起来，适合分析全局语义结构，但仍受固定词表、语料偏差和单词单向量限制。

\[ X_{ij} = \text{number of times word } j \text{ appears in the context of word } i \]

\[ w_i^T \tilde{w}_j + b_i + \tilde{b}_j \approx \log(X_{ij}) \]

\[ vector(king) - vector(man) + vector(woman) \approx vector(queen) \]

代码与案例 
from collections import defaultdict
import numpy as np

sentences = [
    ["natural", "language", "processing", "is", "fun"],
    ["machine", "learning", "is", "useful"],
    ["language", "models", "learn", "representations"]
]

window_size = 2
cooccurrence = defaultdict(float)

for sentence in sentences:
    for i, word in enumerate(sentence):
        start = max(0, i - window_size)
        end = min(len(sentence), i + window_size + 1)
        for j in range(start, end):
            if i == j:
                continue
            context_word = sentence[j]
            distance = abs(i - j)
            cooccurrence[(word, context_word)] += 1.0 / distance

for pair, count in cooccurrence.items():
    print(pair, count)

# In the real GloVe algorithm, these co-occurrence counts are used
# to learn dense vectors whose dot products approximate log counts.

FastText

FastText 将词表示为字符 n-gram 向量之和，因此拼写相近或具有共同词缀的词可以共享统计信息。它能为未登录词组合向量，对形态丰富语言和拼写噪声更稳健；代价是可能过度依赖表面形式，并增加存储与计算。

<wh, whe, her, ere, re>
run, runs, running, runner
Method Main Signal Handles OOV? Static or Contextual
Word2Vec Local prediction No Static
GloVe Global co-occurrence No Static
FastText Subword + prediction Better Static

词嵌入评估

内在评估使用词相似度、类比或邻居质量，便于诊断空间结构；外在评估把 embedding 放入真实任务，观察下游收益。类比准确率不能代表所有语义能力，还可能放大训练语料中的社会偏差，因此应结合任务、语言和频率切片。

\[ \text{sim}(w_1, w_2) = \frac{v_{w_1} \cdot v_{w_2}}{||v_{w_1}|| ||v_{w_2}||} \]

similarity(cat, dog) > similarity(cat, table)

上下文化嵌入

上下文化模型根据整句或更长上下文为每个 token 生成表示，因此 bank 在不同语境中可得到不同向量。表示通常来自深层网络的隐藏状态，可用于特征抽取或端到端微调。层的选择、池化方式和子词聚合都会改变结果。

I deposited money in the bank.
The boat stopped near the river bank.

\[ \text{embedding}(word) = f(word, context) \]

Model Architecture Direction Representation Type
ELMo BiLSTM Bidirectional Contextual word embedding
BERT Transformer Encoder Bidirectional Contextual token embedding
GPT Transformer Decoder Left-to-right Contextual token embedding / generation

ELMo（基于 LSTM）

ELMo 使用双向语言模型，将前向与后向 LSTM 的多层隐藏状态组合成上下文词表示。字符级输入改善未登录词处理，层权重可按任务学习。它开启了深层上下文表示范式，但顺序计算限制并行性，长距离依赖也弱于 Transformer。

\[ w_1, ..., w_{t-1}, w_t, w_{t+1}, ..., w_n \]

BERT（基于 Transformer）

BERT 通过双向 Transformer 编码上下文，并主要使用 masked language modeling 预训练。下游任务可读取 [CLS] 表示或逐 token 隐藏状态。注意子词 token 与原词/字符边界的对齐，且 [MASK] 只在预训练阶段出现会形成训练与推断差异。

The [MASK] sat on the mat.
Input:  Natural language [MASK] is useful.
Target: processing
代码与案例 
import torch
from transformers import AutoTokenizer, AutoModel

model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModel.from_pretrained(model_name)

sentences = [
    "I deposited money in the bank.",
    "The boat stopped near the river bank."
]

inputs = tokenizer(sentences, padding=True, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)

# last_hidden_state shape: (batch_size, sequence_length, hidden_size)
token_embeddings = outputs.last_hidden_state

# A simple sentence embedding can be made by averaging token embeddings.
attention_mask = inputs["attention_mask"].unsqueeze(-1)
sentence_embeddings = (token_embeddings * attention_mask).sum(dim=1) / attention_mask.sum(dim=1)

print(sentence_embeddings.shape)

代码与案例 
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

text = "Natural language processing is"
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)

next_token_logits = outputs.logits[0, -1, :]
top_tokens = torch.topk(next_token_logits, k=5)

for token_id, score in zip(top_tokens.indices, top_tokens.values):
    print(tokenizer.decode(token_id), score.item())

总结：如何选择文本表示

小数据、检索和可解释基线优先考虑 TF-IDF/BM25；需要静态语义或低成本部署时可用 Word2Vec、GloVe、FastText；复杂理解与生成通常使用 BERT/GPT 类上下文化表示。最可靠的选择来自同一数据切分上的性能、成本和误差比较。

Goal Suitable Representation
Simple baseline classification BoW / TF-IDF
Search and ranking BM25
Word similarity or clustering Word2Vec / GloVe / FastText
Handling rare or morphologically complex words FastText
Context-sensitive understanding BERT / ELMo
Text generation GPT
