机器学习数学基础

机器学习把几何、概率、微分、信息与数值计算结合在一起。它们不是建模开始后就可以丢在一旁的独立先修课，而是从五个角度描述同一个系统：

  • 线性代数描述数据、参数、变换与几何结构；
  • 概率与统计描述不确定性、采样、估计与预测；
  • 微积分描述敏感性以及参数应如何变化；
  • 信息论度量不确定性与概率分布之间的分歧；
  • 数值计算决定一个代数上正确的方法能否可靠、高效地计算。

本章是面向 ML 的桥梁，而不是对 Linear Algebra、Single-Variable Calculus 和 Statistics 专题笔记的替代。目标是让模型公式变得可读。面对每个数学对象，都应询问：它的形状是什么？表示什么？操作成立需要哪些假设？几何或概率意义发生了什么变化？它还会在哪个学习算法中出现？

本章有意采用小型数值实验。当我们可以核对公式形状、测量几何条件，并把解析梯度与有限差分比较时，公式会更容易理解和信任。

记号与形状

数学记号压缩了大量结构信息。在机器学习中，形状错误常常就是概念错误：样本和特征被颠倒、批次维消失，或标量总损失与逐样本损失向量混淆。

标量、向量、矩阵与张量

标量（scalar）是一个数，例如学习率 \(\eta\)、损失 \(L\) 或正则化强度 \(\lambda\)。向量（vector）是有序数列，例如一个特征向量 \(x\in\mathbb{R}^{d}\) 或参数向量 \(w\in\mathbb{R}^{d}\)。矩阵（matrix）有两个轴，例如数据矩阵 \(X\in\mathbb{R}^{n\times d}\)。张量（tensor）把这一思想推广到更多轴：图像批次的形状可以是 (batch, height, width, channels)，序列批次可以是 (batch, time, embedding)。

下标选择分量。\(x_i\) 表示向量第 \(i\) 项，\(X_{ij}\) 表示矩阵第 \(i\) 行第 \(j\) 列。上标要结合上下文解释：\(x^{(i)}\) 常表示第 \(i\) 个样本，而 \(X^\top\) 表示转置。转置交换两个轴，因此若 \(X\in\mathbb{R}^{n\times d}\)，则 \(X^\top\in\mathbb{R}^{d\times n}\)。

利用形状推理，矩阵乘法几乎可以机械完成。若

\[ A\in\mathbb{R}^{m\times n}, \qquad B\in\mathbb{R}^{n\times p}, \]

则内侧维度 \(n\) 匹配，结果 \(AB\in\mathbb{R}^{m\times p}\)。元素 \((AB)_{ij}\) 是 \(A\) 第 \(i\) 行与 \(B\) 第 \(j\) 列的内积。逐元素乘法不同，它组合对齐位置，通常要求形状相同或可广播。

广播（broadcasting）是一种编程约定，它在概念上把小数组沿大数组重复。把偏置 \(b\in\mathbb{R}^{k}\) 加到一批分数 \(S\in\mathbb{R}^{n\times k}\)，就是对每行加入同一个 \(k\) 维偏置。广播很方便，但意外广播也可能悄悄产生看似合理的错误结果。

数据集与设计矩阵

监督学习数据集记为

\[ \mathcal{D}=\{(x^{(i)},y^{(i)})\}_{i=1}^{n}. \]

把各样本行向量堆叠得到设计矩阵

\[ X= \begin{bmatrix} (x^{(1)})^\top\\ \vdots\\ (x^{(n)})^\top \end{bmatrix} \in\mathbb{R}^{n\times d}. \]

其中 \(n\) 是样本数，\(d\) 是特征数。标量回归中 \(y\in\mathbb{R}^{n}\)；\(k\) 类 one-hot 标签中 \(Y\in\{0,1\}^{n\times k}\)。线性预测器计算 (Xw+b)，其中 \(w\in\mathbb{R}^{d}\)、\(Xw\in\mathbb{R}^{n}\)，标量 \(b\) 会广播到每个样本。

有些教材把样本存为列。两种约定没有天然优劣，但每份推导和代码都必须内部一致。本博客在没有特别说明时使用“样本为行”的约定。

Python 示例：检查形状并验证批量线性模型 
import numpy as np

# Four samples, each described by three features.
X = np.array(
    [
        [1.0, 0.2, 3.0],
        [1.0, 1.1, 2.0],
        [1.0, 2.4, 0.5],
        [1.0, 3.2, 1.3],
    ]
)
w = np.array([0.5, -1.0, 0.8])
b = 0.25

# (4 x 3) @ (3,) -> (4,), then the scalar bias is broadcast.
scores = X @ w + b

assert X.shape[1] == w.shape[0]
assert scores.shape == (X.shape[0],)

print("X shape:", X.shape)
print("w shape:", w.shape)
print("scores shape:", scores.shape)
print("scores:", scores.round(3))

模型与数据中的线性代数

线性代数既是表示语言，也是几何语言。矩阵可以被看作存储的数字、特征方向集合、变换向量的函数，或相关性揭示低维结构的数据集。不同模型会使用不同解释。

向量空间、基与投影

向量空间（vector space）是对向量加法和标量乘法封闭的集合。向量 \(v_1,\ldots,v_k\) 的张成空间（span）是其所有线性组合：

\[ \operatorname{span}(v_1,\ldots,v_k) =\left\{\sum_{j=1}^{k}a_jv_j:a_j\in\mathbb{R}\right\}. \]

基（basis）是能够张成空间的线性无关集合，它提供坐标。同一个几何向量在不同基下有不同数值坐标。特征可视为坐标方向，学习表示则可理解为更换基，使重要变化更容易分离或压缩。

正交投影寻找子空间中距离给定点最近的点。若 \(Q\) 的列正交归一，则 \(b\) 到 \(\operatorname{Col}(Q)\) 的投影为 \(QQ^\top b\)。对于满列秩矩阵 \(A\)，投影矩阵为

\[ P=A(A^\top A)^{-1}A^\top. \]

最小二乘选择 \(\hat{x}\)，使 \(p=A\hat{x}\) 是最接近 \(b\) 的预测：

\[ \hat{x}=\arg\min_x\|b-Ax\|_2^2. \]

在最优点，残差 \(e=b-A\hat{x}\) 与 \(A\) 的每一列正交，得到正规方程 \(A^\top A\hat{x}=A^\top b\)。几何上，这表示沿任何模型特征方向移动，都无法继续减小残差。

概念参考：MIT OpenCourseWare, Projection Matrices and Least Squares。

Python 示例：验证最小二乘的几何性质 
import numpy as np

# Fit a line b approximately equal to intercept + slope * t.
t = np.array([0.0, 1.0, 2.0, 3.0, 4.0])
A = np.column_stack([np.ones_like(t), t])
b = np.array([1.1, 2.0, 2.9, 4.2, 4.8])

# lstsq uses a stable factorization rather than explicitly inverting A.T @ A.
x_hat, squared_residuals, rank, singular_values = np.linalg.lstsq(A, b, rcond=None)
projection = A @ x_hat
residual = b - projection

print("[intercept, slope]:", x_hat.round(4))
print("fitted values:", projection.round(4))
print("residual:", residual.round(4))
print("A.T @ residual:", (A.T @ residual).round(12))
print("rank:", rank, "singular values:", singular_values.round(4))

范数、内积与距离

内积衡量方向对齐程度。在欧氏空间中，\(x^\top z=\sum_jx_jz_j\)。它通过 \(\|x\|_2=\sqrt{x^\top x}\) 定义长度，并通过

\[ \cos\theta=\frac{x^\top z}{\|x\|_2\|z\|_2} \]

定义夹角。范数衡量向量大小，一般 \(p\)-范数为

\[ \|x\|_p=\left(\sum_{j=1}^{d}|x_j|^p\right)^{1/p}. \]

重要情形包括 \(\|x\|_1=\sum_j|x_j|\)、欧氏 \(\|x\|_2\) 和 \(\|x\|_\infty=\max_j|x_j|\)。距离通常是差向量的范数，即 \(d(x,z)=\|x-z\|\)，第 02 章已介绍。

范数选择也定义正则化几何。L2 惩罚平滑地抑制大系数，并倾向于在相关特征之间分配权重；L1 约束区域具有尖角，更容易产生精确零系数。因此，范数不只说明如何计算长度，也说明什么样的参数向量算“小”。

Python 示例：比较范数、方向对齐与尺度 
import numpy as np

x = np.array([3.0, -4.0, 0.5])
z = np.array([1.0, -1.0, 2.0])

l1 = np.linalg.norm(x, ord=1)
l2 = np.linalg.norm(x, ord=2)
linf = np.linalg.norm(x, ord=np.inf)
cosine = (x @ z) / (np.linalg.norm(x) * np.linalg.norm(z))

print("L1 norm:", round(l1, 3))
print("L2 norm:", round(l2, 3))
print("L-infinity norm:", round(linf, 3))
print("dot product:", round(x @ z, 3))
print("cosine similarity:", round(cosine, 3))

秩、逆与伪逆

矩阵的秩（rank）是线性无关行或列的数量。设计矩阵低秩表示某些特征方向可由其他方向构造，参数可能不可识别：多个系数向量会产生相同预测。

方阵 \(A\in\mathbb{R}^{d\times d}\) 只有满秩时才有逆，且 \(A^{-1}A=AA^{-1}=I\)。学习代码中显式构造逆通常不如 solve、lstsq、QR 或 SVD 求解线性系统稳定、高效。

Moore-Penrose 伪逆 \(A^+\) 把求逆推广到矩形或秩亏矩阵，给出最小二乘解 \(x=A^+b\)；存在多个等价解时，它返回 L2 范数最小的解。伪逆不会让缺失信息重新出现，小奇异值仍会使估计对噪声高度敏感。

Python 示例：用伪逆求解秩亏系统 
import numpy as np

# Column 2 is exactly twice column 1, so the matrix has rank 1 rather than 2.
A = np.array([[1.0, 2.0], [2.0, 4.0], [3.0, 6.0]])
b = np.array([1.0, 2.0, 3.0])

print("rank:", np.linalg.matrix_rank(A))

try:
    normal_equation_solution = np.linalg.solve(A.T @ A, A.T @ b)
except np.linalg.LinAlgError as error:
    print("normal equations fail:", error)

minimum_norm_solution = np.linalg.pinv(A) @ b
print("pseudoinverse solution:", minimum_norm_solution.round(4))
print("prediction:", (A @ minimum_norm_solution).round(4))
print("residual norm:", round(np.linalg.norm(b - A @ minimum_norm_solution), 12))

特征值与特征分解

对方阵 \(A\)，若非零向量 \(v\) 满足

\[ Av=\lambda v, \]

则它是特征向量。变换仅按特征值 \(\lambda\) 改变 \(v\) 的大小，不改变方向，至多发生符号反转。实对称矩阵具有正交归一特征向量和实特征值，可分解为 \(A=Q\Lambda Q^\top\)。

协方差矩阵和 Hessian 都是对称矩阵。协方差矩阵的特征向量给出正交变化方向，特征值表示沿该方向的方差；Hessian 的特征值描述局部曲率：较大正值代表陡峭方向，较小值代表平坦方向，负值表示从鞍点继续下降的方向。

若对所有 \(x\) 都有 \(x^\top A x\geq0\)，矩阵为半正定；对称矩阵中这等价于所有特征值非负。协方差矩阵必为半正定，因为方差不可能为负。

Python 示例：从协方差矩阵恢复主方差方向 
import numpy as np

rng = np.random.default_rng(5)
base = rng.normal(size=500)
X = np.column_stack(
    [
        2.0 * base + rng.normal(scale=0.3, size=500),
        0.8 * base + rng.normal(scale=0.2, size=500),
    ]
)
X_centered = X - X.mean(axis=0)
covariance = np.cov(X_centered, rowvar=False)

# eigh is specialized for symmetric matrices and returns ascending eigenvalues.
eigenvalues, eigenvectors = np.linalg.eigh(covariance)
order = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[order]
eigenvectors = eigenvectors[:, order]

first_direction = eigenvectors[:, 0]
projected_variance = np.var(X_centered @ first_direction, ddof=1)

print("covariance:\n", covariance.round(3))
print("eigenvalues:", eigenvalues.round(3))
print("first eigenvector:", first_direction.round(3))
print("variance along it:", round(projected_variance, 3))

奇异值分解

特征分解适用于方阵，对对称方阵尤其良好。奇异值分解适用于任意 \(A\in\mathbb{R}^{m\times n}\)：

\[ A=U\Sigma V^\top. \]

秩为 \(r\) 的紧致 SVD 中，\(U\in\mathbb{R}^{m\times r}\) 包含正交归一输出方向，\(V\in\mathbb{R}^{n\times r}\) 包含正交归一输入方向，对角矩阵 \(\Sigma\in\mathbb{R}^{r\times r}\) 包含奇异值 \(\sigma_1\geq\cdots\geq\sigma_r>0\)。\(V^\top\) 把输入换到奇异向量坐标，\(\Sigma\) 缩放各方向，\(U\) 再把结果放入输出空间。

概念参考：MIT OpenCourseWare, Singular Value Decomposition。

保留最大的 \(k\) 个奇异值可得

\[ A_k=\sum_{j=1}^{k}\sigma_j u_jv_j^\top, \]

它在 Frobenius 范数和谱范数下都是最佳秩-\(k\) 近似。这一性质支撑 PCA、潜在语义分析、矩阵补全、去噪、压缩和低秩参数化。把每个非零 \(\sigma_j\) 换成 \(1/\sigma_j\) 即得伪逆，因此极小奇异值会放大噪声。

分解 矩阵要求 主要 ML 解释
特征分解 \(A=Q\Lambda Q^{-1}\) 方阵且可对角化；对称 \(A\) 最简单 不变方向、协方差方差、Hessian 曲率
SVD \(A=U\Sigma V^\top\) 任意矩形矩阵 输入/输出方向、秩、压缩、稳定最小二乘
Python 示例：度量低秩 SVD 重构误差 
import numpy as np

rng = np.random.default_rng(9)

# Construct a matrix with two strong latent factors plus small noise.
left_factors = rng.normal(size=(40, 2))
right_factors = rng.normal(size=(2, 20))
A = left_factors @ right_factors + 0.08 * rng.normal(size=(40, 20))

U, singular_values, Vt = np.linalg.svd(A, full_matrices=False)
original_norm = np.linalg.norm(A, ord="fro")

for rank_k in [1, 2, 5, 10]:
    approximation = (
        U[:, :rank_k]
        @ np.diag(singular_values[:rank_k])
        @ Vt[:rank_k, :]
    )
    relative_error = np.linalg.norm(A - approximation, ord="fro") / original_norm
    print(f"rank {rank_k:2d} relative error: {relative_error:.4f}")

print("leading singular values:", singular_values[:6].round(3))

概率与统计

概率为不确定结果规定模型，统计则从观测样本反推产生数据的过程或参数。在 ML 中，分类器可以输出条件分布，损失可以是负对数似然，而有限数据上计算的评估结果本身也具有不确定性。

随机变量与常见分布

随机变量 \(X\) 把结果映射为数值。离散变量具有概率质量函数 \(p(x)=P(X=x)\)；连续变量具有密度 \(p(x)\)，区间概率由积分得到，单点处密度本身不是概率。

分布 支持集与参数 常见 ML 作用
Bernoulli \(x\in\{0,1\}\)，成功概率 \(p\) 二元标签、二元似然
Categorical \(K\) 类之一，概率向量 \(\pi\) 多分类预测
Binomial \(n\) 次 Bernoulli 试验中的成功次数 聚合事件计数
Gaussian \(x\in\mathbb{R}\)，均值 \(\mu\)、方差 \(\sigma^2\) 残差模型、潜变量、近似
Poisson 非负计数，率 \(\lambda\) 单位暴露区间中的事件数
Exponential 正等待时间，率 \(\lambda\) 无记忆事件之间的时间
Beta \(p\in(0,1)\)，形状 \(\alpha,\beta\) 概率的先验或不确定性

分布是对支持集、形状和变异性的假设。为正值且强偏斜的计数选择 Gaussian 似然并不是无害记号，它规定了模型认为哪些误差合理。

Python 示例：比较经验矩与分布参数 
import numpy as np

rng = np.random.default_rng(11)
sample_size = 100_000

bernoulli = rng.binomial(n=1, p=0.3, size=sample_size)
poisson = rng.poisson(lam=4.0, size=sample_size)
gaussian = rng.normal(loc=2.0, scale=1.5, size=sample_size)

cases = {
    "Bernoulli(p=0.3)": (bernoulli, 0.3, 0.3 * 0.7),
    "Poisson(lambda=4)": (poisson, 4.0, 4.0),
    "Gaussian(mu=2, sd=1.5)": (gaussian, 2.0, 1.5 ** 2),
}

for name, (sample, theoretical_mean, theoretical_variance) in cases.items():
    print(
        name,
        {
            "sample_mean": round(sample.mean(), 3),
            "theoretical_mean": theoretical_mean,
            "sample_variance": round(sample.var(), 3),
            "theoretical_variance": theoretical_variance,
        },
    )

联合、边缘与条件概率

联合分布 \(p(x,y)\) 同时描述两个变量。边缘化通过求和或积分移除变量：

\[ p(x)=\sum_y p(x,y). \]

条件分布把样本空间限制在 \(Y=y\) 的情形：

\[ p(x\mid y)=\frac{p(x,y)}{p(y)}, \qquad p(y)>0. \]

乘法规则重新排列该定义：

\[ p(x,y)=p(x\mid y)p(y)=p(y\mid x)p(x). \]

边缘化组合竞争解释，条件化更新相关样本空间。在监督学习中，经验数据集近似联合过程 \(p(x,y)\)，判别模型则直接学习 \(p(y\mid x)\) 或由它导出的决策。

Python 示例：从联合表推导边缘与条件概率 
import numpy as np

# Rows: weather {dry, rain}; columns: transport {walk, bus}.
joint = np.array(
    [
        [0.42, 0.18],
        [0.08, 0.32],
    ]
)

p_weather = joint.sum(axis=1)
p_transport = joint.sum(axis=0)
p_bus_given_rain = joint[1, 1] / p_weather[1]
p_rain_given_bus = joint[1, 1] / p_transport[1]

print("P(weather):", p_weather)
print("P(transport):", p_transport)
print("P(bus | rain):", round(p_bus_given_rain, 3))
print("P(rain | bus):", round(p_rain_given_bus, 3))
print("Conditionals are different because their denominators differ.")

期望、方差与协方差

期望是按概率加权的平均。对离散变量，

\[ \mathbb{E}[X]=\sum_x x\,p(x). \]

它描述分布，不一定是实际可能出现的值。即使变量相关，期望仍具有线性性：\(\mathbb{E}[aX+bY]=a\mathbb{E}[X]+b\mathbb{E}[Y]\)。

方差衡量对均值的平方偏离：

\[ \operatorname{Var}(X)=\mathbb{E}[(X-\mathbb{E}[X])^2]. \]

协方差衡量两个变量是否共同变化：

\[ \operatorname{Cov}(X,Y)=\mathbb{E}[(X-\mu_X)(Y-\mu_Y)]. \]

正协方差表示偏离方向一致，负协方差表示相反，零协方差表示没有线性关联。零协方差通常不意味着独立。相关系数用标准差归一化协方差，消除了单位，却仍然只捕捉特定形式的关联。

对于随机向量 \(X\in\mathbb{R}^d\)，协方差矩阵 \(\Sigma\in\mathbb{R}^{d\times d}\) 存储全部成对协方差，对角线是方差，并决定多元 Gaussian 的椭圆几何。

Python 示例：区分协方差、相关与独立 
import numpy as np

rng = np.random.default_rng(13)
x = rng.normal(size=20_000)
y_linear = 2.0 * x + rng.normal(scale=0.5, size=x.size)
y_nonlinear = x ** 2

linear_covariance = np.cov(x, y_linear, ddof=1)[0, 1]
linear_correlation = np.corrcoef(x, y_linear)[0, 1]
nonlinear_correlation = np.corrcoef(x, y_nonlinear)[0, 1]

print("Cov(x, 2x + noise):", round(linear_covariance, 3))
print("Corr(x, 2x + noise):", round(linear_correlation, 3))
print("Corr(x, x^2):", round(nonlinear_correlation, 3))
print("x and x^2 are dependent even though their linear correlation is near zero.")

Bayes 规则与条件独立

Bayes 规则反转条件概率：

\[ p(\theta\mid D)=\frac{p(D\mid\theta)p(\theta)}{p(D)}. \]

先验 \(p(\theta)\) 描述观察数据 \(D\) 之前的信念或频率；似然 \(p(D\mid\theta)\) 衡量数据与候选参数的相容程度；证据 \(p(D)=\int p(D\mid\theta)p(\theta)d\theta\) 对所有候选解释归一化；后验 \(p(\theta\mid D)\) 是更新后的分布。

若没有归一化，似然并不是 \(\theta\) 上的概率分布。这一区别很重要：\(p(\text{positive}\mid\text{disease})\) 是检测灵敏度，而临床真正关心的 \(p(\text{disease}\mid\text{positive})\) 是后验，并强烈依赖患病率。

概念参考：MIT OpenCourseWare, Conditional Probability, Independence, and Bayes’ Theorem。

给定 \(Z\) 后，若

\[ p(x,y\mid z)=p(x\mid z)p(y\mid z), \]

则 \(X\) 与 \(Y\) 条件独立。条件独立比无条件独立更弱，也更实用。Naive Bayes 假设给定类别后各特征条件独立；图模型编码大量这类假设，以分解大型联合分布。

Python 示例：用 Bayes 规则计算罕见事件后验 
prior = 0.01
sensitivity = 0.90
false_positive_rate = 0.05

# Total probability of a positive result under both possible states.
p_positive = (
    sensitivity * prior
    + false_positive_rate * (1.0 - prior)
)
posterior = sensitivity * prior / p_positive

print("P(positive):", round(p_positive, 4))
print("P(condition | positive):", round(posterior, 4))
print("Posterior percentage:", f"{100 * posterior:.1f}%")

采样与估计

总体量 \(\mu\) 是参数；样本均值 \(\bar{X}\) 等统计量是随机变量，因为它会随样本改变。估计器（estimator）是把数据映射为估计值的规则。偏差询问其期望估计是否等于目标；方差询问估计在不同样本间变化多少；一致性询问样本量增大时估计是否趋近目标。

最大似然估计选择使 \(p(D\mid\theta)\) 最大的参数，通常通过最小化负对数似然实现。最大后验估计最大化 \(p(D\mid\theta)p(\theta)\)，从而把先验与正则化连接起来。除非同时给出区间、后验分布、bootstrap 变化或重复切分分析，否则这些点估计会隐藏不确定性。

大数定律解释样本平均为何逐渐稳定。中心极限定理说明在适当条件下，即使原观测偏斜，许多标准化样本均值也会近似 Gaussian。它并不表示原始数据变成 Gaussian，也不能在不检查假设时自动挽救相关或重尾采样。

Python 示例：观察偏斜总体均值的采样分布 
import numpy as np

rng = np.random.default_rng(17)
repetitions = 20_000

def skewness(values):
    centered = values - values.mean()
    return np.mean(centered ** 3) / np.mean(centered ** 2) ** 1.5

for sample_size in [1, 5, 30, 100]:
    # Each row is one repeated sample from an exponential population.
    samples = rng.exponential(scale=1.0, size=(repetitions, sample_size))
    sample_means = samples.mean(axis=1)
    print(
        f"n={sample_size:3d}",
        "mean=", round(sample_means.mean(), 3),
        "std=", round(sample_means.std(), 3),
        "skew=", round(skewness(sample_means), 3),
    )

微积分与矩阵微积分

训练需要回答：当成千上万乃至数十亿参数改变时，一个标量目标如何变化？微积分提供局部敏感性，矩阵微积分则组织这些敏感性，而无需展开每个坐标。

偏导数与梯度

对于 \(f:\mathbb{R}^d\rightarrow\mathbb{R}\)，偏导数 \(\partial f/\partial x_j\) 在其他坐标固定时改变第 \(j\) 个坐标。梯度堆叠所有偏导数：

\[ \nabla f(x)= \begin{bmatrix} \frac{\partial f}{\partial x_1}&\cdots&\frac{\partial f}{\partial x_d} \end{bmatrix}^{\!\top}. \]

沿单位向量 \(u\) 的方向导数为 \(u^\top\nabla f(x)\)。在欧氏距离下，梯度指向局部增长最快方向，因此 \(-\nabla f\) 是局部下降最快方向。

对均方误差

\[ L(w)=\frac{1}{n}\|Xw-y\|_2^2, \]

残差 \(Xw-y\in\mathbb{R}^n\)，梯度为

\[ \nabla_wL=\frac{2}{n}X^\top(Xw-y)\in\mathbb{R}^d. \]

形状解释了计算：\(X^\top\in\mathbb{R}^{d\times n}\) 把逐样本残差信号聚合回每个特征权重的一项梯度。

Python 示例：用有限差分检查矩阵微积分梯度 
import numpy as np

X = np.array([[1.0, 0.2], [1.0, 1.3], [1.0, 2.1], [1.0, 3.0]])
y = np.array([1.0, 2.2, 2.8, 4.1])
w = np.array([0.4, 0.9])

def mse(parameters):
    residual = X @ parameters - y
    return np.mean(residual ** 2)

analytic_gradient = (2.0 / len(y)) * X.T @ (X @ w - y)

epsilon = 1e-6
numeric_gradient = np.zeros_like(w)
for index in range(len(w)):
    step = np.zeros_like(w)
    step[index] = epsilon
    numeric_gradient[index] = (mse(w + step) - mse(w - step)) / (2 * epsilon)

print("analytic gradient:", analytic_gradient.round(8))
print("numeric gradient: ", numeric_gradient.round(8))
print("maximum difference:", np.max(np.abs(analytic_gradient - numeric_gradient)))

Jacobian 与 Hessian

若 \(f:\mathbb{R}^d\rightarrow\mathbb{R}^m\) 输出向量，Jacobian \(J\in\mathbb{R}^{m\times d}\) 存储每个输出—输入导数：

\[ J_{ij}=\frac{\partial f_i}{\partial x_j}. \]

每一行描述一个输出如何变化，每一列描述所有输出如何响应一个输入。深度学习库通常不会实体化完整 Jacobian，而是在反向模式自动微分中计算向量—Jacobian 乘积。

对于标量 \(f\)，Hessian 是梯度的 Jacobian：

\[ H_{ij}=\frac{\partial^2f}{\partial x_i\partial x_j}. \]

它描述局部曲率和参数交互。Newton 方法用 \(H^{-1}\nabla f\) 按曲率缩放更新，但完整 Hessian 昂贵且可能不定；quasi-Newton 与 Hessian—向量方法近似所需曲率信息。

Python 示例：通过形状检查 Jacobian 与 Hessian 
import numpy as np

x1, x2 = 2.0, -1.0

# f(x1, x2) = [x1*x2, x1^2 + sin(x2)] has a 2 x 2 Jacobian.
jacobian = np.array(
    [
        [x2, x1],
        [2.0 * x1, np.cos(x2)],
    ]
)

# g(x) = 0.5*x^T H x + c^T x has constant Hessian H.
hessian = np.array([[4.0, 1.0], [1.0, 2.0]])
curvatures = np.linalg.eigvalsh(hessian)

print("Jacobian shape:", jacobian.shape)
print(jacobian.round(3))
print("\nHessian:\n", hessian)
print("Hessian eigenvalues:", curvatures.round(3))
print("Positive eigenvalues mean this quadratic is strictly convex.")

链式法则

模型是函数复合。若 \(q=g(x)\)、\(L=f(q)\)，标量链式法则为

\[ \frac{dL}{dx}=\frac{dL}{dq}\frac{dq}{dx}. \]

第一个因子是最终损失对中间值的上游敏感性，第二个因子是中间值对输入的局部敏感性。反向传播从输出向输入应用这条规则，并复用前向计算缓存的值。

来源：Stanford CS231n, Backpropagation and the Chain Rule。

向量函数通过 Jacobian 复合。许多参数共同产生一个标量损失时，反向模式自动微分尤其高效，因为它传播向量—Jacobian 乘积而不构造完整 Jacobian。若计算图出现分支，梯度贡献需要相加，因为共享变量会通过每条出边影响损失。

Python 示例：手工完成标量前向与反向传播 
# Function: f = (x + y) * z
x, y, z = -2.0, 5.0, -4.0

# Forward pass caches the intermediate q.
q = x + y
f = q * z

# Backward pass starts with df/df = 1 and applies local derivatives.
df = 1.0
dq = z * df       # df/dq = z
dz = q * df       # df/dz = q
dx = 1.0 * dq     # dq/dx = 1
dy = 1.0 * dq     # dq/dy = 1

print("forward: q =", q, "f =", f)
print("gradients: df/dx =", dx, "df/dy =", dy, "df/dz =", dz)

Taylor 近似

Taylor 展开在 \(x\) 附近近似光滑函数。对于小位移 \(\Delta\)，

\[ f(x+\Delta)\approx f(x)+\nabla f(x)^\top\Delta +\frac{1}{2}\Delta^\top H(x)\Delta. \]

一阶项根据斜率预测变化，二阶项校正曲率。梯度下降依赖局部线性模型与足够小的步长，Newton 方法使用二次模型。过大的更新会离开近似有效区域，因此学习率和信赖域控制很重要。

Python 示例：比较一阶与二阶 Taylor 近似 
import numpy as np

# Approximate exp(x) around x0 = 0, where f = f' = f'' = 1.
def first_order(delta):
    return 1.0 + delta

def second_order(delta):
    return 1.0 + delta + 0.5 * delta ** 2

for delta in [0.05, 0.5, 1.0]:
    exact = np.exp(delta)
    linear_error = abs(exact - first_order(delta))
    quadratic_error = abs(exact - second_order(delta))
    print(
        f"delta={delta:.2f}",
        f"exact={exact:.5f}",
        f"first_error={linear_error:.5f}",
        f"second_error={quadratic_error:.5f}",
    )

信息论

信息论定量处理不确定性与分布不匹配。在 ML 中，它出现在决策树分裂、分类损失、变分推断、表示学习、语言建模和特征选择中。

熵与交叉熵

对离散分布 \(p=(p_1,\ldots,p_K)\)，熵为

\[ H(p)=-\sum_{k=1}^{K}p_k\log p_k. \]

每个 \(p_k\) 是结果概率，约定 \(0\log0=0\) 来自连续极限。自然对数以 nat 度量熵，以 2 为底则用 bit。某一结果几乎确定时熵低，均匀分布时熵最大。

来源：Google for Developers, Exact Splitter for Binary Classification。

当真实结果服从 \(p\)，而预测概率为 \(q\) 时，交叉熵为

\[ H(p,q)=-\sum_{k=1}^{K}p_k\log q_k. \]

对于真实类别为 \(c\) 的 one-hot 目标，除 \(-\log q_c\) 外所有项都为零。给观测类别很低概率会产生大损失，给零概率则损失无穷。因此交叉熵不仅看 top class 是否正确，也惩罚置信度。

Python 示例：检查二元熵与 one-hot 交叉熵 
import numpy as np

def binary_entropy(p):
    probabilities = np.array([p, 1.0 - p], dtype=float)
    positive = probabilities > 0
    return -np.sum(probabilities[positive] * np.log2(probabilities[positive]))

for p in [0.0, 0.1, 0.25, 0.5, 0.9, 1.0]:
    print(f"p={p:.2f}, entropy={binary_entropy(p):.3f} bits")

true_class = 2
predicted = np.array([0.05, 0.15, 0.70, 0.10])
cross_entropy = -np.log(predicted[true_class])
print("\nOne-hot cross-entropy:", round(cross_entropy, 4), "nats")

KL 散度

Kullback-Leibler 散度衡量用 \(q\) 表示 \(p\) 时增加的对数损失：

\[ D_{\mathrm{KL}}(p\|q)=\sum_k p_k\log\frac{p_k}{q_k}. \]

它满足 \(D_{\mathrm{KL}}(p\|q)\geq0\)，且仅当分布几乎处处一致时为零。它不是距离：通常 \(D_{\mathrm{KL}}(p\|q)\neq D_{\mathrm{KL}}(q\|p)\)，也不满足三角不等式。若某处 \(p_k>0\) 而 \(q_k=0\)，散度为无穷。

交叉熵可分解为

\[ H(p,q)=H(p)+D_{\mathrm{KL}}(p\|q). \]

目标分布 \(p\) 固定时，对 \(q\) 最小化交叉熵也会最小化 KL 散度。其不对称性在变分推断中很重要：不同 KL 方向对遗漏模态和覆盖低密度区域的惩罚不同。

Python 示例：验证交叉熵等于熵加 KL 散度 
import numpy as np

p = np.array([0.60, 0.30, 0.10])
q = np.array([0.45, 0.45, 0.10])

entropy_p = -np.sum(p * np.log(p))
cross_entropy_pq = -np.sum(p * np.log(q))
kl_pq = np.sum(p * np.log(p / q))
kl_qp = np.sum(q * np.log(q / p))

print("H(p):", round(entropy_p, 6))
print("H(p, q):", round(cross_entropy_pq, 6))
print("KL(p || q):", round(kl_pq, 6))
print("H(p) + KL(p || q):", round(entropy_p + kl_pq, 6))
print("KL(q || p):", round(kl_qp, 6), "(different direction)")

互信息

互信息衡量联合分布偏离独立性的程度：

\[ I(X;Y)=D_{\mathrm{KL}}\big(p(x,y)\|p(x)p(y)\big) =\sum_{x,y}p(x,y)\log\frac{p(x,y)}{p(x)p(y)}. \]

当且仅当 \(X\) 与 \(Y\) 独立时为零；虽然由 KL 构造，它本身对称。等价恒等式 \(I(X;Y)=H(X)-H(X\mid Y)\) 表示观察 \(Y\) 后，关于 \(X\) 的不确定性平均减少多少。

互信息能够检测非线性依赖，并支持过滤式特征选择、决策树信息增益和表示学习目标。但从有限连续数据估计它很困难，分箱、密度估计或神经估计器都会引入偏差和调参选择。

Python 示例：比较独立变量与相关变量的互信息 
import numpy as np

def mutual_information(joint):
    joint = np.asarray(joint, dtype=float)
    joint = joint / joint.sum()
    p_x = joint.sum(axis=1, keepdims=True)
    p_y = joint.sum(axis=0, keepdims=True)
    independent_reference = p_x @ p_y
    mask = joint > 0
    return np.sum(joint[mask] * np.log2(joint[mask] / independent_reference[mask]))

independent = np.array([[0.25, 0.25], [0.25, 0.25]])
associated = np.array([[0.45, 0.05], [0.05, 0.45]])

print("Independent MI:", round(mutual_information(independent), 6), "bits")
print("Associated MI:", round(mutual_information(associated), 6), "bits")

数值计算

真实计算机使用有限精度。代数等价不保证数值行为相同，算法复杂度也决定一个正确方法能否扩展到实际规模。

条件性与浮点误差

浮点数只近似有限个实数。舍入误差通常很小，但病态问题会放大它。对满秩矩阵，2-范数条件数为

\[ \kappa_2(A)=\frac{\sigma_{\max}(A)}{\sigma_{\min}(A)}. \]

条件数接近一表示各方向缩放相近；很大则表示至少一个方向几乎被压扁，小输入扰动可能造成大解变化。条件性是问题本身的属性，数值稳定性则是求解算法的属性。

最小二乘中构造 \(X^\top X\) 会把条件数平方，因此通常优先使用 QR 或 SVD 求解器。其他常见风险包括相减消去、除以极小值、指数溢出、概率连乘下溢和显式矩阵求逆。

Python 示例：观察病态线性系统的敏感性 
import numpy as np

size = 10
row = np.arange(size)[:, None]
column = np.arange(size)[None, :]
hilbert = 1.0 / (row + column + 1.0)

true_solution = np.ones(size)
b = hilbert @ true_solution

# Apply a tiny relative perturbation to the observed right-hand side.
perturbation = np.zeros_like(b)
perturbation[-1] = 1e-10
estimated = np.linalg.solve(hilbert, b + perturbation)

relative_input_change = np.linalg.norm(perturbation) / np.linalg.norm(b)
relative_solution_change = np.linalg.norm(estimated - true_solution) / np.linalg.norm(true_solution)

print("condition number:", f"{np.linalg.cond(hilbert):.3e}")
print("relative input change:", f"{relative_input_change:.3e}")
print("relative solution change:", f"{relative_solution_change:.3e}")

Log-Sum-Exp 与稳定概率计算

概率模型经常连乘许多小概率。转到对数空间会把乘法变成加法，防止下溢。另一条关键恒等式是

\[ \log\sum_i e^{z_i} =m+\log\sum_i e^{z_i-m}, \qquad m=\max_i z_i. \]

减去 \(m\) 后，每个指数都不为正，最大指数值为一。同样的平移也能稳定 softmax，因为给所有 logit 加同一个常数会在分子分母中抵消。

数值原理参考：SciPy logsumexp documentation。

在临时代码中裁剪概率可以防止 log(0)，却会改变目标。log-sum-exp、log_softmax 和库中的交叉熵实现能更忠实地保留原数学定义。

Python 示例：比较朴素与稳定 softmax 
import numpy as np

logits = np.array([1000.0, 1001.0, 1002.0])

with np.errstate(over="ignore", invalid="ignore"):
    raw_exponentials = np.exp(logits)
    naive_softmax = raw_exponentials / raw_exponentials.sum()

shifted = logits - logits.max()
stable_exponentials = np.exp(shifted)
stable_softmax = stable_exponentials / stable_exponentials.sum()
stable_logsumexp = logits.max() + np.log(stable_exponentials.sum())

print("naive exponentials:", raw_exponentials)
print("naive softmax:", naive_softmax)
print("stable softmax:", stable_softmax.round(6))
print("stable log-sum-exp:", round(stable_logsumexp, 6))

向量化与计算复杂度

向量化把大量标量操作表示成数组操作，让优化数值库在编译循环、SIMD 指令和并行硬件上执行。对批次 \(X\in\mathbb{R}^{n\times d}\) 和权重 \(W\in\mathbb{R}^{d\times k}\)，计算 (XW) 的复杂度约为 \(O(ndk)\)。Big-O 忽略常数，却揭示增长由哪些维度主导。

向量化不会消除计算成本。为 \(n\) 个样本实体化完整成对距离矩阵需要 \(O(n^2)\) 内存，常成为真正瓶颈。批处理、稀疏矩阵、低秩结构、迭代求解器和近似最近邻，以精确度或数据遍历次数换取可管理的内存与时间。

平方欧氏距离恒等式

\[ \|x_i-z_j\|_2^2=\|x_i\|_2^2+\|z_j\|_2^2-2x_i^\top z_j \]

把嵌套坐标循环转换为矩阵乘法，但最终 \(n\times m\) 结果仍然占据内存。

Python 示例：向量化成对平方距离并验证结果 
import numpy as np

rng = np.random.default_rng(23)
X = rng.normal(size=(5, 3))
Z = rng.normal(size=(4, 3))

# Broadcasting plus matrix multiplication computes every pair at once.
x_squared = np.sum(X ** 2, axis=1, keepdims=True)
z_squared = np.sum(Z ** 2, axis=1, keepdims=True).T
distances_vectorized = x_squared + z_squared - 2.0 * X @ Z.T

# A small explicit loop is useful as a correctness oracle.
distances_loop = np.empty((len(X), len(Z)))
for i, x in enumerate(X):
    for j, z in enumerate(Z):
        distances_loop[i, j] = np.sum((x - z) ** 2)

print("distance matrix shape:", distances_vectorized.shape)
print("maximum difference:", np.max(np.abs(distances_vectorized - distances_loop)))
print(distances_vectorized.round(3))

\[ L(W)=-\frac{1}{n}\sum_{i=1}^{n}\log\operatorname{softmax}(XW)_{i,y_i}, \]
