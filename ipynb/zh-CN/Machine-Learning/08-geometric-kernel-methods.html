基于实例、几何与核的方法

几何学习首先要回答：哪些观测应当相互影响？ 这一判断由数据表示、距离或相似度，以及把所得几何结构转换为预测的规则共同编码。

本章研究三个相互关联的方法族：

  • 基于实例的方法 保存训练样本，并依据查询点的局部邻域进行预测；
  • 间隔方法 构造分离曲面，并偏好具有更大几何净空的边界；
  • 核方法 用潜在高维特征空间中的成对内积取代显式坐标。

这些方法不会自动继承有意义的几何结构。标准化一个变量、对类别做 one-hot 编码、加入无关特征或更换 embedding，都可能重新排列全部邻居并改变每个间隔。因此，预处理、距离选择、特征学习和超参数调节都必须位于验证流程内部。

距离不仅是实现细节，更是一种 归纳偏置：模型假设相邻点具有相关目标，宽间隔分隔面比窄间隔更容易泛化，而较高的核相似度意味着更相似的预测行为。方法质量取决于这种几何是否匹配真实的数据生成问题。

基于实例与最近邻学习

最近邻方法属于 非参数方法，因为它们不预先限定一个固定的有限维预测公式。它们也称为 惰性学习器：拟合阶段主要保存训练集，并可能构建搜索索引；大部分计算推迟到查询到来时完成。

给定查询 \(x\)，模型寻找 \(d(x,x_i)\) 较小的观测，并假设其标签或响应能提供关于 \(Y\mid X=x\) 的信息。无需求解全局优化问题，它便可表示不规则的局部边界；代价是较大的存储、查询时计算，以及对表示方式的高度敏感。

最近邻方法

距离度量

数学上的 metric \(d(x,z)\) 满足非负性、同一性、对称性与三角不等式。这些性质使树索引能够进行精确剪枝。实用的相似度函数不一定是 metric，但依赖 metric 性质的算法此时可能不再正确。

Minkowski 距离族为

\[ d_p(x,z)=\left(\sum_{j=1}^{m}|x_j-z_j|^p\right)^{1/p}, \qquad p\ge 1. \]

\(p=1\) 得到 Manhattan 距离，\(p=2\) 得到 Euclidean 距离。\(0<p<1\) 可强调稀疏坐标差异，却违反三角不等式，因此不属于 metric。

平方 Mahalanobis 距离

\[ d_M^2(x,z)=(x-z)^\top S^{-1}(x-z) \]

利用协方差 \(S\) 降低高变异方向的权重，并考虑相关特征。它等价于在恰当 whitening 变换后计算 Euclidean 距离。当 \(S\) 估计不稳定或奇异，尤其是维度接近样本量时，需要使用收缩估计或低维表示。

Cosine 相似度

\[ s_{\cos}(x,z)=\frac{x^\top z}{\lVert x\rVert_2\lVert z\rVert_2} \]

比较方向而非幅值。它常用于稀疏文本计数与 embedding，因为向量长度可能反映文档长度或置信度，而不是语义身份。实践中常用 \(1-s_{\cos}\) 作为 cosine 距离，但它在所有情形下并不满足 metric 的全部性质。

类别型和混合类型数据需要超越数值缩放的语义。Hamming 距离统计不匹配项，Jaccard 距离比较集合或二元存在性，Gower 类距离组合各变量归一化后的差异。把无序类别任意编码为整数会制造虚假的数值顺序，不应直接送入 Euclidean KNN。

Python 示例：计算多种距离并比较邻居排序 
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

query = np.array([1.0, 2.0, 0.0])
points = np.array([
    [2.0, 2.0, 0.0],   # one coordinate differs
    [1.5, 2.5, 0.5],   # several moderate differences
    [10.0, 20.0, 0.0], # same direction, very different magnitude
])

def minkowski_distance(rows, target, p):
    return np.sum(np.abs(rows - target) ** p, axis=1) ** (1 / p)

distances = {
    "Manhattan": minkowski_distance(points, query, p=1),
    "Euclidean": minkowski_distance(points, query, p=2),
    "cosine distance": 1 - cosine_similarity(points, query[None, :]).ravel(),
}

for name, values in distances.items():
    print(f"{name:>15}: distances={np.round(values, 3)}, ranking={np.argsort(values)}")

Euclidean 距离带有单位，因此即使某个大尺度特征与任务无关，也可能支配距离。缩放并不总等于标准化：物理量纲一致的变量可能应保留原单位，重尾变量可能需要 robust scaling，领域成本也可能支持有意设置特征权重。

Python 示例：展示缩放如何改变最近观测 
import numpy as np
from sklearn.preprocessing import StandardScaler

# Columns represent age in years and annual spending in dollars.
customers = np.array([
    [24.0, 20_000.0],
    [49.0, 51_000.0],
    [51.0, 80_000.0],
    [75.0, 50_500.0],
])
query = np.array([[50.0, 50_000.0]])

raw_distance = np.linalg.norm(customers - query, axis=1)

# Fit the scaler on stored training cases, then transform the query.
scaler = StandardScaler().fit(customers)
scaled_distance = np.linalg.norm(
    scaler.transform(customers) - scaler.transform(query), axis=1
)

print("nearest without scaling:", int(np.argmin(raw_distance)))
print("nearest after scaling:  ", int(np.argmin(scaled_distance)))
print("scaled distances:", np.round(scaled_distance, 3))
One-Nearest Neighbour（1-NN）

1-NN 直接采用距离最近的单个存储观测进行预测：

\[ i^*(x)=\arg\min_i d(x,x_i), \qquad \widehat y(x)=y_{i^*(x)}. \]

在分类任务中，1-NN 把空间划分为 Voronoi 单元，每个单元中的查询都继承对应训练点的标签。如果不存在特征向量重复但标签冲突的情况，训练误差为零，因为每个观测本身就是自己的最近邻。这种插值并不是泛化能力的证据。

该方法模型偏差极低，但方差很高。一个错误标签点可能控制整个局部区域，而且只要存储样本改变，边界就可能改变。在正则条件和极大样本下，1-NN 渐近分类误差至多约为 Bayes error 的两倍；但这一上界并不会让有限样本、高维或分布漂移的数据变得容易。

1-NN prediction
Input: stored pairs (x_i, y_i), query x, distance d
1. Compute d(x, x_i) for every candidate.
2. Select i* with the smallest distance.
3. Return y_i* and optionally the distance as a familiarity signal.
Python 示例：实现 1-NN，并区分重代入误差与留一误差 
import numpy as np
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=120, noise=0.22, random_state=4)

def one_nn_predict(train_X, train_y, query_X):
    squared_distance = ((query_X[:, None, :] - train_X[None, :, :]) ** 2).sum(axis=2)
    return train_y[np.argmin(squared_distance, axis=1)]

# Resubstitution lets every point retrieve itself and is optimistically biased.
training_prediction = one_nn_predict(X, y, X)

# Leave-one-out excludes the query point by setting the diagonal distance to infinity.
pairwise_squared = ((X[:, None, :] - X[None, :, :]) ** 2).sum(axis=2)
np.fill_diagonal(pairwise_squared, np.inf)
loo_prediction = y[np.argmin(pairwise_squared, axis=1)]

print("resubstitution accuracy:", np.mean(training_prediction == y))
print("leave-one-out accuracy: ", round(np.mean(loo_prediction == y), 3))
K-Nearest Neighbours（KNN）

KNN 用大小为 \(k\) 的局部样本替代单个不稳定标签。分类时，

\[ \widehat y(x)=\arg\max_c\sum_{i\in N_k(x)}\mathbb 1(y_i=c), \]

回归时，

\[ \widehat f(x)=\frac{1}{k}\sum_{i\in N_k(x)}y_i. \]

较小的 \(k\) 产生高度局部且不规则的预测，偏差低而方差高；较大的 \(k\) 能平滑噪声，却可能跨越真实类别边界或平均不同响应机制。选择奇数 \(k\) 可以减少部分二分类平局，但不能消除多分类或等距离平局，实现仍需确定性的破局规则。

图片来源：scikit-learn，Nearest Neighbors Classification。

Python 示例：由成对距离实现 KNN 分类与回归 
import numpy as np

train_X = np.array([[0.0], [1.0], [2.0], [3.0], [4.0]])
class_y = np.array([0, 0, 0, 1, 1])
regression_y = np.array([0.2, 0.9, 2.2, 2.8, 4.3])
queries = np.array([[1.6], [3.4]])
k = 3

distance = np.abs(queries - train_X.T)
neighbor_index = np.argpartition(distance, kth=k - 1, axis=1)[:, :k]

classification = []
regression = []
for row in neighbor_index:
    counts = np.bincount(class_y[row])
    classification.append(np.flatnonzero(counts == counts.max())[0])
    regression.append(regression_y[row].mean())

print("neighbor indices:\n", neighbor_index)
print("class predictions:", classification)
print("regression predictions:", np.round(regression, 3))

\(k\)、距离度量、特征变换与投票规则都是超参数，而且相互影响，必须联合选择。即使缩放不使用标签，在交叉验证之前拟合缩放器仍会造成信息泄漏。

Python 示例：在防泄漏流水线中联合调节 k 与距离 
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

X, y = make_moons(n_samples=500, noise=0.28, random_state=23)
X_development, X_test, y_development, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=23
)

pipeline = Pipeline([
    ("scale", StandardScaler()),
    ("knn", KNeighborsClassifier()),
])
search = GridSearchCV(
    pipeline,
    {
        "knn__n_neighbors": [1, 3, 5, 9, 15, 25, 41],
        "knn__p": [1, 2],
        "knn__weights": ["uniform", "distance"],
    },
    scoring="accuracy",
    cv=StratifiedKFold(5, shuffle=True, random_state=23),
).fit(X_development, y_development)

print("selected settings:", search.best_params_)
print("development CV accuracy:", round(search.best_score_, 3))
print("untouched test accuracy:", round(search.score(X_test, y_test), 3))
加权最近邻

均匀投票平等对待最近点与第 \(k\) 近点。加权估计则使用

\[ \widehat f(x)= \frac{\sum_{i\in N_k(x)}w_i(x)y_i} {\sum_{i\in N_k(x)}w_i(x)}, \qquad w_i(x)=\frac{1}{(d(x,x_i)+\epsilon)^q}, \]

或者使用超出带宽后变为零的紧支撑核。分类时用类别指示量替代 \(y_i\)。指数 \(q\) 或带宽控制局部性，必须经过验证。如果查询与存储点完全重合，稳健实现应直接依据这些零距离匹配进行预测，而不是发生除零。

图片来源：scikit-learn，Nearest Neighbors Regression。

Python 示例：检查反距离权重如何改变局部预测 
import numpy as np
from sklearn.neighbors import KNeighborsRegressor

X = np.array([[0.0], [1.0], [2.0], [3.0], [4.0]])
y = np.array([0.0, 1.0, 2.0, 8.0, 4.0])
query = np.array([[2.2]])

for weights in ("uniform", "distance"):
    model = KNeighborsRegressor(n_neighbors=3, weights=weights).fit(X, y)
    distances, indices = model.kneighbors(query)
    print(
        f"{weights:>8}: prediction={model.predict(query)[0]:.3f}, "
        f"neighbors={indices[0].tolist()}, distances={np.round(distances[0], 2)}"
    )

当“局部性”具有合理语义、预期查询附近有足够密集的相关观测，而且内存与延迟可以接受时，最近邻模型最有优势。它们不善于外推：在观测支持集之外，模型只返回最不远的存储样本，而不会学习趋势。因此，应监控较大的最近邻距离，并把它视为分布外或低熟悉度信号。

维度灾难

维度灾难 并非一条定理，而是环境维度升高引发的一组效应：空间体积增长极快，有限样本变得稀疏；局部邻域必须扩大才能容纳足够观测；许多常规距离逐渐失去区分度。局部方法直接受到影响，因为它们既需要附近有足够数据，也需要可靠的距离排序。

距离集中

假设某邻域在每个坐标轴上保留比例 \(r\)，则它占轴对齐 \(d\) 维总体积的比例为 \(r^d\)。若每个坐标范围只保留一半，要在该区域中期望得到一个均匀分布点，大约需要 \(2^d\) 个观测。这个指数计算只是示意，却说明了二维中很局部的半径为何在五十维中几乎为空。

当许多独立坐标共同贡献距离时，其贡献会逐渐平均。对于常见分布，最近与最远距离之差相对于距离总体大小变得很小。KNN 因而必须依赖微小差异区分观测，而这些差异可能主要来自噪声、测量误差或任意缩放。

环境维度并非全部。数据可能位于低维流形附近，而学习到的 embedding 可以恢复有用的局部结构。反过来，即使维度不高，少量缩放不当或无关的特征也能破坏原本有意义的邻域。

Python 示例：模拟 Euclidean 距离集中 
import numpy as np

rng = np.random.default_rng(18)
n_points = 4_000

for dimension in [2, 5, 10, 25, 50, 100]:
    points = rng.normal(size=(n_points, dimension))
    query = np.zeros(dimension)
    distance = np.linalg.norm(points - query, axis=1)
    nearest, typical, farthest = np.min(distance), np.mean(distance), np.max(distance)
    relative_spread = (farthest - nearest) / typical
    print(
        f"d={dimension:>3}: nearest={nearest:6.2f}, mean={typical:6.2f}, "
        f"farthest={farthest:6.2f}, relative spread={relative_spread:5.2f}"
    )

绝对距离会随维度增长，但相对离散程度会收缩。这不表示所有高维任务都无法完成，而是说明不能想当然地采用 Euclidean 局部性。

Python 示例：展示无关维度如何降低 KNN 表现 
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(37)
informative_X, y = make_moons(n_samples=1_000, noise=0.24, random_state=37)

for noise_dimensions in [0, 5, 20, 80]:
    noise = rng.normal(size=(len(informative_X), noise_dimensions))
    X = np.column_stack([informative_X, noise])
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, stratify=y, random_state=37
    )
    model = make_pipeline(
        StandardScaler(),
        KNeighborsClassifier(n_neighbors=15),
    ).fit(X_train, y_train)
    print(
        f"total dimensions={X.shape[1]:>3}, "
        f"test accuracy={model.score(X_test, y_test):.3f}"
    )

缩放与特征相关性

缩放把数值特征放到可比较单位，却无法区分有用变异与无关变异。特征选择、监督式度量学习和表示学习解决的是更强的问题：对于当前目标，哪些方向应被视为相似？

对角特征加权定义

\[ d_w^2(x,z)=\sum_j w_j(x_j-z_j)^2, \qquad w_j\ge 0, \]

而学习到的线性变换 \(A\) 给出 \(d_A(x,z)=\lVert A(x-z)\rVert_2\)。例如 Neighborhood Components Analysis（NCA）学习一个变换，使随机邻居拥有同类标签的概率增大。由于它使用标签，所以它属于估计器的一部分，必须在每个训练折中独立拟合。

降维也可以去除噪声，但无监督方差不等于预测相关性。PCA 可能丢弃方差很低却能强力区分类别的方向；监督变换则可能在小样本中过拟合标签。两种选择都需要样本外评估。

Python 示例：在 KNN 之前学习监督式距离度量 
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier, NeighborhoodComponentsAnalysis
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = make_classification(
    n_samples=700,
    n_features=12,
    n_informative=3,
    n_redundant=3,
    n_repeated=0,
    class_sep=1.1,
    flip_y=0.05,
    random_state=12,
)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=12
)

models = {
    "scaled KNN": make_pipeline(
        StandardScaler(), KNeighborsClassifier(n_neighbors=11)
    ),
    "NCA + KNN": make_pipeline(
        StandardScaler(),
        NeighborhoodComponentsAnalysis(n_components=3, max_iter=120, random_state=12),
        KNeighborsClassifier(n_neighbors=11),
    ),
}

for name, model in models.items():
    model.fit(X_train, y_train)
    print(f"{name:>10}: test accuracy={model.score(X_test, y_test):.3f}")

当标签定义任务特定的邻域时，度量学习很有价值，但它把研究问题从“哪些原始观测彼此接近”改为“如何变换观测以改善这些标签”。这一差别会影响解释、迁移到新任务以及分布漂移下的行为。

高效最近邻搜索

精确 KNN 预测看似必须把查询与每个存储向量比较。搜索索引尝试在不计算全部完整距离的情况下排除候选。它是否有效取决于维度、metric、数据分布、更新方式和硬件；渐近复杂度看似优秀的树，在实际中也可能输给向量化的 brute-force 矩阵运算。

Brute Force、KD-Tree 与 Ball Tree

Brute force 计算全部查询—候选距离，对于 \(n\) 个 \(d\) 维向量，每次查询需要 \(O(nd)\) 工作。它精确、几乎没有索引开销、支持多种 metric，并能利用稠密线性代数、SIMD、GPU 与批处理；在小数据集或高维向量上通常很有竞争力。

KD-tree 通过轴对齐切分递归划分点集。查询时，可排除不可能含有更近点的包围矩形。构建约为 \(O(n\log n)\)，低维平均查询时间可接近 \(O(\log n)\)，但最坏情况仍为 \(O(n)\)，且随维度升高，剪枝效果迅速恶化。

Ball tree 把点组织为嵌套的 metric 球，并利用三角不等式给出的下界剪枝。它支持更多 metric，在中等维度或非轴对齐结构上可能优于 KD-tree，但仍无法摆脱距离集中。

leaf_size 在树深、内存与叶节点内 brute-force 工作量之间权衡。algorithm="auto" 是合理起点，却不能替代使用生产形态查询做基准测试。

Python 示例：在低维与较高维度中基准测试精确搜索算法 
from time import perf_counter
import numpy as np
from sklearn.neighbors import NearestNeighbors

rng = np.random.default_rng(21)

for dimension in [4, 35]:
    database = rng.normal(size=(4_000, dimension))
    queries = rng.normal(size=(300, dimension))
    print(f"\ndimension={dimension}")

    reference_indices = None
    for algorithm in ["brute", "kd_tree", "ball_tree"]:
        started = perf_counter()
        index = NearestNeighbors(
            n_neighbors=8,
            algorithm=algorithm,
            metric="euclidean",
            leaf_size=30,
        ).fit(database)
        fit_ms = 1_000 * (perf_counter() - started)

        started = perf_counter()
        _, indices = index.kneighbors(queries)
        query_ms = 1_000 * (perf_counter() - started)

        if reference_indices is None:
            reference_indices = indices
        same_first_query = set(indices[0]) == set(reference_indices[0])
        print(
            f"  {algorithm:>9}: fit={fit_ms:7.1f} ms, query={query_ms:7.1f} ms, "
            f"same neighbors={same_first_query}"
        )

计时依赖机器，不应被视为普遍结论。关键是经常发生的反转：空间树在低维可以加速，而高维时遍历开销与弱剪枝可能使 brute force 更快。

近似最近邻

近似最近邻（ANN）系统有意允许遗漏部分真实邻居，以换取更低延迟或内存。主要方法族包括：

  • locality-sensitive hashing：使邻近向量更可能进入同一 bucket；
  • 图索引，如 hierarchical navigable small-world graph：沿近邻连接贪心导航；
  • 倒排文件与 product quantization：把搜索限制在粗粒度单元，并压缩向量块；
  • 随机投影或学习到的低维 embedding：先生成候选，再进行精确重排序。

主要质量指标是 recall at \(k\)：

\[ \operatorname{Recall@}k =\frac{|N_k^{\text{approx}}(x)\cap N_k^{\text{exact}}(x)|}{k}, \]

并在真实查询上聚合。评估精度时还必须同时考虑构建时间、更新成本、内存、平均与尾部延迟、过滤、删除行为和下游任务质量。如果用于检索的 metric 本身与预测目标不一致，再高的邻居 recall 也没有价值。

Python 示例：评估投影候选检索与精确重排序 
from time import perf_counter
import numpy as np
from sklearn.random_projection import GaussianRandomProjection

rng = np.random.default_rng(32)
n_database, n_queries, original_dimension = 3_000, 100, 80
latent_dimension = 10

# Vectors have lower-dimensional latent structure embedded in 80 dimensions.
projection = rng.normal(size=(latent_dimension, original_dimension))
database = rng.normal(size=(n_database, latent_dimension)) @ projection
database += rng.normal(scale=0.15, size=database.shape)
queries = rng.normal(size=(n_queries, latent_dimension)) @ projection
queries += rng.normal(scale=0.15, size=queries.shape)

def top_k_indices(query_matrix, candidate_matrix, k):
    squared = ((query_matrix[:, None, :] - candidate_matrix[None, :, :]) ** 2).sum(axis=2)
    return np.argpartition(squared, kth=k - 1, axis=1)[:, :k]

k = 10
started = perf_counter()
exact = top_k_indices(queries, database, k)
exact_ms = 1_000 * (perf_counter() - started)

# This is a teaching approximation, not a production HNSW implementation.
mapper = GaussianRandomProjection(n_components=12, random_state=32).fit(database)
small_database = mapper.transform(database)
small_queries = mapper.transform(queries)

started = perf_counter()
candidate_index = top_k_indices(small_queries, small_database, k=40)
approximate = []
for query, candidates in zip(queries, candidate_index):
    candidate_distance = ((database[candidates] - query) ** 2).sum(axis=1)
    approximate.append(candidates[np.argpartition(candidate_distance, kth=k - 1)[:k]])
approximate_ms = 1_000 * (perf_counter() - started)

recall = np.mean([
    len(set(found) & set(truth)) / k
    for found, truth in zip(approximate, exact)
])
print("mean recall@10:", round(recall, 3))
print("exact computation time (ms):", round(exact_ms, 1))
print("projected candidate plus rerank time (ms):", round(approximate_ms, 1))

这个小型 NumPy 示例演示候选生成与重排序，但并不承诺加速，因为它仍会扫描所有投影向量。生产级 ANN 的收益来自真实索引、压缩存储、优化内核与批处理。评估方法可以跨实现迁移，而性能数字不能。

线性分隔面与 Perceptron

最近邻通过局部比较分类。线性分隔面则把全部训练信息压缩为一个得分

\[ f(x)=w^\top x+b, \]

并根据其符号预测。这与第 07 章的线性预测量具有相同几何结构，但训练目标现在聚焦分类错误或间隔，而不是由似然校准的概率。

决策边界

边界 \(w^\top x+b=0\) 是法向量为 \(w\) 的超平面。任意点 \(x\) 到边界的带符号垂直距离为

\[ \frac{w^\top x+b}{\lVert w\rVert_2}. \]

同时把 \(w\) 和 \(b\) 乘以同一正数，不会改变边界，也不会改变归一化后的带符号距离，但会改变原始得分。因此，在“较大得分”具有几何意义前，优化问题必须固定或惩罚尺度。

如果 \(x\) 已包含多项式、样条或学习到的特征，线性边界在原始数据空间中可以是非线性的。所以它的限制是相对于表示方式而言，而不只是原始两列数据中可视化出来的形状。

Python 示例：计算带符号距离并验证边界的尺度不变性 
import numpy as np

w = np.array([2.0, -1.0])
b = 0.5
X = np.array([[0.0, 0.0], [2.0, 1.0], [-1.0, 2.0]])

def signed_distance(features, weight, intercept):
    return (features @ weight + intercept) / np.linalg.norm(weight)

original = signed_distance(X, w, b)
rescaled = signed_distance(X, 7 * w, 7 * b)

print("raw scores:", np.round(X @ w + b, 3))
print("signed distances:", np.round(original, 3))
print("distances after scaling (w, b):", np.round(rescaled, 3))
print("same predictions:", np.array_equal(original >= 0, rescaled >= 0))

Perceptron 更新规则

对于标签 \(y_i\in\{-1,+1\}\)，Perceptron 依次访问观测，并且仅在

\[ y_i(w^\top x_i+b)\le 0 \]

时更新。由错误驱动的更新为

\[ w\leftarrow w+\eta y_i x_i, \qquad b\leftarrow b+\eta y_i, \]

其中 \(\eta>0\) 为步长。误分类正样本使 \(w\) 朝其特征向量移动；误分类负样本使 \(w\) 远离该向量，从而改变法向量并旋转或平移边界。

Perceptron training
Initialize w = 0 and b = 0.
Repeat over shuffled training observations:
    if y_i (w^T x_i + b) <= 0:
        w <- w + eta y_i x_i
        b <- b + eta y_i
Stop after a mistake-free pass or a predefined epoch budget.

若全部观测范数不超过 \(R\)，且存在单位向量以间隔 \(\gamma>0\) 将其分开，则 Perceptron 收敛定理把错误次数限制在 \((R/\gamma)^2\)。该定理说明大间隔问题更容易，却不适用于标签始终不可线性分离的情况。

在含噪数据上，基础算法可能循环，最终边界也依赖观测顺序。固定 epoch 上限、pocket algorithm 或 averaged Perceptron 能给出可用结果，但都不会把得分变成概率，也不会显式最大化间隔。

Python 示例：实现 Perceptron，并比较可分数据与含噪标签 
import numpy as np
from sklearn.datasets import make_blobs

def fit_perceptron(X, y, epochs=40, learning_rate=1.0, seed=0):
    rng = np.random.default_rng(seed)
    w = np.zeros(X.shape[1])
    b = 0.0
    mistakes_per_epoch = []

    for _ in range(epochs):
        mistakes = 0
        for index in rng.permutation(len(X)):
            if y[index] * (X[index] @ w + b) <= 0:
                w += learning_rate * y[index] * X[index]
                b += learning_rate * y[index]
                mistakes += 1
        mistakes_per_epoch.append(mistakes)
        if mistakes == 0:
            break
    return w, b, mistakes_per_epoch

X, label01 = make_blobs(
    n_samples=180, centers=[(-2, -2), (2, 2)], cluster_std=0.65, random_state=7
)
y_clean = np.where(label01 == 0, -1, 1)
y_noisy = y_clean.copy()
y_noisy[:18] *= -1

for name, labels in [("separable", y_clean), ("label noise", y_noisy)]:
    w, b, history = fit_perceptron(X, labels, epochs=40, seed=7)
    accuracy = np.mean(np.where(X @ w + b >= 0, 1, -1) == labels)
    print(
        f"{name:>11}: epochs={len(history):>2}, final mistakes={history[-1]:>2}, "
        f"training accuracy={accuracy:.3f}"
    )

Perceptron 是有价值的在线线性基线，也连接了错误最小化与间隔方法。逻辑回归加入概率似然，支持向量机则加入显式的间隔最大化。

支持向量机

支持向量机（SVM）利用最接近违反约束的观测来选择分隔面。它不只寻找训练误差较低的任意边界，而是在经验违规与较大几何间隔之间权衡，得到凸优化问题和稀疏的对偶表示。

最大间隔分类

对于正确分类的点，归一化带符号间隔为

\[ \frac{y_i(w^\top x_i+b)}{\lVert w\rVert_2}. \]

由于缩放 \((w,b)\) 不改变边界，hard-margin SVM 把最近点的函数间隔固定为 1，并求解

\[ \begin{aligned} \min_{w,b}\quad & \frac{1}{2}\lVert w\rVert_2^2 \\ \text{subject to}\quad & y_i(w^\top x_i+b)\ge 1 \quad\text{for every }i. \end{aligned} \]

两个支撑超平面为 \(w^\top x+b=\pm1\)，间距为 \(2/\lVert w\rVert_2\)。因此，最小化权重范数等价于最大化几何净空。接触这些平面的点称为 支持向量；只要远处的正确分类点不越过间隔，移动它不会改变最优解。

图片来源：scikit-learn，Maximum Margin Separating Hyperplane。

Python 示例：恢复间隔宽度和支持向量间隔 
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

X, y = make_blobs(
    n_samples=120, centers=[(-2, -2), (2, 2)], cluster_std=0.7, random_state=6
)
scaler = StandardScaler().fit(X)
scaled_X = scaler.transform(X)
model = SVC(kernel="linear", C=10_000).fit(scaled_X, y)

w = model.coef_[0]
margin_width = 2 / np.linalg.norm(w)
signed_functional_margin = np.where(y == 1, 1, -1) * model.decision_function(scaled_X)

print("number of support vectors:", len(model.support_))
print("geometric margin width:", round(margin_width, 3))
print(
    "functional margins of support vectors:",
    np.round(signed_functional_margin[model.support_], 3),
)

硬间隔与软间隔

当类别重叠、标签含噪或相同特征向量对应不同标签时，硬间隔不再可行。Soft-margin SVM 引入松弛变量 \(\xi_i\ge0\)：

\[ \begin{aligned} \min_{w,b,\xi}\quad & \frac{1}{2}\lVert w\rVert_2^2+C\sum_i\xi_i \\ \text{subject to}\quad & y_i(w^\top x_i+b)\ge1-\xi_i. \end{aligned} \]

\(\xi_i=0\) 表示点位于正确间隔线上或其外侧；\(0<\xi_i\le1\) 表示点进入间隔但仍在边界正确一侧；\(\xi_i>1\) 对应误分类。参数 \(C\) 控制违规惩罚：

  • 较大 \(C\) 更重视拟合训练样本，可能产生更窄、正则化更弱的间隔；
  • 较小 \(C\) 容忍更多违规，以获得更宽、更平滑的边界。

这一约定与 ridge 的 alpha 等正则化强度相反：增大 \(C\) 会减弱正则化。由于 \(\lVert w\rVert_2\) 和间隔依赖特征单位，特征缩放不可缺少。

类别权重可用类别或观测特定的惩罚取代统一 \(C\)，从而把边界推向多数类一侧。但权重应依据错误成本和评估指标选择，而不是机械追求各类别准确率相等。

Python 示例：检查 C 如何改变间隔宽度和支持向量 
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

X, y = make_classification(
    n_samples=600,
    n_features=2,
    n_redundant=0,
    n_informative=2,
    n_clusters_per_class=1,
    class_sep=0.9,
    flip_y=0.08,
    random_state=11,
)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=11
)

for C in [0.01, 1.0, 100.0]:
    pipeline = make_pipeline(StandardScaler(), SVC(kernel="linear", C=C)).fit(
        X_train, y_train
    )
    svm = pipeline[-1]
    margin_width = 2 / np.linalg.norm(svm.coef_[0])
    print(
        f"C={C:>6}: margin width={margin_width:5.2f}, "
        f"support vectors={len(svm.support_):>3}, "
        f"train={pipeline.score(X_train, y_train):.3f}, "
        f"test={pipeline.score(X_test, y_test):.3f}"
    )

Hinge Loss

消去松弛变量可得 hinge loss：

\[ \ell_{\text{hinge}}(y,f(x))=\max(0,1-yf(x)). \]

正确分类且位于间隔外的点损失为零；位于间隔内但分类正确的点损失为正；误分类点损失大于 1。逻辑损失则对任意有限得分都保持正值，并在似然模型下支持概率估计。

在线性 soft-margin 情形下，忽略缩放约定后，目标可写作

\[ \frac{1}{2}\lVert w\rVert_2^2 +C\sum_i\max(0,1-y_i(w^\top x_i+b)). \]

Hinge loss 是凸函数，但在间隔 1 处不可微；次梯度、坐标与对偶优化可以直接处理这一尖点。Squared hinge 对较大违规惩罚更强，并在部分区域更平滑，却失去普通 hinge loss 的分段线性稳健性。

Python 示例：计算 hinge loss 与得分次梯度 
import numpy as np

y = np.array([1, 1, 1, -1, -1])
score = np.array([2.0, 0.4, -0.5, -1.3, 0.2])
signed_margin = y * score
loss = np.maximum(0.0, 1.0 - signed_margin)

# Away from the corner y*f(x)=1, d loss / d score is -y inside the margin.
score_subgradient = np.where(signed_margin < 1.0, -y, 0.0)

for label, value, margin, item_loss, gradient in zip(
    y, score, signed_margin, loss, score_subgradient
):
    print(
        f"y={label:+d}, score={value:+.1f}, margin={margin:+.1f}, "
        f"hinge={item_loss:.1f}, subgradient={gradient:+.1f}"
    )

SVM 决策得分可按相对边界的置信程度排序，但不是校准概率。SVC(probability=True) 会加入内部校准并增加计算；当概率质量重要时，显式留出或交叉验证校准流程更容易审计。

对偶问题与支持向量

引入 Lagrange 乘子 \(\alpha_i\) 可得 soft-margin 对偶问题：

\[ \begin{aligned} \max_\alpha\quad & \sum_i\alpha_i-\frac{1}{2} \sum_i\sum_j\alpha_i\alpha_jy_iy_jx_i^\top x_j \\ \text{subject to}\quad & 0\le\alpha_i\le C, \qquad \sum_i\alpha_i y_i=0. \end{aligned} \]

拟合权重为 \(w=\sum_i\alpha_i y_i x_i\)，所以预测为

\[ f(x)=\sum_i\alpha_i y_i x_i^\top x+b. \]

只有 \(\alpha_i>0\) 的观测参与预测，它们就是支持向量。在理想 KKT 条件下，\(\alpha_i=0\) 表示间隔外的点，\(0<\alpha_i<C\) 表示间隔上的点，\(\alpha_i=C\) 表示位于间隔内或其边界的点；数值容差与重复观测使软件中的分类只是近似。

Python 示例：由支持向量重建 RBF SVM 决策函数 
import numpy as np
from sklearn.datasets import make_moons
from sklearn.metrics.pairwise import rbf_kernel
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

X, y = make_moons(n_samples=260, noise=0.2, random_state=8)
scaler = StandardScaler().fit(X)
scaled_X = scaler.transform(X)
gamma = 1.2
model = SVC(kernel="rbf", C=3.0, gamma=gamma).fit(scaled_X, y)

query = scaled_X[[3, 80, 170]]
similarity = rbf_kernel(query, model.support_vectors_, gamma=gamma)

# dual_coef_ already stores alpha_i * y_i for binary SVC.
manual_score = similarity @ model.dual_coef_.ravel() + model.intercept_[0]
api_score = model.decision_function(query)

print("training observations:", len(X))
print("support vectors used in prediction:", len(model.support_))
print("manual scores:", np.round(manual_score, 6))
print("API scores:   ", np.round(api_score, 6))
print("largest difference:", np.max(np.abs(manual_score - api_score)))

对偶形式为 kernel 打开了入口，因为训练和预测只需要成对内积。它也揭示部署成本：非线性 SVM 必须把每个查询与所有保留的支持向量比较。当线性边界足够且数据规模很大时，应优先考虑 LinearSVC 或随机线性 SVM 求解器。

核方法

SVM 对偶只通过内积 \(x_i^\top x_j\) 使用训练点。若存在显式特征映射 \(\phi\)，同一算法可使用 \(\phi(x_i)^\top\phi(x_j)\)，在变换空间学习线性分隔面。Kernel 直接计算这一内积：

\[ K(x,z)=\langle\phi(x),\phi(z)\rangle_{\mathcal H}. \]

变换空间 \(\mathcal H\) 可以是极高维甚至无限维。Kernel trick 避免构造其中的显式坐标，却不会消除成对计算，也不保证所选相似度能够泛化。

Kernel Trick

对于训练输入 \(x_1,\ldots,x_n\)，Gram 矩阵 的元素为 \(K_{ij}=K(x_i,x_j)\)。标准核方法要求实值 kernel 对称且半正定：对任意有限输入集合和向量 \(c\)，

\[ c^\top Kc\ge0. \]

该条件保证 \(K\) 的行为等价于某个 Hilbert 空间中的内积。只有“相似”还不够：一个对称函数仍可能产生负的 Gram 特征值，使常规凸优化解释失效。在附加正则条件下，Mercer 定理为此类 kernel 给出特征函数展开。

可以安全构造有效 kernel：半正定 kernel 的非负加权和与乘积仍然有效；对任意显式映射，\(K(x,z)=\phi(x)^\top\phi(z)\) 也有效。对 kernel 做中心化和对角归一化可能有用，但训练数据与新观测必须使用一致操作。

Python 示例：检查 Gram 矩阵与半正定性 
import numpy as np
from sklearn.metrics.pairwise import linear_kernel, polynomial_kernel, rbf_kernel

X = np.array([[0.0, 0.0], [1.0, 0.5], [-0.5, 1.5], [2.0, -1.0]])
kernels = {
    "linear": linear_kernel(X),
    "polynomial": polynomial_kernel(X, degree=2, gamma=0.5, coef0=1.0),
    "RBF": rbf_kernel(X, gamma=0.8),
    # Symmetric does not imply PSD: this matrix has eigenvalues 3 and -1.
    "invalid similarity": np.array([[1.0, 2.0], [2.0, 1.0]]),
}

for name, gram in kernels.items():
    eigenvalues = np.linalg.eigvalsh(gram)
    print(
        f"{name:>18}: symmetric={np.allclose(gram, gram.T)}, "
        f"minimum eigenvalue={eigenvalues.min():+.6f}"
    )

Linear、Polynomial 与 RBF Kernel

主要 kernel 对相似性采用不同假设：

\[ \begin{aligned} K_{\text{linear}}(x,z) &= x^\top z,\\ K_{\text{poly}}(x,z) &= (\gamma x^\top z+r)^d,\\ K_{\text{RBF}}(x,z) &= \exp(-\gamma\lVert x-z\rVert_2^2). \end{aligned} \]

当现有表示已支持线性边界时，linear kernel 最合适，尤其适用于极高维稀疏文本特征。Polynomial kernel 引入最高 \(d\) 次交互，coef0 控制低阶项贡献，其尺度和次数可能使数值快速增长。

RBF kernel 根据局部 Euclidean 距离赋予相似度，\(\gamma\) 是平方长度尺度的倒数：

  • 较小 \(\gamma\) 产生广泛影响和平滑、缓慢变化的函数；
  • 较大 \(\gamma\) 产生狭窄影响范围，甚至可能把单个观测隔离出来。

图片来源：scikit-learn，Classification Boundaries with Different SVM Kernels。

特征缩放会改变平方距离，进而改变每个 RBF 值。\(C\) 与 \(\gamma\) 也相互作用：高 \(\gamma\) 带来局部灵活度，高 \(C\) 则强烈惩罚局部违规。两者应在对数网格中联合调节，而不是逐一调整。

图片来源：scikit-learn，RBF SVM Parameters。

部分 SVM 库实现的 sigmoid 函数并非对所有参数都半正定，因此较少作为默认 kernel。自定义领域 kernel 应先通过数学证明或 Gram 谱检查，再在实际任务上验证。

Python 示例：比较不同 kernel，并联合调节 RBF 的 C 与 gamma 
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

Kernel Ridge Regression 与 Support Vector Regression

Kernelization 不只用于分类。Kernel ridge regression（KRR） 在 reproducing-kernel Hilbert space 中求解带正则的平方误差回归：

\[ \min_{f\in\mathcal H} \sum_i(y_i-f(x_i))^2+\lambda\lVert f\rVert_{\mathcal H}^2. \]

根据 representer theorem，解具有 \(f(x)=\sum_i\alpha_iK(x_i,x)\) 的形式；在一种常见缩放约定下，

\[ \alpha=(K+\lambda I)^{-1}y. \]

平方损失通常使每个训练观测都具有非零系数，因此预测需要使用完整训练集。

Support vector regression（SVR） 使用 \(\epsilon\)-insensitive loss：

\[ \ell_\epsilon(y,f(x))=\max(0,|y-f(x)|-\epsilon). \]

位于半宽 \(\epsilon\) 管道内的误差不产生损失；通常只有位于管道边界或外部的观测成为支持向量。\(C\) 控制超出管道后的惩罚，\(\epsilon\) 控制可忽略偏差。较大的 \(\epsilon\) 通常产生更稀疏但偏差更大的预测器。

图片来源：scikit-learn，Support Vector Regression with Linear and Nonlinear Kernels。

Python 示例：比较 Kernel Ridge 与稀疏 epsilon-SVR 
import numpy as np
from sklearn.kernel_ridge import KernelRidge
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split
from sklearn.svm import SVR

rng = np.random.default_rng(28)
X = np.sort(rng.uniform(0, 7, size=280))[:, None]
y = np.sin(X[:, 0]) + 0.12 * X[:, 0] + rng.normal(scale=0.2, size=len(X))
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=28
)

models = {
    "Kernel Ridge": KernelRidge(kernel="rbf", gamma=0.8, alpha=0.12),
    "epsilon-SVR": SVR(kernel="rbf", gamma=0.8, C=8.0, epsilon=0.12),
}

for name, model in models.items():
    model.fit(X_train, y_train)
    rmse = np.sqrt(mean_squared_error(y_test, model.predict(X_test)))
    retained = len(model.support_) if hasattr(model, "support_") else len(X_train)
    print(
        f"{name:>12}: test RMSE={rmse:.3f}, "
        f"training cases used at prediction={retained}/{len(X_train)}"
    )

KRR 具有闭式线性系统解和平滑平方损失；SVR 求解受约束凸问题并可形成稀疏表示。两者都需要调节 kernel 与正则化，都难以扩展到极大的 \(n\)，而且没有合适 kernel 或均值结构时，都无法在支持集之外可靠外推全局趋势。

Kernel 近似

精确 \(n\times n\) Gram 矩阵需要 \(O(n^2)\) 内存；精确 kernel 求解器的训练时间可在平方到立方量级之间变化，具体取决于算法和数据。近似特征映射使用显式向量 \(z(x)\in\mathbb R^D\) 代替 kernel，使

\[ \widetilde\phi_D(x)^\top\widetilde\phi_D(x') \approx K(x,x'). \]

变换后的数据即可使用可扩展的线性求解器和 minibatch。

对于平移不变的 RBF kernel，random Fourier features 从 kernel 的谱分布采样频率。一种常见形式为

\[ z_j(x)=\sqrt{\frac{2}{D}}\cos(\omega_j^\top x+b_j), \]

其中 \(\omega_j\sim\mathcal N(0,2\gamma I)\)，\(b_j\sim\operatorname{Uniform}(0,2\pi)\)。增大 \(D\) 会降低 Monte Carlo 近似误差，却增加内存和线性模型成本。

Nystroem 方法 采样 landmark 观测，并利用涉及这些 landmark 的 kernel 值构造低秩近似。质量取决于 landmark 数量及代表性。均匀采样简单；面对非均匀数据，基于 leverage 或聚类的采样可能更好。

图片来源：scikit-learn，Explicit Feature Map Approximation for RBF Kernels。

Python 示例：观察 random Fourier 近似误差如何随维度变化 
import numpy as np
from sklearn.kernel_approximation import RBFSampler
from sklearn.metrics.pairwise import rbf_kernel

x = np.array([[0.2, -1.0, 0.7]])
z = np.array([[1.1, -0.4, 0.2]])
gamma = 0.7
exact = rbf_kernel(x, z, gamma=gamma)[0, 0]

print("exact RBF similarity:", round(exact, 5))
for components in [20, 100, 500, 2_000]:
    mapper = RBFSampler(
        gamma=gamma,
        n_components=components,
        random_state=components,
    ).fit(np.vstack([x, z]))
    approximate = mapper.transform(x) @ mapper.transform(z).T
    print(
        f"components={components:>4}: approximation={approximate[0, 0]:+.5f}, "
        f"absolute error={abs(approximate[0, 0] - exact):.5f}"
    )

单次随机抽样不一定在每次增大 \(D\) 时都单调改善。近似质量应跨多个随机种子总结，或通过下游验证评估，而不能由一对向量推断。

Python 示例：比较精确 RBF SVM 与显式 RBF 近似 
from time import perf_counter
from sklearn.datasets import load_digits
from sklearn.kernel_approximation import RBFSampler
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import LinearSVC, SVC

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=16
)
gamma = 0.015

models = {
    "exact RBF SVC": make_pipeline(
        StandardScaler(), SVC(kernel="rbf", C=5.0, gamma=gamma)
    ),
    "RFF + LinearSVC": make_pipeline(
        StandardScaler(),
        RBFSampler(gamma=gamma, n_components=500, random_state=16),
        LinearSVC(C=2.0, max_iter=10_000, random_state=16),
    ),
}

for name, model in models.items():
    started = perf_counter()
    model.fit(X_train, y_train)
    fit_seconds = perf_counter() - started
    print(
        f"{name:>15}: accuracy={model.score(X_test, y_test):.3f}, "
        f"fit time={fit_seconds:.3f}s"
    )

近似维度、kernel 带宽与线性模型正则化构成一个耦合的模型选择问题。当精确 kernel 的存储或优化成为瓶颈时，近似才有价值；在小数据集上，它的额外开销可能超过收益。

选择几何模型或核模型

这些方法共享几何语言，却采用不同折中。KNN 保留几乎全部局部细节，并在预测时付出成本；Perceptron 或 linear SVM 把数据压缩为一个超平面；精确非线性 kernel 在训练观测上保留稀疏或稠密展开；kernel 近似则把计算重新移入显式有限维表示。

方法 边界或预测形状 拟合特征 预测与存储 最适合的起始条件 主要风险
1-NN / KNN 局部、不规则 保存数据并构建索引 与存储样本比较 metric 有意义且局部覆盖密集 噪声、维度、延迟
Perceptron 在表示特征中线性 在线错误更新 一次点积 大规模流式线性任务 无最大间隔或概率；含噪时循环
Linear SVM 最大间隔超平面 凸线性优化 一次点积 稀疏高维特征 遗漏非线性结构
RBF SVM 平滑非线性局部边界 成对 kernel 优化 与支持向量比较 具有局部平滑性的中等规模数据 对 \(C\)/\(\gamma\) 敏感且扩展性差
Kernel Ridge 平滑 kernel 回归 稠密线性系统 通常使用全部训练样本 中等 \(n\)、平方损失下的平滑回归 预测稠密且对离群值敏感
SVR epsilon 管道 kernel 回归 受约束凸优化 支持向量展开 中等 \(n\)、允许稀疏误差 \(C\)、\(\epsilon\) 与 kernel 耦合调节
近似 kernel + 线性模型 有限维非线性特征映射 可扩展线性优化 \(D\) 维点积 精确 Gram 矩阵过大 近似误差与额外超参数

不存在普遍的准确率排名。可辩护的选择流程是：

  1. 在比较模型前定义预测单位、目标总体、评估指标与数据划分结构；
  2. 建立经过缩放的线性基线，复杂几何必须展示可重复的增益；
  3. 根据特征语义设计表示和距离，而不是照搬估计器默认值；
  4. 把缩放、度量学习与 kernel 近似置于交叉验证流水线内部；
  5. 联合调节相互耦合的控制量：\(k\) 与 metric/权重，SVM 的 \(C\) 与 kernel 参数，SVR 的 \(C\) 与 \(\epsilon\)，近似维度与下游正则化；
  6. 分别评估任务指标与概率校准；KNN 投票比例和 SVM 得分都不会自动成为可靠概率；
  7. 在接近部署的数据上测试内存、索引构建、更新频率、吞吐量和尾部延迟；
  8. 部署后监控最近距离、支持向量数量、校准、子群体误差与表示漂移。
Python 示例：在一次最终测试前，从 KNN、linear SVM 与 RBF SVM 中选择模型 
from time import perf_counter
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

X, y = make_moons(n_samples=900, noise=0.27, random_state=44)
X_development, X_test, y_development, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=44
)
cv = StratifiedKFold(5, shuffle=True, random_state=44)

candidates = {
    "KNN": (
        Pipeline([("scale", StandardScaler()), ("model", KNeighborsClassifier())]),
        {
            "model__n_neighbors": [3, 7, 15, 31],
            "model__weights": ["uniform", "distance"],
            "model__p": [1, 2],
        },
    ),
    "linear SVM": (
        Pipeline([("scale", StandardScaler()), ("model", SVC(kernel="linear"))]),
        {"model__C": np.logspace(-2, 2, 5)},
    ),
    "RBF SVM": (
        Pipeline([("scale", StandardScaler()), ("model", SVC(kernel="rbf"))]),
        {
            "model__C": np.logspace(-1, 2, 4),
            "model__gamma": np.logspace(-2, 1, 4),
        },
    ),
}

searches = {}
for name, (pipeline, grid) in candidates.items():
    started = perf_counter()
    search = GridSearchCV(pipeline, grid, scoring="accuracy", cv=cv).fit(
        X_development, y_development
    )
    elapsed = perf_counter() - started
    searches[name] = search
    print(
        f"{name:>10}: development CV={search.best_score_:.3f}, "
        f"search time={elapsed:.2f}s"
    )

# Choose with development CV only; the test set has not influenced this decision.
winner_name = max(searches, key=lambda name: searches[name].best_score_)
winner = searches[winner_name].best_estimator_
print("selected model:", winner_name)
print("selected settings:", searches[winner_name].best_params_)
print("untouched test accuracy:", round(winner.score(X_test, y_test), 3))

对于小型且表示良好的数据集，KNN 是直观的局部基线；对于高维稀疏输入，正则化 linear SVM 通常是计算上最强的起点；对于样本量中等且具有明确非线性局部结构的数据，RBF SVM 或 kernel regression 很有竞争力；在更大规模下，学习到的 embedding 配合 ANN 检索，或显式 kernel 近似，往往能在满足运行约束的同时保留几何直觉。

核心结论不是某一种几何永远获胜，而是表示、相似度、正则化、搜索与验证共同定义了一个耦合系统。再复杂的估计器也无法挽救与特征含义相矛盾的距离。
