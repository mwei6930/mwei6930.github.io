概率模型与贝叶斯学习

点预测器只返回一个答案：类别、数值或排序得分。概率模型 返回可能答案上的分布，并说明构造该分布所依赖的假设。当两个最可能标签相同的预测不应被视为同样确定，或者不同错误具有不同代价时，这一区别非常重要。

概率学习区分三个相关对象：

  1. 抽样模型 描述参数固定时观测如何产生，例如 \(p(y\mid x,\theta)\)；
  2. 参数分布 描述对 \(\theta\) 的已有认识。在贝叶斯学习中，它由先验 \(p(\theta)\) 更新为后验 \(p(\theta\mid\mathcal D)\)；
  3. 预测分布 对模型及当前参数知识所蕴含的所有可能结果取平均。

概率式（probabilistic） 比 贝叶斯式（Bayesian） 范围更广。逻辑回归、最大似然 Gaussian naive Bayes 和校准后的 random forest 都会输出概率，却不一定为参数建立后验分布。贝叶斯学习进一步为未知量建立概率模型，并把其不确定性传播到预测中。因此，必须区分“输出一个概率值”与“进行了完整后验推断”。

这一工作流包含两个经常被混淆的层次。推断 使用数据获得未知量或结果上的分布；决策 把该分布与损失或效用函数结合以选择行动。35% 的事件概率是关于不确定性的陈述；它是否足以触发干预，则取决于干预与不干预的相对后果。

问题 数学对象 典型输出
数据可能如何产生？ 似然 \(p(\mathcal D\mid\theta)\) 参数对观测的拟合程度
关于参数知道什么？ 后验 \(p(\theta\mid\mathcal D)\) Credible region 与参数抽样
接下来可能发生什么？ 预测分布 \(p(y_*\mid x_*,\mathcal D)\) 概率、均值、分位数与区间
应采取什么行动？ 后验风险 \(R(a\mid x_*,\mathcal D)\) 最小风险行动
不确定性是否可信？ 校准、覆盖率与诊断 可靠性证据及局限

本章按难度递增构建这一链条。Naive Bayes 与 Gaussian discriminant analysis 展示显式分布假设如何产生分类器；共轭模型展示精确贝叶斯更新；Bayesian regression 与 Gaussian process 传播参数或函数不确定性；近似推断处理无法精确积分的后验。最后回到实践问题：模型的概率与区间是否足以支撑决策。

贝叶斯决策理论

贝叶斯决策理论把不确定信念连接到行动。它并不要求每个系统都必须采用贝叶斯参数先验，而是指出：一旦获得合适的预测分布，在给定损失函数下，理性行动就是期望损失最小的行动。这会暴露固定阈值或原始 accuracy 隐藏的假设。

后验预测

给定训练数据 \(\mathcal D\)、新输入 \(x_*\) 和模型参数 \(\theta\)，贝叶斯预测对后验积分，而不是假装一个拟合参数值绝对正确：

\[ p(y_*\mid x_*,\mathcal D) =\int p(y_*\mid x_*,\theta)\,p(\theta\mid\mathcal D)\,d\theta. \]

两个因子作用不同：\(p(y_*\mid x_*,\theta)\) 表示模型固定时结果的随机变化；\(p(\theta\mid\mathcal D)\) 表示观察有限数据后仍存在的模型参数不确定性。积分是所有合理参数值所给预测的加权平均。

Plug-in prediction 用 \(p(y_*\mid x_*,\hat\theta)\) 替代积分，其中 \(\hat\theta\) 可以是 maximum-likelihood、MAP 或后验均值。当后验高度集中且预测关于 \(\theta\) 近似线性时，它通常便宜且准确；但在数据少、识别弱、发生外推或含非线性变换时，可能过度自信，因为一般而言 \(p(y_*\mid x_*,E[\theta])\ne E[p(y_*\mid x_*,\theta)]\)。

对于成功概率为 \(\theta\) 的 Bernoulli 事件与 \(\operatorname{Beta}(\alpha,\beta)\) 先验，观察到 \(s\) 次成功、\(f\) 次失败后，

\[ \theta\mid\mathcal D\sim\operatorname{Beta}(\alpha+s,\beta+f), \qquad P(y_*=1\mid\mathcal D)=\frac{\alpha+s}{\alpha+\beta+s+f}. \]

最后一项是后验预测概率，也恰好是 \(\theta\) 的后验均值，但这种相等只针对当前 Bernoulli 预测。完整后验仍包含“概率本身有多不确定”的信息。

Python 示例：解析与 Monte Carlo 后验预测 
import numpy as np
from scipy.stats import beta

# Prior knowledge and observed Bernoulli outcomes.
alpha_prior, beta_prior = 2.0, 2.0
successes, failures = 7, 3
alpha_post = alpha_prior + successes
beta_post = beta_prior + failures

# Closed-form posterior predictive probability for the next outcome.
analytic_predictive = alpha_post / (alpha_post + beta_post)

# Monte Carlo integration: average p(y*=1 | theta)=theta over posterior draws.
rng = np.random.default_rng(7)
theta_draws = rng.beta(alpha_post, beta_post, size=100_000)
mc_predictive = theta_draws.mean()
credible_interval = beta.ppf([0.025, 0.975], alpha_post, beta_post)

print(f"posterior: Beta({alpha_post:.0f}, {beta_post:.0f})")
print(f"analytic predictive probability: {analytic_predictive:.4f}")
print(f"Monte Carlo predictive probability: {mc_predictive:.4f}")
print(f"95% credible interval for theta: {credible_interval.round(3)}")

上面的后验区间针对未知事件率 \(\theta\)，不是单个未来二元结果的 95% prediction interval，因为该结果只能为 0 或 1。参数不确定性、结果不确定性与某个估计数值摘要的不确定性应始终分别命名。

损失、风险与 Bayes 最优决策

假设在真实状态 \(y\) 被观察前选择行动 \(a\)，\(L(a,y)\) 是由此产生的损失。离散结果下的 后验风险 为

\[ R(a\mid x,\mathcal D) =E[L(a,Y)\mid x,\mathcal D] =\sum_y L(a,y)p(y\mid x,\mathcal D), \]

连续结果则用积分替代求和。Bayes action 为

\[ a^*(x)=\arg\min_a R(a\mid x,\mathcal D). \]

对称 zero-one loss 中，正确分类代价为 0，任何错误分类代价为 1。最小化风险会选择概率最大的类别，所以 Bayes action 等于 MAP 类别。这个熟悉规则只是一个特例，并非普遍原则。

在二元预测中，令 \(p=P(Y=1\mid x,\mathcal D)\)，false positive 成本为 \(C_{FP}\)，false negative 成本为 \(C_{FN}\)。两种风险为

\[ R(\hat y=1)=C_{FP}(1-p), \qquad R(\hat y=0)=C_{FN}p. \]

当

\[ p>\frac{C_{FP}}{C_{FP}+C_{FN}} \]

时预测类别 1。如果 false negative 的成本是 false positive 的五倍，阈值应为 \(1/(1+5)\approx0.167\)，而不是 0.5。阈值来自后果，并且必须在代表部署环境的验证分布上估计，不能用最终测试集调节。

系统还可以支持 abstention 或转交人工。如果拒绝处理的固定成本 \(C_R\) 小于两个自动行动的风险，就应拒绝。这提供了原则明确的人工复核区域，而不是把低置信度仅当作非正式警告。

Python 示例：在非对称成本与 abstention 下选择最小风险行动 
import numpy as np

prob_positive = np.array([0.05, 0.20, 0.35, 0.60, 0.92])
false_positive_cost = 1.0
false_negative_cost = 5.0
reject_cost = 0.45

# Rows are cases; columns are actions [predict 0, predict 1, reject].
risk_predict_0 = false_negative_cost * prob_positive
risk_predict_1 = false_positive_cost * (1.0 - prob_positive)
risk_reject = np.full_like(prob_positive, reject_cost)
risks = np.column_stack([risk_predict_0, risk_predict_1, risk_reject])

labels = np.array(["predict 0", "predict 1", "refer"])
actions = labels[np.argmin(risks, axis=1)]
threshold_without_rejection = (
    false_positive_cost / (false_positive_cost + false_negative_cost)
)

print(f"cost-sensitive threshold without rejection: {threshold_without_rejection:.3f}")
for probability, case_risks, action in zip(prob_positive, risks, actions):
    print(f"p={probability:.2f} risks={case_risks.round(2)} -> {action}")

非对称二元成本 由成本推导的概率阈值 False-positive 与 false-negative 成本
平方误差 后验预测均值 惩罚随误差平方增长

即使利益相关者无法提供精确货币成本，贝叶斯决策理论仍有价值。写出合理的损失矩阵，并在一组成本范围内测试结论，可以让运行权衡可见。若一个模型的 accuracy 略低，但概率校准更好并能在真正重要的损失下支持更优决策，它仍可能是更好的选择。

生成式与判别式建模

可以根据所建模的分布组织概率分类器。生成式分类器 建模特征与标签如何联合出现；判别式分类器 直接建模观测特征条件下的标签，或学习可进一步获得条件概率的决策函数。

联合分布与条件分布建模

生成式分类器把联合分布分解为

\[ p(x,y)=p(y)p(x\mid y). \]

预测时用 Bayes rule 转换为

\[ p(y=c\mid x) =\frac{p(y=c)p(x\mid y=c)}{\sum_k p(y=k)p(x\mid y=k)}. \]

类别先验 \(p(y=c)\) 描述流行率，类条件密度 \(p(x\mid y=c)\) 描述类别 \(c\) 的观测形态。Naive Bayes、LDA、QDA、hidden Markov model 与许多 mixture model 都采用这一路径。因为联合模型定义了 \(x\) 的分布，原则上可生成合成观测、判断输入是否合理、在某些场景利用无标签观测，并通过边缘化处理缺失特征。

判别式概率模型则直接针对

\[ p(y\mid x;\theta). \]

逻辑回归、conditional random field 与判别式训练的神经分类器都是例子。SVM 也属于判别式模型，尽管其原始间隔不是自动校准概率。判别式模型无需分配容量拟合 \(p(x)\)，可以专注于预测所需的边界或条件概率。

这些术语描述的是分解方式，而非模型质量。生成式模型可以非常灵活，判别式模型也可能严重设定错误。同样，从条件语言模型生成文本，并不意味着系统每个部分都属于这一统计意义上的生成式分类器。

优势与权衡

生成式假设可以降低数据需求。如果每个类别确实是特征独立的 Gaussian，估计类别均值与方差在统计上很高效；判别边界可能需要更多标签样本才能发现同一规律。假设错误时优势会反转：直接条件模型避免拟合 \(x\) 中与目标无关的部分，并可能渐近接近更好的决策边界。

这形成一个实用的偏差—方差权衡：

  • 强且近似正确的假设 可使生成式模型用小样本快速学习；
  • 较弱或被违反的假设 可能使概率有偏，即使分类 accuracy 尚可；
  • 判别式训练 在标签数据充足时往往占优，但不会自动解决校准、外推或分布漂移；
  • 只有在完整生成模型可信且缺失机制可辩护时，才能自然地通过边缘分布处理 缺失特征。
Python 示例：比较生成式与判别式模型随样本量增长的学习表现 
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import log_loss
from sklearn.naive_bayes import GaussianNB

rng = np.random.default_rng(12)

def sample_gaussian_classes(n, rng):
    # The GaussianNB assumptions are deliberately correct in this experiment.
    y = rng.integers(0, 2, size=n)
    means = np.where(y[:, None] == 1, 0.65, -0.65)
    X = rng.normal(loc=means, scale=1.0, size=(n, 8))
    return X, y

X_test, y_test = sample_gaussian_classes(20_000, rng)

for n_train in [20, 50, 200, 1_000]:
    scores = {"GaussianNB": [], "LogisticRegression": []}
    for repeat in range(20):
        X_train, y_train = sample_gaussian_classes(n_train, rng)
        models = {
            "GaussianNB": GaussianNB(),
            "LogisticRegression": LogisticRegression(max_iter=2_000),
        }
        for name, model in models.items():
            model.fit(X_train, y_train)
            probability = model.predict_proba(X_test)[:, 1]
            scores[name].append(log_loss(y_test, probability))

    result = {name: np.mean(values) for name, values in scores.items()}
    print(f"n={n_train:4d}: " + ", ".join(
        f"{name} log-loss={value:.3f}" for name, value in result.items()
    ))

这个实验有意让 Gaussian naive Bayes 处于有利条件，展示正确结构假设可以带来的收益，而不是建立普遍排名。负责任的比较还应在相关、重尾与漂移特征下重复，并同时评估决策与概率质量。

实践问题不能孤立地问“生成式还是判别式”，而应问：哪些假设可信、需要哪些输出、有多少标签数据，以及部署中如何评价错误。

Naive Bayes

Naive Bayes 是一组建立在一个强简化上的生成式分类器：类别已知后，各特征条件独立。该假设很少严格成立，却把困难的高维密度估计转化为许多小型一维估计。模型因而速度快、天然支持稀疏数据，并成为文本与类别问题的重要基线。

对于特征向量 \(x=(x_1,\ldots,x_d)\) 与类别 \(c\)，

\[ p(x\mid y=c)=\prod_{j=1}^{d}p(x_j\mid y=c), \]

所以分类使用

\[ \hat y =\arg\max_c p(y=c)\prod_{j=1}^{d}p(x_j\mid y=c). \]

大量概率相乘会造成数值下溢，因此实现比较 log score：

\[ g_c(x)=\log p(y=c)+\sum_{j=1}^{d}\log p(x_j\mid y=c). \]

归一化分母 \(p(x)\) 对所有类别相同，在只需获胜类别时可省略；需要后验概率时，则必须通常通过 log-sum-exp 归一化恢复。

Gaussian、Multinomial、Bernoulli 与 Categorical 模型

Naive 指条件独立结构；特征似然仍必须匹配数据表示。

变体 特征模型 合适表示 重要假设
Gaussian NB \(x_j\mid y=c\sim\mathcal N(\mu_{cj},\sigma_{cj}^2)\) 连续测量 每个特征在类别条件下为 Gaussian
Multinomial NB 具有类别特定事件概率的计数向量 Token count、事件计数 计数来自重复类别事件
Bernoulli NB \(x_j\in\{0,1\}\) Token presence、二元指示量 存在/缺失有信息，忽略重复次数
Categorical NB 每个特征与类别有一个类别分布 颜色、地区、设备类型 类别是离散状态而非数值大小

Gaussian NB 为每个类别—特征对估计一个均值与方差。单维贡献呈二次形态，但对角协方差假设排除了类别内部特征相关。数学上无需缩放，因为每个特征拥有自身方差；不过变换可能改善 Gaussian 近似。

Multinomial NB 常用于文本分类。对类别 \(c\)，token \(j\) 的概率为 \(\phi_{cj}\)，文档提供 token count \(x_j\)：

\[ \log p(x\mid y=c)=\text{constant}(x)+\sum_j x_j\log\phi_{cj}. \]

重复出现会重复累积证据。文档长度影响似然，所以该模型描述的是计数生成事件，而不是文档间的 Euclidean 距离。

Bernoulli NB 先把每个特征二值化，同时为出现和未出现事件计分：

\[ \log p(x\mid y=c) =\sum_j x_j\log\phi_{cj}+(1-x_j)\log(1-\phi_{cj}). \]

当一个词是否出现很重要，而重复次数贡献很小时，它可能更合适。Categorical NB 把每个输入列视为多值状态；整数编码只是标签，不代表顺序大小。

Python 示例：实现支持未知类别的 Categorical Naive Bayes 
from collections import Counter
import numpy as np

class CategoricalNaiveBayes:
    def __init__(self, alpha=1.0):
        self.alpha = float(alpha)

    def fit(self, X, y):
        X = np.asarray(X, dtype=object)
        y = np.asarray(y, dtype=object)
        self.classes_, class_counts = np.unique(y, return_counts=True)
        self.log_prior_ = {
            c: np.log(count / len(y))
            for c, count in zip(self.classes_, class_counts)
        }
        self.levels_ = [set(X[:, j]) | {"<UNK>"} for j in range(X.shape[1])]
        self.log_prob_ = {}

        for c in self.classes_:
            rows = X[y == c]
            self.log_prob_[c] = []
            for j, levels in enumerate(self.levels_):
                counts = Counter(rows[:, j])
                denominator = len(rows) + self.alpha * len(levels)
                table = {
                    level: np.log((counts[level] + self.alpha) / denominator)
                    for level in levels
                }
                self.log_prob_[c].append(table)
        return self

    def predict(self, X):
        X = np.asarray(X, dtype=object)
        predictions = []
        for row in X:
            scores = {}
            for c in self.classes_:
                score = self.log_prior_[c]
                for j, value in enumerate(row):
                    level = value if value in self.levels_[j] else "<UNK>"
                    score += self.log_prob_[c][j][level]
                scores[c] = score
            predictions.append(max(scores, key=scores.get))
        return np.asarray(predictions)

X = [
    ["sunny", "high"], ["sunny", "normal"], ["rain", "high"],
    ["rain", "normal"], ["overcast", "high"], ["overcast", "normal"],
]
y = ["stay", "go", "stay", "go", "go", "go"]

model = CategoricalNaiveBayes(alpha=1.0).fit(X, y)
print(model.predict([["sunny", "high"], ["snow", "normal"]]))

    examples, model.predict(examples), probabilities
):

条件独立与平滑

条件独立意味着模型中任意特征对都满足

\[ X_j\perp X_k\mid Y. \]

它 不表示 特征在边际上独立。两个词可能因都与某一主题相关而频繁共现；在给定主题类别后，这种依赖可能消失或减弱。如果特征在每个类别内部仍然冗余，例如同时加入一个测量值及多个近重复变换，假设就会失败。

即使存在依赖，Naive Bayes 仍可能分类良好，因为类别得分排序正确的要求弱于联合密度正确。它的后验概率更脆弱：相关证据会被重复相乘，常导致过度自信。

对大小为 \(V\) 的 multinomial 事件词表，加性平滑估计

\[ \hat\phi_{cj} =\frac{N_{cj}+\alpha}{\sum_{k=1}^{V}N_{ck}+\alpha V}, \]

其中 \(N_{cj}\) 是类别 \(c\) 中事件 \(j\) 的计数。\(\alpha=1\) 时为 Laplace smoothing。平滑防止未见事件把整个文档在某类别下的概率变为零，也会把稀有估计向更均匀的分布收缩。分母必须匹配事件模型：categorical 特征每列有独立类别表，multinomial 文本则共享事件词表。

Python 示例：观察条件相关特征造成的过度自信 
import numpy as np
from sklearn.metrics import accuracy_score, brier_score_loss, log_loss
from sklearn.naive_bayes import GaussianNB
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(21)
n = 8_000

    latent + rng.normal(scale=0.05, size=n) for _ in range(8)
])

    model = GaussianNB().fit(X[train], y[train])
    probability = model.predict_proba(X[test])[:, 1]
    prediction = probability >= 0.5
    print(
        f"{name:24s}",
        f"accuracy={accuracy_score(y[test], prediction):.3f}",
        f"log-loss={log_loss(y[test], probability):.3f}",
        f"Brier={brier_score_loss(y[test], probability):.3f}",
        f"extreme={(np.abs(probability - 0.5) > 0.49).mean():.3f}",
    )

模型可能保留合理决策边界，而 log loss 与 Brier score 恶化。因此，当概率、阈值或期望成本将被实际使用时，应以概率敏感指标和 reliability diagram 评估 Naive Bayes。

Naive Bayes 仍适合作为高维稀疏基线、流式计数更新，以及延迟或解释性比最后一点预测增益更重要的场景。其假设应被视为可检验后果的计算设计，而不是现实特征从不交互的断言。

Gaussian 判别分析

Gaussian discriminant analysis 用每个类别的多元 Gaussian 模型，取代 Gaussian naive Bayes 的逐特征独立。协方差矩阵表示相关性，因此模型可以描述倾斜椭圆云，而不仅是轴对齐分布。

对先验为 \(\pi_c\)、均值为 \(\mu_c\)、协方差为 \(\Sigma_c\) 的类别 \(c\)，

\[ p(x\mid y=c) =\frac{1}{(2\pi)^{d/2}|\Sigma_c|^{1/2}} \exp\left[-\frac12(x-\mu_c)^T\Sigma_c^{-1}(x-\mu_c)\right]. \]

二次型是平方 Mahalanobis 距离。它与 Euclidean 距离不同，会相对于类别协方差度量位移：沿高方差方向的移动，比在高度集中的方向上同样大小的移动更不意外。行列式 \(|\Sigma_c|\) 则校正类别分布占据的体积。

取对数并删除类别间共享项，得到判别得分

\[ \delta_c(x) =-\frac12\log|\Sigma_c| -\frac12(x-\mu_c)^T\Sigma_c^{-1}(x-\mu_c) +\log\pi_c. \]

预测选择得分最大的类别。LDA 与 QDA 的区别完全在于协方差如何共享。

Linear Discriminant Analysis

LDA 假设共同协方差矩阵：

\[ \Sigma_1=\cdots=\Sigma_C=\Sigma. \]

从每个类别得分中删除共同二次项 \(-\tfrac12x^T\Sigma^{-1}x\) 后，剩余判别函数关于 \(x\) 线性：

\[ \delta_c^{LDA}(x) =x^T\Sigma^{-1}\mu_c -\frac12\mu_c^T\Sigma^{-1}\mu_c +\log\pi_c. \]

两类得分相等定义一个超平面。因此，LDA 把生成式 Gaussian 模型与线性决策边界结合起来；由于 \(\Sigma^{-1}\) 会考虑相关特征，边界仍可倾斜。

对于 \(C\) 个类别和 \(d\) 个特征，LDA 估计 \(C\) 个均值，却只估计一个 \(d\times d\) 协方差矩阵。共享会降低方差，在每类观测较少时尤其有用。它还支持监督投影到最多 \(C-1\) 个判别维度，不过分类与降维是同一拟合量的不同用途。

Python 示例：复现 LDA 判别计算 
import numpy as np
from scipy.special import softmax
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

rng = np.random.default_rng(4)
covariance = np.array([[1.2, 0.7], [0.7, 1.0]])
X0 = rng.multivariate_normal([-1.0, 0.0], covariance, size=120)
X1 = rng.multivariate_normal([1.0, 0.8], covariance, size=80)
X = np.vstack([X0, X1])
y = np.r_[np.zeros(len(X0), dtype=int), np.ones(len(X1), dtype=int)]

classes = np.unique(y)
priors = np.array([(y == c).mean() for c in classes])
means = np.vstack([X[y == c].mean(axis=0) for c in classes])

# Maximum-likelihood pooled within-class covariance: divide by total n.
scatter = sum((X[y == c] - means[c]).T @ (X[y == c] - means[c]) for c in classes)
pooled_covariance = scatter / len(X)
precision = np.linalg.inv(pooled_covariance)

X_new = np.array([[-0.5, 0.1], [0.4, 0.5], [1.5, 1.0]])
scores = np.column_stack([
    X_new @ precision @ means[c]
    - 0.5 * means[c] @ precision @ means[c]
    + np.log(priors[c])
    for c in classes
])
manual_probability = softmax(scores, axis=1)

sklearn_lda = LinearDiscriminantAnalysis(solver="lsqr").fit(X, y)
library_probability = sklearn_lda.predict_proba(X_new)

print("manual probabilities:\n", manual_probability.round(4))
print("scikit-learn probabilities:\n", library_probability.round(4))
print("maximum absolute difference:", np.max(np.abs(manual_probability - library_probability)))

Quadratic Discriminant Analysis

QDA 为每个类别估计独立协方差 \(\Sigma_c\)。类别特定的 \(x^T\Sigma_c^{-1}x\) 不再抵消，等得分集合成为二次曲面，因此可表示由不同方向或离散程度造成的弯曲边界。

这种灵活性代价很高。每个完整协方差矩阵含 \(d(d+1)/2\) 个唯一元素；\(C\) 类 QDA 估计的协方差参数约为 LDA 的 \(C\) 倍。若某类独立观测数不超过 \(d\)，经验协方差会奇异；在真正奇异前，求逆也可能数值不稳。此时需要更多数据、降维、对角协方差或正则化。

上方展示共享协方差足够的情况；下方展示类别协方差不同时 QDA 捕获弯曲边界。来源：scikit-learn LDA/QDA example。

Python 示例：在共享与不同协方差下比较 LDA 和 QDA 
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis
from sklearn.metrics import accuracy_score, log_loss

rng = np.random.default_rng(10)

def make_problem(n_per_class, covariance_0, covariance_1):
    X0 = rng.multivariate_normal([-0.8, 0.0], covariance_0, size=n_per_class)
    X1 = rng.multivariate_normal([0.8, 0.5], covariance_1, size=n_per_class)
    return np.vstack([X0, X1]), np.r_[np.zeros(n_per_class), np.ones(n_per_class)]

shared = np.array([[1.0, 0.65], [0.65, 1.0]])
different_0 = np.array([[1.4, 0.9], [0.9, 0.8]])
different_1 = np.array([[0.5, -0.35], [-0.35, 1.3]])

for setting, cov0, cov1 in [
    ("shared covariance", shared, shared),
    ("different covariances", different_0, different_1),
]:
    X_train, y_train = make_problem(250, cov0, cov1)
    X_test, y_test = make_problem(5_000, cov0, cov1)
    print(setting)
    for model in [LinearDiscriminantAnalysis(), QuadraticDiscriminantAnalysis()]:
        model.fit(X_train, y_train)
        probability = model.predict_proba(X_test)[:, 1]
        print(
            f"  {model.__class__.__name__:30s}",
            f"accuracy={accuracy_score(y_test, probability >= 0.5):.3f}",
            f"log-loss={log_loss(y_test, probability):.3f}",
        )

协方差 shrinkage 把不稳定的经验协方差推向结构化目标，通常是缩放单位矩阵：

\[ \hat\Sigma_{shrink}=(1-\lambda)\hat\Sigma+\lambda\tau I, \qquad 0\leq\lambda\leq1. \]

小 \(\lambda\) 更信任经验相关，大 \(\lambda\) 则抑制相关。这不只是数值补丁，而是关于样本能支撑多少相关结构的偏差—方差选择。

Gaussian NB 每类对角 \(\Sigma_c\) 通常二次 协方差成本最低；忽略相关
LDA 一个完整共享 \(\Sigma\) 线性 强共享；较低方差
QDA 每类完整 \(\Sigma_c\) 二次 灵活；高方差且数据需求高

贝叶斯参数学习

经典点估计为未知参数寻找一个值；贝叶斯参数学习则寻找一个分布，表示先验信息与观测证据结合后仍然合理的取值。均值或众数可以用于摘要，但分布形状和离散程度是结果的一部分，不是事后可选的误差条。

先验、似然与后验

参数 \(\theta\) 与数据 \(\mathcal D\) 的 Bayes rule 为

\[ p(\theta\mid\mathcal D) =\frac{p(\mathcal D\mid\theta)p(\theta)}{p(\mathcal D)}, \qquad p(\mathcal D)=\int p(\mathcal D\mid\theta)p(\theta)d\theta. \]

  • 先验 \(p(\theta)\) 表示当前数据之前的不确定性；
  • 似然 \(p(\mathcal D\mid\theta)\) 衡量每个参数值解释观测的程度。把它视为 \(\theta\) 的函数时，在与先验结合并归一化前，它不是 \(\theta\) 上的概率分布；
  • 后验 \(p(\theta\mid\mathcal D)\) 是更新后的分布；
  • 证据 或边际似然 \(p(\mathcal D)\) 归一化后验，并衡量整个模型在先验平均后预测已观测数据的能力。

独立观测的似然项相乘，log-likelihood 项相加。样本量增加时，正则且可识别的模型通常越来越由数据主导；数据较弱时，先验和似然都可能实质影响后验。

估计方式 优化或积分 保留内容
Maximum likelihood \(\hat\theta_{MLE}=\arg\max_\theta p(\mathcal D\mid\theta)\) 一个受数据支持的参数值
Maximum a posteriori \(\hat\theta_{MAP}=\arg\max_\theta p(\mathcal D\mid\theta)p(\theta)\) 一个经先验正则化的参数值
完整贝叶斯推断 计算或近似 \(p(\theta\mid\mathcal D)\) 合理参数值上的分布

MAP 经常类似正则化：零均值 Gaussian 先验产生 \(L_2\) 惩罚，Laplace 先验产生 \(L_1\) 惩罚。等价性只针对众数；只有 ridge 或 lasso 系数并不会提供后验分布或后验预测不确定性。

共轭先验

如果后验与先验属于同一分布族，称先验与似然 共轭。共轭把积分与重复更新转化为分布参数上的代数运算，尤其适合教学、在线更新以及大型概率模型中的组件。

Beta-Bernoulli 模型中的更新是加性的：

\[ \operatorname{Beta}(\alpha,\beta) +(s\text{ successes},f\text{ failures}) \longrightarrow \operatorname{Beta}(\alpha+s,\beta+f). \]

\(\alpha-1\) 与 \(\beta-1\) 有时被解释为先验伪计数，但不应过度延伸：先验编码完整分布，而 \(\alpha+\beta\) 等参数控制集中程度。

Python 示例：执行顺序 Beta-Bernoulli 更新 
import numpy as np
from scipy.stats import beta

observations = np.array([1, 0, 1, 1, 1, 0, 1, 1, 0, 1])
alpha, beta_parameter = 2.0, 2.0

print("step  mean   95% credible interval")
for step, outcome in enumerate(observations, start=1):
    # A success increments alpha; a failure increments beta.
    alpha += outcome
    beta_parameter += 1 - outcome
    mean = alpha / (alpha + beta_parameter)
    interval = beta.ppf([0.025, 0.975], alpha, beta_parameter)
    print(f"{step:>4d}  {mean:.3f}  [{interval[0]:.3f}, {interval[1]:.3f}]")

对于类别概率 \(\pi=(\pi_1,\ldots,\pi_K)\) 的 \(K\) 类结果，共轭先验是 Dirichlet：

\[ \pi\sim\operatorname{Dirichlet}(\alpha_1,\ldots,\alpha_K), \qquad \pi\mid\mathcal D\sim\operatorname{Dirichlet}(\alpha_1+n_1,\ldots,\alpha_K+n_K). \]

类别 \(k\) 的后验预测概率为

\[ P(y_*=k\mid\mathcal D)=\frac{\alpha_k+n_k}{\sum_j(\alpha_j+n_j)}. \]

Python 示例：Dirichlet-Categorical 后验预测 
import numpy as np

classes = np.array(["basic", "plus", "premium"])
prior = np.array([1.0, 1.0, 1.0])
observed_counts = np.array([8, 3, 1])
posterior = prior + observed_counts
predictive = posterior / posterior.sum()

rng = np.random.default_rng(5)
probability_draws = rng.dirichlet(posterior, size=50_000)
intervals = np.quantile(probability_draws, [0.025, 0.975], axis=0)

for index, name in enumerate(classes):
    print(
        f"{name:7s}: predictive={predictive[index]:.3f}, "
        f"95% interval for class probability="
        f"[{intervals[0, index]:.3f}, {intervals[1, index]:.3f}]"
    )

共轭模型还包括 Beta-Binomial、Dirichlet-Multinomial、Gamma-Poisson 与 Normal-Normal。公式很方便，但共轭性应服从科学测量模型，而不能反过来主导选择。对于强删失、有界或重尾观测，仅因 Gaussian likelihood 有闭式解并不足以使它合理。

后验预测分布

后验回答参数问题，多数部署系统则需要结果问题。后验预测分布为

\[ p(\tilde y\mid\mathcal D) =\int p(\tilde y\mid\theta)p(\theta\mid\mathcal D)d\theta. \]

若 Normal likelihood 的观测方差 \(\sigma^2\) 已知，且 Normal 先验为

\[ y_i\mid\mu\sim\mathcal N(\mu,\sigma^2), \qquad \mu\sim\mathcal N(\mu_0,\tau_0^2), \]

后验为 Normal，参数满足

\[ \tau_n^2=\left(\frac{1}{\tau_0^2}+\frac{n}{\sigma^2}\right)^{-1}, \qquad \mu_n=\tau_n^2\left(\frac{\mu_0}{\tau_0^2}+\frac{n\bar y}{\sigma^2}\right). \]

单个未来观测的预测分布为

\[ \tilde y\mid\mathcal D\sim\mathcal N(\mu_n,\sigma^2+\tau_n^2). \]

方差包含两项：\(\sigma^2\) 是模型下不可约的结果变异，\(\tau_n^2\) 是均值不确定性。更多数据会缩小第二项，却不会消除第一项。

Python 示例：分离参数不确定性与结果不确定性 
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(14)
true_mean = 2.0
observation_sd = 1.5
prior_mean, prior_sd = 0.0, 2.0
all_data = rng.normal(true_mean, observation_sd, size=100)

for n in [1, 5, 20, 100]:
    sample = all_data[:n]
    posterior_variance = 1.0 / (
        1.0 / prior_sd**2 + n / observation_sd**2
    )
    posterior_mean = posterior_variance * (
        prior_mean / prior_sd**2 + sample.sum() / observation_sd**2
    )
    predictive_sd = np.sqrt(observation_sd**2 + posterior_variance)
    interval = norm.interval(0.95, loc=posterior_mean, scale=predictive_sd)
    print(
        f"n={n:3d}: posterior mean={posterior_mean:.3f}, "
        f"parameter sd={np.sqrt(posterior_variance):.3f}, "
        f"predictive sd={predictive_sd:.3f}, interval={np.round(interval, 3)}"
    )

Prior predictive check 先从先验抽参数，再从 likelihood 模拟数据，用于拟合前检查先验是否蕴含合理尺度的观测。Posterior predictive check 改用后验抽样，并把复制数据的有意义摘要与真实数据比较。两者都不能证明模型为真，却能揭示与现象不相容的假设。

当数据较弱或模型仅部分可识别时，应进行 prior sensitivity 分析。在多个科学上合理的先验下重新拟合，比较后验预测与决策，而不只比较参数均值。若运行结论随先验剧烈变化，这种依赖就是结果的一部分，必须报告。

贝叶斯线性回归与逻辑回归

贝叶斯回归采用熟悉的预测函数，但把系数视为不确定量。它不只返回 \(\hat w\)，而是得到 \(p(w\mid\mathcal D)\)，并在该分布上平均预测。先验正则化支持较弱的方向，后验协方差则记录哪些系数组合仍然不确定。

贝叶斯线性回归

考虑 Gaussian 线性模型

\[ y=Xw+\varepsilon, \qquad \varepsilon\sim\mathcal N(0,\sigma^2I), \]

及 Gaussian 先验

\[ w\sim\mathcal N(m_0,S_0). \]

似然和先验共轭，所以后验仍为 Gaussian：

\[ S_N=\left(S_0^{-1}+\frac{1}{\sigma^2}X^TX\right)^{-1}, \]

\[ m_N=S_N\left(S_0^{-1}m_0+\frac{1}{\sigma^2}X^Ty\right). \]

\(S_0^{-1}\) 是先验精度，\(X^TX/\sigma^2\) 是数据精度，后验精度为两者之和。\(X\) 充分测量的系数方向会集中；共线或观测较弱的方向保持宽广，并受先验更强影响。

对于新行向量 \(x_*\)，

\[ y_*\mid x_*,\mathcal D \sim \mathcal N\left(x_*^Tm_N,\;\sigma^2+x_*^TS_Nx_*\right). \]

第一项方差是观测噪声，第二项是投影到新输入上的系数不确定性。外推点的特征组合未被训练数据严格约束，因此第二项通常更大。

Python 示例：闭式贝叶斯多项式回归 
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(2)
x = np.linspace(-1.0, 1.0, 18)
y = 0.4 + 1.2 * x - 0.8 * x**2 + rng.normal(scale=0.25, size=len(x))

def design(values):
    # Intercept, linear term, and quadratic term.
    values = np.asarray(values)
    return np.column_stack([np.ones_like(values), values, values**2])

X = design(x)
noise_sd = 0.25
prior_mean = np.zeros(X.shape[1])
prior_covariance = 4.0 * np.eye(X.shape[1])

prior_precision = np.linalg.inv(prior_covariance)
posterior_covariance = np.linalg.inv(
    prior_precision + X.T @ X / noise_sd**2
)
posterior_mean = posterior_covariance @ (
    prior_precision @ prior_mean + X.T @ y / noise_sd**2
)

x_test = np.array([-1.5, 0.0, 1.5])
X_test = design(x_test)
mean = X_test @ posterior_mean
parameter_variance = np.einsum("ij,jk,ik->i", X_test, posterior_covariance, X_test)
predictive_sd = np.sqrt(noise_sd**2 + parameter_variance)
lower, upper = norm.interval(0.95, loc=mean, scale=predictive_sd)

print("posterior coefficient mean:", posterior_mean.round(3))
for value, prediction, sd, lo, hi in zip(x_test, mean, predictive_sd, lower, upper):
    print(f"x={value:>4.1f}: mean={prediction:>6.3f}, sd={sd:.3f}, 95% PI=[{lo:.3f}, {hi:.3f}]")

尽管假设噪声方差恒定，区间仍会在训练范围外变宽，这是外推多项式系数产生的 epistemic uncertainty。但它仍以多项式模型正确为条件；若模型没有表示变化点或遗漏变量的可能性，再窄的区间也无法涵盖这些机制。

预测带反映拟合 Bayesian ridge 模型下的不确定性；不同拟合说明 empirical-Bayes 超参数优化可能依赖初始化。来源：scikit-learn Bayesian ridge example。

BayesianRidge 通常通过迭代最大化边际似然估计系数和噪声精度。这称为 empirical Bayes 或 type-II maximum likelihood：超参数以点估计，而不是在 hyperprior 下被完整积分。该方法实用且高效，但其不确定性输出不应被描述为包含全部超参数不确定性。

贝叶斯逻辑回归

二元逻辑回归使用

\[ P(y_i=1\mid x_i,w)=\sigma(x_i^Tw), \qquad \sigma(z)=\frac{1}{1+e^{-z}}. \]

若 Gaussian 先验为 \(w\sim\mathcal N(0,\Lambda^{-1})\)，忽略常数后的 log posterior 为

\[ \log p(w\mid X,y) =\sum_i\left[y_i x_i^Tw-\log(1+e^{x_i^Tw})\right] -\frac12w^T\Lambda w. \]

在匹配惩罚下，其众数等价于 \(L_2\) 正则逻辑回归。与 Gaussian 线性回归不同，Bernoulli-logistic likelihood 与 Gaussian 先验不共轭。后验并非精确 Gaussian，预测概率

\[ P(y_*=1\mid x_*,\mathcal D) =\int\sigma(x_*^Tw)p(w\mid\mathcal D)dw \]

也没有初等闭式解，需要 Laplace approximation、variational inference、expectation propagation 或 Monte Carlo。

Laplace approximation 首先寻找 MAP 系数 \(\hat w\)，再用众数附近的二次函数近似 negative log posterior。若

\[ H=X^TWX+\Lambda, \qquad W_{ii}=\hat p_i(1-\hat p_i), \]

则

\[ p(w\mid\mathcal D)\approx\mathcal N(\hat w,H^{-1}). \]

逆 Hessian 是局部协方差估计。当后验近似单峰且主要概率质量附近近似二次时，它信息充分；但无法表示强偏斜、重尾或多峰。

Python 示例：使用 Laplace approximation 进行贝叶斯逻辑回归 
import numpy as np
from scipy.optimize import minimize
from scipy.special import expit

rng = np.random.default_rng(15)
x = rng.normal(size=90)
true_probability = expit(-0.3 + 1.4 * x)
y = rng.binomial(1, true_probability)
X = np.column_stack([np.ones_like(x), x])

# A weak prior on the intercept and a stronger regularizing prior on the slope.
prior_precision = np.diag([0.05, 0.5])

def objective(w):
    z = X @ w
    negative_log_likelihood = np.sum(np.logaddexp(0.0, z) - y * z)
    return negative_log_likelihood + 0.5 * w @ prior_precision @ w

def gradient(w):
    return X.T @ (expit(X @ w) - y) + prior_precision @ w

fit = minimize(objective, x0=np.zeros(2), jac=gradient, method="BFGS")
map_w = fit.x
fitted_probability = expit(X @ map_w)
weights = fitted_probability * (1.0 - fitted_probability)
hessian = X.T @ (weights[:, None] * X) + prior_precision
laplace_covariance = np.linalg.inv(hessian)

# Integrate predictions over the approximate posterior by Monte Carlo.
x_test = np.array([-2.0, 0.0, 2.0])
X_test = np.column_stack([np.ones_like(x_test), x_test])
rng = np.random.default_rng(16)
w_draws = rng.multivariate_normal(map_w, laplace_covariance, size=100_000)
integrated_probability = expit(X_test @ w_draws.T).mean(axis=1)
plugin_probability = expit(X_test @ map_w)

print("MAP coefficients:", map_w.round(3))
print("posterior standard deviations:", np.sqrt(np.diag(laplace_covariance)).round(3))
for value, plug_in, integrated in zip(x_test, plugin_probability, integrated_probability):
    print(f"x={value:>4.1f}: plug-in={plug_in:.3f}, posterior-integrated={integrated:.3f}")

当系数不确定性较大时，后验积分常把极端 plug-in 概率推向 0.5，但这不是普遍校准保证。设定错误的 likelihood、有偏样本或发生漂移的部署总体仍可能产生自信且错误的概率。

当系数不确定性、小样本正则化与决策敏感预测重要时，贝叶斯线性和逻辑回归很有价值。它们仍然是条件模型：因果解释仍需合适设计和识别论证，后验不确定性不会修复混杂或泄漏。

Gaussian Process

Gaussian process（GP）是函数上的概率分布。它不先选有限组基函数系数，而是通过均值函数 \(m(x)\) 和协方差 kernel \(k(x,x')\) 规定哪些函数值应相似：

\[ f\sim\mathcal{GP}(m,k). \]

这表示对任意有限输入 \(x_1,\ldots,x_n\)，

\[ \begin{bmatrix}f(x_1)\\ \vdots\\ f(x_n)\end{bmatrix} \sim \mathcal N\left( \begin{bmatrix}m(x_1)\\ \vdots\\ m(x_n)\end{bmatrix}, K \right), \qquad K_{ij}=k(x_i,x_j). \]

Kernel 因而是函数结构上的先验。RBF kernel

\[ k_{RBF}(x,x')=\sigma_f^2\exp\left(-\frac{\lVert x-x'\rVert^2}{2\ell^2}\right) \]

包含幅度 \(\sigma_f^2\) 与 length scale \(\ell\)。小 \(\ell\) 允许快速变化，大 \(\ell\) 使相距较远的输入保持耦合并偏好更平滑变化。Matérn kernel 更显式地控制可微性，periodic kernel 编码重复，和与积可组合假设。Kernel 选择是模型设计，而不是装饰性的相似度选项。

拟合前，每条曲线都是 kernel 先验下的合理函数；条件化迫使后验函数在观测附近一致，而其他位置保留更多变化。来源：scikit-learn GP prior/posterior example。

Gaussian Process Regression

假设观测满足

\[ y=f(X)+\varepsilon, \qquad \varepsilon\sim\mathcal N(0,\sigma_n^2I). \]

令 \(K=K(X,X)\)、\(K_*=K(X,X_*)\)、\(K_{**}=K(X_*,X_*)\)。零先验均值下，对联合 Gaussian 条件化可得

\[ E[f_*\mid X,y,X_*] =K_*^T(K+\sigma_n^2I)^{-1}y, \]

\[ \operatorname{Cov}(f_*\mid X,y,X_*) =K_{**}-K_*^T(K+\sigma_n^2I)^{-1}K_*. \]

均值是观测的 kernel 加权插值；协方差等于先验不确定性减去与训练点相关所解释的部分。若要预测带噪未来观测而非潜在函数，应向后验协方差再加 \(\sigma_n^2I\)。

实现应采用 Cholesky factorization，而不是显式形成逆矩阵。可以加入较小的正对角 jitter 保证数值稳定；已知观测噪声属于统计模型，不应与纯数值 jitter 混淆。

Python 示例：由 kernel 矩阵计算 Gaussian-process 后验 
import numpy as np
from scipy.linalg import cho_solve, solve_triangular
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF

rng = np.random.default_rng(6)
X = np.linspace(0.0, 5.0, 12)[:, None]
y = np.sin(X[:, 0]) + rng.normal(scale=0.15, size=len(X))
X_test = np.linspace(-0.5, 5.5, 40)[:, None]
length_scale = 0.9
noise_sd = 0.15

def rbf(A, B, ell):
    squared_distance = (A[:, None, :] - B[None, :, :]) ** 2
    return np.exp(-squared_distance.sum(axis=2) / (2.0 * ell**2))

K = rbf(X, X, length_scale) + noise_sd**2 * np.eye(len(X))
K_cross = rbf(X, X_test, length_scale)
K_test = rbf(X_test, X_test, length_scale)

L = np.linalg.cholesky(K)
alpha = cho_solve((L, True), y)
manual_mean = K_cross.T @ alpha
v = solve_triangular(L, K_cross, lower=True)
manual_variance = np.clip(np.diag(K_test) - np.sum(v**2, axis=0), 0.0, None)

library = GaussianProcessRegressor(
    kernel=RBF(length_scale=length_scale, length_scale_bounds="fixed"),
    alpha=noise_sd**2,
    optimizer=None,
).fit(X, y)
library_mean, library_sd = library.predict(X_test, return_std=True)

print("max mean difference:", np.max(np.abs(manual_mean - library_mean)))
print("max latent SD difference:", np.max(np.abs(np.sqrt(manual_variance) - library_sd)))
print("edge/interior latent SD:", np.round(library_sd[[0, 20, -1]], 3))

Kernel 与函数空间先验

可以为 kernel 超参数指定先验并积分，但许多 GP 库通过最大化 log marginal likelihood 选择超参数：

\[ \log p(y\mid X) =-\frac12y^T K_y^{-1}y -\frac12\log|K_y| -\frac n2\log(2\pi), \qquad K_y=K+\sigma_n^2I. \]

第一项奖励数据拟合；log-determinant 项惩罚把概率质量铺得过宽的协方差结构；固定 \(n\) 时最后一项为常数。这种自动 Occam effect 很有用，但目标可能具有局部最优，且仍以所选 kernel family 为条件。通常需要多次优化器重启和输入缩放。

Python 示例：检查 RBF length scale 如何改变 evidence

rng = np.random.default_rng(11)

    model = GaussianProcessRegressor(
        kernel=RBF(length_scale, length_scale_bounds="fixed"),
        alpha=0.12**2,
        optimizer=None,
    ).fit(X, y)
    adjacent_correlation = np.exp(
        -(X[1, 0] - X[0, 0]) ** 2 / (2.0 * length_scale**2)

RBF GP 假设极高平滑度，并在远离数据时回归先验。这对空间插值可能合理，对长期外推则可能危险。时间序列可能需要趋势、周期与变化噪声成分；空间数据可能需要各向异性 length scale；结构化对象则需要尊重其表示的 kernel。

Gaussian Process Classification

分类时，在潜在函数上放置 GP 先验，再通过链接函数变换：

\[ f\sim\mathcal{GP}(0,k), \qquad P(y_i=1\mid f_i)=\sigma(f_i), \]

也可使用 probit。Bernoulli likelihood 破坏 Gaussian 共轭，因此潜变量后验不再是 Gaussian；形成预测概率前，需要 Laplace approximation、expectation propagation、variational inference 或抽样。

颜色表示多分类概率，而不只是硬边界；anisotropic kernel 为每个特征学习独立 length scale。来源：scikit-learn GPC Iris example。

近似贝叶斯推断

精确贝叶斯推断需要计算

\[ p(\theta\mid\mathcal D) =\frac{p(\mathcal D,\theta)}{\int p(\mathcal D,\theta')d\theta'}. \]

分母可能是高维积分；即使后验密度已知，预测积分也未必有解析解。非共轭 likelihood、层级潜变量、mixture component 与神经网络会迅速使精确计算不可用。近似推断因此属于模型流水线，而不只是实现细节。

三类主要策略回答不同的计算问题：

  • Laplace approximation： 后验能否由众数附近的局部 Gaussian 曲率表示？
  • Variational inference： 能否把推断转化为在可处理分布族上的优化？
  • Monte Carlo： 能否利用带权或相关随机抽样估计期望？

近似误差不同于后验不确定性。较窄的 variational distribution 可能反映近似低估离散程度，而不是证据很强。Monte Carlo standard error 也不同：它描述后验量因有限模拟产生的数值精度，而不是该量在模型下的不确定程度。

Laplace Approximation

令

\[ h(\theta)=\log p(\mathcal D,\theta) \]

为未归一化 log posterior，\(\hat\theta\) 为其众数。二阶 Taylor expansion 给出

\[ h(\theta)\approx h(\hat\theta) -\frac12(\theta-\hat\theta)^T H(\theta-\hat\theta), \]

其中

\[ H=-\nabla^2 h(\hat\theta) \]

是众数处 negative Hessian。对二次式取指数得到

\[ p(\theta\mid\mathcal D) \approx\mathcal N(\hat\theta,H^{-1}). \]

找到众数后，该方法是确定性的，并复用优化曲率。当后验质量集中在一个内部众数附近，且 log density 近似二次时效果良好；对偏斜、有界、重尾或多峰后验表现较差，在 Hessian 奇异或非正定时也可能失败。

Python 示例：比较 Laplace approximation 与数值后验 
import numpy as np
from scipy.optimize import minimize_scalar

# Poisson observations with log-rate z and Gaussian prior z ~ N(0, 1.2^2).
counts = np.array([0, 0, 1])
prior_sd = 1.2

def log_posterior(z):
    # Terms constant in z are omitted.
    return counts.sum() * z - len(counts) * np.exp(z) - 0.5 * (z / prior_sd) ** 2

fit = minimize_scalar(lambda z: -log_posterior(z), bounds=(-7.0, 4.0), method="bounded")
mode = fit.x
negative_second_derivative = len(counts) * np.exp(mode) + 1.0 / prior_sd**2
laplace_sd = 1.0 / np.sqrt(negative_second_derivative)

# In one dimension, a dense grid gives a useful numerical reference.
grid = np.linspace(-7.0, 3.0, 60_000)
density = np.exp(np.array([log_posterior(z) for z in grid]) - log_posterior(mode))
density /= np.trapezoid(density, grid)
exact_mean = np.trapezoid(grid * density, grid)
exact_variance = np.trapezoid((grid - exact_mean) ** 2 * density, grid)
cdf = np.cumsum(density)
cdf /= cdf[-1]
exact_interval = np.interp([0.025, 0.975], cdf, grid)

print(f"Laplace on log-rate: mean={mode:.3f}, sd={laplace_sd:.3f}")
print(f"grid posterior:       mean={exact_mean:.3f}, sd={np.sqrt(exact_variance):.3f}")
print("grid 95% interval:", exact_interval.round(3))
print("Laplace 95% interval:", np.round([mode - 1.96 * laplace_sd, mode + 1.96 * laplace_sd], 3))

近似依赖所选参数化。对 log-rate \(z\) 的 Gaussian 近似，会使 rate \(\lambda=e^z\) 呈 log-normal；直接在 \(\lambda\) 上近似会给出不同结果，并可能把概率质量放到不可能的负值。参数化属于 Laplace 精度的一部分。

Variational Inference

Variational inference（VI）选择可处理分布族 \(q_\phi(\theta)\)，并拟合参数 \(\phi\) 以近似后验。直接最小化

\[ \operatorname{KL}(q_\phi\Vert p) =E_q\left[\log\frac{q_\phi(\theta)}{p(\theta\mid\mathcal D)}\right] \]

看似需要未知 evidence。重排可得

\[ \log p(\mathcal D) =\underbrace{E_q[\log p(\mathcal D,\theta)]-E_q[\log q_\phi(\theta)]}_{\operatorname{ELBO}(\phi)} +\operatorname{KL}(q_\phi\Vert p). \]

Evidence 不依赖 \(\phi\)，所以最大化 evidence lower bound（ELBO） 等价于最小化 KL divergence。第一项奖励解释数据与先验结构；entropy 项则阻止 \(q\) 在没有依据时坍缩。

Mean-field VI 分解为 \(q(\theta)=\prod_jq_j(\theta_j)\)，计算方便却无法表示后验相关。常见 reverse-KL 方向会强烈惩罚把质量放在目标低密度区域，却对遗漏另一个独立峰惩罚较弱，因此可能只选一个 mode 并低估不确定性。

Python 示例：观察 reverse-KL Gaussian VI 选择一个 mode 
import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp

# Symmetric bimodal target: 0.5 N(-2, 0.55^2) + 0.5 N(2, 0.55^2).
target_means = np.array([-2.0, 2.0])
target_sd = 0.55
nodes, weights = np.polynomial.hermite.hermgauss(80)
weights = weights / np.sqrt(np.pi)

def normal_logpdf(x, mean, sd):
    return -0.5 * ((x - mean) / sd) ** 2 - np.log(sd * np.sqrt(2.0 * np.pi))

def target_logpdf(x):
    components = np.vstack([
        np.log(0.5) + normal_logpdf(x, mean, target_sd)
        for mean in target_means
    ])
    return logsumexp(components, axis=0)

def reverse_kl(parameters):
    mean, log_sd = parameters
    sd = np.exp(log_sd)
    # Gauss-Hermite quadrature computes expectations under q=N(mean, sd^2).
    samples = mean + np.sqrt(2.0) * sd * nodes
    log_q = normal_logpdf(samples, mean, sd)
    return np.sum(weights * (log_q - target_logpdf(samples)))

for start in [[-1.5, -0.5], [1.5, -0.5]]:
    result = minimize(reverse_kl, start, method="BFGS")
    print(
        f"start mean={start[0]:>4.1f} -> q mean={result.x[0]:>6.3f}, "
        f"q sd={np.exp(result.x[1]):.3f}, KL={result.fun:.3f}"
    )

target_sd_total = np.sqrt(target_sd**2 + target_means[0] ** 2)
print(f"target mean=0.000, target marginal sd={target_sd_total:.3f}")

优化后的 Gaussian 覆盖一个 mode，而不是跨越低密度谷对两峰取平均。更丰富的 mixture variational family 可以表示两峰。一般而言，normalizing flow、结构化协方差与层级 variational family 用更多计算换取表达能力。

大数据 VI 常使用 minibatch 与 stochastic gradient。Reparameterization trick 把 Gaussian 抽样写为 \(\theta=\mu+\sigma\odot\epsilon\)、\(\epsilon\sim\mathcal N(0,I)\)，使梯度可穿过样本。ELBO 收敛只说明在所选分布族内优化完成，并不能证明该族准确近似后验。

Monte Carlo 方法

Monte Carlo 以随机抽样近似期望。若独立样本 \(\theta^{(s)}\sim p(\theta\mid\mathcal D)\)，则

\[ E[g(\theta)\mid\mathcal D] \approx\frac1S\sum_{s=1}^{S}g(\theta^{(s)}). \]

通常无法直接从后验抽样。Importance sampling 从 proposal 抽样并重加权，少量权重占据主导时会失败；Markov chain Monte Carlo（MCMC） 构造平稳分布为后验的相关链；Hamiltonian Monte Carlo（HMC） 使用梯度与模拟动力学，在连续空间提出远距离且高接受率的 proposal；No-U-Turn Sampler 会自适应轨迹长度。

Metropolis-Hastings 提出 \(\theta'\sim q(\theta'\mid\theta)\)，并以概率

\[ \alpha =\min\left(1, \frac{p(\mathcal D,\theta')q(\theta\mid\theta')} {p(\mathcal D,\theta)q(\theta'\mid\theta)} \right) \]

接受。对称 random-walk proposal 中，proposal 项抵消。被拒绝 proposal 必须作为当前状态保留在链中；删除它们会改变平稳分布。

Python 示例：使用 Metropolis-Hastings 抽样 Beta-Binomial 后验 
import numpy as np
from scipy.special import expit
from scipy.stats import beta

rng = np.random.default_rng(22)
successes, failures = 14, 6
alpha_prior, beta_prior = 2.0, 2.0

def log_target_on_logit(z):
    theta = expit(z)
    # Beta posterior density plus the Jacobian d(theta)/dz=theta(1-theta).
    return (
        (alpha_prior + successes) * np.log(theta)
        + (beta_prior + failures) * np.log1p(-theta)
    )

n_steps = 16_000
burn_in = 3_000
proposal_sd = 0.75
z = 0.0
draws = np.empty(n_steps)
accepted = 0

for step in range(n_steps):
    proposal = z + rng.normal(scale=proposal_sd)
    log_ratio = log_target_on_logit(proposal) - log_target_on_logit(z)
    if np.log(rng.uniform()) < min(0.0, log_ratio):
        z = proposal
        accepted += 1
    draws[step] = expit(z)

posterior_draws = draws[burn_in:]

def teaching_ess(values, max_lag=1_000):
    # Initial-positive-pair estimate for illustration, not a replacement for Stan diagnostics.
    centered = values - values.mean()
    denominator = centered @ centered
    autocorrelation = [1.0]
    for lag in range(1, min(max_lag, len(values) - 1)):
        autocorrelation.append(centered[:-lag] @ centered[lag:] / denominator)
    paired_sum = 0.0
    for lag in range(1, len(autocorrelation) - 1, 2):
        pair = autocorrelation[lag] + autocorrelation[lag + 1]
        if pair <= 0:
            break
        paired_sum += pair
    return len(values) / (1.0 + 2.0 * paired_sum)

exact_a = alpha_prior + successes
exact_b = beta_prior + failures
print(f"acceptance rate: {accepted / n_steps:.3f}")
print(f"estimated ESS: {teaching_ess(posterior_draws):.0f} of {len(posterior_draws)} draws")
print(f"sample mean={posterior_draws.mean():.4f}, exact mean={exact_a / (exact_a + exact_b):.4f}")
print("sample interval:", np.quantile(posterior_draws, [0.025, 0.975]).round(4))
print("exact interval: ", beta.ppf([0.025, 0.975], exact_a, exact_b).round(4))

只有诊断模拟后，MCMC 输出才可使用。多条分散初始化链应到达同一典型区域；rank-normalized split \(\hat R\) 比较链内与链间行为；bulk/tail effective sample size 衡量考虑自相关后的信息量；Monte Carlo standard error 衡量模拟精度。HMC 还必须检查 divergent transition、maximum tree depth 与 energy diagnostic。Stan diagnostics documentation 建议使用多链，并报告现代 rank-normalized \(\hat R\) 及 bulk/tail ESS。

Thinning 一般只有在存储受限时有用。保留全部 warmup 后抽样，通常至少与每隔 \(k\) 个保留一个一样有信息。增加迭代不能修复困在一个 mode 的链、有偏的 variational family 或设定错误的模型。

方法 表示 计算形式 典型失败
Laplace 一个局部 Gaussian 众数寻找与 Hessian 偏斜、边界、多峰
Mean-field VI 分解的可处理 \(q\) ELBO 优化 遗漏依赖与低估离散程度
Structured / flow VI 更丰富的变换 \(q\) 随机优化 优化更难且仍有分布族偏差
Importance sampling 带权 proposal 抽样 可并行抽样 权重退化
MCMC / HMC 相关后验抽样 迭代模拟 混合差、divergence、成本高

推断方法应根据后验几何、数据规模、延迟和最终决策所需精度选择。对新模型，先在可精确检查的小型版本上与数值积分或高质量 MCMC 比较，是验证快速近似的有效方式。

不确定性、校准与模型比较

后验分布在自身模型假设下内部一致，却不会自动与外部世界校准。Likelihood 可能遗漏重尾，先验可能排除合理机制，训练样本可能存在选择偏差，部署输入也可能漂移。因此，不确定性必须作为预测主张接受评估，不能仅因模型带有 Bayesian 标签就被信任。

Aleatoric 与 Epistemic Uncertainty

对参数不确定性 \(\theta\mid\mathcal D\)，全方差公式把预测方差分解为

\[ \operatorname{Var}(Y_*\mid x_*,\mathcal D) =\underbrace{E_{\theta\mid\mathcal D}[\operatorname{Var}(Y_*\mid x_*,\theta)]}_{\text{aleatoric under the model}} +\underbrace{\operatorname{Var}_{\theta\mid\mathcal D}[E(Y_*\mid x_*,\theta)]}_{\text{epistemic under the model}}. \]

Aleatoric uncertainty 描述参数固定后仍存在的结果变异，例如类别重叠或测量噪声；epistemic uncertainty 描述模型量的不确定性，可随有信息数据增加而缩小。该分解相对于模型而言：遗漏变量引起的不确定性在纳入该变量前可能表现为 aleatoric，而设定错误的后验可能完全低估 epistemic uncertainty。

对 domain 外输入产生较高 epistemic uncertainty 是理想行为，却没有保证。GP 可能在远离训练点时回归先验，而神经网络或线性模型可能以极端置信度外推。仍然需要显式漂移检测、代表性验证和安全 fallback。

校准与 Proper Scoring Rule

二元概率预测器在以下意义下校准：被赋予概率 \(q\) 的案例中，事件发生频率也为 \(q\)：

\[ P(Y=1\mid\hat p(X)=q)=q. \]

Reliability diagram 对预测分箱，比较平均预测概率与观察事件频率。点位于对角线下方表示该区域的正类概率过度自信；位于上方表示不够自信。曲线旁还需概率直方图，因为案例很少的 bin 噪声很大，而只在基准率附近预测的模型可能看似校准，却几乎没有 discrimination。

对角线代表理想 reliability；下方直方图展示各模型实际把概率质量放在哪里。来源：scikit-learn calibration comparison。

概率质量有多个维度：

  • Calibration： 声明概率是否匹配条件频率？
  • Discrimination： 高风险案例是否获得比低风险案例更高的得分？
  • Sharpness： 在保持校准的前提下，模型是否能给出远离基准率的有信息预测？
  • Decision value： 概率是否在相关行动与成本下产生较低损失？

Log loss 与 Brier score 是严格 proper scoring rule，在期望意义上鼓励报告真实概率。二元 log loss 为

\[ -\frac1n\sum_i[y_i\log\hat p_i+(1-y_i)\log(1-\hat p_i)], \]

Brier score 为

\[ \frac1n\sum_i(\hat p_i-y_i)^2. \]

两者都混合 calibration 与 discrimination，所以单独使用都无法诊断 reliability。Expected calibration error（ECE）总结分箱差异，却强烈依赖分箱且不是 proper scoring rule。它应配合而不是取代 reliability diagram、log loss、Brier score 与校准估计的不确定区间。

Python 示例：比较已校准、过度自信与不够自信的概率 
import numpy as np
from scipy.special import expit, logit
from sklearn.metrics import brier_score_loss, log_loss, roc_auc_score

rng = np.random.default_rng(31)
x = rng.normal(size=50_000)
true_probability = expit(1.3 * x - 0.25)
y = rng.binomial(1, true_probability)

predictions = {
    "calibrated": true_probability,
    "overconfident": expit(1.9 * logit(true_probability)),
    "underconfident": expit(0.55 * logit(true_probability)),
}

def expected_calibration_error(y_true, probability, n_bins=15):
    edges = np.linspace(0.0, 1.0, n_bins + 1)
    bin_id = np.clip(np.digitize(probability, edges) - 1, 0, n_bins - 1)
    error = 0.0
    for index in range(n_bins):
        mask = bin_id == index
        if mask.any():
            gap = abs(y_true[mask].mean() - probability[mask].mean())
            error += mask.mean() * gap
    return error

for name, probability in predictions.items():
    print(
        f"{name:14s}: log-loss={log_loss(y, probability):.4f}, "
        f"Brier={brier_score_loss(y, probability):.4f}, "
        f"AUC={roc_auc_score(y, probability):.4f}, "
        f"ECE={expected_calibration_error(y, probability):.4f}"
    )

三种变换保持排序，因此 AUC 几乎相同，但概率敏感指标能够区分它们。这说明良好排序分数并不表示决策阈值或期望成本可信。

Post-hoc calibration 可拟合 sigmoid、isotonic mapping 或 temperature 参数。校准器需要未参与基础模型拟合的数据；数据较少时可 cross-fit。流行率或 covariate shift 后必须重新检查校准，而且一条全局曲线可能隐藏子群体失准。

Posterior Predictive Check

后验预测检查抽取

\[ \theta^{(s)}\sim p(\theta\mid\mathcal D), \qquad y_{rep}^{(s)}\sim p(y\mid\theta^{(s)}), \]

再比较统计量 \(T(y)\) 与 \(T(y_{rep}^{(s)})\)。统计量应针对有科学意义的失效模式，例如尾部大小、零值频率、类别不平衡、自相关、最长连续段或残差结构。发现差异表示拟合模型无法复现观测的某个方面；未发现差异也不能证明模型对所有用途都足够。

Python 示例：使用 posterior predictive check 检测重尾 
import numpy as np
from scipy.stats import invgamma, t

rng = np.random.default_rng(42)
observed = t.rvs(df=2, size=100, random_state=rng)  # Deliberately heavy-tailed data.
n = len(observed)

# Weak Normal-Inverse-Gamma prior for a Normal likelihood.
mu0, kappa0, alpha0, beta0 = 0.0, 0.01, 2.0, 2.0
sample_mean = observed.mean()
sum_squares = np.sum((observed - sample_mean) ** 2)
kappa_n = kappa0 + n
mu_n = (kappa0 * mu0 + n * sample_mean) / kappa_n
alpha_n = alpha0 + n / 2.0
beta_n = beta0 + 0.5 * sum_squares + (
    kappa0 * n * (sample_mean - mu0) ** 2 / (2.0 * kappa_n)
)

n_replications = 5_000
sigma2_draws = invgamma.rvs(alpha_n, scale=beta_n, size=n_replications, random_state=rng)
mu_draws = rng.normal(mu_n, np.sqrt(sigma2_draws / kappa_n))
replicated = rng.normal(
    loc=mu_draws[:, None],
    scale=np.sqrt(sigma2_draws)[:, None],
    size=(n_replications, n),
)

def standardized_maximum(values, axis=-1):
    mean = values.mean(axis=axis, keepdims=True)
    sd = values.std(axis=axis, ddof=1, keepdims=True)
    return np.max(np.abs((values - mean) / sd), axis=axis)

observed_statistic = standardized_maximum(observed)
replicated_statistic = standardized_maximum(replicated, axis=1)
posterior_predictive_p = np.mean(replicated_statistic >= observed_statistic)

print(f"observed standardized maximum: {observed_statistic:.3f}")
print(f"replicated median maximum: {np.median(replicated_statistic):.3f}")
print(f"posterior predictive tail probability: {posterior_predictive_p:.4f}")

很小的后验预测尾概率表示 Normal 模型很少复现观测尾部统计量。Student-\(t\) likelihood、污染成分或显式离群过程可能更合理。若不解释数据生成过程就删除极端观测，只会隐藏不匹配，而不是解决问题。

模型证据、预测比较与平均

贝叶斯模型 evidence 在先验上积分似然：

\[ p(\mathcal D\mid M) =\int p(\mathcal D\mid\theta,M)p(\theta\mid M)d\theta. \]

Bayes factor \(p(\mathcal D\mid M_1)/p(\mathcal D\mid M_2)\) 更新模型间先验 odds。Evidence 奖励拟合，同时惩罚会预测与观测不相似数据的先验体积，所以对先验尺度敏感：即使后验估计看似合理，过于 diffuse 的先验也可能大幅降低 evidence。因此，Bayes factor 应使用真正指定的先验与 sensitivity analysis，而不是任意“noninformative”尺度。

Held-out log score、nested cross-validation、leave-one-out cross-validation 与 WAIC 等预测方法聚焦样本外表现，回答的问题不同于在封闭模型列表上的 posterior odds。任何准则都不能消除定义部署总体、在划分内部重新拟合预处理，以及处理时间或群组依赖的必要性。

当多个模型仍然合理时，Bayesian model averaging 使用

\[ p(y_*\mid x_*,\mathcal D) =\sum_m p(y_*\mid x_*,\mathcal D,M_m)p(M_m\mid\mathcal D). \]

它传播模型身份的不确定性，而不是假装被选模型事先已知。预测分布 stacking 是相关方法，但其权重针对预测表现选择，而不解释为 posterior model probability。

Python 示例：使用 Bayesian model averaging 组合模型不确定性 
import numpy as np
from scipy.special import softmax

model_names = np.array(["linear", "tree", "Gaussian process"])
log_evidence = np.array([-42.0, -43.5, -47.0])
prior_model_probability = np.array([1 / 3, 1 / 3, 1 / 3])
event_probability = np.array([0.20, 0.55, 0.80])

log_posterior_weight = log_evidence + np.log(prior_model_probability)
posterior_model_probability = softmax(log_posterior_weight)
averaged_probability = posterior_model_probability @ event_probability

print("posterior model probabilities:")
for name, weight, probability in zip(
    model_names, posterior_model_probability, event_probability
):
    print(f"  {name:16s}: weight={weight:.3f}, event probability={probability:.2f}")
print(f"Bayesian model-averaged event probability: {averaged_probability:.3f}")

# Convert the averaged probability to an action using the deployment loss.
false_positive_cost, false_negative_cost = 1.0, 4.0
threshold = false_positive_cost / (false_positive_cost + false_negative_cost)
print(f"decision threshold={threshold:.3f}, action={int(averaged_probability > threshold)}")

该示例只说明机制，并不建议随意使用 marginal likelihood。实际工作中，evidence 必须来自一致的模型与先验设定，而 stacking 权重必须由防泄漏预测估计得到。

实用概率建模工作流

  1. 分别定义预测与行动。 说明目标分布、可用行动与后果重大的错误。
  2. 指定观测模型。 选择匹配测量产生方式的 likelihood 支持集、噪声、依赖和缺失假设。
  3. 选择并审视先验。 模拟 prior predictive 观测，并对弱识别量做 sensitivity analysis。
  4. 采用适合后验几何的推断方法。 条件允许时，在可处理的小版本上验证快速近似。
  5. 诊断计算。 按方法检查优化器稳定性、Hessian 条件、ELBO 行为或多链 MCMC 诊断。
  6. 检查拟合模型。 使用 posterior predictive check、残差结构与领域特定差异统计量。
  7. 在未触碰且具有代表性的数据上评估预测。 衡量 proper score、校准、区间覆盖率、子群体行为与决策损失。
  8. 压力测试分布漂移。 测试流行率变化、外推、缺失和 fallback/abstention 行为。
  9. 连同条件报告不确定性。 区分结果、参数、模型、近似与 Monte Carlo 不确定性。
主张 最低支持检查 常见错误
“概率可靠” 代表性数据上的 reliability curve 与 proper score 只报告 AUC
“区间是 95%” 相关条件下的经验覆盖率与宽度 把模型区间视为 distribution-free
“MCMC 已收敛” 多链、\(\hat R\)、bulk/tail ESS、trace 与 sampler diagnostic 只凭肉眼看一条平滑 trace
“VI 准确” 在可处理案例上与更强推断或模拟比较 把 ELBO 收敛当作后验验证
“贝叶斯模型知道自己不知道什么” 漂移与设定错误压力测试 假设后验离散程度涵盖遗漏机制
“模型 A 更好” 带不确定性的防泄漏预测或决策比较 根据训练 evidence 或一次噪声划分选择

概率建模最重要的价值，是让不确定性能够参与运行决策。目标不是为每个预测机械附加区间，而是把假设、证据、预测分布与损失连接成可检查、可检验的链条。当其中任何一环较弱，正确做法可能是扩大模型、收集更多数据、改变行动，或明确拒绝自动化该决策。
