线性回归与广义线性模型

线性模型是把数据表示、概率、优化、正则化和解释性连接起来的最透明起点。给定变换后的特征向量 \(\phi(x)\)，模型首先构造一个加性得分：

\[ \eta(x)=\beta_0+\phi(x)^\top\beta. \]

这里的 线性 指模型关于待估系数 \(\beta\) 是线性的，并不要求响应与原始输入之间必须是一条直线。多项式项、交互项与样条基函数都可以进入 \(\phi(x)\)；随后，非线性的逆链接函数还可以把 \(\eta\) 映射为概率或正值发生率。

本章从两个互补视角使用线性模型：

  • 作为 预测器，依据第 06 章的实验协议评价其在未见数据上的表现；
  • 作为 统计模型，只有在明确满足抽样与分布假设时，其系数和不确定性才具有相应解释。

预测准确并不意味着系数具有因果意义。系数描述的是在给定特征、链接函数、数据生成总体与正则化条件下的条件关联。若要作因果解释，还必须针对处理分配、混杂、选择偏差、测量过程与个体间干扰提出可辩护的识别论证。

线性预测模型

线性回归和逻辑回归共享系统成分 \(\eta=\beta_0+x^\top\beta\)，但响应值的取值范围和用于拟合的似然不同。线性回归将 \(\eta\) 直接作为实数条件均值；逻辑回归则先通过 sigmoid 函数，将它映射为 \([0,1]\) 内的概率。

线性回归

线性回归建模的是条件均值，而不是声称每个观测点都必须落在一条直线上：

\[ \mathbb E[Y\mid X=x]=\beta_0+x^\top\beta. \]

单个观测可写成 \(Y_i=\beta_0+x_i^\top\beta+\varepsilon_i\)，其中 \(\varepsilon_i\) 表示当前特征未能解释的变化。较弱条件下，该模型仍可用于预测；传统置信区间与假设检验则依赖后文讨论的更强假设。

简单（双变量）线性回归

只有一个预测变量时，

\[ \widehat y=\widehat\beta_0+\widehat\beta_1x. \]

\(\widehat\beta_1\) 表示 \(x\) 增加一个单位时，\(Y\) 的条件均值估计改变多少；\(\widehat\beta_0\) 是 \(x=0\) 时的拟合均值。如果零远离观测范围，截距在数学上虽不可缺少，却可能没有实际科学含义。拟合斜率总结的是建模区间内的关联，不应被外推到数据没有支持的区域。

对于带截距的普通最小二乘，简单回归的闭式估计为

\[ \widehat\beta_1= \frac{\sum_i(x_i-\overline x)(y_i-\overline y)} {\sum_i(x_i-\overline x)^2}, \qquad \widehat\beta_0=\overline y-\widehat\beta_1\overline x. \]

斜率等于协方差除以预测变量方差。相关系数会同时标准化两个变量，因此没有单位且具有对称性；回归斜率带有单位，并明确区分响应变量和预测变量的角色。

Python 示例：手动计算简单回归斜率并进行验证 
import numpy as np
from sklearn.linear_model import LinearRegression

x = np.array([1.0, 2.0, 3.0, 5.0, 7.0, 8.0])
y = np.array([2.1, 3.9, 5.8, 9.2, 12.7, 15.1])

# Closed-form ordinary least-squares estimates with an intercept.
slope = np.sum((x - x.mean()) * (y - y.mean())) / np.sum((x - x.mean()) ** 2)
intercept = y.mean() - slope * x.mean()

model = LinearRegression().fit(x.reshape(-1, 1), y)

print("manual intercept and slope:", np.round([intercept, slope], 4))
print("sklearn intercept and slope:", np.round([model.intercept_, model.coef_[0]], 4))
print("prediction at x=6:", round(float(model.predict([[6.0]])[0]), 3))
print("training residuals:", np.round(y - model.predict(x.reshape(-1, 1)), 3))
多元线性回归

对于 \(p\) 个预测变量，

\[ \mathbb E[Y\mid X=x] =\beta_0+\beta_1x_1+\cdots+\beta_px_p. \]

\(\beta_j\) 表示一种 偏关联：在其他已建模预测变量保持不变时，\(x_j\) 增加一个单位所对应的 \(Y\) 期望变化。当预测变量无法独立变化、重要交互项被遗漏，或者改变一个变量必然会带动其他变量变化时，这种“保持其他变量不变”的解释可能并不现实。

类别变量通过指示列或对比编码进入模型。交互项 \(x_1x_2\) 允许 \(x_1\) 的斜率依赖于 \(x_2\)：

\[ \frac{\partial\mathbb E[Y\mid X]}{\partial x_1} =\beta_1+\beta_{12}x_2. \]

包含交互项时通常也应保留相应主效应，因为删除主效应会强行施加一个很强的约束：每当另一个变量为零时，该变量的效应也必须为零。

Python 示例：多元回归分离被相关预测变量掩盖的效应 
import numpy as np
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(113)
n = 1200
x1 = rng.normal(size=n)
x2 = 0.85 * x1 + rng.normal(scale=0.45, size=n)  # strongly correlated with x1
y = 3.0 * x1 - 2.0 * x2 + rng.normal(scale=0.5, size=n)

simple = LinearRegression().fit(x1[:, None], y)
multiple = LinearRegression().fit(np.column_stack([x1, x2]), y)

print("true coefficients:                 ", [3.0, -2.0])
print("x1 coefficient when x2 is omitted:", round(simple.coef_[0], 3))
print("multiple-regression coefficients:  ", np.round(multiple.coef_, 3))
print("correlation between x1 and x2:     ", round(np.corrcoef(x1, x2)[0, 1], 3))

由于 \(x_1\) 与 \(x_2\) 同步变化，简单回归的斜率会吸收部分遗漏预测变量的关联。把一个变量加入回归式并不会自动在因果意义上“控制混杂”；特征集合与函数形式仍须遵循可信的因果结构。

模型拟合

为截距添加一列全 1 后，记设计矩阵为 \(X\in\mathbb R^{n\times(p+1)}\)、响应为 \(y\in\mathbb R^n\)、系数为 \(\beta\)。普通最小二乘求解

\[ \widehat\beta =\arg\min_\beta\|y-X\beta\|_2^2. \]

令梯度为零可得正规方程

\[ X^\top X\widehat\beta=X^\top y. \]

若 \(X\) 满列秩，则 \(\widehat\beta=(X^\top X)^{-1}X^\top y\)。实际软件通常采用 QR 分解、奇异值分解或迭代求解器，而不会显式计算逆矩阵，因为形成 \(X^\top X\) 会把条件数平方，从而放大数值误差。

在最优解处，残差 \(e=y-X\widehat\beta\) 满足 \(X^\top e=0\)，即它与设计矩阵的每一列都正交。即使系数不唯一，拟合向量 \(\widehat y\) 仍可能唯一。当若干列线性相关时，无穷多个系数向量会给出相同拟合值；伪逆会从中选择一个最小范数解。

若误差相互独立且 \(\varepsilon_i\sim\mathcal N(0,\sigma^2)\)，最小化平方误差等价于最大化似然。在条件均值为零且方差恒定时，Gauss-Markov 定理说明 OLS 是最佳线性无偏估计量；这里“最佳”仅指在线性无偏估计量中方差最小，并非在所有可能的非线性方法中预测最好。

Python 示例：秩亏对系数稳定性的破坏大于对预测的影响 
import numpy as np
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(127)
x1 = rng.normal(size=300)
x2 = rng.normal(size=300)
x3 = x1 + x2  # exact linear dependence
X = np.column_stack([x1, x2, x3])
y = 2.0 * x1 - 1.0 * x2 + rng.normal(scale=0.05, size=300)

base = LinearRegression().fit(X, y)

# A tiny perturbation breaks the exact dependence and can change the coefficient allocation.
X_perturbed = X.copy()
X_perturbed[:, 2] += rng.normal(scale=1e-5, size=len(X))
perturbed = LinearRegression().fit(X_perturbed, y)

prediction_change = np.max(np.abs(base.predict(X) - perturbed.predict(X_perturbed)))

print("design rank / number of columns:", np.linalg.matrix_rank(X), X.shape[1])
print("coefficients on rank-deficient X:", np.round(base.coef_, 3))
print("coefficients after tiny perturbation:", np.round(perturbed.coef_, 3))
print("maximum fitted-value change:", f"{prediction_change:.6f}")
评估指标

第 06 章已经介绍 MAE、RMSE、\(R^2\)、残差切片、不确定性和有效的数据划分。对于线性模型，还需特别理解以下三点。

第一，\(R^2\) 把平方误差与仅含截距的均值基线比较：

\[ R^2=1-\frac{\sum_i(y_i-\widehat y_i)^2}{\sum_i(y_i-\overline y)^2}. \]

它在未见数据上可以为负，也不能证明函数形式正确。调整后的 \(R^2\) 会惩罚拟合斜率的数量：

\[ \overline R^2 =1-(1-R^2)\frac{n-1}{n-p-1}, \]

但它依然是样本内准则，不能替代验证集评估。

第二，条件均值 的不确定性不同于 新观测 的不确定性。\(\mathbb E[Y\mid X=x_*]\) 的置信区间反映系数估计的不确定性；预测区间还必须包含不可约的观测噪声，因此更宽。

第三，传统标准误依赖其推导所采用的模型和抽样过程。交叉验证衡量重采样下的预测稳定性，却不会自动给出有效的系数推断；较小的系数 \(p\) 值同样不能证明模型具有良好的样本外预测价值。

Python 示例：比较均值响应区间与预测区间 
import numpy as np
from scipy.stats import t

rng = np.random.default_rng(131)
x = rng.uniform(0, 10, size=180)
y = 4.0 + 1.7 * x + rng.normal(scale=2.2, size=len(x))

X = np.column_stack([np.ones(len(x)), x])
beta = np.linalg.lstsq(X, y, rcond=None)[0]
residual = y - X @ beta
n, p = X.shape
residual_variance = residual @ residual / (n - p)
xtx_inverse = np.linalg.inv(X.T @ X)

new_row = np.array([1.0, 6.0])
mean_prediction = new_row @ beta
mean_variance = residual_variance * (new_row @ xtx_inverse @ new_row)

# A new observation contains both mean-estimation uncertainty and fresh noise.
mean_se = np.sqrt(mean_variance)
observation_se = np.sqrt(mean_variance + residual_variance)
critical_value = t.ppf(0.975, df=n - p)
mean_interval = mean_prediction + critical_value * np.array([-mean_se, mean_se])
observation_interval = mean_prediction + critical_value * np.array([
    -observation_se, observation_se
])

print("estimated coefficients:", np.round(beta, 3))
print("fitted mean at x=6:", round(mean_prediction, 3))
print("95% mean-response interval:", np.round(mean_interval, 3))
print("95% new-observation interval:", np.round(observation_interval, 3))
print("The observation interval is wider because it includes new-case noise.")

逻辑回归

逻辑回归在保留线性预测量的同时，对 Bernoulli 概率建模。对于 \(Y\in\{0,1\}\)，

\[ p(x)=\Pr(Y=1\mid X=x) =\sigma(\eta) =\frac{1}{1+e^{-\eta}}, \qquad \eta=\beta_0+x^\top\beta. \]

应用 logit 链接可得

\[ \log\frac{p(x)}{1-p(x)}=\beta_0+x^\top\beta. \]

因此，\(\beta_j\) 表示 对数优势 的加性变化；在其他已建模特征不变时，\(e^{\beta_j}\) 表示 \(x_j\) 增加一个单位后优势的乘数。优势比不等于风险比，当事件很常见时，两者可能相差很大。

最大似然等价于最小化二元交叉熵：

\[ -\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]. \]

该目标不存在类似 OLS 的普通闭式系数解，通常使用 Newton、quasi-Newton、坐标下降或随机优化。概率曲面是非线性的，但 \(p=0.5\) 的决策边界是超平面 \(\eta=0\)。部署时改用不同于 \(0.5\) 的阈值，会平移这条平行边界，而无需重新拟合概率模型。

Python 示例：由拟合得分重建逻辑概率，并解释标准化后的优势比 
import numpy as np
from scipy.special import expit
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

data = load_breast_cancer()
X, y = data.data, data.target
model = make_pipeline(
    StandardScaler(),
    LogisticRegression(C=1.0, max_iter=2000, random_state=137),
).fit(X, y)

# Choose an observed case near the fitted boundary so both outcomes remain plausible.
all_probabilities = model.predict_proba(X)[:, 1]
row_index = np.argmin(np.abs(all_probabilities - 0.5))
scaled_row = model[0].transform(X[[row_index]])
linear_score = model[1].intercept_[0] + scaled_row @ model[1].coef_[0]
manual_probability = expit(linear_score)[0]
api_probability = model.predict_proba(X[[row_index]])[0, 1]

largest = np.argsort(np.abs(model[1].coef_[0]))[-3:][::-1]
print("manual / API probability:", round(manual_probability, 6), round(api_probability, 6))
print("largest one-standard-deviation odds multipliers:")
for index in largest:
    print(f"  {data.feature_names[index]:28s} exp(beta)={np.exp(model[1].coef_[0, index]):.3f}")

当数据完全可分时，随着系数绝对值不断增大，未正则化似然仍可持续提高。预测会趋近 0 或 1，但有限的最大似然系数可能并不存在。正则化可产生有限且更稳定的解；同时，系数的含义也由无惩罚似然估计变为有意引入偏差的预测估计。

Python 示例：正则化控制完全分离条件下的系数增长 
import numpy as np
from sklearn.linear_model import LogisticRegression

x = np.r_[np.linspace(-3.0, -0.2, 40), np.linspace(0.2, 3.0, 40)][:, None]
y = np.r_[np.zeros(40, dtype=int), np.ones(40, dtype=int)]

models = {
    "almost unregularized": LogisticRegression(C=1e8, max_iter=5000),
    "regularized": LogisticRegression(C=1.0, max_iter=5000),
}

for name, model in models.items():
    model.fit(x, y)
    near_boundary = model.predict_proba([[-0.2], [0.2]])[:, 1]
    print(
        f"{name:20s}",
        "coefficient =", round(model.coef_[0, 0], 3),
        "P(y=1 | x=-0.2, 0.2) =", np.round(near_boundary, 4),
    )

当响应尺度或链接尺度上的加性效应合理、样本量足以支撑系数数量且外推受到控制时，线性回归与逻辑回归非常有效。基函数扩展用于表达平滑非线性效应，正则化用于缓解方差与病态条件，而 GLM 框架则明确规定响应分布。

广义线性模型框架

广义线性模型（GLM） 通过分离以下三个选择来扩展线性回归：

  1. 与响应取值范围和方差相匹配的条件分布；
  2. 包含系统性特征效应的线性预测量；
  3. 把条件均值连接到该预测量的链接函数。

该框架建模

\[ \mu_i=\mathbb E[Y_i\mid X_i], \qquad g(\mu_i)=\eta_i=\beta_0+x_i^\top\beta. \]

线性关系成立于 链接尺度 \(\eta\)，而不一定成立于响应尺度 \(\mu\)。分布与链接函数的选择同时规定了预测的有效范围、条件方差以及系数含义。

随机成分

随机成分指定 \(Y_i\mid X_i\) 的分布，因而决定响应的支持集和均值—方差关系。GLM 常写作

\[ \operatorname{Var}(Y_i\mid X_i)=\phi V(\mu_i), \]

其中 \(V(\mu)\) 是由分布族决定的方差函数；若该分布包含离散参数，则由 \(\phi\) 表示。

分布族 响应取值范围 条件方差 典型用途
Gaussian 实数 \(\phi\) 条件方差近似恒定的连续结果
Bernoulli \(0\) 或 \(1\) \(\mu(1-\mu)\) 二元事件
Binomial \(0,\ldots,m_i\) \(m_i\pi_i(1-\pi_i)\) 已知试验次数中的成功数
Poisson 非负整数 \(\mu\) 带暴露量的事件计数或发生率
Gamma 正连续数 \(\phi\mu^2\) 右偏的正值成本或持续时间

这里规定的是条件分布，并不要求 \(Y\) 的边际直方图具有相同形状。由于条件均值随 \(X\) 变化，一组 Gaussian 条件分布的混合完全可能形成非 Gaussian 的边际分布。

Poisson 分布要求均值与方差相等，这在实践中往往过于严格。过度离散 指条件方差超过 Poisson 假设的方差，常由未建模异质性、依赖关系或过多零值导致。即使条件均值模型仍有用，标准误和预测区间也可能过窄。此时，负二项模型或 quasi-likelihood 方差修正通常更合适。

Python 示例：比较不同响应分布族的经验均值—方差关系 
import numpy as np

rng = np.random.default_rng(139)
means = [0.2, 0.5, 0.8]

print("Bernoulli samples")
for mean in means:
    sample = rng.binomial(1, mean, size=100_000)
    print(f"  mean={sample.mean():.3f}, variance={sample.var():.3f}, theory={mean * (1 - mean):.3f}")

print("\nPoisson samples")
for mean in [0.5, 2.0, 8.0]:
    sample = rng.poisson(mean, size=100_000)
    print(f"  mean={sample.mean():.3f}, variance={sample.var():.3f}, theory={mean:.3f}")

print("\nGaussian samples with constant variance")
for mean in [-2.0, 0.0, 3.0]:
    sample = rng.normal(mean, 1.5, size=100_000)
    print(f"  mean={sample.mean():.3f}, variance={sample.var():.3f}, theory={1.5 ** 2:.3f}")

线性预测量

系统成分为

\[ \eta_i=\beta_0+x_i^\top\beta+o_i, \]

其中 \(o_i\) 是可选的 offset（偏置项），其系数固定为 1。预测量可以包含连续变量、编码后的类别、交互项、多项式或样条基函数，以及已知 offset，同时仍保持关于 \(\beta\) 的线性。

当不同观测发生事件的机会不同时，offset 尤其重要。若 \(Y_i\) 是在暴露量 \(E_i\) 下观察到的计数，Poisson 发生率模型使用

\[ \log\mu_i =\log E_i+\beta_0+x_i^\top\beta, \]

于是

\[ \frac{\mu_i}{E_i}=\exp(\beta_0+x_i^\top\beta). \]

已知的 \(\log E_i\) offset 让期望计数与暴露量成比例缩放。若把暴露量当作普通特征学习，模型会去估计一个本应由测量过程固定的系数；若完全遗漏暴露量，则会把“发生机会”与“风险”混为一谈。

Python 示例：使用暴露量 offset 恢复 Poisson 事件发生率效应 
import numpy as np
from sklearn.linear_model import PoissonRegressor

rng = np.random.default_rng(149)
n = 2500
risk_feature = rng.normal(size=n)

# Exposure is associated with risk here, making omission visibly misleading.
log_exposure = 0.5 * risk_feature + rng.normal(scale=0.45, size=n)
exposure = np.clip(np.exp(log_exposure), 0.1, 4.0)

# The true event rate per exposure unit is exp(-1.2 + 0.65 * risk_feature).
true_rate = np.exp(-1.2 + 0.65 * risk_feature)
count = rng.poisson(exposure * true_rate)
X = risk_feature[:, None]

# Fitting count / exposure with exposure as sample weight is likelihood-
# equivalent to a Poisson count model with log(exposure) as a fixed offset.
with_offset = PoissonRegressor(alpha=0.0, max_iter=1_000).fit(
    X,
    count / exposure,
    sample_weight=exposure,
)
without_offset = PoissonRegressor(alpha=0.0, max_iter=1_000).fit(X, count)

print("true intercept and slope:       ", [-1.2, 0.65])
print("with exposure adjustment:       ", np.round([
    with_offset.intercept_, with_offset.coef_[0]
], 3))
print("without exposure adjustment:    ", np.round([
    without_offset.intercept_, without_offset.coef_[0]
], 3))
print("rate ratio for +1 feature unit: ", round(np.exp(with_offset.coef_[0]), 3))

在其他已建模变量和暴露量固定时，发生率比 \(e^{\beta_j}\) 表示期望发生率的乘数。与优势比一样，除非因果设计提供支持，否则它仍只是关联。

链接函数

链接函数 \(g\) 把均值的有效定义域映射到预测量所使用的无约束实数域：

\[ g(\mu)=\eta, \qquad \mu=g^{-1}(\eta). \]

恒等逆链接允许任意实数均值；sigmoid 将 Bernoulli 均值限制在 \([0,1]\)；指数函数则保证 Poisson 或 Gamma 均值为正。链接函数也决定系数解释：

  • 恒等链接：\(\beta_j\) 是每增加一个特征单位所对应的均值加性差异；
  • logit 链接：\(e^{\beta_j}\) 是优势的乘数；
  • log 链接：\(e^{\beta_j}\) 是均值或发生率的乘数。

典范链接（canonical link） 将指数族分布的自然参数直接连接到 \(\eta\)，通常可简化似然方程。Gaussian-identity、Bernoulli-logit 与 Poisson-log 都是典范组合。“典范”并不等于在所有问题中都正确；科学解释、数值行为和校准要求都可能支持另一种合法链接。

链接函数描述条件均值，而不是对观测 \(y\) 任意做变换。对 \(\log(y)\) 做最小二乘再取指数，通常不等价于 log-link GLM，因为 \(\mathbb E[e^{\log Y}\mid X]\) 与 \(e^{\mathbb E[\log Y\mid X]}\) 不相等，而且零值无法在没有临时修补的情况下取对数。

Python 示例：Poisson log 链接保证计数预测非负 
import numpy as np
from sklearn.linear_model import LinearRegression, PoissonRegressor
from sklearn.metrics import mean_poisson_deviance
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(151)
X = rng.uniform(-3.5, 2.5, size=(3000, 1))
true_mean = np.exp(-0.8 + 0.75 * X[:, 0])
y = rng.poisson(true_mean)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.35, random_state=151
)

ols = LinearRegression().fit(X_train, y_train)
poisson = PoissonRegressor(alpha=0.0, max_iter=1000).fit(X_train, y_train)

ols_prediction = ols.predict(X_test)
poisson_prediction = poisson.predict(X_test)

print("minimum OLS prediction:    ", round(ols_prediction.min(), 3))
print("minimum Poisson prediction:", round(poisson_prediction.min(), 3))
print("negative OLS predictions:  ", int(np.sum(ols_prediction <= 0)))
print("Poisson test deviance:      ", round(mean_poisson_deviance(y_test, poisson_prediction), 3))

# Poisson deviance is undefined for nonpositive predictions, so clipping OLS is only a diagnostic workaround.
clipped_ols = np.clip(ols_prediction, 1e-8, None)
print("clipped-OLS test deviance:  ", round(mean_poisson_deviance(y_test, clipped_ols), 3))

指数族分布

单参数指数族密度可写为

\[ p(y\mid\theta,\phi) =\exp\left( \frac{y\theta-b(\theta)}{a(\phi)}+c(y,\phi) \right), \]

其中 \(\theta\) 是自然参数，\(\phi\) 控制离散程度，而 \(b\) 决定矩：

\[ \mathbb E[Y]=b'(\theta), \qquad \operatorname{Var}(Y)=a(\phi)b''(\theta). \]

这一形式把 Gaussian、Bernoulli/binomial、Poisson、Gamma 和 inverse-Gaussian 分布统一起来，并在同一数学框架下提供似然、得分方程、偏差残差与迭代重加权最小二乘拟合。

偏差（deviance） 比较拟合模型与饱和模型；后者在该分布族允许的范围内尽可能贴合每一个观测：

\[ D=2\left[\ell(\text{saturated})-\ell(\text{fitted})\right]. \]

在同一数据上，较低偏差表示更好的似然拟合，但训练偏差总会随模型灵活度增加而改善。模型比较应使用样本外偏差或带惩罚的信息准则，而且不同响应分布族的偏差值通常不能直接互换比较。

Python 示例：计算 Poisson 偏差贡献并定位拟合较差的计数 
import numpy as np

y = np.array([0, 1, 2, 8, 3, 12], dtype=float)
predicted_mean = np.array([0.4, 0.8, 2.5, 4.0, 3.2, 7.0])

# For y=0, the limit of y * log(y / mu) is zero.
log_term = np.zeros_like(y)
positive = y > 0
log_term[positive] = y[positive] * np.log(y[positive] / predicted_mean[positive])
contribution = 2 * (log_term - (y - predicted_mean))

for observed, predicted, deviance in zip(y, predicted_mean, contribution):
    print(f"observed={observed:>4.0f}, predicted={predicted:>4.1f}, deviance={deviance:.3f}")
print("total mean Poisson deviance:", round(contribution.mean(), 3))

框架比较。 Gaussian identity 回归适合条件方差近似恒定的实值结果；Bernoulli-logit 回归建模事件概率；Poisson-log 回归建模非负计数或发生率，并可通过 offset 纳入暴露量；Gamma-log 回归适合右偏的正值均值。诊断必须同时检查线性预测量和所选均值—方差关系。

基函数扩展与非线性效应

直线经常过于严格，但不必因此完全放弃线性模型。基函数扩展 把原始输入转换为派生特征：

\[ x \longmapsto \phi(x)=[\phi_1(x),\ldots,\phi_m(x)]^\top, \qquad \eta(x)=\beta_0+\sum_{j=1}^{m}\beta_j\phi_j(x). \]

拟合曲线关于 \(x\) 可以是非线性的，同时仍关于未知系数保持线性，因此熟悉的最小二乘或 GLM 优化仍然适用。表示方式决定模型可以表达哪些形状；正则化和验证则决定数据能够支持多大的灵活度。

多项式回归

多项式回归以变量的幂作为基函数。\(d\) 次模型为

\[ \widehat y=\beta_0+\beta_1x+\beta_2x^2+\cdots+\beta_dx^d. \]

尽管曲线关于 \(x\) 非线性，但系数以加性形式进入，因此它仍是线性模型。对于多个预测变量，PolynomialFeatures 还可生成 \(x_1x_2\) 等交叉乘积，用于表示一个变量的效应依赖于另一个变量的交互关系。

次数控制偏差与灵活度之间的权衡：直线无法表示曲率，适度次数的多项式可以，而高次多项式可能在观测之间振荡、对噪声极其敏感，并在外推时失控。原始幂特征之间也高度相关，容易造成数值病态。中心化或标准化 \(x\)、使用正交多项式基以及正则化系数可以提高稳定性，但次数仍必须在交叉验证内部选择。

图片来源：scikit-learn，Polynomial and Spline Interpolation。

样条与广义加性模型

样条通过在若干 结点（knots） 处连接低次多项式片段来表示平滑函数。B-spline 基函数具有局部支撑：改变一个系数主要影响有限区域，而不会改变整条曲线。这种局部性通常使样条比单一的高次全局多项式更稳定。

对于三次样条，相邻片段必须以连续的一阶和二阶导数连接。灵活度由结点数量与位置、多项式次数以及平滑惩罚共同决定。基函数太少会欠拟合；过多且无惩罚的基函数则可能复现噪声。

图片来源：scikit-learn，Polynomial and Spline Interpolation。

广义加性模型（GAM） 在 GLM 线性预测量的尺度上组合多个平滑的一维效应：

\[ g\!\left(\mathbb E[Y\mid X]\right) =\beta_0+f_1(x_1)+f_2(x_2)+\cdots+f_p(x_p). \]

每个 \(f_j\) 通常用样条基表示，并通过粗糙度惩罚估计。GAM 能展示非线性的偏效应，同时比不受约束的黑箱模型更容易解释。但默认的加性结构也是限制：\(f(x_1,x_2)\) 这类交互必须有意识地加入，而且平滑曲线仍表示关联而非因果。

Python 示例：比较全局多项式与局部支撑样条

正则化线性模型

当预测变量很多、彼此相关或由大规模基函数表示时，只最小化训练损失可能产生不稳定系数。正则化 增加一个偏好简单参数向量的惩罚项：

\[ \widehat\beta =\arg\min_\beta\left[ \mathcal L(\beta)+\lambda\,\Omega(\beta) \right]. \]

\(\mathcal L\) 衡量数据拟合误差，\(\Omega\) 衡量系数复杂度，\(\lambda\ge 0\) 控制两者权衡。较大的 \(\lambda\) 会增加偏差，却可能充分降低方差，从而改善未见数据上的表现。截距一般不参与惩罚。

由于惩罚依赖系数大小，通常必须把特征缩放到可比较的尺度。缩放应放入拟合流水线，使每个验证折只用自身训练部分估计预处理参数。惩罚强度是超参数，不能根据训练误差选择。

Ridge 回归

Ridge 回归使用平方 \(L_2\) 范数：

\[ \widehat\beta_{\text{ridge}} =\arg\min_\beta \left\{ \lVert y-X\beta\rVert_2^2+\lambda\lVert\beta\rVert_2^2 \right\}. \]

对中心化数据且不惩罚截距时，

\[ \widehat\beta_{\text{ridge}} =(X^\top X+\lambda I)^{-1}X^\top y. \]

加入 \(\lambda I\) 会稳定 \(X^\top X\) 中特征值很小的方向，因此 ridge 特别适合多重共线性：它不会允许相关预测变量获得数值很大且方向相反的系数，而是分散信号并整体收缩。随着正则化增强，系数平滑趋近于零，却很少精确等于零，所以 ridge 不是特征选择方法。

图片来源：scikit-learn，Ridge Coefficients as a Function of Regularization。

Python 示例：展示 ridge 如何稳定多重共线条件下的系数 
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.metrics import mean_squared_error
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(22)
n = 180
latent = rng.normal(size=n)
X = np.column_stack([
    latent + rng.normal(scale=0.03, size=n),
    latent + rng.normal(scale=0.03, size=n),
    rng.normal(size=n),
])
y = 3.0 * latent + 0.5 * X[:, 2] + rng.normal(scale=0.7, size=n)

X_test = rng.normal(size=(300, 3))
# Recreate the same correlation structure in the test set.
test_latent = X_test[:, 0].copy()
X_test[:, 0] = test_latent + rng.normal(scale=0.03, size=300)
X_test[:, 1] = test_latent + rng.normal(scale=0.03, size=300)
y_test = 3.0 * test_latent + 0.5 * X_test[:, 2] + rng.normal(scale=0.7, size=300)

models = {
    "OLS": LinearRegression(),
    "Ridge": make_pipeline(StandardScaler(), Ridge(alpha=10.0)),
}
coefficient_samples = {name: [] for name in models}
test_errors = {name: [] for name in models}

for _ in range(120):
    rows = rng.integers(0, n, size=n)  # bootstrap resample
    for name, model in models.items():
        model.fit(X[rows], y[rows])
        fitted = model[-1] if name == "Ridge" else model
        coefficient_samples[name].append(fitted.coef_)
        test_errors[name].append(mean_squared_error(y_test, model.predict(X_test)))

for name in models:
    coefficient_sd = np.std(coefficient_samples[name], axis=0)
    print(
        f"{name:>5}: coefficient SD={np.round(coefficient_sd, 3)}, "
        f"mean test MSE={np.mean(test_errors[name]):.3f}"
    )

前两个变量携带几乎相同的信息。OLS 在不同 bootstrap 样本中可能把权重大幅地从一个变量转移到另一个变量，同时保持相似的组合预测。Ridge 可降低单个系数的变异并经常改善预测，但收缩后的系数不再具有无惩罚 OLS 无偏估计量的相同解释。

Lasso 回归

Lasso 使用 \(L_1\) 范数：

\[ \widehat\beta_{\text{lasso}} =\arg\min_\beta \left\{ \frac{1}{2n}\lVert y-X\beta\rVert_2^2 +\lambda\lVert\beta\rVert_1 \right\}. \]

绝对值惩罚在坐标轴处带有尖角。当损失等高线扩张并接触可行域时，最优点经常落在尖角上，使部分系数精确为零。由此，lasso 内嵌了稀疏特征选择器；当真实信号确实稀疏时，它可以提升可解释性。

稀疏不等于确定。在预测变量高度相关时，lasso 可能近乎任意地保留其中一个并丢弃同样合理的另一个；微小的数据改变便可能改变所选特征集合。普通最小二乘的标准误在数据驱动选择后也不再有效。在把入选变量解释为实质性重要因素之前，需要稳定性检查、嵌套验证与领域推理。

Elastic Net

Elastic Net 组合 \(L_1\) 与平方 \(L_2\) 惩罚：

\[ \widehat\beta =\arg\min_\beta \left\{ \frac{1}{2n}\lVert y-X\beta\rVert_2^2 +\lambda\left[ \rho\lVert\beta\rVert_1 +\frac{1-\rho}{2}\lVert\beta\rVert_2^2 \right] \right\}, \]

其中 \(\rho=1\) 得到 lasso，\(\rho=0\) 时趋近 ridge。\(L_1\) 部分允许精确零值；\(L_2\) 部分鼓励相关预测变量更倾向于成组进入或退出模型。\(\lambda\) 与混合比例 \(\rho\) 都应通过验证选择。

图片来源：scikit-learn，Lasso and Elastic Net Paths。

    cv=cv,
).fit(X, y)

for name, search in [("Lasso", lasso_search), ("Elastic Net", elastic_search)]:
    coef = search.best_estimator_.named_steps["model"].coef_
    print(
        f"{name:>11}: first three coefficients={np.round(coef[:3], 3)}, "
        f"nonzero count={np.count_nonzero(np.abs(coef) > 1e-8)}"
    )

多分类线性分类

二元逻辑回归产生一个对数优势得分。具有 \(K>2\) 个类别的目标，需要一种把多个得分组织成单一预测的策略。主要线性方法要么把任务分解为多个二分类问题，要么利用归一化 softmax 似然联合拟合全部类别。

One-vs-Rest 与 One-vs-One

One-vs-Rest（OvR） 训练 \(K\) 个二分类器。第 \(k\) 个分类器把类别 \(k\) 与其余所有类别的并集区分开，预测时选择最大决策得分。它只需要 \(K\) 个模型，且易于并行；但每个负类由异质类别混合而成，独立拟合出的二元概率也不会自然形成总和为 1 的一致概率分布。

One-vs-One（OvO） 为每一对类别训练一个分类器，共需

\[ \binom{K}{2}=\frac{K(K-1)}{2} \]

个模型。推理时通过成对投票或校准后的成对得分决定获胜类别。每个学习器只看到更小、通常也更简单的二分类问题，这对支持向量机等算法可能有利；但模型数量随类别数平方增长，而且把成对决策转化为全局一致概率并不容易。

Softmax 回归

Softmax 回归又称多项逻辑回归，它联合拟合全部类别。对于类别 \(k\)，

\[ z_k(x)=\beta_{0k}+x^\top\beta_k, \qquad p(Y=k\mid x)= \frac{\exp(z_k)}{\sum_{j=1}^{K}\exp(z_j)}. \]

分母把各类别耦合起来，因此概率非负且总和为 1。参数通常结合正则化，通过最小化多分类交叉熵来估计：

\[ -\sum_{i=1}^{n}\sum_{k=1}^{K} \mathbb 1(y_i=k)\log p(Y=k\mid x_i). \]

给所有类别得分加上同一常数不会改变 softmax 概率，因此实现会采用隐式或显式的可识别性约定。为了数值稳定，软件会在取指数前减去最大 logit。

类别 \(a\) 和 \(b\) 之间的决策边界满足 \(z_a(x)=z_b(x)\)，即

\[ (\beta_a-\beta_b)^\top x+(\beta_{0a}-\beta_{0b})=0. \]

所以在所表示的特征空间中，每对类别之间的边界都是线性的。基函数扩展可使边界在原始输入空间中弯曲，但模型对扩展后特征仍保持线性。

)))

假设与诊断

得到一张拟合系数表并不意味着线性模型分析已经结束。诊断 用于检查模型的函数形式、方差、依赖关系和高影响观测是否与预期用途相容。诊断无法证明模型为真，但能揭示若干可识别的失效方式。

诊断必须尊重数据生成结构。当观测具有聚类、重复测量、空间依赖或时间顺序时，随机训练—测试划分、普通标准误与逐点独立残差假设都不恰当。

线性、独立性与同方差性

对 OLS 而言，条件均值系数无偏最关键的条件是

\[ \mathbb E[\varepsilon\mid X]=0. \]

如果遗漏变量、选择机制、同时性或测量过程使未解释成分与已纳入预测变量系统相关，该条件便会失败。训练样本残差均值很小并不能检验此条件，因为截距本身就会强制样本残差和为零。

常见假设各自承担不同作用：

  • 条件均值的线性： \(\mathbb E[Y\mid X]\) 关于表示后的特征具有加性和线性结构。对 GLM，则要求链接尺度上满足 \(g(\mu)=X\beta\)。
  • 独立性： 观测之间不存在未建模依赖。时间序列、重复测量、家庭、班级和地理聚类经常违反这一条件。
  • 同方差性： \(\operatorname{Var}(\varepsilon\mid X)=\sigma^2\) 为常数。若条件均值正确，异方差不一定使 OLS 系数有偏，但传统标准误会失效，而且 OLS 不再是最有效的线性无偏估计量。
  • 近似正态性： 正态误差支持精确的小样本 \(t\) 和 \(F\) 推断。计算 OLS 预测并不需要正态性，大样本推断也常依赖渐近近似。

对于逻辑回归，误差既非 Gaussian，也不应具有恒定方差，因为 \(\operatorname{Var}(Y\mid X)=p(1-p)\)。相关检查包括独立性、logit 尺度关系设定正确、组间有充分重叠、没有完全分离以及概率校准良好。

Python 示例：检测异方差，并比较传统标准误与 HC3 标准误 
import numpy as np
from scipy.stats import chi2

rng = np.random.default_rng(42)
n = 500
x = rng.uniform(0, 5, n)

# The conditional mean is linear, but noise grows with x.
noise_scale = 0.3 + 0.55 * x
y = 1.0 + 2.2 * x + rng.normal(scale=noise_scale)
X = np.column_stack([np.ones(n), x])

beta = np.linalg.lstsq(X, y, rcond=None)[0]
residual = y - X @ beta
xtx_inverse = np.linalg.inv(X.T @ X)
leverage = np.einsum("ij,jk,ik->i", X, xtx_inverse, X)

# Conventional covariance assumes one common residual variance.
sigma2 = residual @ residual / (n - X.shape[1])
conventional_covariance = sigma2 * xtx_inverse

# HC3 inflates each squared residual according to its leverage.
hc3_weight = (residual / (1 - leverage)) ** 2
hc3_meat = X.T @ (X * hc3_weight[:, None])
hc3_covariance = xtx_inverse @ hc3_meat @ xtx_inverse

# Breusch-Pagan LM test: regress squared residuals on the predictors.
aux_beta = np.linalg.lstsq(X, residual**2, rcond=None)[0]
aux_fitted = X @ aux_beta
aux_r2 = 1 - np.sum((residual**2 - aux_fitted) ** 2) / np.sum(
    (residual**2 - np.mean(residual**2)) ** 2
)
lm_stat = n * aux_r2
lm_pvalue = chi2.sf(lm_stat, df=X.shape[1] - 1)

print("slope estimate:", round(beta[1], 3))
print("conventional slope SE:", round(np.sqrt(conventional_covariance[1, 1]), 3))
print("HC3 robust slope SE:", round(np.sqrt(hc3_covariance[1, 1]), 3))
print("Breusch-Pagan p-value:", f"{lm_pvalue:.3g}")

稳健标准误只修复异方差造成的一种推断后果，不能修复错误的均值函数、依赖关系、遗漏混杂或不当外推。如果方差本身具有科学意义，方差模型、变量变换、加权最小二乘或合适的 GLM 可能更好。

多重共线性与高影响观测

多重共线性 表示一个预测变量可由其他变量近似重构。它不一定损害观测特征分布内部的预测，却会使单个系数估计敏感，因为数据无法提供足够信息来分配共享效应。

对于预测变量 \(X_j\)，方差膨胀因子为

\[ \operatorname{VIF}_j=\frac{1}{1-R_j^2}, \]

其中 \(R_j^2\) 来自用其余预测变量回归 \(X_j\)。较大的 VIF 表示系数方差被放大，却不构成必须删除变量的通用规则。设计矩阵条件数提供互补的整体度量；由于它依赖尺度，应先标准化预测变量再解释。

异常观测可以从两个不同方面产生影响：

  • 杠杆值 \(h_{ii}\) 是 \(H=X(X^\top X)^{-1}X^\top\) 的第 \(i\) 个对角元素，用于衡量预测变量取值有多不寻常；
  • 残差大小 衡量观测响应与拟合响应之间的差异。

删除某观测会明显改变拟合时，该观测具有较强 影响力。Cook 距离综合杠杆值与残差信息。遵循趋势的高杠杆点可能残差很小；位于特征中心的大残差点则可能杠杆有限。两者都不应被自动删除：应先核实数据质量、理解其代表的总体，并在有依据的情况下报告包含与排除该观测的敏感性结果。

Python 示例：计算 VIF、杠杆值与 Cook 距离 
import numpy as np

rng = np.random.default_rng(5)
n = 120
x1 = rng.normal(size=n)
x2 = 0.97 * x1 + rng.normal(scale=0.12, size=n)  # strong collinearity
x3 = rng.normal(size=n)
y = 1.0 + 1.5 * x1 + 1.5 * x2 - 0.7 * x3 + rng.normal(scale=0.7, size=n)

# Add one unusual predictor combination with an inconsistent response.
x1 = np.append(x1, 4.5)
x2 = np.append(x2, 4.4)
x3 = np.append(x3, -3.0)
y = np.append(y, -4.0)

features = np.column_stack([x1, x2, x3])
X = np.column_stack([np.ones(len(features)), features])
names = ["x1", "x2", "x3"]

# VIF uses an auxiliary regression of each feature on all other features.
vifs = {}
for column, name in enumerate(names):
    target = features[:, column]
    others = np.delete(features, column, axis=1)
    auxiliary_X = np.column_stack([np.ones(len(others)), others])
    fitted = auxiliary_X @ np.linalg.lstsq(auxiliary_X, target, rcond=None)[0]
    r2 = 1 - np.sum((target - fitted) ** 2) / np.sum((target - target.mean()) ** 2)
    vifs[name] = 1 / (1 - r2)

beta = np.linalg.lstsq(X, y, rcond=None)[0]
residual = y - X @ beta
xtx_inverse = np.linalg.inv(X.T @ X)
leverage = np.einsum("ij,jk,ik->i", X, xtx_inverse, X)
n_rows, p = X.shape
mse = residual @ residual / (n_rows - p)
studentized = residual / np.sqrt(mse * (1 - leverage))
cooks_d = (residual**2 / (p * mse)) * leverage / (1 - leverage) ** 2
top = np.argsort(cooks_d)[-3:][::-1]

print("VIF:", {name: round(float(value), 2) for name, value in vifs.items()})
for row in top:
    print(
        f"row={row:>3}, leverage={leverage[row]:.3f}, "
        f"studentized residual={studentized[row]:.2f}, "
        f"Cook D={cooks_d[row]:.3f}"
    )

残差诊断

普通残差为 \(e_i=y_i-\widehat y_i\)。其尺度与预期模式取决于拟合模型，因此没有任何一张图能回答全部诊断问题。

  • 残差对拟合值图 可揭示曲率、方差变化与均值模型遗漏的子群体；
  • 残差对各预测变量或时间顺序图 能揭示拟合值图隐藏的局部设定错误和依赖；
  • Normal Q-Q 图 检查标准化残差尾部是否支持 Gaussian 小样本推断，但不检验线性；
  • Scale-location 图 强调残差离散程度的变化；
  • 残差对杠杆值图 帮助识别特征位置与响应偏差共同影响拟合的观测。

对于 GLM，原始残差按构造就具有不等方差。Pearson 残差 除以模型给出的标准差；偏差残差 则分配每个观测对模型偏差的贡献。二元模型还应结合校准曲线、严格评分规则和有意义子群体上的表现进行检查。

Python 示例：利用残差结构检测遗漏的非线性效应 
import numpy as np
from scipy.stats import f

rng = np.random.default_rng(15)
x = rng.uniform(-2.5, 2.5, 260)
y = 1.0 + 1.4 * x + 1.1 * x**2 + rng.normal(scale=0.9, size=len(x))

linear_X = np.column_stack([np.ones(len(x)), x])
quadratic_X = np.column_stack([np.ones(len(x)), x, x**2])

def fit_ols(design, outcome):
    beta = np.linalg.lstsq(design, outcome, rcond=None)[0]
    residual = outcome - design @ beta
    return beta, residual, residual @ residual

_, linear_residual, linear_rss = fit_ols(linear_X, y)
_, quadratic_residual, quadratic_rss = fit_ols(quadratic_X, y)

# Nested-model F test asks whether the added x^2 term materially reduces RSS.
added_parameters = quadratic_X.shape[1] - linear_X.shape[1]
remaining_df = len(y) - quadratic_X.shape[1]
f_statistic = ((linear_rss - quadratic_rss) / added_parameters) / (
    quadratic_rss / remaining_df
)
nonlinearity_pvalue = f.sf(f_statistic, added_parameters, remaining_df)

# Average residuals in ordered x bins. A correct mean model should not leave
# a stable U-shaped pattern across these groups.
edges = np.quantile(x, np.linspace(0, 1, 7))
bin_id = np.clip(np.digitize(x, edges[1:-1]), 0, 5)
bin_means = [linear_residual[bin_id == group].mean() for group in range(6)]

# Constants common to both Gaussian AIC values are omitted; the difference is unchanged.
linear_aic = len(y) * np.log(linear_rss / len(y)) + 2 * linear_X.shape[1]
quadratic_aic = len(y) * np.log(quadratic_rss / len(y)) + 2 * quadratic_X.shape[1]

print("linear-model binned residual means:", np.round(bin_means, 2))
print("nested nonlinearity test p-value:", f"{nonlinearity_pvalue:.3g}")
print("linear AIC (up to a constant):", round(linear_aic, 1))
print("quadratic AIC (up to a constant):", round(quadratic_aic, 1))

一个实用的诊断循环是：检查数据来源与缺失机制；拟合预先指定的模型；查看残差结构和影响力；把每个异常追溯到可能机制；修改表示、分布、方差或依赖模型；最后在未触碰数据上重新评估。反复修改模型直至诊断图“好看”，会使诊断本身成为另一轮自适应拟合，因此验证性结论仍需诚实验证或新数据支持。

优势、局限与模型选择

线性模型与广义线性模型仍是强有力的默认方案，因为它们把假设明确地暴露出来。标准形式训练迅速、目标函数凸、支持稀疏输入，并提供从拟合得分到预测的直接路径。它们也是有价值的诊断基线：如果复杂得多的模型无法稳定超过正则化线性模型，额外复杂度可能没有依据。

其可解释性是有条件的，而非自动获得。只有明确特征单位、参考组、链接尺度、交互项、正则化与条件变量后，系数才有具体含义。面对相关预测变量，可能存在多种几乎等价的系数分配；使用基函数扩展时，单个系数只描述某个基函数而非完整效应，此时偏效应曲线更有信息。没有因果设计时，预测系数绝不能被提升为因果效应。

  • 平方误差回归可能对结果离群值敏感；
  • 存在依赖、异方差、选择偏差或分布设定错误时，普通推断公式会失效；
  • 在观测特征范围之外，预测可能外推到不合理数值；
  • 稀疏惩罚可能使特征选择显得比数据实际支持的更确定。

一个可辩护的模型选择过程应按以下顺序进行：

  1. 定义预测单位、目标总体、结果支持集以及与决策相关的估计目标；
  2. 选择尊重群组、时间和重复实体的数据划分策略；
  3. 使用仅由训练数据拟合的流水线构造特征，只在有依据时加入交互或平滑效应；
  4. 使响应分布和链接函数与结果及其均值—方差关系相匹配；
  5. 把正则化强度、基函数复杂度和决策阈值视为超参数，在开发数据上选择；
  6. 使用与任务一致的指标：条件均值用平方误差，概率用 log loss，计数模型用偏差；当概率驱动决策时还要检查校准；
  7. 检查残差、校准、子群体表现、系数稳定性与高影响观测；
  8. 最终锁定流水线只在未触碰测试数据上评估一次，部署后继续监控分布漂移。
Python 示例：在开发数据上比较线性候选模型，并仅测试一次 
import numpy as np
from sklearn.datasets import load_diabetes
from sklearn.linear_model import ElasticNet, LinearRegression, Ridge
from sklearn.metrics import mean_squared_error, r2_score
from sklearn.model_selection import GridSearchCV, KFold, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import SplineTransformer, StandardScaler

X, y = load_diabetes(return_X_y=True)
X_development, X_test, y_development, y_test = train_test_split(
    X, y, test_size=0.2, random_state=27
)
cv = KFold(n_splits=5, shuffle=True, random_state=27)

candidates = {
    "OLS": (
        Pipeline([("scale", StandardScaler()), ("model", LinearRegression())]),
        {},
    ),
    "Ridge": (
        Pipeline([("scale", StandardScaler()), ("model", Ridge())]),
        {"model__alpha": np.logspace(-3, 3, 13)},
    ),
    "Elastic Net": (
        Pipeline([
            ("scale", StandardScaler()),
            ("model", ElasticNet(max_iter=30_000)),
        ]),
        {
            "model__alpha": np.logspace(-3, 1, 10),
            "model__l1_ratio": [0.2, 0.5, 0.8],
        },
    ),
    "Spline + Ridge": (
        Pipeline([
            ("basis", SplineTransformer(degree=2, include_bias=False)),
            ("scale", StandardScaler()),
            ("model", Ridge()),
        ]),
        {
            "basis__n_knots": [3, 4, 5],
            "model__alpha": [0.1, 1.0, 10.0, 100.0],
        },
    ),
}

searches = {}
for name, (pipeline, grid) in candidates.items():
    search = GridSearchCV(
        pipeline,
        grid,
        scoring="neg_mean_squared_error",
        cv=cv,
    ).fit(X_development, y_development)
    searches[name] = search
    cv_rmse = np.sqrt(-search.best_score_)
    print(f"{name:>14}: development CV RMSE={cv_rmse:.2f}")

# Select using development CV only. The test set has not influenced this choice.
winner_name = max(searches, key=lambda name: searches[name].best_score_)
winner = searches[winner_name].best_estimator_
test_prediction = winner.predict(X_test)

print("selected model:", winner_name)
print("untouched test RMSE:", round(np.sqrt(mean_squared_error(y_test, test_prediction)), 2))
print("untouched test R2:", round(r2_score(y_test, test_prediction), 3))

某次划分中的获胜名称并不是普遍排名，而是当前数据集、候选集合、指标和验证设计的共同结果。当候选模型差异相对于折间不确定性很小时，应优先选择更简单或运行风险更低的模型，并报告不确定性，而不是宣称存在决定性胜者。

因此，线性建模最好被理解为一套严谨工作流，而非一条公式：表示效应，选择响应分布与链接函数，在数据可支撑的尺度上正则化，验证完整流水线，并诊断那些使预测和解释值得信赖的假设。
