机器学习总览

English 中文

机器学习研究系统如何通过数据或交互改善自身行为，同时在未见经验上保持良好表现。因此，一套完整体系不能只是算法目录，还必须把问题定义、数据、数学假设、学习目标、优化、实验证据、可靠性与部署连接起来。

本系列遵循这些依赖关系展开：第一至第三部分构建经典核心，第四部分介绍高级学习设置，第五部分讨论可信系统与研究实践。神经网络基础在这里作为过渡，而架构特定内容保留在独立的 Deep Learning 系列中。

学习路径

问题与数据
-> 数学与统计基础
-> 学习目标、优化与评估
-> 监督式与无监督式模型族
-> 高级学习范式
-> 可靠系统与研究实践

章节目录

基础与方法论

这些章节定义可学习问题，并建立后续所有模型共用的数据、数学、理论、优化与实验方法。

  1. 机器学习问题、学习范式与工作流

  4. 统计学习理论与泛化
  5. 学习目标与优化
  6. 评估、实验设计与模型选择

监督学习

这些章节按照模型对几何、概率、划分、结构与表示所作的假设组织监督学习方法。

  1. 线性回归与广义线性模型
  2. 基于实例、几何与核的方法
  3. 规则学习、决策树与集成方法
  4. 概率模型与贝叶斯学习
  5. 图模型与序列预测

无监督学习与表示学习

这些章节说明模型如何在没有直接目标标签时发现群组、密度、异常、潜在因子、流形与稀疏表示。

  1. 聚类、密度估计与异常检测
  2. 降维与稀疏表示

高级学习范式

这些章节从独立同分布的有标签样本扩展到有限监督、迁移、顺序决策与因果问题。

  1. 有限、弱与噪声监督下的学习

  3. 在线学习、Bandit 与强化学习
  4. Causal Machine Learning（英文）

可靠且实用的机器学习

  2. Machine Learning Systems and Research Practice（英文）
