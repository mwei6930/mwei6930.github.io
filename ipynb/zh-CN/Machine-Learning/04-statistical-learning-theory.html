统计学习理论与泛化

学习算法只能看到有限数据集，真正目的却是在未参与训练的样本上可靠预测。统计学习理论（statistical learning theory）研究这种跨越在何时、为何合理。它连接四个实践中容易混淆的对象：未知数据生成分布、已经观测的样本、学习器可以选择的模型家族，以及执行选择的算法。

令 \((X,Y)\sim P\) 表示从未知总体分布 \(P\) 抽取的未来输入—标签对。训练样本为

\[ S=\{(x_i,y_i)\}_{i=1}^{n}\sim P^n, \]

其中 \(n\) 是样本数，\(P^n\) 表示假设各样本独立同分布地来自 \(P\)。假设 \(h\in\mathcal H\) 把输入映射为预测，损失 \(\ell(h(x),y)\) 衡量该预测的代价。假设空间 \(\mathcal H\) 可以是直线集合、深度受限的树、固定架构的神经网络，或算法可以搜索的任意其他家族。

核心问题不只是“模型能否拟合 \(S\)”，而是：

在哪些假设下，\(S\) 上测得的性能能够为从 \(P\) 新抽取样本上的性能提供证据？

常见理论假设训练与未来样本服从同一分布，且损失定义明确并受到足够控制。时间依赖、用户层相关、反馈循环、标签泄漏或部署分布漂移，都可能使这些假设失效，即使数学界本身推导正确。因此，统计学习理论是陈述保证及其成立条件的语言，而不是自动证明任何数据集都具代表性的证书。

总体风险与经验风险

期望风险

最终真正关心的量是总体风险（population risk），也称期望风险或真实风险：

\[ R(h)=\mathbb E_{(X,Y)\sim P}\left[\ell(h(X),Y)\right]. \]

符号 含义
\(P\) 未来样本的未知分布
\((X,Y)\) 从 \(P\) 抽取的随机输入—标签对
\(h\) \(\mathcal H\) 中的一条预测规则
\(\ell\) 与任务匹配的损失，如平方误差或 log loss
\(R(h)\) 在无限次未来抽样上的平均损失

回归平方损失为 \(\ell(h(x),y)=(h(x)-y)^2\)，此时 \(R(h)\) 是期望平方预测误差。二分类零一损失为 \(\ell(h(x),y)=\mathbf 1[h(x)\neq y]\)，此时 \(R(h)\) 是总体误分类概率。损失决定“好”的含义；同一个预测器在不同损失下可以有不同风险。

因为 \(P\) 未知，总体风险通常不可观测。即便很大的留出测试集，也只能估计 \(R(h)\)，不能得到期望本身。当两个模型测试分数极其接近时，这一区别很重要：有限样本不确定性可能大于报告差值。

示意图综合自 Stanford CS229 notes 与 Cornell CS4780 statistical learning theory。

由于无法直接计算 \(R(h)\)，学习过程使用经验风险：

\[ \widehat R_S(h)=\frac{1}{n}\sum_{i=1}^{n}\ell(h(x_i),y_i). \]

对于一个固定 \(h\)，这是用样本平均估计期望，其随机性来自 \(S\)。若样本独立、损失方差有限且数据有代表性，\(n\) 增大时 \(\widehat R_S(h)\) 倾向于接近 \(R(h)\)。两者差

\[ R(h)-\widehat R_S(h) \]

称为泛化差距（generalization gap）。对于一个固定模型和一次样本，它的符号不保证为正；但专门按极低训练误差选出的模型，经验风险通常过于乐观。

Python 示例：经验风险围绕总体风险波动 
import numpy as np

rng = np.random.default_rng(4)

def data_process(size, generator):
    x = generator.uniform(-1.0, 1.0, size=size)
    y = np.sin(np.pi * x) + generator.normal(scale=0.25, size=size)
    return x, y

def fixed_predictor(x):
    # The hypothesis is fixed before any sample is inspected.
    return 0.8 * x

def mean_squared_risk(x, y):
    return np.mean((fixed_predictor(x) - y) ** 2)

# A very large Monte Carlo sample is used only as a population-risk proxy.
x_population, y_population = data_process(300_000, rng)
population_risk = mean_squared_risk(x_population, y_population)

empirical_risks = []
for _ in range(10):
    x_sample, y_sample = data_process(30, rng)
    empirical_risks.append(mean_squared_risk(x_sample, y_sample))

print("population-risk proxy:", round(population_risk, 4))
print("ten empirical risks:   ", np.round(empirical_risks, 4))
print("empirical mean/std:    ", round(np.mean(empirical_risks), 4), round(np.std(empirical_risks), 4))

实验区分两类误差：固定线性规则系统性地无法表示正弦函数，而每个 30 样本估计还会因输入与噪声不同而波动。更多数据能减少后者，却不能修复前者。

经验风险最小化

经验风险最小化（ERM）选择训练损失最低的假设：

\[ \widehat h_S\in\arg\min_{h\in\mathcal H}\widehat R_S(h). \]

下标 \(S\) 很重要：样本不同，最小化结果也可能不同。ERM 是一般原则，不是某一个优化器。最小二乘回归、通过负对数似然实现的最大似然估计，以及完全生长的决策树，都可以被看作在不同假设空间与损失下的 ERM。

ERM 会产生微妙的选择效应：同一份数据既用于比较候选，又用于报告获胜者的训练误差。若 \(\mathcal H\) 很灵活，某个假设就可能拟合偶然噪声。它在观测样本上的低 \(\widehat R_S\) 确实真实，却不一定意味着低 \(R\)。因此，只对一个固定假设成立的集中界不够；被选中的 \(\widehat h_S\) 本身依赖数据。

Python 示例：ERM 可能偏好总体风险更大的模型 
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(12)

def true_function(x):
    return np.sin(np.pi * x)

x_train = rng.uniform(-1.0, 1.0, size=35)
y_train = true_function(x_train) + rng.normal(scale=0.25, size=len(x_train))

# A large fresh sample approximates future population risk under the same process.
x_future = rng.uniform(-1.0, 1.0, size=20_000)
y_future = true_function(x_future) + rng.normal(scale=0.25, size=len(x_future))

rows = []
for degree in [1, 3, 5, 15]:
    model = make_pipeline(
        PolynomialFeatures(degree=degree, include_bias=False),
        LinearRegression(),
    )
    model.fit(x_train[:, None], y_train)
    train_mse = mean_squared_error(y_train, model.predict(x_train[:, None]))
    future_mse = mean_squared_error(y_future, model.predict(x_future[:, None]))
    rows.append((degree, train_mse, future_mse, future_mse - train_mse))

print("degree | train MSE | future MSE | gap")
for degree, train_mse, future_mse, gap in rows:
    print(f"{degree:6d} | {train_mse:9.4f} | {future_mse:10.4f} | {gap:7.4f}")

最高次数模型可以绕过各观测点来降低训练误差。ERM 在数学上并没有“失败”，它准确解决了给定目标。真正的失败是把经验目标和假设空间当作部署风险的充分代理。

结构风险最小化

结构风险最小化（SRM）把假设组织成表达能力逐渐增强的类别

\[ \mathcal H_1\subset\mathcal H_2\subset\cdots \]

并平衡拟合与容量。一个实践抽象是

\[ \widehat h =\arg\min_{h\in\mathcal H} \left[\widehat R_S(h)+\lambda\,\Omega(h)\right], \]

其中 \(\Omega(h)\) 度量复杂度，\(\lambda\geq0\) 控制惩罚强度。经典 SRM 从容量界推导惩罚；现代实践常通过正则化、深度限制、间隔控制、架构选择、早停或基于验证的超参数选择实现同一原则。

惩罚必须对应有意义的容量概念。在玩具多项式家族中惩罚次数合理，但对权重共享或强正则化神经网络只惩罚原始参数数可能误导。多数真实工作流中，理论也不会自动给出 \(\lambda\)，它应在不使用最终测试集的条件下选择。

Python 示例：玩具结构风险准则平衡拟合与次数 
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(21)
true_function = lambda x: np.sin(np.pi * x)

x_train = rng.uniform(-1.0, 1.0, 55)
y_train = true_function(x_train) + rng.normal(scale=0.30, size=len(x_train))
x_test = rng.uniform(-1.0, 1.0, 10_000)
y_test = true_function(x_test) + rng.normal(scale=0.30, size=len(x_test))

penalty_strength = 0.008
records = []
for degree in range(1, 16):
    model = make_pipeline(
        PolynomialFeatures(degree=degree, include_bias=False),
        LinearRegression(),
    )
    model.fit(x_train[:, None], y_train)
    train_mse = mean_squared_error(y_train, model.predict(x_train[:, None]))
    criterion = train_mse + penalty_strength * degree
    test_mse = mean_squared_error(y_test, model.predict(x_test[:, None]))
    records.append((degree, train_mse, criterion, test_mse))

erm = min(records, key=lambda row: row[1])
srm = min(records, key=lambda row: row[2])
oracle = min(records, key=lambda row: row[3])  # visible only in this simulation

print("selection       degree  train_MSE  criterion  future_MSE")
for label, row in [("ERM", erm), ("toy SRM", srm), ("future oracle", oracle)]:
    print(f"{label:13s} {row[0]:6d} {row[1]:10.4f} {row[2]:10.4f} {row[3]:11.4f}")

模拟中的 oracle 使用未来标签，真实项目中并不可得，这里只用于展示准则试图近似什么。复杂度惩罚不能保证选到 oracle 模型，但会减少以巨大灵活性换取微小训练改善的诱因。

假设空间与归纳偏置

没有假设时，学习器无法从有限观测推导唯一规则。许多函数在所有训练点上一致，却在其他位置分歧。让某种延伸优于其他延伸的限制，共同构成学习器的归纳偏置。

假设空间提供其中一部分偏置。线性回归假设响应可由所选特征的线性组合近似；浅树偏好较短的轴对齐规则层次；卷积网络编码局部性与权重共享。即使名义架构不变，正则化、优化、预处理和数据增强也会增加偏好。

归纳偏置不可避免，也不等同于统计偏差。有用偏置捕捉问题中的稳定结构，有害偏置则排除部署所需关系。实践问题是：\(\mathcal H\) 与算法编码的假设是否匹配领域。

模型容量

容量（capacity）描述模型家族可以表示多少种不同输入—输出关系。容量更高的类别可以拟合更广泛的数据集。它可以由多项式次数、树深与叶数、线性特征数量及范数、核带宽、间隔、神经架构或参数约束控制。

参数数只是粗略代理。同参数量模型会因参数化、范数、间隔、不变性、稀疏性、优化器和输入分布不同而行为不同。反过来，过参数化模型可以插值训练数据，而算法仍可能在另一种复杂度度量下稳定选择相对简单的解。

容量带来两个相反可能：

  • 容量过低时，模型家族不能表示底层关系；
  • 不受控制的容量过高时，有限样本偶然性更容易被拟合。

更多数据能支撑更大类别，因为它为区分真实结构与偶然拟合提供更多证据。因此容量应相对于样本量、噪声、特征几何和学习算法讨论，而不是简单贴上“复杂模型”标签。

近似误差与估计误差

令 \(h^*\) 为所有考虑预测器中的总体风险最小者，并令

\[ h^*_{\mathcal H}\in\arg\min_{h\in\mathcal H}R(h) \]

为 \(\mathcal H\) 内最佳预测器。若 \(\widehat h\) 从有限样本中学习，其超额风险可分解为

\[ R(\widehat h)-R(h^*) =\underbrace{R(h^*_{\mathcal H})-R(h^*)}_{\text{近似误差}} +\underbrace{R(\widehat h)-R(h^*_{\mathcal H})}_{\text{估计误差}}. \]

近似误差来自 \(\mathcal H\) 的限制，即使有无限数据和完美优化，直线也不能复现任意振荡函数。估计误差来自仅用有限随机样本在 \(\mathcal H\) 中做选择。表达能力更强通常降低近似误差，却可能提高估计不确定性。

若算法没有找到预期经验最小值，还会增加优化误差。三种误差回答不同问题：

误差 诊断问题 常见响应
近似 这个家族能否表示模式？ 更丰富特征或模型类别
估计 样本能否可靠识别正确成员？ 更多代表性数据、正则化、较低容量
优化 训练是否到达合适解？ 优化器、学习率、初始化、数值检查

这些概念很有用，却常无法直接测量，因为 \(P\)、\(h^*\) 和 \(h^*_{\mathcal H}\) 未知。

Python 示例：在受控模拟中估计近似与估计效应 
import numpy as np

rng = np.random.default_rng(31)
grid = np.linspace(-1.0, 1.0, 1_000)
truth = np.sin(np.pi * grid)

def fit_polynomial(x, y, degree):
    # np.polynomial uses increasing powers and is stable on the scaled interval [-1, 1].
    return np.polynomial.polynomial.polyfit(x, y, deg=degree)

def predict_polynomial(coefficients, x):
    return np.polynomial.polynomial.polyval(x, coefficients)

print("degree | approximation | estimation | total-to-truth")
for degree in [1, 3, 7]:
    # A dense noiseless grid approximates the best-in-class population predictor.
    population_coefficients = fit_polynomial(grid, truth, degree)
    best_in_class = predict_polynomial(population_coefficients, grid)
    approximation = np.mean((best_in_class - truth) ** 2)

    learned_predictions = []
    for _ in range(150):
        x_sample = rng.uniform(-1.0, 1.0, 30)
        y_sample = np.sin(np.pi * x_sample) + rng.normal(scale=0.25, size=30)
        sample_coefficients = fit_polynomial(x_sample, y_sample, degree)
        learned_predictions.append(predict_polynomial(sample_coefficients, grid))

    learned_predictions = np.asarray(learned_predictions)
    estimation = np.mean((learned_predictions - best_in_class) ** 2)
    total_to_truth = np.mean((learned_predictions - truth) ** 2)
    print(f"{degree:6d} | {approximation:13.5f} | {estimation:10.5f} | {total_to_truth:14.5f}")

一次家族存在明显表示限制；三次能以适中估计不确定性捕捉主要形状；七次在稠密网格上近似误差几乎为零，却难以从 30 个含噪观测稳定拟合交互系数。由于有限 Monte Carlo 模拟可能保留交叉项，显示的两个量并不严格相加；它是诊断性演示，不是未知现实分解的直接估计器。

欠拟合与过拟合

当表示、特征、优化或训练时间不足，使学习系统即使在训练分布上也无法达到足够低误差时，称为欠拟合（underfitting）。当训练样本性能显著优于目标分布的未见样本时，称为过拟合（overfitting）。前者通常与有效容量不足有关，后者与不可靠的泛化差距有关。

它们是经验诊断，不是模型名称的永久属性。深度 10 的树可以在高度结构化问题上欠拟合，也可以在微小含噪数据上过拟合；大规模神经网络在强数据、优化与正则偏置下也能良好泛化。讨论时必须说明数据集、损失、切分和训练流程。

来源：Google Machine Learning Crash Course, Overfitting。

训练、验证与泛化误差

三个标准数据角色必须保持不同：

  • 训练集估计梯度或模型参数；
  • 验证集比较超参数、特征、阈值与停止时刻；
  • 测试集在开发决策固定后只使用一次，估计最终性能。

验证集是学习过程的一部分。反复尝试并选择最佳验证分数会让决策适应验证噪声，使该分数过于乐观。诚实泛化估计需要最终未接触测试集、嵌套交叉验证或外部评估集。第 06 章将详细讨论实验协议。

训练误差通常较低，因为模型正是依据这些观测选择的。误差组合比任何单个数字更有信息：

训练误差 验证误差 可能解释
高 高且相近 欠拟合、特征弱、优化失败或目标含噪
低 高很多 过拟合、训练泄漏或分布不匹配
低 低且相近 拟合有希望，但仍受测试不确定性与部署漂移影响
高 反而更低 切分不匹配、小样本噪声或流水线错误
Python 示例：绘制多项式容量的验证曲线 
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(44)
true_function = lambda x: np.cos(1.5 * np.pi * x)

x_train = rng.uniform(0.0, 1.0, 45)
y_train = true_function(x_train) + rng.normal(scale=0.15, size=len(x_train))
x_validation = rng.uniform(0.0, 1.0, 2_000)
y_validation = true_function(x_validation) + rng.normal(scale=0.15, size=len(x_validation))

print("degree | training MSE | validation MSE | generalization gap")
for degree in [1, 2, 4, 8, 12, 16]:
    model = make_pipeline(
        PolynomialFeatures(degree=degree, include_bias=False),
        LinearRegression(),
    )
    model.fit(x_train[:, None], y_train)
    train_mse = mean_squared_error(y_train, model.predict(x_train[:, None]))
    validation_mse = mean_squared_error(
        y_validation, model.predict(x_validation[:, None])
    )
    print(
        f"{degree:6d} | {train_mse:12.4f} | {validation_mse:14.4f} |"
        f" {validation_mse - train_mse:18.4f}"
    )

验证曲线（validation curve）在训练规模固定时改变控制容量的超参数，可定位高偏差与高方差区域；但选择最佳点本身仍消耗验证信息。

学习曲线

学习曲线（learning curve）改变训练样本数，并同时度量训练与验证性能。它不同于“损失—迭代次数”曲线：横轴是数据量，而不是优化时间。

典型模式包括：

  • 两条曲线以小差距停在较差性能：在改善表示或特征前，增加同类数据可能帮助有限；
  • 训练强、验证落后，但差距随样本量缩小：更多代表性数据可能降低方差；
  • 两条曲线持续改善：增加数据可能有价值；
  • 曲线持续分离或不稳定：需要检查容量、泄漏、非 i.i.d. 切分或分布漂移。

来源：scikit-learn, Plotting Learning Curves and Checking Models’ Scalability。图中的 “test score” 指留出交叉验证分数，不是反复查看的最终测试集。

Python 示例：用交叉验证计算学习曲线

学习曲线是诊断工具，不是因果证明。差距缩小暗示方差问题，但从错误分布收集更多样本无法修复分布错配、标签偏差、泄漏或不适合的目标。

偏差—方差分解

偏差与方差解释拟合预测器在假想的不同训练数据集之间如何变化。它们属于完整学习流程：假设空间、优化器、正则化、样本量和数据分布共同决定结果。

偏差、方差与不可约噪声

假设回归过程

\[ Y=f(X)+\varepsilon, \qquad \mathbb E[\varepsilon\mid X]=0, \qquad \operatorname{Var}(\varepsilon\mid X=x)=\sigma^2, \]

并令 \(\widehat f_S(x)\) 是在随机样本 \(S\) 上训练后的预测。固定输入 \(x\) 处的平方损失满足

\[ \mathbb E_{S,\varepsilon}\left[(Y-\widehat f_S(x))^2\mid X=x\right] =\underbrace{\left(\mathbb E_S[\widehat f_S(x)]-f(x)\right)^2}_{\text{偏差}^2} +\underbrace{\mathbb E_S\left[(\widehat f_S(x)-\mathbb E_S\widehat f_S(x))^2\right]}_{\text{方差}} +\underbrace{\sigma^2}_{\text{不可约噪声}}. \]

偏差衡量学习器平均预测相对回归函数的系统偏移；方差衡量预测对所观察训练样本的敏感性；不可约噪声是在给定过程下无法由已有 \(X\) 预测的 \(Y\) 变化。

该公式要求平方误差、给定条件均值假设，并对重复数据集取平均。它不是可以原样套到 accuracy、F1 或任意分类损失上的通用恒等式；相关分解存在，但项与解释不同。

Python 示例：验证平方误差偏差—方差分解 
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(64)
noise_sd = 0.25
grid = np.linspace(-1.0, 1.0, 160)
true_values = np.sin(np.pi * grid)

print("degree | bias^2 | variance | noise | sum | simulated test MSE")
for degree in [1, 3, 7]:
    predictions = []
    for _ in range(220):
        x_train = rng.uniform(-1.0, 1.0, 28)
        y_train = np.sin(np.pi * x_train) + rng.normal(scale=noise_sd, size=28)
        model = make_pipeline(
            PolynomialFeatures(degree=degree, include_bias=False),
            LinearRegression(),
        )
        model.fit(x_train[:, None], y_train)
        predictions.append(model.predict(grid[:, None]))

    predictions = np.asarray(predictions)
    mean_prediction = predictions.mean(axis=0)
    bias_squared = np.mean((mean_prediction - true_values) ** 2)
    variance = np.mean(np.var(predictions, axis=0))
    noise = noise_sd ** 2

    # Give every learned model an independent noisy future target at each x.
    future_targets = true_values + rng.normal(scale=noise_sd, size=predictions.shape)
    simulated_mse = np.mean((predictions - future_targets) ** 2)
    decomposition = bias_squared + variance + noise
    print(
        f"{degree:6d} | {bias_squared:6.4f} | {variance:8.4f} |"
        f" {noise:5.4f} | {decomposition:6.4f} | {simulated_mse:18.4f}"
    )

Monte Carlo 噪声使等式无法数值上完全相等，但模拟测试误差应接近三项之和。实验也说明：模型平均偏差可以很小，却因不同样本上的预测剧烈变化而不可靠。

偏差—方差权衡

提高有效容量通常降低偏差，因为学习器能表示更多模式；也可能提高方差，因为更多规则可以解释小样本。正则化、集成和更多数据常降低方差，更丰富特征或模型类别常降低偏差。这些是趋势，不是定律。

干预 典型影响 重要限制
提高模型容量 降低偏差，可能提高方差 优化与隐式偏置可能同时改变两者
加强正则化 降低方差，可能提高偏差 合适惩罚取决于表示
增加代表性数据 常降低方差 不修复系统错配或标签偏差
平均多样模型 降低方差 组件错误高度相关时效果有限
改善信息性特征 可在较小方差代价下降低偏差 特征选择可能泄漏验证信息

经典 U 形验证曲线概括一种常见状态，但偏差和方差并不要求测试风险随单一容量标量增长时必然 U 形。后文的现代插值和 double descent 会说明这个简图并不普适。

正则化与容量控制

正则化改变学习流程，使拟合每一个训练细节不再是唯一优先事项。它在经验风险相近的假设之间编码偏好。

显式与隐式正则化

显式正则化加入可见项或约束，例如

\[ \min_w\left[\widehat R_S(w)+\lambda\Omega(w)\right] \qquad\text{或}\qquad \min_w\widehat R_S(w)\ \text{subject to}\ \Omega(w)\leq c. \]

\(\Omega(w)\) 定义哪些参数算复杂，\(\lambda\) 或 \(c\) 设定强度。在适当凸条件下，约束形式与惩罚形式密切相关，但不同缩放约定中的数值超参数不能直接互换。

隐式正则化在没有显式惩罚时产生。梯度下降可能偏好特定最小范数或大间隔解；早停限制高方差方向被完全拟合；架构引入权重共享或局部性；随机优化与有限精度也可能偏好某些插值解。“隐式”不表示神秘或总是有益，只表示偏好由过程诱导，而不是单独写成 \(\Omega\)。

L1 与 L2 惩罚

对 \(w\in\mathbb R^d\)，常见惩罚为

\[ \Omega_{L1}(w)=\|w\|_1=\sum_{j=1}^{d}|w_j|, \qquad \Omega_{L2}(w)=\|w\|_2^2=\sum_{j=1}^{d}w_j^2. \]

L2 平滑收缩系数，并倾向在相关特征间共享权重；L1 在零处不可微，常产生稀疏系数。特征尺度很重要：大尺度特征对应系数与小尺度特征对应系数不可直接比较，因此通常需要标准化。

两种惩罚都不是自动发现真特征的工具。相关预测变量中，L1 可能不稳定地选择一个；L2 可能保留许多弱系数。惩罚应反映期望归纳偏置，并在验证协议内调节。

Python 示例：比较无正则、L2 与 L1 线性模型 
import numpy as np
from sklearn.linear_model import Lasso, LinearRegression, Ridge
from sklearn.metrics import mean_squared_error
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(73)
n_train, n_test, n_features = 140, 4_000, 24

# Correlated features arise from five shared latent factors.
latent_train = rng.normal(size=(n_train, 5))
latent_test = rng.normal(size=(n_test, 5))
mixing = rng.normal(size=(5, n_features))
x_train = latent_train @ mixing + 0.25 * rng.normal(size=(n_train, n_features))
x_test = latent_test @ mixing + 0.25 * rng.normal(size=(n_test, n_features))

true_weights = np.zeros(n_features)
true_weights[[1, 7, 14, 20]] = [2.0, -1.5, 1.2, -0.8]
y_train = x_train @ true_weights + rng.normal(scale=1.0, size=n_train)
y_test = x_test @ true_weights + rng.normal(scale=1.0, size=n_test)

models = {
    "unregularized": LinearRegression(),
    "L2 Ridge": Ridge(alpha=0.1),
    "L1 Lasso": Lasso(alpha=0.03, max_iter=20_000),
}

print("model          test MSE  coefficient L2  non-zero coefficients")
for name, estimator in models.items():
    model = make_pipeline(StandardScaler(), estimator)
    model.fit(x_train, y_train)
    coefficients = model[-1].coef_
    test_mse = mean_squared_error(y_test, model.predict(x_test))
    non_zero = np.count_nonzero(np.abs(coefficients) > 1e-8)
    print(f"{name:14s} {test_mse:8.4f} {np.linalg.norm(coefficients):15.4f} {non_zero:22d}")

单次模拟不能证明哪种惩罚普遍更好，只能展示它们鼓励的解结构不同。若关心系数稳定性，必须在新样本上重复实验。

早停与数据增强

迭代训练中，低频或证据强的结构往往早于微弱含噪方向被拟合。早停（early stopping）监控验证指标，保留最佳迭代的参数而不是最终参数。停止时间成为控制容量的超参数，不能查看测试集后选择。

来源：Google Machine Learning Crash Course, Overfitting。

Python 示例：在梯度下降中实现基于验证的早停 
import numpy as np
from sklearn.preprocessing import PolynomialFeatures, StandardScaler

rng = np.random.default_rng(81)
true_function = lambda x: np.sin(np.pi * x)

x_train = rng.uniform(-1.0, 1.0, 32)[:, None]
y_train = true_function(x_train[:, 0]) + rng.normal(scale=0.28, size=32)
x_validation = rng.uniform(-1.0, 1.0, 500)[:, None]
y_validation = true_function(x_validation[:, 0]) + rng.normal(scale=0.28, size=500)

polynomial = PolynomialFeatures(degree=12, include_bias=False)
scaler = StandardScaler()
train_features = scaler.fit_transform(polynomial.fit_transform(x_train))
validation_features = scaler.transform(polynomial.transform(x_validation))

# Add an unpenalized intercept column.
train_design = np.column_stack([np.ones(len(x_train)), train_features])
validation_design = np.column_stack([np.ones(len(x_validation)), validation_features])
weights = np.zeros(train_design.shape[1])

best_weights = weights.copy()
best_iteration = 0
best_validation_mse = np.inf
learning_rate = 0.015

for iteration in range(1, 5_001):
    residual = train_design @ weights - y_train
    gradient = (2.0 / len(y_train)) * train_design.T @ residual
    weights -= learning_rate * gradient

    validation_mse = np.mean((validation_design @ weights - y_validation) ** 2)
    if validation_mse < best_validation_mse:
        best_validation_mse = validation_mse
        best_iteration = iteration
        best_weights = weights.copy()

best_train_mse = np.mean((train_design @ best_weights - y_train) ** 2)
final_train_mse = np.mean((train_design @ weights - y_train) ** 2)
final_validation_mse = np.mean((validation_design @ weights - y_validation) ** 2)

print("best iteration:", best_iteration)
print("best train/validation MSE:", round(best_train_mse, 4), round(best_validation_mse, 4))
print("final train/validation MSE:", round(final_train_mse, 4), round(final_validation_mse, 4))

数据增强（data augmentation）用假定保持目标不变的变换扩展观测样本，例如小幅图像平移、音频扰动、语义安全的文本变换或领域模拟。它通过编码不变性实现正则化，其正确性完全依赖“标签保持”假设。水平翻转适合许多物体图像，却不适合文字、非对称解剖或交通标志。增强改变有效训练分布，并不会凭空创造独立信息。

Python 示例：把数据增强检验为不变性假设 
import numpy as np
from sklearn.datasets import make_moons
from sklearn.metrics import accuracy_score
from sklearn.tree import DecisionTreeClassifier

plain_scores, augmented_scores = [], []

for seed in range(30):
    rng = np.random.default_rng(seed)
    x_train, y_train = make_moons(n_samples=40, noise=0.22, random_state=seed)
    x_test, y_test = make_moons(n_samples=3_000, noise=0.22, random_state=10_000 + seed)

    plain = DecisionTreeClassifier(random_state=seed)
    plain.fit(x_train, y_train)
    plain_scores.append(accuracy_score(y_test, plain.predict(x_test)))

    # Assume small coordinate perturbations preserve the moon label.
    copies = [x_train]
    labels = [y_train]
    for _ in range(8):
        copies.append(x_train + rng.normal(scale=0.06, size=x_train.shape))
        labels.append(y_train)

    augmented = DecisionTreeClassifier(random_state=seed)
    augmented.fit(np.vstack(copies), np.concatenate(labels))
    augmented_scores.append(accuracy_score(y_test, augmented.predict(x_test)))

print("mean plain accuracy:    ", round(np.mean(plain_scores), 4))
print("mean augmented accuracy:", round(np.mean(augmented_scores), 4))
print("mean difference:        ", round(np.mean(np.array(augmented_scores) - np.array(plain_scores)), 4))

跨多个样本的平均比一个有利随机种子更有信息。即便如此，结果也只支持该合成不变性与模型的组合；更强或语义无效的扰动会损害泛化。

PAC 学习

PAC 学习把“可学习”变成关于准确度、置信度、样本量与假设空间复杂度的定量陈述。

Probably Approximately Correct Learning

在可实现二分类设定中，如果对类别内任意目标概念和任意数据分布，足够多样本都能让学习器返回满足下式的 \(\widehat h_S\)，则称其为概率近似正确（PAC）：

\[ \Pr_{S\sim P^n}\left(R(\widehat h_S)\leq\varepsilon\right)\geq 1-\delta. \]

\(\varepsilon\in(0,1)\) 是可容忍总体误差，对应“approximately correct”；\(\delta\in(0,1)\) 是随机采样产生更差模型的最大概率，对应“probably”。概率针对训练样本的随机抽取，而不是一个已训练模型是否恰好正确分类单个点。

基于 Cornell CS6781, Theoretical Foundations of Machine Learning 的 PAC 定义。

样本复杂度函数 \(m_{\mathcal H}(\varepsilon,\delta)\) 给出充分的 \(n\)。有意义的保证应关于 \(1/\varepsilon\)、\(1/\delta\) 或 \(\log(1/\delta)\)，以及 \(\mathcal H\) 的容量度量呈多项式增长。PAC 的“分布无关”表示保证适用于满足设定的任意固定 \(P\)，但仍假定训练与评估都从同一个 \(P\) 抽取。

PAC 界通常保守。它的价值不只是精确预测所需数据量，还在于揭示哪些量从根本上控制泛化，并区分理论保证与经验观察。

可实现与不可知设定

可实现（realizable）设定假设存在某个 \(h\in\mathcal H\) 的总体误差为零。例如无噪声阈值标签可以被阈值假设精确拟合。这个假设便于分析，却很强：真实标签会有噪声，特征可能不完整，真实决策规则也可能不在 \(\mathcal H\) 中。

不可知（agnostic）设定移除该假设，目标改为相对最佳可用假设的超额风险：

\[ R(\widehat h_S) \leq \inf_{h\in\mathcal H}R(h)+\varepsilon \]

且概率至少为 \(1-\delta\)。最佳成员不可避免的风险不归咎于学习器。这更接近实际监督学习，因为标签与表示很少允许完美预测。

Python 示例：对比可实现与含噪阈值学习 
import numpy as np

rng = np.random.default_rng(93)

def fit_threshold_erm(x, y):
    # Candidate thresholds are the two outer sentinels and every midpoint.
    sorted_x = np.sort(np.unique(x))
    candidates = np.concatenate(
        [[sorted_x[0] - 1.0], (sorted_x[:-1] + sorted_x[1:]) / 2.0, [sorted_x[-1] + 1.0]]
    )
    errors = [np.mean((x >= threshold).astype(int) != y) for threshold in candidates]
    return candidates[int(np.argmin(errors))], min(errors)

true_threshold = 0.25
x_train = rng.uniform(-1.0, 1.0, 120)
clean_labels = (x_train >= true_threshold).astype(int)

# Agnostic case: labels are flipped independently with probability 0.15.
noisy_labels = clean_labels.copy()
flips = rng.random(len(noisy_labels)) < 0.15
noisy_labels[flips] = 1 - noisy_labels[flips]

x_population = rng.uniform(-1.0, 1.0, 200_000)
population_clean = (x_population >= true_threshold).astype(int)

for name, labels in [("realizable", clean_labels), ("agnostic/noisy", noisy_labels)]:
    threshold, train_error = fit_threshold_erm(x_train, labels)
    population_error_against_clean_rule = np.mean(
        (x_population >= threshold).astype(int) != population_clean
    )
    print(
        f"{name:15s} threshold={threshold:7.3f},"
        f" train error={train_error:.3f}, clean-rule population error={population_error_against_clean_rule:.3f}"
    )

可实现情形中，一旦样本从两侧夹住目标阈值，就应出现零训练误差。含噪情形中，没有阈值能解释任意翻转，所以有意义的基准是最佳阈值风险而不是零。

VC 维与打散

有限假设类可以用 \(\log|\mathcal H|\) 控制，但许多重要类别含有无限多参数取值。Vapnik-Chervonenkis 理论度量一个类别能在有限点集上表达多少种标注。

若对于点集 \(\{x_1,\ldots,x_m\}\) 的全部 \(2^m\) 种二元标签分配，都至少存在一个 \(h\in\mathcal H\) 实现它，则称二元假设类 \(\mathcal H\) 打散（shatter）了这些点。打散并不要求同一个模型同时拟合全部标注，而是类别中可以为每种标注选择不同模型。

VC 维是至少存在一个可被打散的 (m) 点集合时最大的 \(m\)；若任意大集合都可打散，VC 维为无穷。

基于 Cornell CS4780, Shattering and VC Dimension。

图展示二维仿射直线的两个事实：存在可被打散的三点集合，故 VC 维至少为 3；不存在可被打散的四点集合，故至多为 3。第二个结论必须考虑所有可能排列，而不只是展示一个四点集合失败。\(\mathbb R^d\) 中仿射线性分类器的一般结果是 VC 维 \(d+1\)。

增长函数

增长函数（growth function）统计 \(\mathcal H\) 在 (m) 个点上最多能产生多少种不同标注：

\[ \Pi_{\mathcal H}(m) =\max_{x_1,\ldots,x_m} \left| \left\{(h(x_1),\ldots,h(x_m)):h\in\mathcal H\right\} \right|. \]

总有 \(\Pi_{\mathcal H}(m)\leq2^m\)。当且仅当 \(\Pi_{\mathcal H}(m)=2^m\) 时，类别能打散某个 (m) 点集合。一旦 (m) 超过有限 VC 维 (d)，Sauer-Shelah 引理把增长从指数限制为多项式：

\[ \Pi_{\mathcal H}(m)\leq\sum_{i=0}^{d}{m\choose i} \leq\left(\frac{em}{d}\right)^d \quad\text{for }m\geq d. \]

从无限制指数增长转为容量受控增长，使许多无限类别能够获得一致收敛。

Python 示例：枚举直线上阈值的增长函数 
import itertools
import numpy as np

def threshold_labelings(points):
    points = np.sort(np.asarray(points))
    candidates = np.concatenate(
        [[points[0] - 1.0], (points[:-1] + points[1:]) / 2.0, [points[-1] + 1.0]]
    )
    return {tuple((points >= threshold).astype(int)) for threshold in candidates}

for m in range(1, 7):
    points = np.arange(m, dtype=float)
    realized = threshold_labelings(points)
    all_binary = set(itertools.product([0, 1], repeat=m))
    print(
        f"m={m}: realized={len(realized):2d}, possible={len(all_binary):2d},"
        f" shattered={realized == all_binary}"
    )

一维单向阈值只产生 \(m+1\) 种标注：全零、全一，以及在每个间隙的一次转换。它能打散一点却不能打散两点，所以按此方向定义 VC 维为 1。允许两种方向会改变小样本计数和 VC 维，精确假设定义很重要。

参数数量之外的模型复杂度

对于许多经典二元类别，VC 维比原始参数数量更有信息，但仍是最坏情况度量。现代泛化还可能依赖间隔、权重范数、路径范数、所选解的平坦性或稳定性、压缩、架构不变性与数据分布。

模型家族 比单纯模型名更有信息的容量控制
线性分类器 输入维度、间隔、特征范数、权重范数
决策树 深度、叶数、最小叶大小、剪枝
核方法 核、带宽、RKHS 范数、间隔
神经网络 架构、范数、间隔、优化器、增强、学习表示

多参数模型在特定分布上的有效容量可以很低，小模型也能通过高度自适应特征记忆。容量最好被看作“假设—算法—数据”组合的属性。

集中不等式与泛化界

集中不等式形式化样本平均如何接近期望。推理顺序很重要：先控制一个假设，再同时控制学习器可能选择的所有假设，最后反解所需样本量。

Hoeffding 不等式

令 \(Z_1,\ldots,Z_n\) 为 \([0,1]\) 中独立、共同均值为 \(\mu\) 的随机变量。Hoeffding 不等式给出

\[ \Pr\left(\left|\frac{1}{n}\sum_{i=1}^{n}Z_i-\mu\right|\geq\varepsilon\right) \leq2\exp(-2n\varepsilon^2). \]

对一个固定分类器 \(h\)，令 \(Z_i=\mathbf1[h(x_i)\neq y_i]\)，样本平均就是 \(\widehat R_S(h)\)，\(\mu=R(h)\)。该界分布无关，但要求观测独立且损失有界。平方损失并不自动位于 \([0,1]\)；必须先有界、裁剪并接受目标变化，或改用其他不等式与尾部假设。

指数项表明，把 \(\varepsilon\) 减半大致需要四倍样本；把置信度提高到 \(1-\delta\) 只会使样本量按对数增长。

Python 示例：比较经验偏差概率与 Hoeffding 界 
import numpy as np

rng = np.random.default_rng(107)
event_probability = 0.30
epsilon = 0.10
trials = 30_000

print("n    empirical failure    Hoeffding upper bound")
for n in [20, 50, 100, 300, 800]:
    sample_means = rng.binomial(n=n, p=event_probability, size=trials) / n
    empirical_failure = np.mean(np.abs(sample_means - event_probability) >= epsilon)
    bound = min(1.0, 2.0 * np.exp(-2.0 * n * epsilon ** 2))
    print(f"{n:3d} {empirical_failure:18.6f} {bound:24.6f}")

该界是上界保证，不是精确概率预测。因为它要保护所有满足假设的分布，通常较松。

一致收敛

Hoeffding 控制独立于样本选定的一个 \(h\)；ERM 查看样本后才选择 \(h\)，所以学习需要同时控制：

\[ \sup_{h\in\mathcal H}|R(h)-\widehat R_S(h)|\leq\varepsilon. \]

对有限 \(\mathcal H\)，对每个假设应用 Hoeffding，再使用 union bound：

\[ \Pr\left( \sup_{h\in\mathcal H}|R(h)-\widehat R_S(h)|\geq\varepsilon \right) \leq2|\mathcal H|\exp(-2n\varepsilon^2). \]

解出 \(n\) 后出现的是 \(|\mathcal H|\) 的对数，而不是原大小。无限类别则用增长函数、VC 维、Rademacher complexity、覆盖数、间隔或其他容量度量替代有限计数。

若每个经验风险都紧跟总体风险，一致收敛解释了 ERM 为何安全。设经验最小化器为 \(\widehat h\)，每个差距不超过 \(\varepsilon\)，则

\[ R(\widehat h) \leq \widehat R_S(\widehat h)+\varepsilon \leq \widehat R_S(h^*_{\mathcal H})+\varepsilon \leq R(h^*_{\mathcal H})+2\varepsilon. \]

中间不等式正是 ERM 性质，两侧不等式对两个依赖数据的假设应用一致收敛。

Python 示例：逐个收敛比一致收敛更容易 
import numpy as np

rng = np.random.default_rng(116)
thresholds = np.linspace(-0.9, 0.9, 31)
noise_rate = 0.10

# A large common population approximates the true risk of every threshold.
x_population = rng.uniform(-1.0, 1.0, 400_000)
clean_population = (x_population >= 0.05).astype(int)
population_labels = clean_population.copy()
flips = rng.random(len(population_labels)) < noise_rate
population_labels[flips] = 1 - population_labels[flips]
population_predictions = x_population[:, None] >= thresholds[None, :]
population_risks = np.mean(population_predictions != population_labels[:, None], axis=0)

epsilon = 0.15
n = 100
trials = 2_000
fixed_failures = 0
uniform_failures = 0

for _ in range(trials):
    x = rng.uniform(-1.0, 1.0, n)
    labels = (x >= 0.05).astype(int)
    flips = rng.random(n) < noise_rate
    labels[flips] = 1 - labels[flips]
    empirical_risks = np.mean((x[:, None] >= thresholds) != labels[:, None], axis=0)
    gaps = np.abs(empirical_risks - population_risks)
    fixed_failures += gaps[15] >= epsilon
    uniform_failures += gaps.max() >= epsilon

union_bound = min(1.0, 2 * len(thresholds) * np.exp(-2 * n * epsilon ** 2))
print("fixed-hypothesis failure:", round(fixed_failures / trials, 4))
print("uniform failure:        ", round(uniform_failures / trials, 4))
print("finite-class bound:     ", round(union_bound, 4))

在许多候选中取最大值，会增加找到样本特定偏差的机会。这个多重比较效应对应于在同一验证集上进行大规模超参数搜索。

样本复杂度

令有限类界不超过 \(\delta\) 并解出 \(n\)，得到充分条件

\[ n\geq\frac{\log(2|\mathcal H|/\delta)}{2\varepsilon^2}. \]

它以置信度 \(1-\delta\) 保证每个经验风险与总体风险相差不超过 \(\varepsilon\)。若要求 ERM 超额风险不超过某个给定值，常数可能因前面出现 \(2\varepsilon\) 而改变。引用样本复杂度公式前必须检查定理所保证的精确事件。

Python 示例：检查准确度、置信度与类别大小如何影响样本复杂度 
import math

def sufficient_samples(number_of_hypotheses, epsilon, delta):
    return math.ceil(math.log(2.0 * number_of_hypotheses / delta) / (2.0 * epsilon ** 2))

settings = [
    (100, 0.10, 0.05),
    (100, 0.05, 0.05),
    (1_000_000, 0.10, 0.05),
    (1_000_000, 0.10, 0.001),
]

print("|H|        epsilon   delta    sufficient n")
for size, epsilon, delta in settings:
    print(f"{size:9d} {epsilon:9.3f} {delta:7.3f} {sufficient_samples(size, epsilon, delta):13d}")

可见三条缩放规律：\(n\) 按 \(1/\varepsilon^2\) 增长，按 \(|\mathcal H|\) 的对数增长，按 \(1/\delta\) 的对数增长。结果是充分而非必要条件，并忽略有利分布结构、间隔、稳定性和算法偏置；真实学习所需有用样本可能更少，也可能因假设违反而更多。

算法稳定性与现代泛化

经典容量界询问一个类别中的所有假设是否都能泛化；现代分析常询问更窄的问题：特定算法是否会选择对单个观测不敏感的解？当名义假设类极其庞大时，这种转变很重要。

基于稳定性的推理

令相邻数据集 \(S\) 与 \(S'\) 仅相差一个样本。若对每个评估样本 \(z\) 都有

\[ |\ell(A(S),z)-\ell(A(S'),z)|\leq\beta, \]

则称学习算法 \(A\) 关于损失 \(\ell\) 具有一致稳定性（uniform stability） \(\beta\)。小 \(\beta\) 表示单个观测无法大幅改变学习预测器的损失。稳定算法通常具有较小的期望泛化差距。强凸性与正则化可提高稳定性，高度自适应记忆会削弱它。稳定性属于算法：搜索同一架构的两个优化器也可能不同。

这种推理不要求巨大 \(\mathcal H\) 中每个成员都表现良好，只要求“数据集到选定模型”的映射受控。精确定理依赖有界性、Lipschitz 条件、凸性和稳定性定义，所以“稳定”不能被当成无假设的“稳健”同义词。

上述概念参考 Bousquet and Elisseeff, Stability and Generalization。

Python 示例：正则化降低替换一个样本的敏感性 
import numpy as np
from sklearn.linear_model import Ridge
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler

rng = np.random.default_rng(127)
x = rng.uniform(-1.0, 1.0, 65)[:, None]
y = np.sin(np.pi * x[:, 0]) + rng.normal(scale=0.25, size=len(x))

# Neighboring dataset: replace one observation with an influential example.
x_neighbor = x.copy()
y_neighbor = y.copy()
x_neighbor[0, 0] = 0.98
y_neighbor[0] = 2.5

grid = np.linspace(-1.0, 1.0, 500)[:, None]

print("ridge alpha | RMS prediction change | maximum change")
for alpha in [1e-8, 0.01, 0.1, 1.0, 10.0]:
    def build_model():
        return make_pipeline(
            PolynomialFeatures(degree=12, include_bias=False),
            StandardScaler(),
            Ridge(alpha=alpha),
        )

    model_s = build_model().fit(x, y)
    model_neighbor = build_model().fit(x_neighbor, y_neighbor)
    change = model_s.predict(grid) - model_neighbor.predict(grid)
    root_mean_square_change = np.sqrt(np.mean(change ** 2))
    print(f"{alpha:11.8f} | {root_mean_square_change:21.5f} | {np.max(np.abs(change)):14.5f}")

实验度量预测敏感性，而不是定理对所有相邻数据集和评估点的上确界，但机制清晰可见：更强 L2 收缩减少单个高影响训练观测弯曲高次拟合的程度。

Double Descent

经典叙事预测 U 形测试风险：容量提高先改善近似，随后估计误差占主导。在许多过参数化系统中会出现第二个阶段。接近插值阈值（interpolation threshold）时，模型刚好具有精确拟合训练数据的容量，解可能极度敏感；远超阈值后，测试风险又可能下降，因为算法选择更平滑、更大间隔或最小范数的插值解。这称为 double descent。

根据 Belkin 等人 Reconciling Modern Machine-Learning Practice and the Classical Bias-Variance Trade-Off 的概念图重绘。

Double descent 并不证明模型越大越能泛化，也不推翻偏差—方差分解。它说明单一单调容量概念不足以预测现代参数化中的偏差与方差。曲线依赖数据分布、噪声、特征顺序、正则化、优化器、架构以及选中哪一个插值解；多重下降或单调曲线也可能出现。

Python 示例：在最小范数线性回归中观察 double descent 
import numpy as np

rng = np.random.default_rng(139)
n_train = 80
n_test = 700
max_features = 220
signal_features = 10
capacities = [5, 10, 20, 40, 60, 72, 78, 80, 82, 90, 110, 140, 180, 220]
repetitions = 10

risks = {capacity: [] for capacity in capacities}

for _ in range(repetitions):
    x_train_full = rng.normal(size=(n_train, max_features))
    x_test_full = rng.normal(size=(n_test, max_features))

    teacher = np.empty(max_features)
    teacher[:signal_features] = rng.normal(size=signal_features)
    # Later features carry weaker signal. Their ordering makes capacity explicit
    # while still allowing the far-overparameterized regime to recover structure.
    teacher[signal_features:] = 0.15 * rng.normal(size=max_features - signal_features)
    y_train = x_train_full @ teacher + rng.normal(scale=0.5, size=n_train)
    y_test = x_test_full @ teacher + rng.normal(scale=0.5, size=n_test)

    for capacity in capacities:
        x_train = x_train_full[:, :capacity]
        x_test = x_test_full[:, :capacity]

        # lstsq returns ordinary least squares for p < n and the
        # minimum-L2-norm interpolating solution for p > n.
        coefficients = np.linalg.lstsq(x_train, y_train, rcond=None)[0]
        mse = np.mean((x_test @ coefficients - y_test) ** 2)
        risks[capacity].append(mse)

print("features | median test MSE | interquartile range")
for capacity in capacities:
    values = np.asarray(risks[capacity])
    q25, q75 = np.quantile(values, [0.25, 0.75])
    print(f"{capacity:8d} | {np.median(values):15.4f} | [{q25:8.3f}, {q75:8.3f}]")

\(p=n\) 附近的峰可能很高，因为近奇异设计矩阵会放大标签噪声。越过插值后，最小范数解把拟合分摊到更多方向，额外弱信号特征使风险下降。这只是受控 Gaussian 线性示例；改变特征顺序、信号对齐、正则化或噪声都可能改变或消除该模式。

从理论到模型诊断

当学习理论能改变下一次实验时最有价值。严谨诊断应把观测曲线连接到多个竞争解释，而不是条件反射地增加模型或数据。

观测 可能的理论解释 行动前检查 候选干预
训练与验证误差都高 近似或优化误差 特征、标签、收敛、基线 更丰富表示、更好优化器、修改目标
训练误差低、验证差距大 估计误差或切分错配 泄漏审计、重复切分、组/时间结构 正则化、更多代表性数据、降低有效容量
差距随数据增加缩小 方差受限状态 确认样本匹配部署 收集或标注更多代表性样本
两条学习曲线停在差水平 偏差、含噪目标、信息缺失 Bayes/噪声分析、残差切片 更好特征、目标定义、模型家族
验证好、部署差 \(P_{train}\neq P_{deploy}\) 或反馈 时间、子群、漂移与因果检查 重设切分、适配、监控、重训
跨种子/切分结果变化大 估计或优化不稳定 置信区间与扰动测试 更强正则化、集成、更多数据

一套实践顺序是：

  1. 定义总体与损失。说明未来样本、决策与错误成本。针对错误 \(P\) 或 \(\ell\) 的界没有意义。
  2. 审计采样假设。检查独立性、分组、时间顺序、重复、泄漏及部署是否相对训练平稳。
  3. 保护评估边界。训练用于拟合，验证用于选择，未接触测试集用于最终估计；报告不确定性而非只有点分数。
  4. 绘制验证与学习曲线。区分容量效应与样本量效应，并检查跨折或种子变化。
  5. 每次只改变一种复杂度来源。在保持评估协议时改变模型类、正则化、停止时间或特征表示。
  6. 测试稳定性与切片。替换或移除观测、扰动合理输入并检查子群；均值会掩盖脆弱模型。
  7. 部署后重新检查。经典泛化保证不能抵御任意分布漂移、策略行为或模型自身造成的反馈。
Python 示例：把训练—验证模式转换为可检验假设 
def diagnose(train_error, validation_error, baseline_error, tolerance=0.02):
    gap = validation_error - train_error
    near_baseline = validation_error >= baseline_error - tolerance

    if near_baseline and gap <= tolerance + 1e-12:
        return "Likely underfit or information-limited: inspect features, target noise, and optimization."
    if gap > tolerance:
        return "Likely estimation or split problem: audit leakage, capacity, regularization, and representativeness."
    if validation_error < baseline_error - tolerance:
        return "Promising validation result: quantify uncertainty and evaluate once on an untouched test set."
    return "Ambiguous pattern: repeat splits and inspect learning/validation curves."

cases = {
    "A": (0.31, 0.33, 0.35),
    "B": (0.04, 0.19, 0.35),
    "C": (0.08, 0.09, 0.35),
}

for name, values in cases.items():
    print(name, "->", diagnose(*values))

这个辅助工具只是生成假设，不是自动裁决。误差尺度、不确定性、任务成本、类别不平衡和分布结构共同决定数值差距是否有意义。

本章概念形成一条链：

\[ P \longrightarrow S \longrightarrow \mathcal H \longrightarrow \widehat R_S \longrightarrow \widehat h_S \longrightarrow R(\widehat h_S). \]

总体风险说明目标，经验风险提供可测代理，归纳偏置与容量决定可选择内容，正则化改变偏好，PAC、VC 与集中不等式提供最坏情况下的保证路径，稳定性与现代插值说明被选中的算法可能比名义参数量更重要。下一章将从统计问题“这条规则能泛化吗？”转向计算问题“哪种目标与优化流程能产生这条规则？”
