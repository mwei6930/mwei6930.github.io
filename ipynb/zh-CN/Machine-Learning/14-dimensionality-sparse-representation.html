降维与稀疏表示

数据表示决定了学习算法能够轻松“看到”什么。同一个观测可以被记录为十个原始测量、数千个词频、数百万个图像像素，也可以表示为一个很短的潜在坐标向量。降维（dimensionality reduction）构造低维表示，在保留选定结构的同时，丢弃被认为冗余、含噪或与任务无关的变化。

对于观测 \(\mathbf{x}\in\mathbb R^d\)，降维映射产生

\[ \mathbf z=f(\mathbf x), \qquad \mathbf z\in\mathbb R^k, \qquad k\ll d. \]

这个映射可以是线性的、非线性的、概率式的、随机的，也可以由神经网络学习。稀疏表示（sparse representation）与降维不同但可以互补：它的外部维度可能仍然很高，不过每个观测只有少数坐标被激活。一个具有 1,000 个候选 dictionary atom、但仅有 10 个非零系数的向量，在形状上是高维的，在有效描述上却很简单。

降维从来不是没有代价的压缩。每种方法都在选择需要保留的关系：

  • PCA 保留方差以及线性最小二乘重构；
  • SVD 保留最优低秩矩阵近似；
  • factor analysis 通过潜变量与显式噪声解释协方差；
  • ICA 寻找统计独立的非 Gaussian source；
  • NMF 用非负加性部件构造非负观测；
  • sparse coding 用少数 dictionary atom 重构每个观测；
  • manifold method 保留指定的局部关系或 geodesic relationship；
  • random projection 近似保留大量点对距离；
  • autoencoder 在瓶颈或正则化约束下学习非线性重构映射。

适合可视化的表示可能不适合预测；重构误差很低的表示可能丢弃安全任务所需的稀有特征；视觉上明显分离的嵌入也可能夸大原空间中非常微弱的间隔。因此，本章把评估和防止数据泄漏视为表示学习的一部分，而不是最后才添加的步骤。

为什么需要降维？

高维会同时带来计算和统计困难。存储、矩阵运算、近邻搜索以及模型复杂度都可能随特征数量增长。更隐蔽的问题是：相对于特征空间体积，固定规模的样本会越来越稀疏，可靠的局部证据因而更难获得。

维度灾难

一个 \(d\) 维单位超立方体的体积为一，但边长为 \(r<1\) 的子立方体只占 \(r^d\)。当 \(r=0.5\) 时，中心子立方体在十维中仅占 \(0.5^{10}\approx0.001\)，在五十维中仅占 \(0.5^{50}\approx8.9\times10^{-16}\)。若希望邻域仍包含相同比例的观测，维度升高后就必须大幅扩大邻域。

在许多常见数据模型下，距离也会变得越来越缺乏区分能力。如果独立特征贡献规模相近的随机变化，平方欧氏距离会累加大量随机项并集中在其期望附近。最近点和最远点可能在相对意义上越来越相似，从而削弱 nearest-neighbour、kernel、density 和 clustering 方法。这并不是说所有高维数据都无解。稀疏性、学习到的度量、较低的内在维度和强结构都能让高维问题保持可解。

Python：观察维度增加时的距离集中 
import numpy as np
from scipy.spatial.distance import pdist

rng = np.random.default_rng(14)

for dimension in [2, 10, 50, 200, 1000]:
    X = rng.normal(size=(500, dimension))
    distances = pdist(X, metric="euclidean")
    relative_spread = distances.std() / distances.mean()
    percentile_ratio = np.percentile(distances, 5) / np.percentile(distances, 95)
    print(
        f"d={dimension:4d}",
        "coefficient of variation=", round(relative_spread, 3),
        "p05/p95=", round(percentile_ratio, 3),
    )

随着维度增加，变异系数下降，而低分位数与高分位数之比趋近于一。这个现象是否影响任务，取决于数据结构、度量和建模目的。增加 1,000 个信息丰富的稀疏特征，与增加 1,000 个独立噪声特征并不等价。

压缩、去噪与可视化

降维可以服务于多种彼此不同的目标：

目标 希望保留的内容 常见诊断
压缩 足以高效重构或存储的信息 留出重构误差、压缩比例
去噪 稳定信号，同时丢弃测量波动 残差分析、对干净目标的表现
可视化 与探索问题相关的局部或全局关系 Trustworthiness、重复嵌入、原始特征检查
加速学习 在降低时间和内存后保留任务表现 与未降维基线进行端到端验证
正则化 更低的有效模型复杂度 验证性能与稳定性
解释 具有可辩护领域含义的成分 loading structure、可重复性、专家复核

内在维度（intrinsic dimension）是描述相关数据结构所需的自由度数量，它可能远小于实际记录的特征数。一帧视频可能包含数百万像素，但主要由少量对象位置、光照条件和相机参数控制。内在维度很难估计，并且会随任务变化：保留身份、动作和纹理可能需要不同坐标。

降维还可能产生数据泄漏。如果在 train/test split 之前使用完整数据拟合 PCA、缩放器、manifold method 或特征选择器，测试分布就影响了所学表示。用于预测评估的任何数据依赖变换，都必须在每个训练折内部拟合，再应用于验证数据。

主成分分析

Principal Component Analysis（PCA）是最基本的线性降维方法。它寻找中心化观测变化最大的正交方向，再把观测投影到前 \(k\) 个方向。PCA 是描述性方法而不是监督方法：它不知道哪种变化能预测目标，也不知道哪种变化在领域中最重要。

令中心化数据矩阵为 \(\mathbf X_c\in\mathbb R^{n\times d}\)，即每个特征已经减去样本均值。样本协方差为

\[ \mathbf S=\frac{1}{n-1}\mathbf X_c^\top\mathbf X_c. \]

方差最大化与重构误差

第一主方向 \(\mathbf w_1\) 满足

\[ \mathbf w_1 =\arg\max_{\lVert\mathbf w\rVert_2=1} \operatorname{Var}(\mathbf X_c\mathbf w) =\arg\max_{\lVert\mathbf w\rVert_2=1} \mathbf w^\top\mathbf S\mathbf w. \]

单位范数约束防止通过简单放大 \(\mathbf w\) 来增加方差。使用 Lagrange multiplier 可得到

\[ \mathbf S\mathbf w=\lambda\mathbf w, \]

因此主方向就是协方差矩阵的 eigenvector，并按 eigenvalue 从大到小排列。Eigenvalue \(\lambda_j\) 是成分分数 \(\mathbf X_c\mathbf w_j\) 的样本方差。后续方向在与之前方向正交的约束下，继续最大化剩余方差。

对于 loading matrix \(\mathbf W_k=[\mathbf w_1,\ldots,\mathbf w_k]\)，成分坐标和重构为

\[ \mathbf Z=\mathbf X_c\mathbf W_k, \qquad \widehat{\mathbf X}_c=\mathbf Z\mathbf W_k^\top =\mathbf X_c\mathbf W_k\mathbf W_k^\top. \]

最大化捕获方差的同一个子空间，也会最小化平方正交重构误差

\[ \left\lVert \mathbf X_c-\mathbf X_c\mathbf W_k\mathbf W_k^\top \right\rVert_F^2. \]

这个等价关系同时解释了 PCA 的优势与限制：低方差结构会被有意丢弃，即使它对预测或科学问题非常重要。

Python：通过协方差特征分解实现 PCA 
import numpy as np
from sklearn.decomposition import PCA

rng = np.random.default_rng(22)
latent = rng.normal(size=(500, 2))
mixing = np.array([
    [2.0, 0.2],
    [1.4, -0.7],
    [0.8, 1.5],
    [-0.4, 1.0],
])
X = latent @ mixing.T + rng.normal(scale=0.15, size=(500, 4))

# Centre before constructing the covariance matrix.
mean = X.mean(axis=0)
X_centered = X - mean
covariance = X_centered.T @ X_centered / (len(X) - 1)

# eigh exploits symmetry; reverse the ascending eigenvalue order.
eigenvalues, eigenvectors = np.linalg.eigh(covariance)
order = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[order]
components = eigenvectors[:, order]

scores = X_centered @ components[:, :2]
reconstruction = scores @ components[:, :2].T + mean
manual_mse = np.mean((X - reconstruction) ** 2)

sklearn_pca = PCA(n_components=2).fit(X)
sklearn_reconstruction = sklearn_pca.inverse_transform(sklearn_pca.transform(X))

print("eigenvalues:", np.round(eigenvalues, 3))
print("explained ratios:", np.round(eigenvalues / eigenvalues.sum(), 3))
print("manual reconstruction MSE:", round(manual_mse, 6))
print("sklearn reconstruction MSE:", round(np.mean((X - sklearn_reconstruction) ** 2), 6))

不同实现中的 principal vector 符号可能相反，因为 \(\mathbf w\) 与 \(-\mathbf w\) 张成同一个轴。比较时应关注子空间、解释方差与重构，而不是要求符号完全一致。

通过 Eigendecomposition 与 SVD 计算 PCA

PCA 可以通过协方差 eigendecomposition 计算，但显式构造 \(\mathbf X_c^\top\mathbf X_c\) 可能恶化数值条件，并需要 \(O(d^2)\) 内存。直接对 \(\mathbf X_c\) 应用 Singular Value Decomposition 往往更稳定：

\[ \mathbf X_c=\mathbf U\boldsymbol\Sigma\mathbf V^\top. \]

\(\mathbf V\) 的列就是主方向，并且

\[ \lambda_j=\frac{\sigma_j^2}{n-1}. \]

现代实现会根据矩阵形状和所需成分数，在 full、covariance-based、truncated 和 randomized solver 之间选择。当只需要少量 leading component 时，randomized SVD 尤其有用。

特征缩放会改变 PCA。中心化是必要步骤，标准化则是一项实质性选择。基于协方差矩阵的 PCA 会让高方差单位占主导；标准化后的 PCA 等价于使用相关矩阵，使每个标准化特征初始方差相当。两者都不是普遍正确答案。

选择成分数量

第 \(j\) 个成分的解释方差比为

\[ r_j=\frac{\lambda_j}{\sum_{m=1}^{d}\lambda_m}, \]

累计解释方差为 \(R_k=\sum_{j=1}^{k}r_j\)。90% 或 95% 这样的阈值便于沟通，但本质上是人为规则。其他方法包括 scree plot elbow、留出重构误差、与噪声对比的 parallel analysis、probabilistic PCA 的 likelihood criterion，或下游交叉验证。

Python：比较不同成分数的方差、重构与预测用途 
import numpy as np
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, stratify=y, random_state=31
)

for components in [5, 10, 20, 40]:
    pca = PCA(n_components=components, random_state=31).fit(X_train)
    test_scores = pca.transform(X_test)
    reconstructed = pca.inverse_transform(test_scores)
    test_mse = np.mean((X_test - reconstructed) ** 2)

    classifier = make_pipeline(
        StandardScaler(),
        PCA(n_components=components, random_state=31),
        LogisticRegression(max_iter=2000),
    )
    classifier.fit(X_train, y_train)
    accuracy = accuracy_score(y_test, classifier.predict(X_test))
    print(
        f"k={components:2d}",
        "variance=", round(pca.explained_variance_ratio_.sum(), 3),
        "test MSE=", round(test_mse, 3),
        "test accuracy=", round(accuracy, 3),
    )

能够良好重构像素的成分数，不一定是保留分类性能所需的最小成分数。如果目标是预测，应在预测验证流程内部选择维度；如果目标是科学描述，除了解释方差，还要检查 loadings、残差、稳定性和领域合理性。

奇异值分解

Singular Value Decomposition（SVD）是一种矩阵分解，本身并不是统计模型。任意实矩阵 \(\mathbf X\in\mathbb R^{n\times d}\) 都可以写成

\[ \mathbf X=\mathbf U\boldsymbol\Sigma\mathbf V^\top, \]

其中 \(\mathbf U\) 的列是正交归一的 left singular vector，\(\mathbf V\) 的列是正交归一的 right singular vector，\(\boldsymbol\Sigma\) 包含非负 singular value：

\[ \sigma_1\geq\sigma_2\geq\cdots\geq0. \]

若矩阵秩为 \(r\)，compact SVD 中 \(\mathbf U\in\mathbb R^{n\times r}\)、\(\boldsymbol\Sigma\in\mathbb R^{r\times r}\)、\(\mathbf V\in\mathbb R^{d\times r}\)。每个三元组 \((\mathbf u_j,\sigma_j,\mathbf v_j)\) 贡献一个 rank-one matrix \(\sigma_j\mathbf u_j\mathbf v_j^\top\)。

低秩近似

在第 \(k\) 个 singular value 后截断，得到

\[ \mathbf X_k =\sum_{j=1}^{k}\sigma_j\mathbf u_j\mathbf v_j^\top =\mathbf U_k\boldsymbol\Sigma_k\mathbf V_k^\top. \]

Eckart-Young-Mirsky theorem 表明，\(\mathbf X_k\) 是 Frobenius norm 和 spectral norm 下最优的 rank-\(k\) approximation。在 squared Frobenius loss 下，

\[ \left\lVert\mathbf X-\mathbf X_k\right\rVert_F^2 =\sum_{j=k+1}^{r}\sigma_j^2. \]

这个精确等式把近似误差分解为所有被丢弃 singular direction 的能量，是图像压缩、Latent Semantic Analysis、matrix completion 和高效线性代数的基础。

Python：验证最优 rank-k 重构误差 
import numpy as np

rng = np.random.default_rng(40)
# Create a nearly rank-4 matrix, then add small full-rank noise.
left = rng.normal(size=(120, 4))
right = rng.normal(size=(4, 70))
X = left @ right + rng.normal(scale=0.08, size=(120, 70))

U, singular_values, Vt = np.linalg.svd(X, full_matrices=False)

for rank in [1, 2, 4, 8, 20]:
    reconstruction = (U[:, :rank] * singular_values[:rank]) @ Vt[:rank]
    observed_squared_error = np.linalg.norm(X - reconstruction, ord="fro") ** 2
    theoretical_squared_error = np.sum(singular_values[rank:] ** 2)
    print(
        f"rank={rank:2d}",
        "observed=", round(observed_squared_error, 6),
        "discarded singular energy=", round(theoretical_squared_error, 6),
    )

对中心化数据矩阵应用 SVD 即可得到 PCA。scikit-learn 中的 TruncatedSVD 刻意不对输入中心化，因此可以高效处理稀疏矩阵；如果对稀疏矩阵中心化，原本的零元素通常会变成非零。文本挖掘中，把 TruncatedSVD 应用于 term-document matrix 通常称为 Latent Semantic Analysis（LSA）。由于矩阵未中心化，得到的方向会同时混合总体词频与变化。

Python：对稀疏文本矩阵应用 TruncatedSVD 
from sklearn.decomposition import TruncatedSVD
from sklearn.feature_extraction.text import TfidfVectorizer

documents = [
    "graph algorithms find shortest paths and spanning trees",
    "network flow algorithms optimize capacity through graphs",
    "sorting and searching are fundamental algorithmic problems",
    "neural networks learn layered representations from data",
    "gradient descent trains neural models with backpropagation",
    "representation learning supports language and vision models",
    "probability models quantify uncertainty and latent variables",
    "bayesian inference updates probability distributions with evidence",
]

vectorizer = TfidfVectorizer(stop_words="english")
X_sparse = vectorizer.fit_transform(documents)
svd = TruncatedSVD(n_components=3, random_state=40).fit(X_sparse)
coordinates = svd.transform(X_sparse)
terms = vectorizer.get_feature_names_out()

for component_index, component in enumerate(svd.components_):
    top_terms = terms[component.argsort()[-5:][::-1]]
    print(f"component {component_index + 1}:", top_terms.tolist())

print("sparse input shape:", X_sparse.shape)
print("reduced shape:", coordinates.shape)
print("explained variance ratio sum:", round(svd.explained_variance_ratio_.sum(), 3))

SVD 成分在代数意义上能够最小化低秩平方误差，但并不自动等于语义主题。成分可以同时包含正负 loading，符号可以翻转，相关潜在概念也可能被旋转成混合方向。

Factor Analysis 与 Independent Component Analysis

PCA、Factor Analysis（FA）和 Independent Component Analysis（ICA）都会产生线性潜在坐标，但它们的假设不同。PCA 寻找最大方差的描述性子空间；FA 是包含显式特征噪声的概率协方差模型；ICA 寻找统计独立的 latent source，而不只是互不相关的方向。

潜在因子

Factor analysis 假设

\[ \mathbf x=\boldsymbol\mu+\boldsymbol\Lambda\mathbf z+\boldsymbol\epsilon, \]

其中 \(\mathbf z\sim\mathcal N(\mathbf0,\mathbf I_k)\) 包含 latent factor，\(\boldsymbol\Lambda\in\mathbb R^{d\times k}\) 是 loading matrix，并且

\[ \boldsymbol\epsilon\sim\mathcal N(\mathbf0,\boldsymbol\Psi) \]

是具有 diagonal covariance \(\boldsymbol\Psi\) 的 feature-specific noise。因此，

\[ \operatorname{Cov}(\mathbf x) =\boldsymbol\Lambda\boldsymbol\Lambda^\top+\boldsymbol\Psi. \]

低秩部分解释共享协方差，\(\boldsymbol\Psi\) 则允许每个观测特征拥有独特变化。PCA 不会执行这种共享变化与独特变化的分解；它的重构残差只是与所选子空间正交，而不是拟合得到的对角噪声模型。

Factor loading 的方向并不唯一。如果 \(\mathbf R\) 是正交矩阵，则 \(\boldsymbol\Lambda\mathbf R\) 会产生相同协方差，因为

\[ (\boldsymbol\Lambda\mathbf R)(\boldsymbol\Lambda\mathbf R)^\top =\boldsymbol\Lambda\boldsymbol\Lambda^\top. \]

varimax 等 rotation 试图得到更简单的 loading pattern，但它们加入的是解释准则，并不是发现唯一真实方向。因子数量应通过留出似然、残差相关、parallel analysis、稳定性和领域可解释性共同评估。

Python：恢复潜在因子子空间与独特方差 
import numpy as np
from scipy.linalg import subspace_angles
from sklearn.decomposition import FactorAnalysis, PCA
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(51)
true_loadings = np.array([
    [1.4, 0.0], [1.1, 0.1], [0.8, -0.1],
    [0.0, 1.3], [0.1, 1.0], [-0.1, 0.7],
])
unique_std = np.array([0.25, 0.35, 0.50, 0.20, 0.45, 0.65])
latent = rng.normal(size=(1600, 2))
X = latent @ true_loadings.T + rng.normal(size=(1600, 6)) * unique_std
X_train, X_test = train_test_split(X, test_size=0.30, random_state=51)

fa = FactorAnalysis(n_components=2, rotation="varimax", random_state=51).fit(X_train)
pca = PCA(n_components=2, random_state=51).fit(X_train)

angles = np.degrees(subspace_angles(true_loadings, fa.components_.T))
print("FA principal angles to true loading space:", np.round(angles, 2))
print("true unique variances:", np.round(unique_std**2, 3))
print("estimated unique variances:", np.round(fa.noise_variance_, 3))
print("FA mean held-out log-likelihood:", round(fa.score(X_test), 3))
print("PCA explained variance ratio:", round(pca.explained_variance_ratio_.sum(), 3))

Subspace angle 比较的是张成空间，而不是旋转后的单独列。真实数据中不存在 true loading，因此残差协方差和 out-of-sample likelihood 更重要。

统计独立性

ICA 假设观测信号是潜在 source 的线性混合：

\[ \mathbf x=\mathbf A\mathbf s, \]

并估计 unmixing matrix \(\mathbf W\approx\mathbf A^{-1}\)，使 \(\widehat{\mathbf s}=\mathbf W\mathbf x\) 的成分尽可能相互独立。独立性比零相关更强。对于 Gaussian variable，去相关已经耗尽二阶统计信息，因此 ICA 要求最多只有一个 Gaussian source，并利用 negentropy 或 kurtosis 等非 Gaussian 特征。

ICA 可用于 blind source separation、EEG artifact removal 和多传感器信号分离。成分顺序和尺度不可识别：把一个 source 乘以 \(c\)，再把对应 mixing column 除以 \(c\)，不会改变观测。因此，比较估计 source 时必须先对齐 permutation 和 sign。

Python：使用 FastICA 分离混合的非 Gaussian 信号 
import numpy as np
from scipy import signal
from scipy.optimize import linear_sum_assignment
from sklearn.decomposition import FastICA, PCA

rng = np.random.default_rng(63)
time = np.linspace(0, 8, 2000)
sources = np.column_stack([
    np.sin(2 * time),
    np.sign(np.sin(3 * time)),
    signal.sawtooth(2 * np.pi * time),
])
sources += 0.05 * rng.normal(size=sources.shape)
sources /= sources.std(axis=0)

mixing = np.array([[1.0, 1.0, 0.5], [0.5, 2.0, 1.0], [1.5, 1.0, 2.0]])
observations = sources @ mixing.T

ica_sources = FastICA(
    n_components=3,
    whiten="unit-variance",
    random_state=63,
    max_iter=1000,
).fit_transform(observations)
pca_scores = PCA(n_components=3).fit_transform(observations)

def matched_absolute_correlation(reference, estimated):
    correlations = np.corrcoef(reference.T, estimated.T)[:3, 3:]
    rows, cols = linear_sum_assignment(-np.abs(correlations))
    return np.abs(correlations[rows, cols])

print("ICA matched correlations:", np.round(matched_absolute_correlation(sources, ica_sources), 3))
print("PCA matched correlations:", np.round(matched_absolute_correlation(sources, pca_scores), 3))

PCA 能够对混合信号去相关，但一般无法恢复独立的非 Gaussian source。当线性混合、source independence 和充分采样等假设合理时，ICA 才可能恢复这些源。

非负矩阵分解

Non-Negative Matrix Factorization（NMF）适用于非负数据矩阵，例如像素强度、词频、功率谱或交易金额。它近似分解

\[ \mathbf X\approx\mathbf W\mathbf H, \qquad \mathbf W\geq0, \quad \mathbf H\geq0, \]

其中 \(\mathbf X\in\mathbb R_+^{n\times d}\)，\(\mathbf W\in\mathbb R_+^{n\times k}\) 包含观测系数，\(\mathbf H\in\mathbb R_+^{k\times d}\) 包含成分模式。

基于部件的表示

由于不允许正负抵消，一个观测只能通过相加激活成分来重构。对于人脸图像，成分可能类似眼睛、嘴巴或光照模式；对于文本，成分可能类似词语群组。这种 parts-based interpretation 是非负约束诱导出的倾向，而不是语义真实性保证。

常见目标函数为

\[ \min_{\mathbf W,\mathbf H\geq0} \frac{1}{2}\lVert\mathbf X-\mathbf W\mathbf H\rVert_F^2 +\lambda_W\Omega(\mathbf W) +\lambda_H\Omega(\mathbf H). \]

正则项可以鼓励 coefficient 或 component 稀疏。其他损失还包括 generalized Kullback-Leibler divergence，它与 Poisson observation model 有关，可能适合 count-like data。联合问题是非凸的，不过固定任意一个 factor 后，另一个子问题会更容易。因此，初始化、成分数、solver 和正则化都可能改变结果。

NMF 存在尺度和置换歧义。把 \(\mathbf W\) 的第 \(k\) 列乘以 \(c>0\)，再把 \(\mathbf H\) 的第 \(k\) 行除以 \(c\)，乘积保持不变；成分顺序也任意。跨运行比较大小之前，应先归一化成分。

Python：从非负文本特征中提取加性词语成分 
from sklearn.decomposition import NMF
from sklearn.feature_extraction.text import TfidfVectorizer

documents = [
    "graph search shortest path spanning tree network flow",
    "graph algorithms optimize paths trees and network capacity",
    "dynamic programming and greedy algorithms solve optimization problems",
    "neural networks learn representations with gradient descent",
    "deep neural models use backpropagation and nonlinear layers",
    "representation learning supports language models and computer vision",
    "bayesian probability models represent uncertainty and prior knowledge",
    "probabilistic inference estimates latent variables and distributions",
    "likelihood and posterior distributions support statistical inference",
]

    n_components=3,

    top_terms = terms[component.argsort()[-6:][::-1]]

Dictionary Learning 与 Sparse Coding

Dictionary learning 把每个观测表示为若干 learned atom 的线性组合。与 PCA 不同，dictionary 可以是 overcomplete 的，即 atom 数量可以超过观测维度。这里的简单性来自每个观测只使用少量 atom。

令 \(\mathbf D\in\mathbb R^{m\times d}\) 包含 \(m\) 个行 atom，\(\boldsymbol\alpha_i\in\mathbb R^m\) 编码观测 \(\mathbf x_i\)。Sparse coding 求解的问题可以写为

\[ \min_{\boldsymbol\alpha_i} \frac{1}{2}\lVert\mathbf x_i-\boldsymbol\alpha_i\mathbf D\rVert_2^2 +\lambda\lVert\boldsymbol\alpha_i\rVert_1. \]

重构项奖励保真度，\(L_1\) penalty 促使大量系数变为零或接近零。较大的 \(\lambda\) 得到更简单但重构更差的表示。如果预先知道期望的非零数量，可以用 Orthogonal Matching Pursuit（OMP）贪心选择 atom，而不是使用 \(L_1\) penalty。

稀疏表示

稀疏性可以使表示更高效，也更容易进行局部解释：不同观测会激活不同的小型可复用模式集合。应用包括图像 patch、音频事件、compressed sensing 和特征构造。但稀疏并不自动意味着因果或语义纯净，相关 atom 还可能使单个 code 不稳定。

Dictionary learning 联合优化 code \(\mathbf A\) 和 atom \(\mathbf D\)：

\[ \min_{\mathbf A,\mathbf D} \frac{1}{2}\lVert\mathbf X-\mathbf A\mathbf D\rVert_F^2 +\lambda\lVert\mathbf A\rVert_{1,1}, \qquad \lVert\mathbf d_j\rVert_2\leq1. \]

Atom norm constraint 防止 dictionary atom 任意增大、coefficient 相应缩小，从而不合理地降低 penalty。算法通常交替执行：固定 atom 为观测编码，再固定 code 更新 atom。联合问题仍然是非凸的。

L1-Regularized Reconstruction

\(L_1\) ball 的角与坐标轴对齐，因此 least-squares contour 经常在具有零坐标的位置与它接触。相比之下，\(L_2\) penalty 会平滑缩小所有系数，通常不会产生精确零。这个几何区别与 Lasso regression 完全相同。

Python：比较稠密与稀疏重构 code 
import numpy as np
from sklearn.decomposition import sparse_encode

rng = np.random.default_rng(84)
n_samples, n_features, n_atoms = 300, 25, 45

# Create an overcomplete dictionary with unit-norm atoms.
dictionary = rng.normal(size=(n_atoms, n_features))
dictionary /= np.linalg.norm(dictionary, axis=1, keepdims=True)

# Generate observations from exactly three active atoms each.
true_codes = np.zeros((n_samples, n_atoms))
for row in range(n_samples):
    active = rng.choice(n_atoms, size=3, replace=False)
    true_codes[row, active] = rng.normal(size=3)
X = true_codes @ dictionary + rng.normal(scale=0.02, size=(n_samples, n_features))

# Minimum-norm least squares uses a dense code in an overcomplete system.
dense_codes = X @ np.linalg.pinv(dictionary)
omp_codes = sparse_encode(
    X,
    dictionary,
    algorithm="omp",
    n_nonzero_coefs=3,
)
lasso_codes = sparse_encode(
    X,
    dictionary,
    algorithm="lasso_cd",
    alpha=0.04,
    max_iter=2000,
)

for name, codes in [("dense", dense_codes), ("OMP", omp_codes), ("L1", lasso_codes)]:
    reconstruction = codes @ dictionary
    nonzeros = np.mean(np.sum(np.abs(codes) > 1e-6, axis=1))
    mse = np.mean((X - reconstruction) ** 2)
    print(name, "mean nonzeros=", round(nonzeros, 2), "MSE=", round(mse, 6))

OMP 强制使用指定的 support size，而 \(L_1\) 通过 penalty 选择 support。恢复真实 atom 或 support 需要 incoherence、稀疏度、噪声和样本量等条件；低重构误差本身并不能证明潜在结构正确。

流形学习

Manifold learning 假设高维观测位于一个较低维的弯曲表面附近。例如，三维 Swiss roll 只有两个内在坐标，但穿过外部空间的直线距离可能把沿曲面实际相距很远的点误认为相近。

这些方法通常从局部近邻图开始，因此成败取决于特征表示、度量、样本覆盖和邻居数量。邻居太少会使图断开，邻居太多则会跨越曲面折叠产生 shortcut。与 PCA 不同，大多数 manifold embedding 是非线性的，没有简单 feature loading，也不一定具有全局有效的 inverse transformation。

Isomap 与 Locally Linear Embedding

Isomap尝试保留沿流形的 geodesic distance：

  1. 把每个观测连接到 \(k\) 个最近邻，或指定半径内的观测；
  2. 使用输入空间距离作为边权；
  3. 通过图上的 all-pairs shortest path 近似 geodesic distance；
  4. 对 geodesic-distance matrix 应用 classical multidimensional scaling。

如果 \(d_G(i,j)\) 是图上最短路径距离，Isomap 会寻找低维坐标，使其中的 Euclidean distance 近似 \(d_G(i,j)\)。当采样足够密集，并且近邻图既没有断开也没有错误 shortcut 时，它可以恢复全局流形几何。噪声、孔洞、多流形以及高计算成本都会破坏结果。

Locally Linear Embedding（LLE）保留局部重构关系，而不是全局路径长度。对于每个观测，它先寻找能由邻居重构该点的权重：

\[ \min_{\{w_{ij}\}} \sum_i \left\lVert \mathbf x_i-\sum_{j\in N(i)}w_{ij}\mathbf x_j \right\rVert_2^2, \qquad \sum_{j\in N(i)}w_{ij}=1. \]

随后寻找保留同一组权重的低维坐标 \(\mathbf z_i\)：

\[ \min_{\{\mathbf z_i\}} \sum_i \left\lVert \mathbf z_i-\sum_{j\in N(i)}w_{ij}\mathbf z_j \right\rVert_2^2, \]

同时加入中心化和尺度约束，避免所有坐标都为零的平凡解。LLE 可以展开局部线性的曲面，但对邻居数量、正则化和不均匀采样都很敏感。

Python：在 S-curve 上比较 PCA、Isomap 与 LLE 
from sklearn.datasets import make_s_curve
from sklearn.decomposition import PCA
from sklearn.manifold import Isomap, LocallyLinearEmbedding, trustworthiness
from sklearn.preprocessing import StandardScaler

X, intrinsic_position = make_s_curve(n_samples=900, noise=0.03, random_state=95)
X = StandardScaler().fit_transform(X)

embeddings = {
    "PCA": PCA(n_components=2).fit_transform(X),
    "Isomap": Isomap(n_neighbors=12, n_components=2).fit_transform(X),
    "LLE": LocallyLinearEmbedding(
        n_neighbors=12,
        n_components=2,
        method="standard",
        random_state=95,
    ).fit_transform(X),
}

for name, embedding in embeddings.items():
    local_trust = trustworthiness(X, embedding, n_neighbors=12)
    # Correlation with the known generator coordinate is only available here
    # because this is a controlled synthetic example.
    coordinate_correlation = max(
        abs(__import__("numpy").corrcoef(intrinsic_position, embedding[:, axis])[0, 1])
        for axis in range(2)
    )
    print(
        name,
        "trustworthiness=", round(local_trust, 3),
        "best latent-coordinate correlation=", round(coordinate_correlation, 3),
    )

Trustworthiness 检查低维近邻是否确实是输入空间中的近邻，但不能证明全局距离、拓扑、密度或语义意义得到保留。

t-SNE 与 UMAP

t-distributed Stochastic Neighbor Embedding（t-SNE）把高维邻域 affinity 转换为概率 \(p_{ij}\)，把低维 affinity 转换为 heavy-tailed probability \(q_{ij}\)，再最小化

\[ \operatorname{KL}(P\Vert Q) =\sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}. \]

这个 KL 方向会强烈惩罚“高维中真正的近邻被放到低维远处”，因此 t-SNE 主要强调局部邻域。嵌入中的 Student-\(t\) kernel 允许远距离点对分布得更开，从而缓解 crowding problem。Perplexity 控制有效邻域尺度；early exaggeration、learning rate、初始化和随机种子也会影响地图。

UMAP在输入空间中构造加权 fuzzy neighbour graph，并通过类似 cross-entropy 的目标优化低维图。n_neighbors 控制局部细节与更广泛结构之间的权衡；min_dist 控制低维点能够聚集得多紧；metric 定义输入空间的相似性。UMAP 通常扩展性较好，也能转换新观测，但它仍然依赖模型与超参数。

不要把簇的面积解释为总体方差，不要把簇间空隙解释为经过校准的分离程度，也不要把嵌入密度当作原始密度。用已知标签着色有助于诊断，但不能把标签当作算法发现的结构。如果表示将进入预测模型，预处理和具有 transform 能力的 embedding 都只能在训练数据上拟合。

Python：评估 t-SNE 的邻域保留与随机种子敏感性 
import numpy as np
from scipy.spatial.distance import pdist
from scipy.stats import spearmanr
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE, trustworthiness
from sklearn.preprocessing import StandardScaler

X, labels = load_digits(return_X_y=True)
rng = np.random.default_rng(105)
subset = rng.choice(len(X), size=800, replace=False)
X = StandardScaler().fit_transform(X[subset])

# PCA pre-reduction removes noise and makes t-SNE cheaper.
X_30 = PCA(n_components=30, random_state=105).fit_transform(X)

embeddings = []
for seed in [105, 106]:
    embedding = TSNE(
        n_components=2,
        perplexity=30,
        learning_rate="auto",
        init="pca",
        max_iter=750,
        random_state=seed,
    ).fit_transform(X_30)
    embeddings.append(embedding)
    print("seed", seed, "trustworthiness:", round(trustworthiness(X_30, embedding, n_neighbors=15), 3))

# Pairwise-distance correlation reveals that global geometry can change.
pair_sample = rng.choice(len(X), size=250, replace=False)
distance_correlation = spearmanr(
    pdist(embeddings[0][pair_sample]),
    pdist(embeddings[1][pair_sample]),
).statistic
print("cross-seed global distance correlation:", round(distance_correlation, 3))

随机投影

Random projection 不从数据中学习方向，而是用随机生成矩阵乘以观测来降低维度。对于 \(\mathbf X\in\mathbb R^{n\times d}\) 和投影矩阵 \(\mathbf R\in\mathbb R^{k\times d}\)，

\[ \mathbf Z=\mathbf X\mathbf R^\top. \]

\(\mathbf R\) 的元素可以来自 Gaussian distribution，也可以使用稀疏带符号分布。适当缩放能够保持期望长度稳定。随机投影速度快、适合 streaming，也不需要迭代优化；但投影轴通常无法直接解释。

Johnson-Lindenstrauss lemma 表明，包含 \(n\) 个点的有限集合可以嵌入到只按 \(\log n\) 增长的维度中，同时近似保留全部点对平方距离。以高概率有

\[ (1-\varepsilon)\lVert\mathbf u-\mathbf v\rVert_2^2 \leq \lVert\mathbf R\mathbf u-\mathbf R\mathbf v\rVert_2^2 \leq (1+\varepsilon)\lVert\mathbf u-\mathbf v\rVert_2^2. \]

一种常见的充分界为

\[ k\geq \frac{4\log n}{\varepsilon^2/2-\varepsilon^3/3}. \]

这个界通常较保守，而且与原始维度 \(d\) 无关。允许的失真 \(\varepsilon\) 越小，所需投影维度越多。

Python：测量稀疏随机投影后的点对距离失真 
import numpy as np
from sklearn.random_projection import SparseRandomProjection, johnson_lindenstrauss_min_dim

rng = np.random.default_rng(116)
n_samples, n_features = 500, 2000
X = rng.normal(size=(n_samples, n_features))

epsilon = 0.50
safe_dimension = int(johnson_lindenstrauss_min_dim(n_samples, eps=epsilon))
projector = SparseRandomProjection(
    n_components=safe_dimension,
    random_state=116,
)
Z = projector.fit_transform(X)

# Sample pairs instead of materializing every pairwise distance.
left = rng.integers(0, n_samples, size=6000)
right = rng.integers(0, n_samples, size=6000)
valid = left != right
left, right = left[valid], right[valid]
original_squared = np.sum((X[left] - X[right]) ** 2, axis=1)
projected_squared = np.sum((Z[left] - Z[right]) ** 2, axis=1)
relative_distortion = projected_squared / original_squared - 1

print("original dimension:", n_features)
print("JL sufficient dimension:", safe_dimension)
print("median absolute distortion:", round(np.median(np.abs(relative_distortion)), 3))
print("95th percentile absolute distortion:", round(np.percentile(np.abs(relative_distortion), 95), 3))
print("fraction within epsilon:", round(np.mean(np.abs(relative_distortion) <= epsilon), 3))

当任务依赖距离、数据极宽而且不需要解释 basis 时，random projection 很有吸引力。PCA 会适应样本，因此在相同维度下通常具有更低重构误差；random projection 则计算更便宜，也能在不学习数据方向的情况下保留几何。必须保存随机矩阵和 seed，才能一致地转换未来数据。

作为神经扩展的 Autoencoder

Autoencoder 通过最小化重构损失，学习 encoder \(f_\theta\) 和 decoder \(g_\phi\)：

\[ \mathbf z=f_\theta(\mathbf x), \qquad \widehat{\mathbf x}=g_\phi(\mathbf z), \]

\[ \min_{\theta,\phi} \sum_i \mathcal L\left( \mathbf x_i, g_\phi(f_\theta(\mathbf x_i)) \right). \]

对于标准化实数输入，\(\mathcal L\) 可以是 mean squared error；二元数据可以使用 Bernoulli cross-entropy；count 或 image model 则可能需要与 observation process 匹配的 likelihood。

Undercomplete autoencoder 的瓶颈维度小于输入维度。使用 squared loss 的线性 undercomplete autoencoder，在合适优化下会学习与 PCA 相同的主子空间，不过坐标可以旋转。非线性 activation 可以学习弯曲重构映射，但也会增加优化、可识别性和泛化难度。

Overcomplete network 如果没有约束，可能只学会 identity map。常见变体包括：

  • denoising autoencoder：从损坏输入重构干净输入；
  • sparse autoencoder：惩罚过于广泛的 latent activation；
  • contractive autoencoder：惩罚 encoder 对微小输入变化的敏感度；
  • variational autoencoder：学习正则化概率 latent distribution 与生成式 decoder。

良好重构并不能保证语义有用。模型可能把容量花在背景纹理上、记忆训练样本，或忽略低方差但与目标相关的信号。必须在留出观测上评估，并与简单 PCA baseline 比较。

Python：比较非线性瓶颈 autoencoder 与 PCA 
import numpy as np
from sklearn.decomposition import PCA
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPRegressor
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(128)
latent = rng.uniform(-2.5, 2.5, size=(1200, 2))
# A nonlinear 10-dimensional observation generated from two variables.
X = np.column_stack([
    latent[:, 0], latent[:, 1],
    latent[:, 0] ** 2, latent[:, 1] ** 2,
    latent[:, 0] * latent[:, 1],
    np.sin(latent[:, 0]), np.cos(latent[:, 1]),
    np.sin(latent[:, 0] + latent[:, 1]),
    np.exp(-0.5 * latent[:, 0] ** 2),
    np.exp(-0.5 * latent[:, 1] ** 2),
])
X += rng.normal(scale=0.03, size=X.shape)
X_train, X_test = train_test_split(X, test_size=0.30, random_state=128)

scaler = StandardScaler().fit(X_train)
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)

pca = PCA(n_components=2).fit(X_train_scaled)
pca_reconstruction = pca.inverse_transform(pca.transform(X_test_scaled))

autoencoder = MLPRegressor(
    hidden_layer_sizes=(14, 2, 14),
    activation="tanh",
    solver="adam",
    early_stopping=True,
    validation_fraction=0.15,
    n_iter_no_change=40,
    learning_rate_init=0.005,
    alpha=1e-4,
    max_iter=2000,
    random_state=128,
).fit(X_train_scaled, X_train_scaled)
autoencoder_reconstruction = autoencoder.predict(X_test_scaled)

# Apply the first two fitted hidden layers to obtain bottleneck coordinates.
hidden = np.tanh(X_test_scaled @ autoencoder.coefs_[0] + autoencoder.intercepts_[0])
bottleneck = np.tanh(hidden @ autoencoder.coefs_[1] + autoencoder.intercepts_[1])

print("PCA test reconstruction MSE:", round(mean_squared_error(X_test_scaled, pca_reconstruction), 4))
print("autoencoder test reconstruction MSE:", round(mean_squared_error(X_test_scaled, autoencoder_reconstruction), 4))
print("bottleneck shape:", bottleneck.shape)

这个例子使用 scikit-learn 展示瓶颈机制，避免引入新的 deep-learning dependency。生产级 autoencoder 通常使用 PyTorch、TensorFlow 或 JAX，并结合 mini-batch、validation checkpoint 和架构相关正则化。

评估与选择表示

降维表示必须根据预期用途评估。不存在普遍适用的单一分数，因为重构、邻域保留、预测、解释和压缩对应不同目标。

可用的评估视角包括：

视角 关键问题 示例诊断
重构 能否恢复留出观测？残差集中在哪里？ MSE、likelihood、按特征和子群绘制残差
几何 哪些局部或全局关系得到保留？ Trustworthiness、邻居重叠、距离相关、stress
稳定性 表示能否经受样本、seed 和合理预处理变化？ Principal angle、对齐后的成分相关、邻域一致性
下游用途 降维是否改善真实验证任务？ Nested-CV performance、延迟、内存、校准
解释 能否在不事后编故事的情况下解释成分？ Loading sparsity、领域复核、可重复性
风险 是否抹去或扭曲稀有群体与安全相关方向？ 子群残差、公平性检查、失败案例检查

重构误差应在留出观测上计算。对于类似 PCA 的方法，应比较子空间而不是成分符号；对于 t-SNE 或 UMAP，应检查局部邻域保留并重复不同设置，而不是比较坐标轴；对于稀疏表示，应报告 support 稳定性与重构；对于下游预测，reducer 必须放在验证 pipeline 内部。

Python：在不泄漏测试信息的情况下选择 PCA 维度 
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, stratify=y, random_state=140
)

# Scaling and PCA are refitted inside every training fold.
pipeline = Pipeline([
    ("scale", StandardScaler()),
    ("reduce", PCA(random_state=140)),
    ("classify", LogisticRegression(max_iter=2000)),
])
search = GridSearchCV(
    pipeline,
    param_grid={
        "reduce__n_components": [10, 20, 30, 40],
        "classify__C": [0.1, 1.0],
    },
    cv=4,
    scoring="accuracy",
    n_jobs=1,
)
search.fit(X_train, y_train)
test_accuracy = accuracy_score(y_test, search.predict(X_test))

print("selected parameters:", search.best_params_)
print("cross-validated accuracy:", round(search.best_score_, 3))
print("untouched test accuracy:", round(test_accuracy, 3))

只有在选定成分数和 classifier regularization 后，才使用一次测试集。如果在切分之前拟合 PCA，测试集协方差就会影响表示，使性能估计偏乐观。

Python：量化 bootstrap 样本下的 PCA 子空间稳定性 
import numpy as np
from scipy.linalg import subspace_angles
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X, _ = load_digits(return_X_y=True)
X = StandardScaler().fit_transform(X)
reference = PCA(n_components=10, random_state=151).fit(X).components_.T

rng = np.random.default_rng(151)
largest_angles = []
median_angles = []
for _ in range(30):
    indexes = rng.integers(0, len(X), size=len(X))
    bootstrap_subspace = PCA(n_components=10).fit(X[indexes]).components_.T
    angles = np.degrees(subspace_angles(reference, bootstrap_subspace))
    largest_angles.append(angles.max())
    median_angles.append(np.median(angles))

print("median angle across directions:", round(float(np.median(median_angles)), 2), "degrees")
print("median largest principal angle:", round(float(np.median(largest_angles)), 2), "degrees")
print("95th percentile:", round(float(np.percentile(largest_angles, 95)), 2), "degrees")

多数 leading direction 可能稳定，但所选维度边界处最弱的方向仍然不稳定，尤其是相邻 eigenvalue 几乎相等时。同时报告典型 principal angle 和最大 principal angle，能够揭示这种差异，也不需要任意进行符号或成分匹配。

需求 合理起点 主要风险
线性压缩和可检查 loading PCA 高方差不一定与任务相关
稀疏 term-document reduction TruncatedSVD 未中心化成分混合均值与变化
共享协方差加 feature-specific noise Factor Analysis Rotation 和因子数并不唯一
独立非 Gaussian source ICA 假设很强，顺序与尺度不可识别
加性非负部件 NMF 局部最优和成分不稳定
每个观测只用少量可复用 atom Dictionary learning / sparse coding 相关 dictionary 可能产生不稳定 support
弯曲流形探索 Isomap 或 LLE 近邻图质量与可扩展性
高维可视化 t-SNE 或 UMAP 全局间距和簇形状容易被过度解读
快速保留几何的压缩 Random projection 可解释性弱且存在随机失真
非线性重构表示 Autoencoder 模型容量可能记忆数据或保留无关细节

可靠工作流应从与任务一致的最简单表示开始，与未降维特征比较，在训练切分内部拟合所有数据依赖步骤，并明确报告哪些信息没有得到保留。低维图只是数据的一个模型，并不是数据本身。
