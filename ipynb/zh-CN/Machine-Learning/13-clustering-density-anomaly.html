聚类、密度估计与异常检测

监督学习要求模型预测训练时提供的目标变量。本章讨论的任务面对一种更困难的科学情境：数据中没有目标列告诉我们正确答案是什么，模型需要描述观测数据本身的分布结构。

以下三个任务彼此相关，但不能视为同义词：

  • 聚类（clustering）构造划分、层次结构或软分配，用于概括哪些观测应当归在一起。
  • 密度估计（density estimation）通过估计概率密度 \(p(\mathbf{x})\)，描述观测更可能出现在哪些区域。
  • 异常检测（anomaly detection）依据某种明确的“正常性”定义，对不符合主要结构的观测进行排序。

无监督结果从来不是由数据单独产生的，而是下列因素共同作用的结果：

\[ \text{结果} =f(\text{表示},\text{度量},\text{模型假设},\text{超参数},\text{样本}). \]

即使数据行完全不变，只要改变某个特征的单位、把欧氏距离替换为余弦距离，或调整邻域半径，就可能得到不同答案。因此，没有标签并不意味着没有假设。恰恰因为无法直接用目标变量的预测误差揭示错误，这些假设更需要被明确说明。

分析问题 常见输出 核心风险
数据中是否存在有用的群组？ 硬标签、成员概率或层次结构 算法可能强行构造并无实际意义的群组
概率质量集中在哪里？ 拟合密度或对数密度分数 高维密度估计可能不稳定且校准较差
哪些观测值得进一步调查？ 异常分数与告警阈值 稀有并不必然意味着错误、有害或有价值

本章将从质心、连通性、密度、图结构和概率模型五个角度理解无监督结构。目标不是寻找一个普遍最优的方法，而是理解每种方法如何定义相似性、能够表达什么结构、应当怎样诊断输出，以及何时“没有发现令人信服的结构”才是最可靠的结论。

什么是簇？

簇（cluster）是一组被认为彼此关系更强、而与集合外观测关系较弱的数据点。这个定义有意保留了不完整性，因为“关系更强”可以表示靠近同一个质心、能够通过近邻链条相互到达、位于同一个高密度区域、由同一概率成分生成，或在图中具有较强连接。

假设用年度消费额和购买次数描述客户。一项分析可能希望得到围绕典型客户画像的紧凑群组；另一项分析可能希望找到从偶尔购买到频繁购买的细长轨迹；第三项分析可能希望识别高密度社区，并把少数特殊客户保留为未分配状态。这些问题对应不同的数学结构，因此得出不同的簇完全合理。

相似性、紧凑性、连通性与密度

选择算法之前，首先需要定义观测单位、数据表示和不相似度度量。对于数值向量，欧氏距离为

\[ d_2(\mathbf{x}_i,\mathbf{x}_j) =\sqrt{\sum_{r=1}^{d}(x_{ir}-x_{jr})^2}. \]

每个特征都按其数值单位参与计算。相差 10,000 美元可能完全压过相差 20 次购买，即使购买频率在业务上更重要。标准化把特征 \(r\) 变换为 \((x_{ir}-\bar{x}_r)/s_r\)，使一个标准差的变化可以跨特征比较。但这是一项建模选择，而不是普遍正确的预处理规则：标准化也可能放大方差较小但噪声很强的特征。

余弦相似度比较的是方向：

\[ \operatorname{cos}(\mathbf{x}_i,\mathbf{x}_j) =\frac{\mathbf{x}_i^\top\mathbf{x}_j} {\lVert\mathbf{x}_i\rVert_2\lVert\mathbf{x}_j\rVert_2}. \]

在稀疏文本向量中，当词语的相对构成比文档长度更重要时，余弦相似度通常更合适。曼哈顿距离对单个坐标上的巨大差异可能更稳健；Hamming 或 Jaccard 不相似度适用于二元属性；同时包含数值和类别特征的数据可能需要 Gower 距离等混合类型度量。只有度量本身具有可解释含义，聚类结论才具有可解释性。

主要的簇概念如下：

簇的概念 操作性含义 代表方法 典型限制
紧凑性 簇内观测靠近某个代表点 K-Means、K-Medoids 偏好近似凸形的群组
连通性 成员能够通过近邻成员逐步到达 单链接层次聚类、谱方法 可能通过细小桥梁错误连接两个群组
密度 高密度区域被低密度区域隔开 DBSCAN、HDBSCAN 依赖邻域尺度
分布 成员在某个潜在概率成分下具有较高概率 Gaussian mixture model 依赖选定的概率分布族

不同方法的输出也不相同。硬划分要求每个观测恰好属于一个簇；软分配给出成员概率或责任度；层次结构提供多个分辨率下的嵌套群组；密度方法还可以把部分点标记为噪声。没有哪一种输出天然更真实，它们表达的是不同类型的主张。

Python：观察特征缩放如何改变最近邻 
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import pairwise_distances

# Columns are annual spending in dollars and visits per year.
customers = np.array([
    [20_000, 4],
    [21_500, 16],
    [42_000, 5],
    [43_000, 18],
], dtype=float)
names = np.array(["A", "B", "C", "D"])

raw_distances = pairwise_distances(customers)
scaled_customers = StandardScaler().fit_transform(customers)
scaled_distances = pairwise_distances(scaled_customers)

def nearest_other(distance_matrix, index):
    row = distance_matrix[index].copy()
    row[index] = np.inf
    return names[np.argmin(row)]

for index, name in enumerate(names):
    print(
        name,
        "nearest before scaling:", nearest_other(raw_distances, index),
        "| after scaling:", nearest_other(scaled_distances, index),
    )

在原始表示中，消费额主导了几何关系。标准化后，购买频率可能改变某位客户的最近邻。这个例子并不能证明标准化一定正确，它证明的是：预处理方式本身就是簇定义的一部分。

K-Means 聚类

K-Means 使用每个簇的算术平均值，即质心（centroid），来表示该簇。当目标群组在欧氏空间中较为紧凑，而且均值能够作为有意义的摘要时，K-Means 很合适。它之所以流行，是因为目标函数简单、迭代高效，并且能扩展到大型数值数据集。但这些优点并不意味着所有数据都包含符合 K-Means 假设的簇。

目标函数与 Lloyd 算法

令 \(z_i\in\{1,\ldots,K\}\) 表示观测 \(\mathbf{x}_i\) 的簇分配，\(\boldsymbol\mu_k\) 表示第 \(k\) 个质心。K-Means 最小化簇内平方距离之和：

\[ J(\mathbf z,\boldsymbol\mu) =\sum_{i=1}^{n}\left\lVert \mathbf{x}_i-\boldsymbol\mu_{z_i} \right\rVert_2^2. \]

这个表达式可以逐项理解：对于每个观测，取出由 \(z_i\) 指定的质心，计算二者残差的平方欧氏长度，最后对全部观测求和。平方会加重远距离观测的影响，同时使得在分配固定时，算术平均值成为最优代表点。

Lloyd 算法交替执行两个条件最优化步骤：

Choose K initial centroids.
repeat
    Assignment step:
        assign every observation to its nearest centroid
    Update step:
        replace every centroid by the mean of its assigned observations
until assignments stop changing or the objective improvement is negligible

分配步骤在质心固定时最小化 \(J\)；更新步骤在分配固定时最小化 \(J\)。因此目标函数不会增加。然而，联合问题是非凸的：单调改进只能保证到达一个局部最优解，不能保证全局最优。

Python：从基本步骤实现 Lloyd 算法 
import numpy as np
from sklearn.datasets import make_blobs

X, _ = make_blobs(
    n_samples=240,
    centers=[(-4, -2), (0, 4), (4, -1)],
    cluster_std=[0.8, 1.0, 0.9],
    random_state=7,
)

def lloyd_kmeans(X, n_clusters, seed=0, max_iter=100):
    rng = np.random.default_rng(seed)
    # Start from distinct observations so each centroid is in data space.
    centroids = X[rng.choice(len(X), size=n_clusters, replace=False)].copy()
    inertia_history = []

    for _ in range(max_iter):
        # Assignment: squared distances from every row to every centroid.
        squared_distances = ((X[:, None, :] - centroids[None, :, :]) ** 2).sum(axis=2)
        labels = squared_distances.argmin(axis=1)
        inertia = squared_distances[np.arange(len(X)), labels].sum()
        inertia_history.append(float(inertia))

        # Update: each non-empty cluster is represented by its arithmetic mean.
        new_centroids = centroids.copy()
        for cluster in range(n_clusters):
            members = X[labels == cluster]
            if len(members) > 0:
                new_centroids[cluster] = members.mean(axis=0)

        if np.allclose(new_centroids, centroids):
            centroids = new_centroids
            break
        centroids = new_centroids

    return labels, centroids, np.array(inertia_history)

labels, centroids, history = lloyd_kmeans(X, n_clusters=3, seed=11)
print("iterations:", len(history))
print("objective never increased:", bool(np.all(np.diff(history) <= 1e-9)))
print("final inertia:", round(history[-1], 2))
print("centroids:\n", np.round(centroids, 2))

输出的 inertia 就是目标函数 \(J\)。它可以比较相同数据表示和相同 \(K\) 下的不同运行，但随着 \(K\) 增大一定不会上升，因此不能单独证明正确的簇数。

初始化与 K-Means++

较差的初始质心可能使 Lloyd 算法落入较差的局部最优。执行多次随机初始化，并保留 inertia 最小的结果，可以降低这种风险。K-Means++通过把初始质心分散到数据的不同区域来改进起点：

  1. 从观测中均匀随机选择第一个质心；
  2. 计算每个观测到当前最近已选质心的距离 \(D(\mathbf{x})\)；
  3. 按照与 \(D(\mathbf{x})^2\) 成正比的概率选择下一个质心；
  4. 重复直至选出 \(K\) 个质心，然后运行 Lloyd 算法。

距离现有质心较远的点更可能成为新区域的种子，但这个过程仍具有随机性。实践中应把 K-Means++、多次初始化和明确记录随机种子结合使用。

Python：比较随机初始化与 K-Means++ 
import numpy as np
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

X, _ = make_blobs(
    n_samples=700,
    centers=6,
    cluster_std=[0.7, 1.8, 0.6, 1.2, 0.8, 1.5],
    random_state=12,
)

def inertias_for(initialization):
    scores = []
    for seed in range(20):
        # n_init=1 exposes the variability of one initialization.
        model = KMeans(
            n_clusters=6,
            init=initialization,
            n_init=1,
            random_state=seed,
        )
        model.fit(X)
        scores.append(model.inertia_)
    return np.array(scores)

random_scores = inertias_for("random")
plus_scores = inertias_for("k-means++")

for name, scores in [("random", random_scores), ("k-means++", plus_scores)]:
    print(
        f"{name:11s}",
        "best=", round(scores.min(), 1),
        "median=", round(np.median(scores), 1),
        "worst=", round(scores.max(), 1),
    )

失效模式

K-Means 隐含地偏好近似凸形、离散程度相近且能由均值良好表示的簇。对于弯曲流形、不等密度、规模差异很大的群组、非欧氏相似性、类别数据，以及包含强影响离群点的数据，它可能失败。

由于目标函数使用平方距离，特征缩放尤其关键。离群点会产生平方级影响，并可能把质心从高密度核心区域拉走。K-Medoids 用真实观测替代均值作为代表点，稳健性更强，但计算成本通常更高。对于几何结构合适的超大样本，Mini-Batch K-Means 用近似随机更新换取更快速度。

Python：比较 K-Means 在紧凑 blobs 与弯曲 moons 上的表现 
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs, make_moons
from sklearn.metrics import adjusted_rand_score, silhouette_score
from sklearn.preprocessing import StandardScaler

datasets = {
    "compact blobs": make_blobs(n_samples=500, centers=2, cluster_std=0.8, random_state=4),
    "curved moons": make_moons(n_samples=500, noise=0.07, random_state=4),
}

for name, (X, synthetic_truth) in datasets.items():
    X = StandardScaler().fit_transform(X)
    labels = KMeans(n_clusters=2, n_init=20, random_state=4).fit_predict(X)
    print(
        name,
        "| silhouette:", round(silhouette_score(X, labels), 3),
        "| synthetic ARI:", round(adjusted_rand_score(synthetic_truth, labels), 3),
    )

这里使用合成标签，只是因为数据生成器明确提供了预期几何结构。在真实无监督任务中，这些标签通常不存在。实验说明：即使紧凑性分数看起来合理，也不能据此证明该划分符合应用真正关心的结构。

层次聚类

层次聚类在多个分辨率下表示群组，而不是立刻固定为一个平面划分。结果是一棵由嵌套集合构成的树：相近观测在树的低处合并，更广泛的群组只会在较高的不相似度处汇合。当领域中自然存在“大类内部包含子类型”的结构，或尚不清楚合适簇数时，这种表示很有价值。

凝聚式与分裂式方法

凝聚式（agglomerative）聚类从每个观测单独成簇开始，不断合并最接近的两个簇。分裂式（divisive）聚类从全部观测属于一个簇开始，再递归拆分。凝聚式方法更常用，因为合并操作较为简单，而且已有成熟实现。

凝聚式过程可以写成：

Start with n singleton clusters.
Compute dissimilarities between all current clusters.
repeat until only one cluster remains
    merge the pair with the smallest linkage dissimilarity
    update dissimilarities between the new cluster and all others
    record the merge dissimilarity

其中链接准则（linkage）至关重要。点与点之间的距离并不能自动定义两个集合之间的距离。不同链接规则表达了不同的“群组一致性”含义，因此同一个距离矩阵可以产生截然不同的层次结构。

链接准则与树状图

对于簇 \(A\) 和 \(B\)，令点间距离为 \(d(\mathbf{x}_i,\mathbf{x}_j)\)。单链接、全链接和平均链接分别为

\[ d_{\text{single}}(A,B)=\min_{i\in A,j\in B}d(\mathbf{x}_i,\mathbf{x}_j), \]

\[ d_{\text{complete}}(A,B)=\max_{i\in A,j\in B}d(\mathbf{x}_i,\mathbf{x}_j), \]

\[ d_{\text{average}}(A,B) =\frac{1}{|A||B|}\sum_{i\in A}\sum_{j\in B}d(\mathbf{x}_i,\mathbf{x}_j). \]

单链接只要求两个簇中存在任意一对相近点，因此能够恢复细长形状，但也可能通过狭窄桥梁产生链式误连。全链接控制最远点对的距离，倾向形成紧凑群组，但容易受到极端点影响。平均链接位于二者之间。Ward 链接专门用于平方欧氏几何，每一步选择使簇内平方和增加最少的合并：

\[ \Delta(A,B) =\frac{|A||B|}{|A|+|B|} \left\lVert\boldsymbol\mu_A-\boldsymbol\mu_B\right\rVert_2^2. \]

其中规模因子保证合并决策不只取决于质心距离。Ward 方法与 K-Means 相似，偏好紧凑群组；单链接则表达连通性。

树状图（dendrogram）记录合并序列。叶节点对应观测或初始群组，合并的垂直位置表示链接不相似度。用水平线切割树即可得到平面划分。叶节点的左右顺序不是一维数值测量，合并高度也不是概率或置信度。较大的垂直间隔可以提示相对稳定的分辨率，但不能证明相应群组在现实中必然存在。

直接实现通常需要保存 \(n\times n\) 不相似度结构，因此内存可能达到 \(O(n^2)\)。层次聚类适合探索中等规模样本，但面对数百万观测时，需要近似方法、连通性约束或预先压缩。

Python：比较不同链接方法的合并历史 
import numpy as np
from scipy.cluster.hierarchy import linkage, fcluster
from sklearn.datasets import make_blobs
from sklearn.metrics import adjusted_rand_score

X, synthetic_truth = make_blobs(
    n_samples=60,
    centers=[(-3, 0), (0, 0), (3, 0)],
    cluster_std=[0.35, 0.85, 0.35],
    random_state=9,
)

for method in ["single", "complete", "average", "ward"]:
    # Each row of Z is: left child, right child, merge height, merged size.
    Z = linkage(X, method=method, metric="euclidean")
    labels = fcluster(Z, t=3, criterion="maxclust") - 1
    last_merges = np.round(Z[-3:, 2], 3)
    print(
        f"{method:8s}",
        "last merge heights:", last_merges.tolist(),
        "| synthetic ARI:", round(adjusted_rand_score(synthetic_truth, labels), 3),
    )

这个受控实验使用外部合成标签来展示链接规则的差异。在无标签应用中，应比较树状图结构、缩放与链接选择的敏感性、簇稳定性和领域解释，而不是选择视觉上最漂亮的一棵树。

基于密度的聚类

基于密度的方法把簇定义为包含大量近邻观测的区域，并要求不同簇之间存在稀疏空间。它们能够恢复非凸群组，也可以把部分观测保留为未分配噪声。相应代价是：密度必须相对于邻域尺度和最小局部支持量来定义。

DBSCAN

DBSCAN 使用两个核心超参数：

  • \(\varepsilon\)（eps）是邻域半径；
  • min_samples 是形成稠密邻域所需的最少观测数，其中包含该点自身。

点 \(\mathbf{x}_i\) 的 \(\varepsilon\) 邻域为

\[ N_{\varepsilon}(\mathbf{x}_i) =\{\mathbf{x}_j:d(\mathbf{x}_i,\mathbf{x}_j)\leq\varepsilon\}. \]

若 \(|N_{\varepsilon}(\mathbf{x}_i)|\geq m\)，其中 \(m\) 为 min_samples，该点是核心点（core point）。边界点（border point）自身邻居不足，但位于某个核心点的邻域中。噪声点（noise point）既不是核心点，也不能由核心点通过密度关系到达。一个簇是通过核心邻域链条相连的最大点集，并附带在扩展过程中到达的边界点。

Mark every observation unvisited.
For each unvisited observation x:
    find its epsilon-neighbourhood
    if x is not a core point, provisionally mark it as noise
    otherwise start a new cluster and expand it through core neighbours
        add every density-reachable core point
        attach border points encountered during expansion

较小的 eps 会拆碎簇并产生更多噪声；较大的 eps 会连接区域，甚至把不同簇桥接在一起。增大 min_samples 表示要求更强的密度支持。把每个点到第 \(k\) 个最近邻的距离排序，有时能提示候选尺度，但所谓“肘部”只是诊断线索，而且在密度变化时可能根本不存在。

低维情况下，空间索引可以加速邻域查询。高维空间中距离趋于集中，树索引性能下降，DBSCAN 的计算或内存成本可能接近平方级。特征缩放、度量选择、重复观测和采样密度都会影响结果。

Python：用 DBSCAN 恢复弯曲簇并识别噪声

HDBSCAN 与可变密度

单一的全局 \(\varepsilon\) 往往无法同时保留稀疏簇，并避免稠密簇与周围区域被合并。HDBSCAN 不在一开始固定一个半径，而是在多个密度尺度上建立层次结构。

给定 min_samples，点 \(\mathbf{x}\) 的核心距离是它到第 min_samples 个最近邻的距离。HDBSCAN 定义互达距离：

\[ d_{\text{mr}}(\mathbf{x}_i,\mathbf{x}_j) =\max\left\{ d_{\text{core}}(\mathbf{x}_i), d_{\text{core}}(\mathbf{x}_j), d(\mathbf{x}_i,\mathbf{x}_j) \right\}. \]

它会拉大孤立点周围的距离，同时保留稠密区域内部的距离。随后，HDBSCAN：

  1. 在互达距离下构造最小生成树；
  2. 根据不同密度层级上的边移除过程形成簇层次；
  3. 压缩规模小于 min_cluster_size 的分支；
  4. 选择在较大密度区间内持续存在的稳定簇。

min_cluster_size 表达值得保留的最小群组规模。min_samples 控制密度估计的保守程度，数值越大通常会把更多点标记为噪声。HDBSCAN 降低了对单一半径的依赖，但并没有消除建模选择，也不能保证恢复每一种可变密度结构。

谱聚类

谱聚类首先把观测转换为加权图。每个观测是一个节点，边权 \(w_{ij}\) 表示相似性；随后算法寻找连接较弱的图区域，而不是围绕欧氏质心的紧凑区域。合适的图嵌入能够把原空间中的非凸结构转换为容易划分的结构。

令 \(\mathbf W\) 为对称 affinity matrix，度矩阵为对角矩阵，且

\[ D_{ii}=\sum_j W_{ij}. \]

非归一化图拉普拉斯为 \(\mathbf L=\mathbf D-\mathbf W\)。一种常用的对称归一化形式为

\[ \mathbf L_{\text{sym}} =\mathbf I-\mathbf D^{-1/2}\mathbf W\mathbf D^{-1/2}. \]

与较小特征值对应的特征向量沿强图边变化缓慢。把多个这样的特征向量作为坐标后，连接较强的节点会被映射到相近位置。随后在这个谱嵌入中运行 K-Means，就能近似实现一个在原始坐标中具有非线性边界的 graph cut。

算法流程为：

Construct an affinity graph W from observations.
Compute a graph Laplacian L from W and its degree matrix D.
Extract eigenvectors associated with the smallest relevant eigenvalues.
Treat each row of those eigenvectors as an embedded observation.
Cluster the embedded rows, commonly with K-Means.

affinity graph 是最关键的建模选择。RBF affinity

\[ w_{ij}=\exp(-\gamma\lVert\mathbf{x}_i-\mathbf{x}_j\rVert_2^2) \]

连接所有点对，但权重随距离快速衰减。\(k\)-nearest-neighbour graph 是稀疏图，更强调局部结构。如果图不连通、过于稠密，或者由噪声特征主导，那么特征向量只会忠实地编码一个错误的图。

存储稠密 affinity matrix 需要 \(O(n^2)\) 内存，特征分解也可能成为主要计算瓶颈。稀疏近邻图和近似特征求解器能够缓解问题，但谱聚类通常仍不如 K-Means 易于扩展。它还需要指定簇数，除非 eigengap 或下游标准能够提供合理选择。

混合模型与 EM

混合模型假设每个观测由若干潜在概率成分之一生成。与 K-Means 不同，它显式描述概率密度，并且能够给出成分成员关系的不确定性。概率成分是密度模型中的数学对象，只有经过额外领域验证后，才能把它称为真实世界的簇。

Gaussian Mixture Model

包含 \(K\) 个成分的 Gaussian mixture model（GMM）具有密度

\[ p(\mathbf{x}) =\sum_{k=1}^{K}\pi_k \,\mathcal N(\mathbf{x}\mid\boldsymbol\mu_k,\boldsymbol\Sigma_k), \]

其中 \(\pi_k\geq0\)、\(\sum_k\pi_k=1\)，每个成分具有均值 \(\boldsymbol\mu_k\) 和协方差 \(\boldsymbol\Sigma_k\)。混合权重 \(\pi_k\) 是选择成分 \(k\) 的先验概率。协方差控制方向、尺度和相关性，因此 full-covariance GMM 能表达 K-Means 无法表示的椭圆群组。

协方差约束在灵活性、统计稳定性与计算成本之间权衡：

协方差类型 假设 结果
Spherical 每个成分只有一个方差 圆形成分，参数较少
Diagonal 成分内部特征独立 与坐标轴对齐的椭圆
Tied 所有成分共享一个完整协方差 均值不同但形状相同
Full 每个成分拥有独立完整协方差 灵活，但需要更多数据

K-Means 可以看作一个极限情形：各成分权重相同、具有共同球形方差、方差趋近于零，并采用硬分配。GMM 更灵活，但额外自由度也提高了对初始化和过拟合的敏感性。

Expectation-Maximization

如果潜在成分标签 \(z_i\) 已知，参数估计很直接；如果参数已知，成分概率也很直接。Expectation-Maximization（EM）在这两个较简单的问题之间交替迭代。

E-step 计算成分 \(k\) 对观测 \(i\) 的责任度：

\[ \gamma_{ik} =P(z_i=k\mid\mathbf{x}_i) =\frac{\pi_k\mathcal N(\mathbf{x}_i\mid\boldsymbol\mu_k,\boldsymbol\Sigma_k)} {\sum_{j=1}^{K}\pi_j\mathcal N(\mathbf{x}_i\mid\boldsymbol\mu_j,\boldsymbol\Sigma_j)}. \]

分母对成分分数进行归一化，因此 \(\sum_k\gamma_{ik}=1\)。在 M-step 中，令 \(N_k=\sum_i\gamma_{ik}\)，更新

\[ \pi_k=\frac{N_k}{n}, \qquad \boldsymbol\mu_k =\frac{1}{N_k}\sum_i\gamma_{ik}\mathbf{x}_i, \]

\[ \boldsymbol\Sigma_k =\frac{1}{N_k}\sum_i\gamma_{ik} (\mathbf{x}_i-\boldsymbol\mu_k)(\mathbf{x}_i-\boldsymbol\mu_k)^\top. \]

这些都是加权估计：每个观测按照责任度对所有成分作出贡献。EM 不会降低观测数据对数似然，但可能收敛到局部最优，因此多次初始化、协方差正则化和留出评估很重要。

Python：为一维 Gaussian mixture 实现 EM 
import numpy as np
from scipy.special import logsumexp

rng = np.random.default_rng(5)
X = np.concatenate([
    rng.normal(-2.0, 0.65, size=220),
    rng.normal(2.5, 1.10, size=280),
])

means = np.array([-1.0, 1.0])
variances = np.array([1.0, 1.0])
weights = np.array([0.5, 0.5])
log_likelihoods = []

for _ in range(100):
    # E-step in log space prevents numerical underflow.
    log_components = []
    for weight, mean, variance in zip(weights, means, variances):
        log_density = -0.5 * (
            np.log(2 * np.pi * variance) + (X - mean) ** 2 / variance
        )
        log_components.append(np.log(weight) + log_density)
    log_components = np.column_stack(log_components)
    log_normalizer = logsumexp(log_components, axis=1, keepdims=True)
    responsibilities = np.exp(log_components - log_normalizer)
    log_likelihoods.append(float(log_normalizer.sum()))

    # M-step: update parameters with responsibility-weighted statistics.
    effective_counts = responsibilities.sum(axis=0)
    weights = effective_counts / len(X)
    means = (responsibilities * X[:, None]).sum(axis=0) / effective_counts
    variances = (
        responsibilities * (X[:, None] - means) ** 2
    ).sum(axis=0) / effective_counts
    variances = np.maximum(variances, 1e-6)

print("weights:", np.round(weights, 3))
print("means:", np.round(means, 3))
print("standard deviations:", np.round(np.sqrt(variances), 3))
print("likelihood never decreased:", bool(np.all(np.diff(log_likelihoods) >= -1e-8)))

软簇成员关系

责任度量化了拟合模型下的模糊性。靠近某个成分中心的点可能拥有 \((0.99,0.01)\) 的成员关系，而重叠区域中的点可能为 \((0.52,0.48)\)。它能够支持风险敏感决策，并揭示硬标签隐藏的边界不确定性。

成分数量可以通过留出对数似然或信息准则比较。Bayesian information criterion 为

\[ \operatorname{BIC} =-2\log p(\mathbf X\mid\widehat\theta)+q\log n, \]

其中 \(q\) 是自由参数数量。较低 BIC 在拟合程度与复杂度之间权衡。它是在模型假设下选择有用的密度模型，并不是在发现社会、行为或生物意义上唯一真实的群组数量。

Python：检查软成员关系并用 BIC 选择成分数量 
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.mixture import GaussianMixture

X, _ = make_blobs(
    n_samples=700,
    centers=[(-3, 0), (0, 0.5), (3, 0)],
    cluster_std=[0.7, 1.25, 0.8],
    random_state=16,
)

candidates = []
for components in range(1, 7):
    model = GaussianMixture(
        n_components=components,
        covariance_type="full",
        n_init=10,
        reg_covar=1e-6,
        random_state=16,
    ).fit(X)
    candidates.append((model.bic(X), model))

best_bic, best_model = min(candidates, key=lambda item: item[0])
probabilities = best_model.predict_proba(X)
uncertainty = 1 - probabilities.max(axis=1)
most_ambiguous = np.argsort(uncertainty)[-5:][::-1]

print("selected components:", best_model.n_components)
print("BIC:", round(best_bic, 1))
print("five largest uncertainties:", np.round(uncertainty[most_ambiguous], 3))
print("their memberships:\n", np.round(probabilities[most_ambiguous], 3))

混合成分的编号不是稳定的语义名称：在不改变密度的情况下，成分标签可以任意置换；一个形状不规则的真实群组也可能需要多个 Gaussian 成分才能表示。因此，应把输出解释为模型责任度，而不是 ground-truth 类别概率。

密度估计

密度估计寻找函数 \(\widehat p(\mathbf{x})\)，用于描述概率质量如何分布在特征空间中。它可以支持似然比较、数据模拟、缺失数据模型、异常评分和概率成分建模。它与聚类的目标不同：一个平滑单峰密度可能没有任何有意义的划分，而一个具有实质意义的群组也可能需要多峰密度才能描述。

密度值并不是恰好观察到 \(\mathbf{x}\) 的概率。对于连续数据，这个点概率为零。区域 \(A\) 的概率需要通过积分获得：

\[ P(\mathbf X\in A)=\int_A p(\mathbf{x})\,d\mathbf{x}. \]

密度还依赖测量单位。把米改成厘米会改变密度数值，因为体积微元发生了改变，但对应物理区域的概率不会变化。因此，对数密度只能在数据表示和测度一致时比较。

参数密度模型

参数模型假设密度属于由固定维度参数 \(\theta\) 索引的分布族。例如，多元 Gaussian distribution 使用均值向量和协方差矩阵：

\[ p(\mathbf{x}) =\frac{1}{(2\pi)^{d/2}|\boldsymbol\Sigma|^{1/2}} \exp\left[-\frac{1}{2} (\mathbf{x}-\boldsymbol\mu)^\top \boldsymbol\Sigma^{-1} (\mathbf{x}-\boldsymbol\mu) \right]. \]

二次项是 squared Mahalanobis distance，行列式 \(|\boldsymbol\Sigma|\) 根据协方差椭球的体积和方向进行归一化。当形状假设合理时，单个 Gaussian model 的统计效率很高，但它无法表达彼此分离的多个 mode 或强非椭圆支持集。Gaussian mixture 可以增加 mode，但需要更多参数和局部优化。

最大似然选择使下式最大的参数：

\[ \ell(\theta)=\sum_{i=1}^{n}\log p(\mathbf{x}_i\mid\theta). \]

密度模型应在留出观测上评估。训练似然总会奖励额外灵活性；如果没有协方差正则化，某个 Gaussian 成分甚至可能坍缩在单个点附近。

Kernel Density Estimation

Kernel density estimation（KDE）在每个观测附近放置一个平滑 kernel，然后取平均：

\[ \widehat p_h(\mathbf{x}) =\frac{1}{nh^d}\sum_{i=1}^{n} K\left(\frac{\mathbf{x}-\mathbf{x}_i}{h}\right). \]

其中 \(K\) 是积分为一的非负 kernel，\(h>0\) 是 bandwidth，\(h^d\) 用于校正经过缩放的 \(d\) 维体积。使用 Gaussian kernel 时，KDE 相当于以每个观测为中心、协方差相同的 Gaussian mixture。

相较于具体 kernel 形状，bandwidth 的影响要大得多。较小的 \(h\) 具有低偏差和高方差，可能把采样噪声解释为 mode；较大的 \(h\) 更稳定但偏差较高，可能抹去有意义的 mode。当目标是预测密度时，cross-validated held-out log-likelihood 是合理的选择标准。

KDE 严重受到维度灾难影响。邻域体积按 \(h^d\) 增长，维度增加后若想保持局部分辨率，就需要指数增长的观测数量。无关特征还会进一步稀释邻域。只有在降维保留任务相关密度结构，并且正确处理变换影响时，降维才能缓解问题。

Python：在双峰数据上比较单 Gaussian model 与 KDE

异常检测与新颖性检测

异常分数（anomaly score）按照“正常到异常”的程度对观测排序。把连续分数转化为二元告警还需要阈值。二者必须分开理解：检测器可能很好地排出了稀有事件，但不合理的阈值仍可能产生大量误报，使调查人员无法处理。

应区分两种部署情境：

  • Outlier detection 在可能已经包含异常的训练集上拟合，因此对污染的稳健性很重要。
  • Novelty detection 只在或主要在具有代表性的正常数据上拟合，然后为未来观测评分；训练异常可能扭曲所学的正常区域。

异常可以是全局异常（相对整个样本极端）、局部异常（只相对附近观测异常）、上下文异常（在特定时间、地点或子群条件下异常），也可以是集合异常（单个值正常，但整个序列异常）。任何一种点级检测器都无法自动覆盖全部四类。

统计分数与 Local Outlier Factor

对于近似椭圆分布的数据，squared Mahalanobis distance 可以作为统计异常分数：

\[ s(\mathbf{x}) =(\mathbf{x}-\widehat{\boldsymbol\mu})^\top \widehat{\boldsymbol\Sigma}^{-1} (\mathbf{x}-\widehat{\boldsymbol\mu}). \]

与原始欧氏距离不同，它会校正特征尺度和相关性。但经典均值和协方差估计本身容易受异常影响，因此可能需要 robust covariance estimator。Gaussian 假设形成的是单个全局椭圆，也不适合多峰正常数据。

Local Outlier Factor（LOF）判断一个点的局部密度是否显著低于其邻居。对于邻居 \(o\)，定义 reachability distance：

\[ \operatorname{reach\_dist}_k(p,o) =\max\{d_k(o),d(p,o)\}, \]

其中 \(d_k(o)\) 是 \(o\) 到第 \(k\) 个邻居的距离。局部可达密度是 \(p\) 到邻居集合 \(N_k(p)\) 的平均 reachability distance 的倒数：

\[ \operatorname{lrd}_k(p) =\left( \frac{1}{|N_k(p)|} \sum_{o\in N_k(p)}\operatorname{reach\_dist}_k(p,o) \right)^{-1}. \]

LOF 再把邻居密度与该点密度进行比较：

\[ \operatorname{LOF}_k(p) =\frac{1}{|N_k(p)|} \sum_{o\in N_k(p)} \frac{\operatorname{lrd}_k(o)}{\operatorname{lrd}_k(p)}. \]

接近一表示其局部密度与邻居相当，较大的值提示局部离群点。邻居数量 \(k\) 决定检测尺度，高维距离集中则可能削弱这种比较。

Isolation Forest 与 One-Class SVM

Isolation Forest 使用随机、与坐标轴平行的切分。异常观测通常只需较少切分就能被孤立，而位于稠密区域的点需要更长路径。对多棵随机树的路径长度取平均即可得到可扩展的异常分数，无需显式估计密度。它在许多表格数据中表现良好，但如果异常依赖斜向边界、序列结构或上下文，它可能不合适。

One-Class SVM 在 kernel feature space 中学习正常观测的边界。RBF kernel 能够形成非线性正常区域。参数 \(\nu\) 控制与训练错误和 support vector 有关的界，\(\gamma\) 控制 kernel scale。数据表示和特征缩放都非常关键；在大样本上，该方法的计算成本也可能较高。

Python：在 novelty 模式下比较 LOF、Isolation Forest 与 One-Class SVM 
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.metrics import roc_auc_score
from sklearn.neighbors import LocalOutlierFactor
from sklearn.preprocessing import StandardScaler
from sklearn.svm import OneClassSVM

rng = np.random.default_rng(44)
# Fit only on representative normal observations.
normal_train = rng.normal(loc=[0, 0], scale=[1.0, 0.45], size=(700, 2))
normal_test = rng.normal(loc=[0, 0], scale=[1.0, 0.45], size=(300, 2))
anomaly_test = rng.uniform(low=[-6, -4], high=[6, 4], size=(70, 2))

X_test = np.vstack([normal_test, anomaly_test])
y_test = np.r_[np.zeros(len(normal_test)), np.ones(len(anomaly_test))]

scaler = StandardScaler().fit(normal_train)
X_train_scaled = scaler.transform(normal_train)
X_test_scaled = scaler.transform(X_test)

models = {
    "LOF": LocalOutlierFactor(n_neighbors=30, novelty=True).fit(X_train_scaled),
    "Isolation Forest": IsolationForest(
        n_estimators=300,
        random_state=44,
    ).fit(X_train_scaled),
    "One-Class SVM": OneClassSVM(kernel="rbf", gamma="scale", nu=0.05).fit(X_train_scaled),
}

for name, model in models.items():
    # sklearn scores are larger for more normal observations, so negate them.
    anomaly_score = -model.score_samples(X_test_scaled)
    print(name, "ROC AUC:", round(roc_auc_score(y_test, anomaly_score), 3))

ROC AUC 衡量这个合成实验中的排序能力，并且与阈值无关。在真实部署中，告警 precision、调查容量、漏报成本和延迟标签通常比 ROC AUC 单独一个指标更重要。

Python：把告警阈值校准与模型拟合分开 
import numpy as np
from sklearn.ensemble import IsolationForest

rng = np.random.default_rng(52)
train_normal = rng.normal(size=(1000, 4))
calibration_normal = rng.normal(size=(500, 4))
future_batch = np.vstack([
    rng.normal(size=(195, 4)),
    rng.normal(loc=5.0, scale=0.5, size=(5, 4)),
])

detector = IsolationForest(n_estimators=300, random_state=52).fit(train_normal)
calibration_scores = -detector.score_samples(calibration_normal)
future_scores = -detector.score_samples(future_batch)

# This threshold targets a 1% alert rate on representative normal calibration data.
threshold = np.quantile(calibration_scores, 0.99)
alerts = future_scores >= threshold

print("calibrated threshold:", round(threshold, 3))
print("future alerts:", int(alerts.sum()), "of", len(alerts))
print("indices of largest scores:", np.argsort(future_scores)[-8:][::-1].tolist())

这里的 quantile 是一项运营选择，并不保证未来数据中恰好有百分之一是真异常。分布漂移会改变告警率，因此需要持续监控分数分布、告警量和人工调查结果。

评估无监督结构

无监督评估之所以困难，是因为不存在定义“正确答案”的目标变量。因此，可靠评估需要结合多个相互独立的观察角度，而不能把一个标量指标当作 ground truth。

内部、外部与稳定性标准

内部标准使用拟合时的数据表示、度量和分配。对于观测 \(i\)，令 \(a(i)\) 为它到同簇观测的平均距离，\(b(i)\) 为它到最近其他簇的最小平均距离。silhouette 为

\[ s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}}, \qquad -1\leq s(i)\leq1. \]

较高数值表示该观测到所属簇明显比到最近替代簇更近。平均 silhouette 奖励所选距离下紧凑且分离的簇，因此倾向于凸形划分，也可能惩罚科学上合理的弯曲结构或密度结构。

Calinski-Harabasz index 比较簇间离散与簇内离散，越大越好。Davies-Bouldin index 对每个簇计算它与最相似其他簇的关系并取平均，越小越好。这些指标都继承了质心与距离假设，只能作为诊断，不能作为普遍真值检验。

外部标准把分配结果与未参与拟合的标签比较。Adjusted Rand Index（ARI）衡量经过随机一致性校正后的点对分配一致程度；Normalized Mutual Information（NMI）衡量共享信息。在模拟数据或存在独立专家分类时，它们很有价值。如果不断使用这些标签选择预处理、超参数和算法，那么任务已经变成监督式模型选择，需要保留一个完全未使用的测试集。

稳定性标准检查结论能否经受合理扰动，包括随机初始化、bootstrap 或 subsampling、测量噪声和小幅超参数变化。由于簇名称可以置换，应使用 ARI 等标签置换不变的比较，或比较 co-clustering matrix。稳定划分仍可能建立在错误度量上，但不稳定划分明确说明其实质解释非常脆弱。

密度模型还应通过留出对数似然、模拟摘要的校准或任务相关 predictive check 评估。存在标签的异常检测任务需要 precision-recall curve、调查容量下的 recall、time-aware validation 和告警后复核。最终，领域有效性和下游用途始终独立于几何结构是否整齐。

Python：展示内部指标可能偏好错误的几何结构 
from sklearn.cluster import KMeans, SpectralClustering
from sklearn.datasets import make_moons
from sklearn.metrics import adjusted_rand_score, silhouette_score
from sklearn.preprocessing import StandardScaler

X, synthetic_truth = make_moons(n_samples=700, noise=0.08, random_state=61)
X = StandardScaler().fit_transform(X)

models = {
    "K-Means": KMeans(n_clusters=2, n_init=20, random_state=61),
    "Spectral": SpectralClustering(
        n_clusters=2,
        affinity="nearest_neighbors",
        n_neighbors=14,
        n_init=20,
        random_state=61,
    ),
}

for name, model in models.items():
    labels = model.fit_predict(X)
    print(
        name,
        "| Euclidean silhouette:", round(silhouette_score(X, labels), 3),
        "| synthetic ARI:", round(adjusted_rand_score(synthetic_truth, labels), 3),
    )

Euclidean silhouette 在原始坐标中评估紧凑性，而合成标签编码沿每个月牙的连通性。两个分数不一致是合理的，因为它们回答的是不同问题。

Python：检验小幅测量扰动下的分配稳定性 
import numpy as np
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
from sklearn.metrics import adjusted_rand_score
from sklearn.preprocessing import StandardScaler

X, _ = make_blobs(
    n_samples=600,
    centers=4,
    cluster_std=[0.7, 1.0, 0.8, 1.2],
    random_state=71,
)
X = StandardScaler().fit_transform(X)
base_labels = KMeans(n_clusters=4, n_init=30, random_state=71).fit_predict(X)

rng = np.random.default_rng(71)
stabilities = []
for repeat in range(30):
    perturbed = X + rng.normal(scale=0.03, size=X.shape)
    labels = KMeans(n_clusters=4, n_init=10, random_state=repeat).fit_predict(perturbed)
    stabilities.append(adjusted_rand_score(base_labels, labels))

print("mean perturbation stability:", round(float(np.mean(stabilities)), 3))
print("minimum perturbation stability:", round(float(np.min(stabilities)), 3))

扰动尺度应反映合理的测量不确定性，而不是在看到结果后随意选择。报告时应给出稳定性分布以及哪些观测发生了分配改变，不能只报告均值。

选择无监督方法

方法选择应从科学问题或运营问题出发。“运行聚类”还不是一个完整的问题。需要明确什么是一条观测、哪些变化应被视为相似、是否要求每个观测都属于某个群组，以及结果将如何被使用。

情境 合理起点 原因 诊断重点
大型数值数据，预期群组紧凑 K-Means 或 Mini-Batch K-Means 快速且质心基线易解释 缩放、多次初始化、不同 \(K\) 下的稳定性
中等规模数据，需要嵌套结构 Agglomerative clustering 同时展示多个分辨率 链接敏感性和树状图切割
不规则群组，并可能存在噪声 DBSCAN 直接编码密度连通性 eps、min_samples 和噪声解释
群组具有不同密度 HDBSCAN 选择跨尺度持续存在的分支 最小簇规模和稳定性
相似关系天然构成图 Spectral clustering 使用连通性而非质心几何 affinity 构造和可扩展性
需要软分配或生成式密度 Gaussian mixture 概率成员关系与协方差结构 初始化、协方差类型、留出似然
需要平滑的低维密度 KDE 灵活的非参数估计 bandwidth 和留出似然
需要对异常观测排序 LOF、Isolation Forest 或 One-Class SVM 分别表达局部、孤立和边界假设 time-aware validation 与阈值成本

一个实用工作流是：

  1. 定义观测单位与用途。 明确每行是人、会话、文档、设备还是时间窗口，以及输出要支持什么决策。
  2. 构造可辩护的数据表示。 处理单位、偏态、缺失值、混合类型和无关特征；选择其变化具有领域意义的度量。
  3. 检查简单基线。 在引入复杂方法前，先比较 K-Means、层次结构或单 Gaussian density。
  4. 有目的地改变假设。 调整尺度、链接、邻域大小、成分数量、随机种子和合理的预处理方式。
  5. 从多个角度评估。 结合内部几何、稳定性、留出密度、合理使用的独立标签和领域复核。
  6. 检查原始记录，而不只看图。 二维投影可能扭曲高维邻域，因此必须回到原始特征和代表性样本。
  7. 记录不确定性与噪声。 不要把每个算法成分都强行解释成确定的语义类别。
Python：生成简洁且明确假设的模型比较报告 
import numpy as np
from sklearn.cluster import DBSCAN, KMeans
from sklearn.datasets import make_moons
from sklearn.metrics import silhouette_score
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler

X, _ = make_moons(n_samples=650, noise=0.08, random_state=90)
X = StandardScaler().fit_transform(X)

candidate_labels = {
    "K-Means": KMeans(n_clusters=2, n_init=30, random_state=90).fit_predict(X),
    "DBSCAN": DBSCAN(eps=0.20, min_samples=9).fit_predict(X),
    "GMM": GaussianMixture(n_components=2, n_init=10, random_state=90).fit_predict(X),
}

for name, labels in candidate_labels.items():
    assigned = labels != -1
    unique_assigned = np.unique(labels[assigned])
    # Silhouette requires at least two assigned groups and excludes DBSCAN noise here.
    if len(unique_assigned) >= 2 and assigned.sum() > len(unique_assigned):
        silhouette = silhouette_score(X[assigned], labels[assigned])
    else:
        silhouette = np.nan
    print(
        f"{name:8s}",
        "clusters=", len(unique_assigned),
        "noise_fraction=", round(float((~assigned).mean()), 3),
        "assigned_silhouette=", round(float(silhouette), 3),
    )

这个报告有意不宣布“获胜者”。silhouette 使用欧氏紧凑性，而且这里排除了 DBSCAN 噪声，因此必须与方法假设和未分配记录一起阅读。公平的报告应明确写出这些选择。

无监督分析最重要的习惯是保持克制。即使样本中的结构微弱、不稳定或与任务无关，算法仍会输出簇、分数和密度曲线。分析者的职责不是从每个输出中强行构造故事，而是确定哪些结论能够经受替代表示、不同方法、不同样本和领域审查。
