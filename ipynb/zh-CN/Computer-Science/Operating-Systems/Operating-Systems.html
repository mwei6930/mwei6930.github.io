操作系统总览

English 中文

博客首页

操作系统把处理器、内存、存储和设备转换为程序可以安全使用的抽象。它必须复用有限资源，维持不可信程序之间的隔离，协调并发活动，在故障后恢复持久状态，并提供能够跨硬件演进而保持可用的接口。

本系列不把操作系统机制当作互不相关的名词目录，而是跟随一个程序的完整生命周期：从用户态与内核态边界开始，经过进程创建、并发执行、CPU 与内存虚拟化，再沿 I/O 到达持久存储，最后讨论保护、虚拟机、容器和现代内核设计。

学习路径

内核边界 -> 进程执行 -> 线程与 IPC -> 调度 -> 同步 -> 地址翻译 -> 按需分页 -> I/O -> 文件系统 -> 保护 -> 虚拟化

贯穿全系列的端到端案例

贯穿案例是 shell 管道 cat input.txt | grep kernel > result.txt。Shell 创建进程、连接管道、安装文件描述符、加载可执行代码，并让内核调度相应线程。指令会触发地址翻译与缺页；读写会跨越 I/O 和文件系统栈；权限约束对象访问；容器或虚拟机还可增加新的隔离边界。每一章都会放大这条路径中的一个部分。

与其他计算机科学路径的联系

计算机组成原理解释操作系统依赖的特权级、页表、中断、DMA、缓存一致性和原子指令；计算机网络解释套接字与网络设备接口之上的协议；数据结构与算法提供调度器、内存管理器和文件系统内部使用的队列、树、哈希表、图与优化方法。本系列关注操作系统如何把这些基础组合成受保护服务和可执行策略。

范围边界

本系列聚焦操作系统抽象、接口、实现机制、策略、正确性、性能、持久化与隔离。处理器电路细节属于计算机组成原理；语言解析与优化属于编译器；网络协议设计属于计算机网络；共识、复制与分布式事务属于未来的分布式系统路径。当相关机制有助于解释完整执行路径时，本系列仍会讨论它们与操作系统的接口边界。
