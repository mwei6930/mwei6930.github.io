计算机网络总览

English 中文

博客首页

计算机网络研究由不同管理者控制的机器，如何在不可靠、共享且异构的基础设施上交换信息。完整理解不能停留在记忆协议名称，而应把报文格式和状态机，与体系结构原则、分布式路由决策、性能极限、安全边界和运维证据连接起来。

本系列采用系统化学习路径：先跟随一个分组穿过互联网，再依次研究本地交付、IP 转发、路由、可靠传输、拥塞控制、应用、安全、运维和可编程基础设施。贯穿全文的 HTTPS 请求把各章连在一起，使每项机制始终属于同一个端到端系统。

学习路径

互联网体系结构 -> 本地交付 -> IP 转发 -> 路由 -> 可靠传输 -> 拥塞控制 -> 应用 -> 安全 -> 运维 -> 可编程基础设施

贯穿全系列的端到端案例

案例从主机接入网络、用户打开 HTTPS URL 开始。完整路径会依次引出 Wi-Fi/以太网接入、地址配置、本地解析、DNS、IP 转发、域内与域间路由、TCP 或 QUIC、拥塞控制、TLS、HTTP、内容分发、云基础设施和运维遥测。每章都会放大其中一段，同时保留它与前后机制的联系。

范围边界

本系列聚焦互联网体系结构、协议、实现机制、性能、安全与运维。详细调制和信号处理理论属于数字通信；密码学证明与漏洞利用属于安全专项；共识、复制和分布式事务属于分布式系统。当这些领域的机制能够解释端到端网络行为时，仍会在对应章节中适度讨论。
