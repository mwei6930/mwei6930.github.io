图与核心图算法

图用于描述实体与关系，并不要求存在单一层级。道路连接城市，超链接连接网页，先修关系连接课程，交互连接用户。与树不同，图中可以有多条路径到达同一个顶点，可以包含环、不连通区域，以及依赖方向的可达关系。

本章按照以下逻辑展开：

  • Graph ADT 定义哪些关系可以被查询或修改；
  • 具体表示方式决定这些操作的成本；
  • BFS 与 DFS 提供探索可达结构的通用方法；
  • 遍历状态进一步揭示连通分量、环、二分性与依赖顺序；
  • DSU 在不保存路径的情况下维护不断变化的连通性；
  • 最短路径和最小生成树算法分别优化不同的全局目标。

最重要的习惯是在选择算法前先说明图模型：有向还是无向、加权还是无权、稀疏还是稠密、静态还是持续变化。对一种模型正确的算法，在另一种模型下可能失效或付出不必要的成本。

图的术语与表示

图写作 \(G=(V,E)\)，其中 \(V\) 是顶点（vertices）集合，\(E\) 是连接顶点对的边（edges）集合。社交网络可把人作为顶点、好友关系作为边；道路网络可把路口作为顶点、道路作为带权边。

无向边 \(\{u,v\}\) 可以从任一方向通过。有向边 \((u,v)\) 从 u 指向 v，并不隐含反向边。加权图为每条边附加成本、距离、时间或容量 \(w(u,v)\)。权重具有实际语义，并非装饰：最短路径算法依赖权重是否非负，而 BFS 把每条边都视为一次等价步长。

其他术语描述算法能够利用的结构：

  • 游走（walk）可以重复顶点和边；路径（path）通常不重复顶点；
  • 环（cycle）从同一顶点开始和结束，中间不重复其他顶点；
  • 两个顶点由边连接时称为相邻（adjacent）。无向顶点的度（degree）是与它相接的边数；
  • 有向图的入度（indegree）计算入边，出度（outdegree）计算出边；
  • 简单图（simple graph）没有自环和平行边。多重图可以允许二者，因此其 ADT 与表示必须规定如何存储重复关系；
  • 当 \(|E|\) 远小于 \(|V|^2\) 时称为稀疏图；大量可能的顶点对都相连时称为稠密图。

Graph ADT 把这些语义与存储分离：

ADT 操作 必须提供的行为
add_vertex(v) 若 v 不存在则加入。
add_edge(u, v, weight) 按图类型加入有向或无向关系。
remove_vertex(v) 删除 v 及其全部关联边。
remove_edge(u, v) 删除指定关系。
has_edge(u, v) 判断关系是否存在。
neighbors(v) 迭代从 v 的出边可到达的顶点。
vertices() / edges() 迭代图元素，且不重复产生无向边。

三种常见表示用不同内存代价换取不同查询效率：

操作或性质 邻接表 邻接矩阵 边列表
存储 \(\Theta(|V|+|E|)\) \(\Theta(|V|^2)\) \(\Theta(|V|+|E|)\)
检查边 \((u,v)\) 列表为 \(O(\deg(u))\)；哈希集合期望 \(O(1)\) \(O(1)\) \(O(|E|)\)
遍历 u 的邻居 \(\Theta(\deg(u))\) \(\Theta(|V|)\) \(\Theta(|E|)\)
插入边 摊还 \(O(1)\) \(O(1)\) 摊还 \(O(1)\)
删除边 列表为 \(O(\deg(u))\)；哈希集合期望 \(O(1)\) \(O(1)\) \(O(|E|)\)
遍历全部边 \(\Theta(|V|+|E|)\) \(\Theta(|V|^2)\) \(\Theta(|E|)\)
最适合 稀疏图与遍历 稠密图和常数时间边测试 Kruskal 等以边为中心的算法

这里 \(|V|\) 和 \(|E|\) 分别是顶点数和边数，\(\deg(u)\) 是 u 保存的邻居数。无向邻接表会把每条边存两次，但空间仍是 \(\Theta(|V|+|E|)\)。矩阵无论边是否存在，都为每个可能的有序顶点对保留一个单元格。

Python 实现：基于哈希邻接表的 Graph ADT 
from collections.abc import Hashable, Iterator
from typing import Generic, TypeVar

V = TypeVar("V", bound=Hashable)


class Graph(Generic[V]):
    """用出邻居集合支持的简单无权图。"""

    def __init__(self, directed: bool = False) -> None:
        self.directed = directed
        self._adjacency: dict[V, set[V]] = {}

    def add_vertex(self, vertex: V) -> None:
        self._adjacency.setdefault(vertex, set())

    def add_edge(self, source: V, target: V) -> None:
        self.add_vertex(source)
        self.add_vertex(target)
        self._adjacency[source].add(target)

        if not self.directed:
            # 无向关系在两个邻接集合中各保存一次。
            self._adjacency[target].add(source)

    def remove_edge(self, source: V, target: V) -> None:
        self._adjacency[source].remove(target)
        if not self.directed:
            self._adjacency[target].remove(source)

    def has_edge(self, source: V, target: V) -> bool:
        return target in self._adjacency.get(source, set())

    def neighbors(self, vertex: V) -> frozenset[V]:
        """返回只读快照，防止调用者破坏无向对称性。"""
        return frozenset(self._adjacency[vertex])

    def vertices(self) -> Iterator[V]:
        return iter(self._adjacency)


network: Graph[str] = Graph(directed=False)
network.add_edge("A", "B")
network.add_edge("A", "C")
network.add_edge("C", "D")

assert network.has_edge("B", "A")
assert network.neighbors("A") == frozenset({"B", "C"})
network.remove_edge("A", "B")
assert not network.has_edge("B", "A")

邻居集合让边测试和更新具有期望 \(O(1)\) 成本，代价是哈希表开销且没有内在邻居顺序。列表开销更低并保留插入顺序，但测试或删除边时可能扫描完整邻接表。

练习。 LeetCode 133 - 克隆图训练图表示、节点身份追踪与所有邻接关系的重建。

广度优先搜索与深度优先搜索

图遍历要回答：从顶点 s 出发，哪些顶点可达，又应按什么顺序探索它们的出边？与树不同，图可能返回已经遇到的顶点。因此，正确遍历必须维护已访问集合，避免环导致无限重复，并保证经多条路径到达的顶点只处理一次。

广度优先搜索（BFS）按从起点经过的边数非递减顺序探索顶点。FIFO 队列保存已经发现但尚未展开的前沿。顶点应在入队时标记，而不是稍后出队时标记，否则多个父节点可能重复插入同一顶点。

深度优先搜索（DFS）沿一条出边路径前进，直到不能继续后再回溯。递归调用栈或显式 LIFO 栈保存尚未完成的路径。结束顺序与嵌套探索重要时适合 DFS；无权边距离或层顺序重要时适合 BFS。

BFS(graph, start)
    visited <- {start}
    queue <- FIFO queue containing start
    while queue is not empty
        u <- remove_front(queue)
        visit(u)
        for each v in graph.neighbors(u)
            if v is not in visited
                add v to visited
                add_back(queue, v)

DFS(graph, u, visited)
    add u to visited
    visit(u)
    for each v in graph.neighbors(u)
        if v is not in visited
            DFS(graph, v, visited)

打开原始图片：Wikimedia Commons - Breadth-First-Search-Algorithm.gif 与 Depth-First-Search.gif（CC BY-SA / GFDL）。

使用邻接表时，每个可达顶点只处理一次，每个出邻接项只检查一次。完整遍历因此需要 \(O(|V|+|E|)\) 时间，并用 \(O(|V|)\) 辅助空间保存访问状态和前沿。无向图每条边出现在两个列表中，但 \(2|E|\) 仍为 \(O(|E|)\)。使用邻接矩阵时，寻找每个顶点的邻居都要扫描一整行，遍历时间为 \(O(|V|^2)\)。

BFS 队列在宽前沿中最多保存 \(O(|V|)\) 个顶点。递归 DFS 在长路径最坏情况下需要 \(O(|V|)\) 栈空间，并可能超过语言递归深度；大型图更适合显式栈。

Python 实现：确定性 BFS 与迭代 DFS 
from collections import deque
from collections.abc import Mapping, Sequence


def bfs(graph: Mapping[str, Sequence[str]], start: str) -> list[str]:
    """按边距离非递减顺序访问可达顶点。"""
    order: list[str] = []
    visited = {start}
    queue = deque([start])

    while queue:
        vertex = queue.popleft()
        order.append(vertex)

        for neighbor in graph.get(vertex, ()):
            if neighbor not in visited:
                visited.add(neighbor)       # 在发现时标记。
                queue.append(neighbor)

    return order


def dfs_iterative(
    graph: Mapping[str, Sequence[str]], start: str
) -> list[str]:
    """不使用递归，按深度优先顺序访问可达顶点。"""
    order: list[str] = []
    visited: set[str] = set()
    stack = [start]

    while stack:
        vertex = stack.pop()
        if vertex in visited:
            continue

        visited.add(vertex)
        order.append(vertex)

        # 反向压栈，使列表中的第一个邻居按 LIFO 先处理。
        for neighbor in reversed(graph.get(vertex, ())):
            if neighbor not in visited:
                stack.append(neighbor)

    return order


graph = {
    "A": ["B", "C"],
    "B": ["D", "E"],
    "C": ["F"],
    "D": [], "E": ["F"], "F": [],
}

assert bfs(graph, "A") == ["A", "B", "C", "D", "E", "F"]
assert dfs_iterative(graph, "A") == ["A", "B", "D", "E", "F", "C"]

BFS 和 DFS 都能回答可达性，但邻居顺序未规定时，遍历树不唯一。正确性应依赖找到的顶点或结构性质，而不是某个偶然顺序。

连通性与连通分量

在无向图中，若存在路径连接 u 与 v，二者就是连通的。连通关系把顶点划分为极大的连通分量（connected components）：同一分量内任意顶点互相可达，不同分量之间没有边。这可以用于识别孤立网络、统计聚类、检查所有地点能否通信，或把网格单元建模为顶点后解决岛屿问题。

一次 BFS 或 DFS 能找到起点所在分量。若要找出所有分量，扫描全部顶点，每当遇到未访问顶点就启动一次遍历：

CONNECTED-COMPONENTS(graph)
    visited <- empty set
    components <- empty list
    for each vertex v
        if v is not in visited
            component <- traverse from v
            add every reached vertex to visited
            append component to components
    return components

方向使连通性不再对称。若把所有有向边替换为无向边后图连通，则有向图弱连通。强连通分量（SCC）是极大顶点集合，其中每个顶点都能通过有向路径到达其他任意顶点。把每个 SCC 压缩成一个超级顶点后，所得凝聚图一定是有向无环图。

Kosaraju 的 SCC 算法利用 DFS 完成顺序：

KOSARAJU(graph)
    run DFS on graph and record each vertex when it finishes
    transpose graph by reversing every edge
    process vertices on the transpose in decreasing finish order
    each new DFS tree is one strongly connected component

第一遍的完成顺序保证第二遍从下一个分量开始时，不会逃逸到尚未处理的前驱分量。两遍都检查每个顶点和边，因此在邻接表上，连通分量和 Kosaraju SCC 分解都需要 \(O(|V|+|E|)\) 时间与 \(O(|V|)\) 遍历状态；显式保存转置图另需 \(O(|V|+|E|)\)。

Python 实现：无向连通分量与有向 SCC 
from collections.abc import Mapping, Sequence


def connected_components(
    graph: Mapping[str, Sequence[str]]
) -> list[set[str]]:
    """把无向图划分为可达分量。"""
    visited: set[str] = set()
    result: list[set[str]] = []

    for start in graph:
        if start in visited:
            continue

        component: set[str] = set()
        stack = [start]
        visited.add(start)

        while stack:
            vertex = stack.pop()
            component.add(vertex)
            for neighbor in graph[vertex]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    stack.append(neighbor)

        result.append(component)

    return result


def strongly_connected_components(
    graph: Mapping[str, Sequence[str]]
) -> list[set[str]]:
    """用 Kosaraju 两遍算法返回有向图 SCC。"""
    vertices = set(graph)
    for neighbors in graph.values():
        vertices.update(neighbors)

    visited: set[str] = set()
    finish_order: list[str] = []

    def record_finish(vertex: str) -> None:
        visited.add(vertex)
        for neighbor in graph.get(vertex, ()):
            if neighbor not in visited:
                record_finish(neighbor)
        finish_order.append(vertex)          # 后代完成后再追加。

    for vertex in vertices:
        if vertex not in visited:
            record_finish(vertex)

    transpose: dict[str, list[str]] = {vertex: [] for vertex in vertices}
    for source in vertices:
        for target in graph.get(source, ()):
            transpose[target].append(source)

    visited.clear()
    components: list[set[str]] = []

    for start in reversed(finish_order):
        if start in visited:
            continue
        component: set[str] = set()
        stack = [start]
        visited.add(start)

        while stack:
            vertex = stack.pop()
            component.add(vertex)
            for neighbor in transpose[vertex]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    stack.append(neighbor)
        components.append(component)

    return components


undirected = {
    "A": ["B"], "B": ["A"],
    "C": ["D"], "D": ["C"],
    "E": [],
}
assert {frozenset(c) for c in connected_components(undirected)} == {
    frozenset({"A", "B"}), frozenset({"C", "D"}), frozenset({"E"})
}

directed = {
    "A": ["B"], "B": ["A", "C"],
    "C": ["D"], "D": ["C", "E"], "E": [],
}
assert {frozenset(c) for c in strongly_connected_components(directed)} == {
    frozenset({"A", "B"}), frozenset({"C", "D"}), frozenset({"E"})
}

对于静态图，遍历能返回真实成员并恢复路径。若数据是不断加入边的流，工作负载又主要是反复询问“这两个顶点连通吗”，后文的并查集通常更高效。

环检测与二分图

环表示遍历可以返回先前顶点，但证明环的依据取决于边方向。在无向 DFS 中，立即看到父边是正常现象，因为每条边保存了两个方向；只有遇到已访问且不是父节点的邻居时才存在环。在有向 DFS 中，指向当前递归路径上仍活动顶点的边是回边（back edge），它能证明存在有向环。

有向环检测因此使用三种状态：

  • 白色：尚未发现；
  • 灰色：已经进入但尚未完成，位于当前 DFS 路径上；
  • 黑色：已经完全处理。
HAS-DIRECTED-CYCLE(graph)
    initially color every vertex white

    DFS(u)
        color u gray
        for each edge u -> v
            if v is gray
                return true
            if v is white and DFS(v) is true
                return true
        color u black
        return false

    run DFS from every remaining white vertex

若顶点可划分为集合 \(L\) 和 \(R\)，且每条边的两个端点分别位于两侧，则图是二分图（bipartite graph）。等价地，无向图是二分图，当且仅当它不含奇数长度环。BFS 或 DFS 可以尝试二染色：为起点指定一种颜色，让每个邻居使用相反颜色；若某条边两端颜色相同则拒绝。

IS-BIPARTITE(graph)
    color <- empty map
    for each uncolored start vertex
        color[start] <- blue
        run BFS from start
            for each edge u -- v
                if v is uncolored
                    color[v] <- opposite(color[u])
                else if color[v] equals color[u]
                    return false
    return true

在邻接表上，两种测试都需要 \(O(|V|+|E|)\) 时间与 \(O(|V|)\) 状态。关键区别是所维护的不变量：有向环检测跟踪当前 DFS 路径，二分图测试跟踪沿每条边都必须一致的奇偶颜色分配。

环检测用于依赖验证、死锁分析与拓扑排序；二分结构用于两组分配、匹配问题，以及检查成对冲突能否分到两侧。

Python 实现：有向环与二分染色 
from collections import deque
from collections.abc import Mapping, Sequence


def has_directed_cycle(graph: Mapping[str, Sequence[str]]) -> bool:
    """用白/灰/黑 DFS 状态检测回边。"""
    WHITE, GRAY, BLACK = 0, 1, 2
    vertices = set(graph)
    for neighbors in graph.values():
        vertices.update(neighbors)
    color = {vertex: WHITE for vertex in vertices}

    def visit(vertex: str) -> bool:
        color[vertex] = GRAY
        for neighbor in graph.get(vertex, ()):
            if color[neighbor] == GRAY:
                return True                  # 边返回当前活动路径。
            if color[neighbor] == WHITE and visit(neighbor):
                return True
        color[vertex] = BLACK
        return False

    return any(color[v] == WHITE and visit(v) for v in vertices)


def is_bipartite(graph: Mapping[str, Sequence[str]]) -> bool:
    """尝试让每条边两端获得相反布尔颜色。"""
    vertices = set(graph)
    for neighbors in graph.values():
        vertices.update(neighbors)
    color: dict[str, bool] = {}

    for start in vertices:                    # 处理不连通图。
        if start in color:
            continue
        color[start] = False
        queue = deque([start])

        while queue:
            vertex = queue.popleft()
            for neighbor in graph.get(vertex, ()):
                if neighbor not in color:
                    color[neighbor] = not color[vertex]
                    queue.append(neighbor)
                elif color[neighbor] == color[vertex]:
                    return False
    return True


cyclic = {"A": ["B"], "B": ["C"], "C": ["A"]}
acyclic = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
assert has_directed_cycle(cyclic)
assert not has_directed_cycle(acyclic)

square = {"A": ["B", "D"], "B": ["A", "C"],
          "C": ["B", "D"], "D": ["A", "C"]}
triangle = {"A": ["B", "C"], "B": ["A", "C"], "C": ["A", "B"]}
assert is_bipartite(square)
assert not is_bipartite(triangle)

拓扑排序

有向图的拓扑序（topological ordering）是一个线性序列，其中每条边 \(u\rightarrow v\) 都让 u 出现在 v 之前。它表达依赖关系：先修课先于后续课程，构建目标晚于输入，任务晚于全部前置任务。存在拓扑序当且仅当图是有向无环图（DAG）。

拓扑序不一定唯一。若两个当前可执行任务之间没有依赖，任意一个都可以先出现。拓扑算法承诺满足全部边，而不是复现固定序列，除非另行规定平局规则。

Kahn 算法维护每个顶点的剩余入度。入度为零表示没有尚未完成的前置条件，可以安全输出；移除它的出边后，可能有更多顶点变得可用：

KAHN-TOPOLOGICAL-SORT(graph)
    indegree[v] <- number of incoming edges for every vertex v
    ready <- queue containing every vertex whose indegree is zero
    order <- empty list

    while ready is not empty
        u <- remove_front(ready)
        append u to order
        for each edge u -> v
            indegree[v] <- indegree[v] - 1
            if indegree[v] equals zero
                add_back(ready, v)

    if length(order) is less than |V|
        report a directed cycle
    return order

为什么最终长度可以检测环？每个非空 DAG 至少有一个入度为零的顶点。若仍有顶点剩余但没有任何零入度顶点，在有限剩余子图中持续沿前驱边前进最终必然重复顶点，从而证明存在有向环。

Kahn 算法在邻接表上需要 \(O(|V|+|E|)\) 时间和 \(O(|V|)\) 辅助空间。DFS 也能实现：在所有后代完成后追加顶点，再反转完成顺序，同时用灰色状态检测回边并拒绝环。当先修计数或并行调度批次重要时，Kahn 版本通常更清晰。

Python 实现：带环报告的 Kahn 算法 
from collections import deque
from collections.abc import Mapping, Sequence


def topological_sort(
    graph: Mapping[str, Sequence[str]]
) -> list[str] | None:
    """返回有效拓扑序；有向图含环时返回 None。"""
    # 保留首次出现顺序，同时包括只作为目标出现的顶点。
    vertices = list(graph)
    known = set(vertices)
    for neighbors in graph.values():
        for neighbor in neighbors:
            if neighbor not in known:
                known.add(neighbor)
                vertices.append(neighbor)

    indegree = {vertex: 0 for vertex in vertices}
    for source in vertices:
        for target in graph.get(source, ()):
            indegree[target] += 1

    ready = deque(v for v in vertices if indegree[v] == 0)
    order: list[str] = []

    while ready:
        source = ready.popleft()
        order.append(source)

        for target in graph.get(source, ()):
            indegree[target] -= 1            # 一个前置条件已经完成。
            if indegree[target] == 0:
                ready.append(target)

    return order if len(order) == len(vertices) else None


courses = {
    "Foundations": ["Algorithms", "Databases"],
    "Algorithms": ["Advanced Algorithms"],
    "Databases": ["Project"],
    "Advanced Algorithms": ["Project"],
    "Project": [],
}
order = topological_sort(courses)
assert order is not None
position = {course: i for i, course in enumerate(order)}
assert all(
    position[source] < position[target]
    for source, targets in courses.items()
    for target in targets
)

assert topological_sort({"A": ["B"], "B": ["A"]}) is None

并查集

并查集（Disjoint Set Union，DSU）也称 Union-Find，用于维护元素到互不重叠集合的划分。它高效回答一个狭窄但重要的问题：“这两个元素当前是否属于同一个分量？”可以想象开始时每个顶点都位于独立岛屿，每当一条边到来就合并相应岛屿。

DSU 不保存图路径或邻接表。每个集合表示为一棵有根父节点树，其中一个根作为集合代表。正因为表示更窄，当工作负载是反复合并与连通查询时，它比每加入一条边就重新运行 BFS 更高效。

DSU ADT 提供：

ADT 操作 必须提供的行为
make_set(x) 创建单元素集合 \(\{x\}\)。
find(x) 返回包含 x 的集合代表。
union(x, y) 若代表不同则合并两个集合。
connected(x, y) 判断 find(x) == find(y)。
component_size(x) 返回保存在 x 代表处的分量大小。
component_count() 返回当前互不相交集合数量。

两个结构优化让森林非常浅：

  • 按大小或秩合并（union by size/rank）把较小树的根连接到较大树根下；
  • 路径压缩（path compression）重写 find 途中遇到的父引用，使这些顶点直接或接近直接指向代表。
FIND(x)
    if parent[x] is not x
        parent[x] <- FIND(parent[x])
    return parent[x]

UNION(x, y)
    root_x <- FIND(x)
    root_y <- FIND(y)
    if root_x equals root_y
        return false
    attach the smaller root below the larger root
    update the larger root's size
    return true

同时使用两种优化时，在 n 个元素上执行任意 m 次操作总共需要 \(O(m\alpha(n))\) 时间。\(\alpha(n)\) 是 Ackermann 反函数，增长极慢，对任何实际输入都只是极小常数。因此 find、union 与 connected 的摊还成本为 \(O(\alpha(n))\)，初始化与存储为 \(\Theta(n)\)。

DSU 很适合新增边，却不支持任意删边：删除一条边可能把一个分量拆开，而代表森林保存的信息不足以发现分裂后的两侧。需要恢复路径、分量成员，或图会删除边时，遍历更合适。

Python 实现：按大小合并与路径折半 
class DisjointSet:
    def __init__(self, size: int) -> None:
        if size < 0:
            raise ValueError("size must be non-negative")
        self.parent = list(range(size))
        self.size = [1] * size
        self.components = size

    def find(self, item: int) -> int:
        """返回代表，同时缩短查找路径。"""
        while item != self.parent[item]:
            # 路径折半让每个访问节点指向其祖父节点。
            self.parent[item] = self.parent[self.parent[item]]
            item = self.parent[item]
        return item

    def union(self, first: int, second: int) -> bool:
        """合并两个分量；已经连通时返回 False。"""
        root_a = self.find(first)
        root_b = self.find(second)
        if root_a == root_b:
            return False

        # 连接 root_b 前，先保证 root_a 是较大根。
        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a

        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]
        self.components -= 1
        return True

    def connected(self, first: int, second: int) -> bool:
        return self.find(first) == self.find(second)

    def component_size(self, item: int) -> int:
        return self.size[self.find(item)]

assert dsu.union(0, 1)
assert dsu.union(1, 2)
assert not dsu.union(0, 2)             # 这条边是冗余边。

assert dsu.connected(0, 2)

最短路径

在加权图中，路径长度是各边权重之和。单源最短路径问题要求从源点 s 到每个可达顶点的最小路径距离。除非全部边权相同，答案并不一定是边数最少的路径；经过更多道路的路线可能总成本更低。

最短路径算法维护暂定距离 \(d[v]\)。初始时 \(d[s]=0\)，其他距离均为无穷。对权重为 \(w(u,v)\) 的边 \((u,v)\) 进行松弛（relaxation），就是检查经 u 到达 v 是否能改进当前最佳路线：

\[ d[v] \leftarrow \min\bigl(d[v],\ d[u]+w(u,v)\bigr). \]

其中 \(d[u]\) 是目前已知从源点到 u 的最佳距离，\(w(u,v)\) 是边成本。若第二项更小，算法还记录 parent[v] = u，最终可以从目标向后重建路径。

正确算法取决于权重模型：

图条件 算法 合适表示下的时间 核心思想
无权或每条边成本相同 BFS \(O(|V|+|E|)\) 队列按边距离探索
DAG，边权任意 拓扑松弛 \(O(|V|+|E|)\) 处理出边前所有前驱都已确定
非负边权 Dijkstra 二叉堆为 \(O((|V|+|E|)\log |V|)\) 确定最小暂定距离
有负边但无可达负环 Bellman-Ford \(O(|V||E|)\) 最多 \(|V|-1\) 轮松弛所有边
全点对距离 Floyd-Warshall 时间 \(O(|V|^3)\)，空间 \(O(|V|^2)\) 对允许的中间顶点做动态规划

Dijkstra 使用最小优先队列，条目为 (distance, vertex)。它反复确定暂定距离最小的未确定顶点：

DIJKSTRA(graph, source)
    distance[source] <- 0; every other distance <- infinity
    frontier <- min-priority queue containing (0, source)

    while frontier is not empty
        dist_u, u <- extract_min(frontier)
        if dist_u is stale
            continue
        for each weighted edge u -> v
            candidate <- dist_u + weight(u, v)
            if candidate < distance[v]
                distance[v] <- candidate
                parent[v] <- u
                insert (candidate, v) into frontier

非负权重保证贪心确定步骤正确。若 u 的暂定距离最小，任何稍后到达 u 的替代路径都必须先经过暂定距离至少相同的顶点，再加上一条非负边，因此不可能改进 u。负边会破坏这一论证，因为稍后发现的路径可能降低一个已经被视为最终值的距离。

Python 的 heapq 没有 decrease-key 操作。每次距离改进时可压入新条目，并在旧条目弹出时丢弃。每次成功松弛最多增加一个堆项，时间为 \(O((|V|+|E|)\log |V|)\)；对连通稀疏图常写成 \(O(|E|\log |V|)\)。包括图在内的存储为 \(O(|V|+|E|)\)。

Python 实现：带路径重建的 Dijkstra 
import heapq
import math
from collections.abc import Mapping, Sequence

WeightedGraph = Mapping[str, Sequence[tuple[str, float]]]


def dijkstra(
    graph: WeightedGraph, start: str
) -> tuple[dict[str, float], dict[str, str | None]]:
    """返回从 start 出发的最短距离和前驱链接。"""
    vertices = set(graph)
    for edges in graph.values():
        vertices.update(target for target, _ in edges)

    distance = {vertex: math.inf for vertex in vertices}
    parent: dict[str, str | None] = {vertex: None for vertex in vertices}
    distance[start] = 0.0
    frontier: list[tuple[float, str]] = [(0.0, start)]

    while frontier:
        dist_u, source = heapq.heappop(frontier)
        if dist_u != distance[source]:
            continue                         # 忽略过期堆条目。

        for target, weight in graph.get(source, ()):
            if weight < 0:
                raise ValueError("Dijkstra requires nonnegative weights")

            candidate = dist_u + weight
            if candidate < distance[target]:
                distance[target] = candidate
                parent[target] = source
                heapq.heappush(frontier, (candidate, target))

    return distance, parent


def reconstruct_path(
    parent: Mapping[str, str | None], start: str, target: str
) -> list[str]:
    path: list[str] = []
    current: str | None = target

    while current is not None:
        path.append(current)
        if current == start:
            return list(reversed(path))
        current = parent[current]
    return []                                  # 目标不可达。


graph = {
    "A": [("B", 4), ("C", 1)],
    "B": [("D", 1)],
    "C": [("B", 2), ("D", 5)],
    "D": [],
}
distance, parent = dijkstra(graph, "A")
assert distance["D"] == 4
assert reconstruct_path(parent, "A", "D") == ["A", "C", "B", "D"]

最小生成树

对连通、无向、加权图，生成树（spanning tree）包含全部顶点、保持连通且不含环。任意包含 \(|V|\) 个顶点的生成树恰有 \(|V|-1\) 条边。最小生成树（minimum spanning tree，MST）使所选边权之和最小。

MST 回答“连接全部地点的最便宜网络是什么？”它适合电缆铺设、道路规划、聚类与网络骨干设计。它不是最短路径树：MST 最小化全部基础设施总成本，而最短路径树最小化从特定源点出发的路线。MST 内两个顶点之间的路径可能比原图最短路径更长。

两个交换性质为标准贪心算法提供依据：

  • 切分性质（cut property）：对任意把顶点分为两侧的切分，跨越该切分的某条最轻边对某棵 MST 是安全的；
  • 环性质（cycle property）：在一个环中，严格最重边对至少一棵 MST 不必要，因为其余环边仍能连接它的两个端点。

Kruskal 算法从全局扩展森林。它按权重非递减排序全部边，并用 DSU 只接受端点位于不同当前分量的边：

KRUSKAL(vertices, edges)
    create one DSU set per vertex
    selected <- empty list
    for edge (u, v) in nondecreasing weight order
        if FIND(u) differs from FIND(v)
            add edge to selected
            UNION(u, v)
        if selected contains |V| - 1 edges
            stop
    if fewer than |V| - 1 edges were selected
        report that the graph is disconnected

Prim 算法从一个起点扩展单棵连通树。它的最小堆保存跨越当前切分、从已访问顶点到未访问顶点的边：

PRIM(graph, start)
    visited <- {start}
    frontier <- every edge leaving start in a min-heap
    while frontier is not empty and not every vertex is visited
        edge (u, v) <- extract minimum crossing edge
        if v is already visited
            continue
        accept (u, v); add v to visited
        insert every edge from v to an unvisited neighbor

Kruskal 的排序需要 \(O(|E|\log |E|)\)，对简单连通图等价于 \(O(|E|\log |V|)\)，另加近线性的 DSU 操作。基于堆的 Prim 在邻接表上需要 \(O(|E|\log |V|)\)。对于稠密邻接矩阵，简单的 \(O(|V|^2)\) Prim 可能更合适，因为它避免维护巨大的堆。两者使用邻接表时都占 \(O(|V|+|E|)\) 空间。

相同边权可能产生多棵总权重相同的 MST。若图不连通，除非接口明确要求失败，算法会产生最小生成森林。

Python 实现：在同一张图上运行 Kruskal 与 Prim 
import heapq
from collections.abc import Mapping, Sequence

Edge = tuple[float, str, str]          # (weight, source, target)


class DisjointSet:
    def __init__(self, vertices: Sequence[str]) -> None:
        self.parent = {vertex: vertex for vertex in vertices}
        self.size = {vertex: 1 for vertex in vertices}

    def find(self, vertex: str) -> str:
        if self.parent[vertex] != vertex:
            self.parent[vertex] = self.find(self.parent[vertex])
        return self.parent[vertex]

    def union(self, first: str, second: str) -> bool:
        root_a, root_b = self.find(first), self.find(second)
        if root_a == root_b:
            return False
        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a
        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]
        return True


def kruskal(
    vertices: Sequence[str], edges: Sequence[Edge]
) -> tuple[float, list[Edge]] | None:
    dsu = DisjointSet(vertices)
    selected: list[Edge] = []
    total = 0.0

    for edge in sorted(edges):              # 元组首先按权重排序。
        weight, source, target = edge
        if dsu.union(source, target):        # 拒绝会形成环的边。
            selected.append(edge)
            total += weight
            if len(selected) == len(vertices) - 1:
                return total, selected

    return (0.0, []) if not vertices else None


def prim(
    graph: Mapping[str, Sequence[tuple[str, float]]], start: str
) -> tuple[float, list[Edge]] | None:
    visited = {start}
    frontier: list[Edge] = [
        (weight, start, target) for target, weight in graph[start]
    ]
    heapq.heapify(frontier)
    selected: list[Edge] = []
    total = 0.0

    while frontier and len(visited) < len(graph):
        weight, source, target = heapq.heappop(frontier)
        if target in visited:
            continue

        visited.add(target)
        selected.append((weight, source, target))
        total += weight

        for neighbor, next_weight in graph[target]:
            if neighbor not in visited:
                heapq.heappush(frontier, (next_weight, target, neighbor))

    return (total, selected) if len(visited) == len(graph) else None


vertices = ["A", "B", "C", "D", "E"]
edges: list[Edge] = [
    (1, "A", "B"), (2, "C", "D"), (3, "B", "C"),
    (4, "A", "C"), (5, "D", "E"), (6, "B", "D"), (7, "C", "E"),
]
adjacency = {vertex: [] for vertex in vertices}
for weight, source, target in edges:
    adjacency[source].append((target, weight))
    adjacency[target].append((source, weight))

kruskal_result = kruskal(vertices, edges)
prim_result = prim(adjacency, "A")
assert kruskal_result is not None and kruskal_result[0] == 11
assert prim_result is not None and prim_result[0] == 11
assert len(kruskal_result[1]) == len(vertices) - 1

当边已经以列表形式到达或图较稀疏时，Kruskal 通常很方便；使用邻接表，或算法应从已有连通区域向外增长时，Prim 通常更自然。

对比与选择

在选择算法前先明确输出，图问题会更容易分类。

所需结果 合适起点 必需假设 主要复杂度
存储并遍历稀疏图 邻接表 无 存储 \(\Theta(|V|+|E|)\)
在稠密图中常数时间测试任意边 邻接矩阵 内存足以保存全部顶点对 存储 \(\Theta(|V|^2)\)
可达性或无权最短路径 BFS 最短距离下每条边成本相等 \(O(|V|+|E|)\)
递归结构、完成顺序或回边 DFS 正确维护访问/颜色状态 \(O(|V|+|E|)\)
划分无向静态图 连通分量遍历 完整图可用 \(O(|V|+|E|)\)
在新增边时维护连通性 DSU 不需要删边与路径恢复 每次操作摊还 \(O(\alpha(|V|))\)
依赖顺序 拓扑排序 有向无环图 \(O(|V|+|E|)\)
非负权最短路径 Dijkstra 每条可达边权非负 \(O((|V|+|E|)\log |V|)\)
有负边的最短路径 Bellman-Ford 有限答案要求无可达负环 \(O(|V||E|)\)
连接全部顶点的最低总成本 Kruskal 或 Prim 连通、无向、加权图 \(O(|E|\log |V|)\)

可靠的工作流程是：

  1. 定义顶点与边，包括方向和权重含义；
  2. 判断图稀疏还是稠密，并据此选择表示；
  3. 明确输出：一条路径、全部距离、分量、一个顺序，还是所选边集合；
  4. 找出使算法正确的不变量：BFS 层距离、DFS 活动路径、零剩余入度、DSU 代表、最小暂定距离或安全切分边；
  5. 同时用 \(|V|\) 和 \(|E|\) 分析。只写“\(O(n)\)”会隐藏图表示，使本来正确的复杂度结论变得含糊。

BFS 的队列、DFS 的栈、Dijkstra 与 Prim 的堆、Kruskal 的 DSU 都是辅助数据结构。图算法由围绕这些结构维护的状态与不变量定义，而不是仅由容器本身定义。
