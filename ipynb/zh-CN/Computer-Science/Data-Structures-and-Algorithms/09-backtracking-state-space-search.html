回溯与状态空间搜索

回溯（backtracking）以深度优先方式探索决策空间。它扩展一个部分候选，一旦确认该分支无法产生所需答案就放弃，恢复先前状态，再尝试下一选择。输出是一个构造而不只是数值、选择之间有复杂约束，或没有已知紧凑多项式表述时，回溯很有用。

“回溯”不只是递归。正确实现需要：

  • 包含所有会影响未来合法性的事实的状态；
  • 完整的候选生成器，保证不遗漏有效解；
  • 可逆状态更新，使兄弟分支彼此独立；
  • 安全剪枝谓词，只拒绝没有有用后代的分支；
  • 清晰输出契约：找一个解、枚举全部、计数，还是优化目标。

回溯最坏常为指数时间，因为它可能表示指数数量的有效或潜在有效构造。其实用能力来自约束、规范顺序、传播、良好分支选择与目标界对搜索树的缩减。

重要

回溯不是“撤销一个错误答案”。无论分支失败还是产生有效解，在完整处理后都要恢复部分状态；正是恢复操作保证下一个兄弟分支正确。

状态空间树

状态空间树（state-space tree）是部分决策构成的概念树。根是空状态，一条边增加一个合法选择，节点代表所得部分赋值。叶节点可以是完整解、完整但无效的构造，或在达到最大深度前发现的死路。

这棵树通常惰性生成。算法只保存当前根到节点路径和生成子节点所需元数据，不会预先分配全部节点。因此深度优先遍历很自然：从递归调用返回就对应回到父状态。

若每个内部节点的最大分支因子为 b，解深度最多 d，完整树在 \(b>1\) 时含

\[ 1+b+b^2+\cdots+b^d=\frac{b^{d+1}-1}{b-1}=O(b^d) \]

个节点。b 是每个状态的最大候选数，d 是完整路径决策数。这只是上界，约束可能大幅降低有效分支因子；输出大小也可能强制指数工作，例如显式枚举全部 \(2^n\) 个子集，本身就不可能是多项式总时间。

SEARCH(state, path)
    if state is a complete valid solution
        record a copy of path
        return
    if state cannot be completed
        return

    for each legal choice from state
        apply choice to state and path
        SEARCH(updated state, path)
        undo choice from state and path

Python 实现：生成二叉状态空间树的全部叶节点 
def enumerate_binary_assignments(length: int) -> tuple[list[tuple[int, ...]], int]:
    """返回全部二进制叶赋值和访问的树节点数。"""
    if length < 0:
        raise ValueError("length must be non-negative")

    path: list[int] = []
    leaves: list[tuple[int, ...]] = []
    visited_nodes = 0

    def search(depth: int) -> None:
        nonlocal visited_nodes
        visited_nodes += 1  # 当前部分赋值算一个节点。

        if depth == length:
            leaves.append(tuple(path))
            return

        for bit in (0, 1):
            path.append(bit)
            search(depth + 1)
            path.pop()

    search(0)
    return leaves, visited_nodes


assignments, nodes = enumerate_binary_assignments(3)
assert len(assignments) == 8
assert nodes == 15  # 深度 3 完整树有 1 + 2 + 4 + 8 个节点。
print(assignments)
print("visited nodes:", nodes)

完整二叉树访问 \(2^{n+1}-1\) 个节点。复制每个长度 n 的叶，使输出相关时间与空间均为 \(\Theta(n2^n)\)。排除输出后，DFS 只用 \(O(n)\) 路径和调用栈，而不存整棵树。

选择、探索与撤销

经典回溯框架包含三个操作：

  1. 选择（Choose）：修改当前路径和候选影响的全部辅助结构；
  2. 探索（Explore）：在选择已属于状态时递归；
  3. 撤销（Unchoose）：尝试下一个兄弟前，按相反顺序撤销全部修改。

这建立一个框架不变量：每次循环迭代前，路径与辅助状态都必须准确描述同一个父节点。若选择会追加项目、标记已使用、修改棋盘格并更新累计值，清理就必须恢复全部四部分。

BACKTRACK(parent state)
    for choice in candidates(parent state)
        path.append(choice)          // choose
        mark choice as used

        BACKTRACK(child state)       // explore

        mark choice as unused        // unchoose
        path.pop()

两类错误尤其常见。第一，把 path 本身加入结果会保存多个指向同一可变列表的引用，应加入 path.copy() 或不可变元组。第二，choose 与 unchoose 之间提前 return 会跳过清理。应让清理紧邻递归调用，或使用在异常控制流下也保证恢复的结构。

排列清楚展示了这一模式：深度 i 时，路径恰好包含 i 个不同项目，且 used[j] 为真当且仅当第 j 个项目出现在当前路径。

Python 实现：使用显式可逆状态生成排列 
from collections.abc import Sequence
from typing import TypeVar

T = TypeVar("T")


def permutations(items: Sequence[T]) -> list[tuple[T, ...]]:
    """通过选择/探索/撤销返回不同项目的排列。"""
    if len(set(items)) != len(items):
        raise ValueError("this basic template requires distinct hashable items")

    path: list[T] = []
    used = [False] * len(items)
    results: list[tuple[T, ...]] = []

    def search() -> None:
        if len(path) == len(items):
            results.append(tuple(path))  # 冻结当前解。
            return

        for index, item in enumerate(items):
            if used[index]:
                continue

            path.append(item)       # 选择。
            used[index] = True
            search()                # 探索。
            used[index] = False     # 反序撤销。
            path.pop()

    search()
    return results


answer = permutations(["A", "B", "C"])
assert len(answer) == 6
assert ("C", "B", "A") in answer
print(answer)

对 n 个不同项目，搜索有 \(n!\) 个叶节点。复制每个长度 n 的排列，输出相关时间和空间为 \(\Theta(n\cdot n!)\)。排除输出后，路径、used 数组和递归栈使用 \(O(n)\)。

练习： LeetCode 46 - 全排列直接检验可逆路径与已使用集合不变量。

剪枝策略

剪枝（pruning）是在证明某个部分状态没有任何后代能够贡献所需输出后，停止探索该分支。剪枝只改变性能，不改变答案集合。“这条分支看起来不太可能”只是启发式排序，不是有效剪枝。

四种常见形式为：

剪枝形式 安全条件 例子
可行性剪枝 单调约束已经违反 右括号数量超过左括号
分支限界 乐观界不能超过当前最佳值 剩余最大可能价值仍太小
对称性破除 另一个规范分支代表相同构造 不把相同值放入等价空箱
约束传播 缩减值域后某变量无合法值 Sudoku 候选集合为空

对最大化问题，令 B 为目前最佳完整目标值，UB(s) 为状态 s 所有完成方案的上界。满足

\[ UB(s)\le B \]

时可以安全剪枝。这个界必须乐观：可以高估能够达到的结果，但绝不能低估。更紧的界剪枝更多，更便宜的界计算更快。

候选排序是补充手段。先尝试有希望的选择，可以较早找到强 incumbent，使后续分支限界更有效。在约束满足中，最少剩余值（MRV）选择当前值域最小的变量，以尽早暴露失败。只要剩余选择仍全部探索，排序只影响运行时间，不影响正确性。

GENERATE-PARENTHESES(open, close, path)
    if open = n and close = n
        record path
        return
    if open < n
        choose "("; recurse; unchoose
    if close < open
        choose ")"; recurse; unchoose

条件 close < open 是可行性剪枝。一旦某个前缀的右括号多于左括号，后续字符无法修复该前缀；同样，任何分支都不能使用超过 n 个左括号。

Python 实现：用可行性剪枝生成括号 
def generate_parentheses(pair_count: int) -> list[str]:
    """生成包含 pair_count 对括号的所有平衡字符串。"""
    if pair_count < 0:
        raise ValueError("pair_count must be non-negative")

    path: list[str] = []
    results: list[str] = []

    def search(opened: int, closed: int) -> None:
        if opened == pair_count and closed == pair_count:
            results.append("".join(path))
            return

        if opened < pair_count:
            path.append("(")
            search(opened + 1, closed)
            path.pop()

        # 防止任何右括号过多的前缀。
        if closed < opened:
            path.append(")")
            search(opened, closed + 1)
            path.pop()

    search(0, 0)
    return results


answer = generate_parentheses(3)
assert len(answer) == 5
assert set(answer) == {"((()))", "(()())", "(())()", "()(())", "()()()"}
print(answer)

有效输出数是 Catalan 数

\[ C_n=\frac{1}{n+1}\binom{2n}{n}. \]

每个输出长度为 \(2n\)，所以输出相关时间和空间均为 \(\Theta(nC_n)\)；路径和递归栈使用 \(O(n)\) 辅助空间。可行性剪枝避免大部分 \(2^{2n}\) 个无限制二进制字符串，却无法避免生成有效输出。

练习： LeetCode 22 - 括号生成直接训练如何证明前缀剪枝安全。

子集、排列与组合

这些输出的区别在于顺序是否重要，以及是否必须使用全部项目。回溯状态应直接编码这种区别。

  • 子集可包含任意选择。使用起始下标按输入递增顺序生成，避免同一子集以不同顺序重复产生；
  • 大小为 k 的组合是有目标长度的子集。当剩余项目不足以凑到 k 时可停止；
  • 排列把全部所选项目放入有序安排。used 集合或原地交换记录哪些位置仍可用。
SUBSETS(start, path)
    record path
    for i <- start to n-1
        choose items[i]
        SUBSETS(i+1, path)
        unchoose items[i]

COMBINATIONS(start, path, k)
    if length(path) = k: record path; return
    for i over indices leaving enough remaining items
        choose items[i]; recurse with i+1; unchoose

PERMUTATIONS(path, used)
    if length(path) = n: record path; return
    for each unused index i
        mark i; choose items[i]; recurse; unchoose; unmark i

输入有重复值时，需要额外规范规则。先排序，再跳过同一递归深度的相等值。对于唯一排列，只有相同前驱 i-1 已用于当前路径后，才允许选择下标 i 的重复值。这只保留一种代表顺序，同时允许重复值在不同深度合法使用。

Python 实现：子集、固定大小组合与唯一排列 
def all_subsets(items: list[int]) -> list[tuple[int, ...]]:
    results: list[tuple[int, ...]] = []
    path: list[int] = []

    def search(start: int) -> None:
        results.append(tuple(path))
        for index in range(start, len(items)):
            path.append(items[index])
            search(index + 1)
            path.pop()

    search(0)
    return results


def choose_k(items: list[int], k: int) -> list[tuple[int, ...]]:
    if not 0 <= k <= len(items):
        return []
    results: list[tuple[int, ...]] = []
    path: list[int] = []

    def search(start: int) -> None:
        if len(path) == k:
            results.append(tuple(path))
            return

        needed = k - len(path)
        # 最后候选必须留下 needed - 1 个后续元素。
        last_start = len(items) - needed
        for index in range(start, last_start + 1):
            path.append(items[index])
            search(index + 1)
            path.pop()

    search(0)
    return results


def unique_permutations(items: list[int]) -> list[tuple[int, ...]]:
    ordered = sorted(items)
    used = [False] * len(ordered)
    path: list[int] = []
    results: list[tuple[int, ...]] = []

    def search() -> None:
        if len(path) == len(ordered):
            results.append(tuple(path))
            return

        for index, value in enumerate(ordered):
            if used[index]:
                continue
            if index > 0 and value == ordered[index - 1] and not used[index - 1]:
                continue  # 跳过当前递归深度的相同值。

            used[index] = True
            path.append(value)
            search()
            path.pop()
            used[index] = False

    search()
    return results


assert len(all_subsets([1, 2, 3])) == 8
assert choose_k([1, 2, 3, 4], 2) == [(1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4)]
assert set(unique_permutations([1, 1, 2])) == {(1, 1, 2), (1, 2, 1), (2, 1, 1)}
print(all_subsets([1, 2, 3]))
print(choose_k([1, 2, 3, 4], 2))
print(unique_permutations([1, 1, 2]))
输出族 n 个不同项目的数量 含复制的时间 辅助路径状态
全部子集 \(2^n\) \(\Theta(n2^n)\) \(O(n)\)
大小 k 的组合 \(\binom{n}{k}\) \(\Theta(k\binom{n}{k})\) \(O(k)\)
全部排列 \(n!\) \(\Theta(n\cdot n!)\) \(O(n)\)

这些是输出相关界。显式返回全部结果的算法不可能比写出输出所需大小更快。

约束与棋盘搜索

约束满足问题（CSP）包含变量、每个变量的候选值域以及赋值之间的约束。回溯选择一个未赋值变量，尝试与当前赋值一致的值，传播影响，并在返回时恢复值域。

棋盘搜索在空间上编码同一模式：

  • N 皇后为每行选择一列，同时满足列与对角线约束；
  • Sudoku 为单元格赋数字，并传播行、列与宫限制；
  • 单词搜索为每个字符串位置选择棋盘单元格，并临时标记当前路径已用单元格。

皇后位于行 r、列 c 时，同一下降对角线的 \(r-c\) 相等，同一上升对角线的 \(r+c\) 相等。因此维护已占列、\(r-c\) 和 \(r+c\) 的集合，可让每次安全测试获得期望 \(O(1)\) 成员查询。

N-QUEENS(row r)
    if r = n
        record board
        return
    for column c <- 0 to n-1
        if c, r-c, and r+c are all unused
            mark column and both diagonals
            place queen at (r,c)
            N-QUEENS(r+1)
            remove queen and all three marks

Python 实现：用常数时间约束集合求解 N 皇后 
def solve_n_queens(size: int) -> list[tuple[str, ...]]:
    """返回全部 size x size 的 N 皇后棋盘。"""
    if size < 0:
        raise ValueError("size must be non-negative")

    columns: set[int] = set()
    descending: set[int] = set()  # row - column
    ascending: set[int] = set()   # row + column
    queen_columns: list[int] = []
    solutions: list[tuple[str, ...]] = []

    def search(row: int) -> None:
        if row == size:
            board = tuple(
                "." * column + "Q" + "." * (size - column - 1)
                for column in queen_columns
            )
            solutions.append(board)
            return

        for column in range(size):
            down_key = row - column
            up_key = row + column
            if column in columns or down_key in descending or up_key in ascending:
                continue

            queen_columns.append(column)
            columns.add(column)
            descending.add(down_key)
            ascending.add(up_key)

            search(row + 1)

            ascending.remove(up_key)
            descending.remove(down_key)
            columns.remove(column)
            queen_columns.pop()

    search(0)
    return solutions


solutions = solve_n_queens(4)
assert len(solutions) == 2
print("\n\n".join("\n".join(board) for board in solutions))

逐行表述每列最多尝试一个皇后，所以对角线剪枝前的粗略最坏界为 \(O(n!)\) 个搜索节点，另加每个解棋盘 \(O(n^2)\) 的物化时间。活动路径和三组约束集合使用 \(O(n)\) 辅助空间，返回棋盘主导输出空间。

更难 CSP 可结合 MRV 变量选择、前向检查、位掩码值域与强制赋值传播。每个传播修改也必须可逆，或记录到撤销栈。

练习： LeetCode 51 - N 皇后直接训练行变量、对角线编码与可逆约束集合。

回溯与动态规划

回溯与 DP 可以从同一递推开始。区别在于不同决策历史能否在不改变未来可能延续的情况下合并。

只有状态键包含全部未来相关事实时，记忆化才安全。在 Target Sum 中，为前 i 个值分配符号后，未来只依赖 i 和当前总和 t。到达 \((i,t)\) 的两段历史拥有相同剩余数字和相同后续计数，因此可以共享一个缓存答案。

若遗漏的路径历史影响合法性，记忆化就不安全。在简单路径搜索中，仅 (current_vertex) 不充分，因为不同已访问集合允许不同未来移动。必须把已访问集合纳入状态，例如位掩码；若这产生 \(2^n\) 个状态，DP 仍可能是指数级。

TARGET-SUM(i, total)
    if i = n
        return 1 when total = target, otherwise 0
    return TARGET-SUM(i+1, total + values[i])
         + TARGET-SUM(i+1, total - values[i])

MEMOIZED-TARGET-SUM(i, total)
    use the same recurrence
    cache the answer under key (i, total)
Python 实现：比较未缓存与记忆化 Target Sum 
from functools import cache


def compare_target_sum_calls(
    values: list[int], target: int
) -> tuple[int, int, int]:
    """返回符号分配数、朴素调用数与记忆化函数体调用数。"""
    naive_calls = 0

    def backtrack(index: int, total: int) -> int:
        nonlocal naive_calls
        naive_calls += 1
        if index == len(values):
            return int(total == target)
        return (
            backtrack(index + 1, total + values[index])
            + backtrack(index + 1, total - values[index])
        )

    memo_calls = 0

    @cache
    def memoized(index: int, total: int) -> int:
        nonlocal memo_calls
        memo_calls += 1  # 每个不同 (index, total) 状态只运行一次。
        if index == len(values):
            return int(total == target)
        return (
            memoized(index + 1, total + values[index])
            + memoized(index + 1, total - values[index])
        )

    naive_answer = backtrack(0, 0)
    memo_answer = memoized(0, 0)
    assert naive_answer == memo_answer
    return naive_answer, naive_calls, memo_calls


ways, naive_count, memo_count = compare_target_sum_calls([1] * 10, 0)
assert ways == 252
assert naive_count == 2047
assert memo_count == 66
print(ways, naive_count, memo_count)

未缓存搜索在 n 个位置各有两个选择，时间 \(O(2^n)\)、栈空间 \(O(n)\)。令 \(S=\sum_i |v_i|\)，总和位于 \(-S\) 到 \(S\)，所以记忆化最多有 \(O(nS)\) 个可达 (index,total) 状态，时间与空间均为 \(O(nS)\)（忽略常数）。

当重复状态存在且请求输出可以摘要时使用记忆化。若必须显式枚举每条不同路径，只缓存计数或可行性不能替代构造输出。

练习： LeetCode 494 - 目标和直接检验符号赋值树何时可以按 (index,total) 合并。

对比与选择

需要生成合法构造，或路径相关约束阻止紧凑状态合并时，回溯很合适。无效性出现较早、传播后候选较少，或找到一个解即可停止时，它特别有效。

分支限界（Branch and Bound）是用于优化的状态空间搜索。它维护当前最佳完整解，并为每个部分状态计算乐观目标界。与可行性剪枝不同，被界限剪掉的状态可能包含有效完成方案，只是没有一个能改善当前最佳值。

对正数子集选择，一个简单最大化上界为

\[ UB(i,current)=current+\sum_{j=i}^{n-1} value_j. \]

它假设全部剩余值都能加入，即使容量实际上不允许，所以是乐观且安全的。分数背包松弛能给出更紧但更昂贵的界。

BRANCH-AND-BOUND(state s)
    if s is infeasible: return
    update incumbent when s is a better feasible solution
    if optimistic_bound(s) <= incumbent: return
    explore promising child first
    explore remaining children
Python 实现：对子集价值进行深度优先分支限界 
def best_subset_under_limit(
    values: list[int], limit: int
) -> tuple[int, list[int]]:
    """在不超过 limit 时最大化正数之和。"""
    if limit < 0 or any(value <= 0 for value in values):
        raise ValueError("limit must be non-negative and values positive")

    ordered = sorted(values, reverse=True)  # 先尝试大值，以便早得强 incumbent。
    suffix_sum = [0] * (len(ordered) + 1)
    for index in range(len(ordered) - 1, -1, -1):
        suffix_sum[index] = suffix_sum[index + 1] + ordered[index]

    best_total = 0
    best_path: list[int] = []
    path: list[int] = []

    def search(index: int, current: int) -> None:
        nonlocal best_total, best_path

        if current > limit:
            return  # 不可行；未来正数不能修复。
        if current > best_total:
            best_total = current
            best_path = path.copy()
        if index == len(ordered):
            return

        optimistic = current + suffix_sum[index]
        if optimistic <= best_total:
            return  # 即使全部选择也无法超过 incumbent。

        value = ordered[index]
        path.append(value)
        search(index + 1, current + value)  # 先尝试更有希望的包含分支。
        path.pop()
        search(index + 1, current)

    search(0, 0)
    return best_total, best_path


total, chosen = best_subset_under_limit([8, 7, 6, 5], 13)
assert total == 13
assert sum(chosen) == total
print(total, chosen)

分支限界最坏仍为 \(O(2^n)\)，因为弱界可能什么都剪不掉。深度优先实现除有序输入和后缀界外使用 \(O(n)\) 路径与调用栈。排序与紧界改善访问节点数，而非形式最坏保证。

结构性质 推荐起点
一个局部最佳选择有安全证明 贪心
等价历史共享全部未来延续 动态规划 / 记忆化
路径历史改变未来合法性 带可逆状态的回溯
优化问题有便宜乐观界 分支限界
赋值后可缩减值域 约束传播 + 回溯
必须返回每个有效构造 输出相关回溯

实现前先决定任务需要一个解、全部解、计数还是最佳目标。同一状态空间树可支持每种契约，但停止条件、剪枝规则、记忆化值与输出成本都不同。
