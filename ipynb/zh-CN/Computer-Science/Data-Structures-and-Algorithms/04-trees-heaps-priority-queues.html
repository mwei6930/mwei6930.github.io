树、搜索树、堆与优先队列

线性结构把元素排列在一条路径上，而树（tree）引入了层级关系：一个元素可以通向多个更小的结构，并且每棵子树内部都会重复相同的递归形式。因此，文件系统、语法结构、索引、决策过程、搜索空间与层级数据都很适合用树表示。

本章把三个经常混在一起的概念区分开：

  • 树的表示方式决定节点与关系如何存储；
  • 树算法决定如何访问或更新这些节点；
  • 有序不变量，例如二叉搜索树性质或堆性质，决定哪些操作能够高效完成。

这种区分很重要。二叉树只限制形状；二叉搜索树在此基础上增加全局搜索顺序；二叉堆则增加另一种局部优先级顺序。选择它们的出发点应是程序需要快速执行的操作，而不是它们都能画成树状图。

树的术语与递归结构

树是一组通过父子关系连接且不含环的节点。在有根树中，一个特殊节点称为根（root）。其余每个节点恰好有一个父节点，因此从根到任意节点都只有一条简单路径。可以把它类比为公司组织结构：首席执行官是根，各部门是子树，而一个团队可以在不重画整个公司的情况下独立理解。

树适合解决信息天然嵌套，或选择会反复分裂成更小选择的问题。与扁平数组相比，树直接记录层级；与一般图相比，有根树具有唯一父节点，因此递归处理和路径推理更加简单。

核心术语如下：

  • 一个节点正上方的节点是它的父节点（parent），直接连接的下层节点是它的子节点（children）；拥有同一父节点的节点互为兄弟节点（siblings）。
  • 叶节点（leaf）没有子节点；内部节点（internal node）至少有一个子节点。
  • 祖先（ancestor）位于根到某节点的路径上；后代（descendant）位于该节点之下。
  • 以 v 为根的子树包含 v 及其所有后代。
  • v 的深度（depth）是根到 v 的边数，所以根的深度为 0。
  • v 的高度（height）是从 v 到某个叶节点的最大边数。叶节点高度为 0，整棵树的高度就是根的高度。

树的递归定义非常简洁：一棵树要么为空，要么由一个根以及若干棵互不相交、以其子节点为根的树组成。这个定义直接启发递归算法。计算树的大小或高度时，可以在每棵子树上解决同一个问题，再合并结果：

\[ \operatorname{size}(v)=1+\sum_{u\in\operatorname{children}(v)}\operatorname{size}(u), \]

\[ \operatorname{height}(v)= \begin{cases} 0, & v \text{ 是叶节点},\\ 1+\max\limits_{u\in\operatorname{children}(v)}\operatorname{height}(u), & \text{否则}. \end{cases} \]

其中 v 是当前节点，u 遍历它的子节点。大小公式中的 1 用于计算 v 自身；高度公式中的 1 计算从 v 到所选子节点的那条边。

无论具体如何表示，一般的有根 Tree ADT 都可以承诺以下行为：

ADT 操作 必须提供的行为
root() 返回根；空树返回空结果。
parent(v) 返回非根节点 v 的唯一父节点。
children(v) 按表示所规定的顺序迭代 v 的子节点。
is_leaf(v) 判断 v 是否没有子节点。
add_child(v, x) 在 v 下方连接一个保存 x 的新节点。
remove_subtree(v) 分离 v 及其所有后代。
size() / height() 返回节点数 / 根到叶节点的最大边数。

接口本身不能决定全部复杂度。保存父引用时，parent(v) 为 \(O(1)\)；不保存时，寻找父节点可能需要 \(O(n)\) 遍历。若没有缓存大小和高度，二者都需要 \(O(n)\) 时间，因为每个节点都可能影响答案。递归实现使用 \(O(h)\) 调用栈空间，其中 h 是树高：浅而平衡的树为 \(O(\log n)\)，链状树则为 \(O(n)\)。

Python 实现：递归计算大小与高度 
from dataclasses import dataclass, field
from typing import Generic, TypeVar

T = TypeVar("T")


@dataclass
class TreeNode(Generic[T]):
    value: T
    children: list["TreeNode[T]"] = field(default_factory=list)

    def add_child(self, value: T) -> "TreeNode[T]":
        """创建并连接一个子节点，然后返回它。"""
        child = TreeNode(value)
        self.children.append(child)
        return child


def tree_size(node: TreeNode[T] | None) -> int:
    """计算当前节点及其所有子树中的节点数。"""
    if node is None:
        return 0
    return 1 + sum(tree_size(child) for child in node.children)


def tree_height(node: TreeNode[T] | None) -> int:
    """返回按边计算的高度；约定空树高度为 -1。"""
    if node is None:
        return -1
    if not node.children:
        return 0
    return 1 + max(tree_height(child) for child in node.children)


root = TreeNode("A")
left = root.add_child("B")
root.add_child("C")
left.add_child("D")

assert tree_size(root) == 4
assert tree_height(root) == 2

一般树及其实现

一般树（general tree）允许一个节点拥有任意数量的子节点。目录树、HTML 文档树、分类体系以及分支数不固定的游戏树或搜索树都符合这一抽象。真正需要设计的不是“它是不是树”，而是应如何表示子节点关系，才能匹配应用最常执行的操作。

三种表示尤其常用：

  1. 子节点列表（children list）在每个节点中保存可扩容的子引用列表。遍历一个节点的子节点很直接，也能保留明确的子节点顺序；代价是每个节点都需要一个容器，并且从数组支持的子列表中间删除可能较昂贵。
  2. 首子节点/下一兄弟（first-child/next-sibling）每个节点只保存两个链接。first_child 进入子节点链，重复沿 next_sibling 可遍历全部子节点。它把任意一般树转为二链接表示，避免每个节点内部都有可变大小容器。
  3. 父节点数组（parent array）为每个节点下标 i 保存 parent[i]。父节点查询立即完成且表示紧凑，但若不额外维护反向索引，查找所有子节点必须扫描整个数组。

对于度为 d(v) 的节点 v 和包含 n 个节点的树，结构取舍如下：

操作 子节点列表 首子节点/下一兄弟 仅父节点数组
parent(v) 有父引用 \(O(1)\)；否则 \(O(n)\) 有父引用 \(O(1)\)；否则 \(O(n)\) \(O(1)\)
遍历 children(v) \(\Theta(d(v))\) \(\Theta(d(v))\) \(\Theta(n)\)
追加子节点 摊还 \(O(1)\) 保存末子引用时 \(O(1)\)；否则 \(O(d(v))\) 新建带下标节点时摊还 \(O(1)\)
查找特定子节点 \(O(d(v))\) \(O(d(v))\) \(O(n)\)
遍历整棵树 \(\Theta(n)\) \(\Theta(n)\) 若能高效推导子列表则为 \(\Theta(n)\)
结构存储 \(\Theta(n)\) 个节点链接及列表开销 每个节点恰好两个结构链接 每个节点一个父下标

这些是表示成本，而不是 Tree ADT 永远不变的事实。加入父引用或末子引用，可以通过保存更多信息来加速某些查询。设计原则是：缓存高频查询的关系，同时接受为保持缓存一致而增加的更新工作。

Python 实现：子节点列表形式的一般树 
from dataclasses import dataclass, field
from typing import Generic, Iterator, TypeVar

T = TypeVar("T")


@dataclass
class GeneralTreeNode(Generic[T]):
    value: T
    parent: "GeneralTreeNode[T] | None" = field(default=None, repr=False)
    children: list["GeneralTreeNode[T]"] = field(default_factory=list)

    def add_child(self, value: T) -> "GeneralTreeNode[T]":
        """追加子节点，并维护它的父引用。"""
        child = GeneralTreeNode(value=value, parent=self)
        self.children.append(child)
        return child

    def detach(self) -> None:
        """将当前整棵子树从父节点处分离。"""
        if self.parent is None:
            return
        self.parent.children.remove(self)  # 查找与移动成本为 O(degree(parent))
        self.parent = None


def preorder(node: GeneralTreeNode[T]) -> Iterator[T]:
    """先产生当前节点，再递归产生每棵子树。"""
    yield node.value
    for child in node.children:
        yield from preorder(child)


root = GeneralTreeNode("course")
week_1 = root.add_child("week 1")
week_1.add_child("lecture")
week_1.add_child("tutorial")
root.add_child("week 2")

assert list(preorder(root)) == [
    "course", "week 1", "lecture", "tutorial", "week 2"
]

在 Python 中，子节点列表是可读性最好的默认表示。每个节点链接数量必须固定时，可选首子节点/下一兄弟形式；静态、以下行查询为主的带下标层级则适合父节点数组。

深度优先遍历

深度优先遍历（depth-first traversal，DFS）沿一条分支尽可能深入，再返回探索下一条分支。可以类比为进入一个目录，先处理完其中全部内容，再转到它的兄弟目录。当需要把子树作为整体处理、求值表达式、序列化层级、检测结构性质，或以较小前沿内存探索一条搜索路径时，DFS 很有用。

对于二叉节点，三种标准遍历只在“何时处理当前节点”这一点上不同：

  • 前序（preorder）：节点、左、右。父节点先于后代出现，因此适合复制或序列化树；
  • 中序（inorder）：左、节点、右。在二叉搜索树中会按升序产生键；
  • 后序（postorder）：左、右、节点。父节点依赖已经完成的子结果时很合适，例如删除树或计算目录大小。

递归算法明确表现了处理时机：

PREORDER(node)
    if node is empty
        return
    visit(node)
    PREORDER(node.left)
    PREORDER(node.right)

INORDER(node)
    if node is empty
        return
    INORDER(node.left)
    visit(node)
    INORDER(node.right)

POSTORDER(node)
    if node is empty
        return
    POSTORDER(node.left)
    POSTORDER(node.right)
    visit(node)

每个节点进入一次，只做常数本地工作，所以三种遍历对 n 个节点都需要 \(\Theta(n)\) 时间。递归调用栈在每层保存一个活动栈帧，因此辅助空间为 \(O(h)\)，其中 h 是高度：平衡二叉树为 \(O(\log n)\)，偏斜树为 \(O(n)\)。迭代 DFS 用显式栈替代语言调用栈，但不会消除这一最坏前沿空间需求。

Python 实现：递归与迭代 DFS 顺序 
from dataclasses import dataclass
from typing import Iterator


@dataclass
class BinaryNode:
    value: int
    left: "BinaryNode | None" = None
    right: "BinaryNode | None" = None


def preorder(node: BinaryNode | None) -> Iterator[int]:
    if node is None:
        return
    yield node.value                    # 在两棵子树之前处理。
    yield from preorder(node.left)
    yield from preorder(node.right)


def inorder(node: BinaryNode | None) -> Iterator[int]:
    if node is None:
        return
    yield from inorder(node.left)
    yield node.value                    # 在左右子树之间处理。
    yield from inorder(node.right)


def postorder(node: BinaryNode | None) -> Iterator[int]:
    if node is None:
        return
    yield from postorder(node.left)
    yield from postorder(node.right)
    yield node.value                    # 在两棵子树之后处理。


def iterative_preorder(root: BinaryNode | None) -> list[int]:
    if root is None:
        return []

    result: list[int] = []
    stack = [root]
    while stack:
        node = stack.pop()
        result.append(node.value)

        # 先压入右子节点，使左子节点先被弹出并访问。
        if node.right is not None:
            stack.append(node.right)
        if node.left is not None:
            stack.append(node.left)
    return result


root = BinaryNode(4, BinaryNode(2), BinaryNode(6))
assert list(preorder(root)) == [4, 2, 6]
assert list(inorder(root)) == [2, 4, 6]
assert list(postorder(root)) == [2, 6, 4]
assert iterative_preorder(root) == [4, 2, 6]

广度优先与层序遍历

广度优先遍历（breadth-first traversal，BFS）会先访问深度 d 的所有节点，再访问深度 d + 1 的节点。它在树上的形式称为层序遍历（level-order traversal）。可以想象逐层查看公司组织结构：当前层是前沿，它们的子节点构成下一层前沿。

当答案依赖深度顺序时，例如寻找最近匹配节点、计算每层统计量、填充同层链接或在无权图中寻找最短路径，BFS 比 DFS 更合适。FIFO 队列至关重要，因为最早被发现的前沿节点必须最先处理。

LEVEL-ORDER(root)
    if root is empty
        return empty result

    queue <- FIFO queue containing root
    while queue is not empty
        level_size <- size(queue)
        repeat level_size times
            node <- remove_front(queue)
            visit(node)
            for each child of node
                add_back(queue, child)

处理一层前先记录 level_size，就能建立清晰边界：循环中加入的节点属于下一层，不会被提前消费。每个节点恰好入队和出队一次，因此时间为 \(\Theta(n)\)。队列最多保存树的最大宽度 w，辅助空间为 \(O(w)\)。完全树最后一层可能包含约一半节点，所以最坏空间仍是 \(O(n)\)，尽管 BFS 在狭窄树上通常很紧凑。

Python 实现：保留明确的层边界 
from collections import deque
from dataclasses import dataclass


@dataclass
class BinaryNode:
    value: int
    left: "BinaryNode | None" = None
    right: "BinaryNode | None" = None


def level_order(root: BinaryNode | None) -> list[list[int]]:
    """为每个深度返回一个列表。"""
    if root is None:
        return []

    result: list[list[int]] = []
    queue = deque([root])

    while queue:
        level: list[int] = []

        # 当前队列长度恰好等于当前前沿大小。
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.value)

            if node.left is not None:
                queue.append(node.left)
            if node.right is not None:
                queue.append(node.right)

        result.append(level)

    return result


root = BinaryNode(
    3,
    left=BinaryNode(9),
    right=BinaryNode(20, BinaryNode(15), BinaryNode(7)),
)
assert level_order(root) == [[3], [9, 20], [15, 7]]

二叉树性质

二叉树（binary tree）把每个节点限制为两个有区别的子位置：left 与 right。两个位置不能互换：只有左子节点与只有右子节点在结构上不同。固定分支数支持简洁递归、完全树的数组表示，以及二叉搜索树和堆所使用的有序规则。

常见形状描述回答不同问题：

  • 满二叉树（full）中，每个节点要么没有子节点，要么有两个子节点；
  • 完美二叉树（perfect）既是满二叉树，又要求所有叶节点深度相同；
  • 完全二叉树（complete）除最后一层外每层都填满，最后一层从左向右填充。二叉堆要求这种形状；
  • 高度平衡二叉树（height-balanced）按指定界限约束左右子树高度差。AVL 树要求每个节点的高度差不超过 1；
  • 偏斜树（skewed）的每个内部节点只有一个子节点，因此行为类似链表。

采用按边计算的高度 h 时，第 d 层最多有 \(2^d\) 个节点，因为上一层每个节点最多贡献两个子节点。完美二叉树因此包含

\[ n = 1 + 2 + 2^2 + \cdots + 2^h = 2^{h+1}-1. \]

这里 n 是节点数，h 是最长根到叶路径的边数。解出 h 可见，饱满而浅的树高度为对数级：\(h=\log_2(n+1)-1\)。包含 n 个节点的完全树高度是 \(h=\lfloor\log_2 n\rfloor\)；偏斜树则是 \(h=n-1\)，会把依赖 \(O(h)\) 的算法从对数时间退化为线性时间。

Binary Tree ADT 通常提供 left(v)、right(v)、parent(v)、attach_left、attach_right 与子树分离。使用直接引用时，访问和连接子节点都是 \(O(1)\)。按值搜索仍为 \(O(n)\)，因为普通二叉树没有搜索顺序不变量。保存全部 n 个节点需要 \(\Theta(n)\) 空间。

平衡性可以自底向上检查：每棵子树返回自身高度；只有左右子树都平衡且高度差不超过一时，当前节点才平衡。一次后序遍历同时合并这两个结果，可以避免反复计算高度。

Python 实现：单次遍历汇总大小、高度与平衡性 
from dataclasses import dataclass


@dataclass
class BinaryNode:
    value: int
    left: "BinaryNode | None" = None
    right: "BinaryNode | None" = None


def summarize(node: BinaryNode | None) -> tuple[int, int, bool]:
    """返回（大小、按边计算的高度、AVL 风格平衡性）。"""
    if node is None:
        # 令空树高度为 -1，叶节点加一后的高度正好为 0。
        return 0, -1, True

    left_size, left_height, left_ok = summarize(node.left)
    right_size, right_height, right_ok = summarize(node.right)

    size = 1 + left_size + right_size
    height = 1 + max(left_height, right_height)
    balanced = (
        left_ok
        and right_ok
        and abs(left_height - right_height) <= 1
    )
    return size, height, balanced


root = BinaryNode(
    8,
    left=BinaryNode(4, BinaryNode(2), BinaryNode(6)),
    right=BinaryNode(12),
)
assert summarize(root) == (5, 2, True)

root.left.left.left = BinaryNode(1)
assert summarize(root) == (6, 3, False)

组合遍历让每个节点只贡献一次，因此时间为 \(\Theta(n)\)，调用栈空间为 \(O(h)\)。若在每个节点处分别重新计算高度，朴素版本在偏斜树上可能需要 \(O(n^2)\) 时间。

练习。 LeetCode 110 - 平衡二叉树适合练习这种自底向上的单次遍历表述。

二叉搜索树

二叉搜索树（binary search tree，BST）是在二叉树上增加有序不变量。对每个键为 k 的节点，其左子树中的所有键都小于 k，右子树中的所有键都大于 k。如果允许重复键，实现必须规定一致策略，例如在已有节点中保存计数；把重复项随意放到任意一侧会破坏搜索与验证逻辑。

该不变量让一次比较能够排除大量候选。在一个节点处，一次比较要么完成搜索，要么丢弃整棵子树。因此，浅 BST 能像二分搜索一样工作，同时支持不移动数组后缀的插入与删除。它适合既需要搜索，又需要最小值、最大值、前驱、后继或有序迭代的有序集合与映射。

打开原始图片：Wikimedia Commons - Binary search tree（公有领域）。

BST 支持的有序 Set/Map ADT 包括：

ADT 操作 必须提供的行为
search(k) 返回与 k 关联的项，或未找到结果。
insert(k, value) 在保持有序不变量的同时加入键值对。
delete(k) 删除 k 并保持不变量。
minimum() / maximum() 返回最左 / 最右键。
predecessor(k) / successor(k) 存在时返回相邻的较小 / 较大键。
iterate_sorted() 按升序产生全部键。

搜索与插入只沿一条根到叶路径前进。删除有三种结构情况：

  1. 叶节点可以直接分离；
  2. 只有一个子节点的节点由该子节点替代；
  3. 有两个子节点的节点由其中序后继替代，也就是右子树中的最小节点；随后从原位置删除后继。后继没有左子节点，所以第二次删除会退化为情况 1 或 2。

对于高度为 h 的树，复杂度如下：

操作 复杂度 原因
search、insert、delete \(O(h)\) 每次比较向下移动一层。
minimum / maximum \(O(h)\) 只沿左 / 右引用前进。
有序遍历 \(\Theta(n)\) 中序遍历只产生每个节点一次。
存储 \(\Theta(n)\) 每个键一个节点和常数个链接。

若插入顺序使树大致平衡，h 为 \(O(\log n)\)。向普通 BST 按已经排序的顺序插入键会形成高度 h=n-1 的链，使搜索、插入与删除退化为 \(O(n)\)。对形状的依赖正是自平衡搜索树存在的主要原因。

Python 实现：搜索、插入、删除与有序迭代 
from dataclasses import dataclass
from typing import Iterator


@dataclass
class BSTNode:
    key: int
    left: "BSTNode | None" = None
    right: "BSTNode | None" = None


class BinarySearchTree:
    def __init__(self) -> None:
        self.root: BSTNode | None = None

    def search(self, key: int) -> BSTNode | None:
        current = self.root
        while current is not None:
            if key == current.key:
                return current
            # BST 不变量允许安全丢弃一整棵子树。
            current = current.left if key < current.key else current.right
        return None

    def insert(self, key: int) -> None:
        def insert_from(node: BSTNode | None, key: int) -> BSTNode:
            if node is None:
                return BSTNode(key)
            if key < node.key:
                node.left = insert_from(node.left, key)
            elif key > node.key:
                node.right = insert_from(node.right, key)
            # 忽略重复键：这个类实现集合语义。
            return node

        self.root = insert_from(self.root, key)

    def delete(self, key: int) -> None:
        def delete_from(node: BSTNode | None, key: int) -> BSTNode | None:
            if node is None:
                return None
            if key < node.key:
                node.left = delete_from(node.left, key)
            elif key > node.key:
                node.right = delete_from(node.right, key)
            else:
                if node.left is None:       # 零个或一个子节点。
                    return node.right
                if node.right is None:
                    return node.left

                # 两个子节点：复制中序后继的键。
                successor = node.right
                while successor.left is not None:
                    successor = successor.left
                node.key = successor.key
                node.right = delete_from(node.right, successor.key)
            return node

        self.root = delete_from(self.root, key)

    def inorder(self) -> Iterator[int]:
        def walk(node: BSTNode | None) -> Iterator[int]:
            if node is not None:
                yield from walk(node.left)
                yield node.key
                yield from walk(node.right)

        yield from walk(self.root)


tree = BinarySearchTree()
for key in [8, 3, 10, 1, 6, 14, 4, 7, 13]:
    tree.insert(key)

assert tree.search(7) is not None
assert list(tree.inorder()) == [1, 3, 4, 6, 7, 8, 10, 13, 14]
tree.delete(3)  # 删除有两个子节点的节点。
assert list(tree.inorder()) == [1, 4, 6, 7, 8, 10, 13, 14]

平衡搜索树与 AVL 旋转

自平衡搜索树在保持 BST 有序不变量的同时，防止高度增长成链。AVL 树在每个节点 v 计算平衡因子：

\[ \operatorname{bf}(v)=\operatorname{height}(v.\text{left})-\operatorname{height}(v.\text{right}). \]

左右两项是两棵子树按边计算的高度。当平衡因子为 -1、0 或 1 时，AVL 节点平衡。插入或删除可能使因子变为 2 或 -2；此时通过旋转（rotation）修改常数条链接，同时保持中序键序列不变。

仅检测失衡不能恢复对数搜索，因此需要旋转。旋转把失衡三键结构的中间键向上移动，同时保持全部 BST 大小关系。外侧过重路径（LL 或 RR）用一次旋转修复，内侧过重路径（LR 或 RL）则用两次旋转。

REBALANCE(node)
    update node.height from its children
    balance <- height(node.left) - height(node.right)

    if balance > 1
        if balance_factor(node.left) < 0
            node.left <- ROTATE-LEFT(node.left)    // LR 情况
        return ROTATE-RIGHT(node)                  // 可选修复后成为 LL

    if balance < -1
        if balance_factor(node.right) > 0
            node.right <- ROTATE-RIGHT(node.right) // RL 情况
        return ROTATE-LEFT(node)                   // 可选修复后成为 RR

    return node

AVL 树实现与 BST 相同的有序 Set/Map ADT。它在每个节点中额外缓存高度，每次修改都必须保持元数据正确。左右旋转只改变常数个引用并重新计算两个高度，因此一次旋转为 \(O(1)\)。AVL 高度为 \(O(\log n)\)，从而提供以下最坏保证：

操作 AVL 复杂度 普通非平衡 BST
search \(O(\log n)\) 最坏 \(O(n)\)
insert \(O(\log n)\) 最坏 \(O(n)\)
delete \(O(\log n)\) 最坏 \(O(n)\)
单次旋转 \(O(1)\) 不提供
有序遍历 \(\Theta(n)\) \(\Theta(n)\)
存储 \(\Theta(n)\) \(\Theta(n)\)

AVL 树特别适合需要频繁搜索和可预测延迟的有序字典。它比红黑树约束更严格，可能需要更多再平衡，但通常也能得到更浅的搜索路径。

Python 实现：AVL 插入与四种旋转情况 
from dataclasses import dataclass


@dataclass
class AVLNode:
    key: int
    height: int = 1                 # 按节点计高度可简化更新。
    left: "AVLNode | None" = None
    right: "AVLNode | None" = None


def height(node: AVLNode | None) -> int:
    return node.height if node is not None else 0


def update_height(node: AVLNode) -> None:
    node.height = 1 + max(height(node.left), height(node.right))


def balance_factor(node: AVLNode) -> int:
    return height(node.left) - height(node.right)


def rotate_right(top: AVLNode) -> AVLNode:
    new_top = top.left
    assert new_top is not None
    moved_subtree = new_top.right

    # 保持中序顺序：被移动的子树键位于两个节点键之间。
    new_top.right = top
    top.left = moved_subtree

    update_height(top)              # 先更新较低节点。
    update_height(new_top)
    return new_top


def rotate_left(top: AVLNode) -> AVLNode:
    new_top = top.right
    assert new_top is not None
    moved_subtree = new_top.left

    new_top.left = top
    top.right = moved_subtree

    update_height(top)
    update_height(new_top)
    return new_top


def insert(node: AVLNode | None, key: int) -> AVLNode:
    # 先执行普通 BST 插入。
    if node is None:
        return AVLNode(key)
    if key < node.key:
        node.left = insert(node.left, key)
    elif key > node.key:
        node.right = insert(node.right, key)
    else:
        return node                    # 集合语义：忽略重复项。

    update_height(node)
    balance = balance_factor(node)

    if balance > 1:
        assert node.left is not None
        if key > node.left.key:         # 左-右情况。
            node.left = rotate_left(node.left)
        return rotate_right(node)

    if balance < -1:
        assert node.right is not None
        if key < node.right.key:        # 右-左情况。
            node.right = rotate_right(node.right)
        return rotate_left(node)

    return node


def inorder(node: AVLNode | None) -> list[int]:
    if node is None:
        return []
    return inorder(node.left) + [node.key] + inorder(node.right)


root: AVLNode | None = None
for key in [30, 10, 20, 40, 50]:       # 触发 LR 与 RR 修复。
    root = insert(root, key)

assert inorder(root) == [10, 20, 30, 40, 50]
assert root is not None and abs(balance_factor(root)) <= 1

二叉堆与建堆

二叉堆（binary heap）结合两个不变量：

  • 形状性质：它是一棵完全二叉树；
  • 堆序性质：在最小堆中，每个父键都不大于任一子键；最大堆反转比较方向。

堆序性质有意弱于 BST 顺序。它保证最小堆的最小值位于根，却不规定兄弟节点或不同子树之间的顺序。这一较弱承诺已经足以高效删除最高优先级项，并允许紧凑的数组表示。

对于从零开始的数组下标 i：

\[ \operatorname{parent}(i)=\left\lfloor\frac{i-1}{2}\right\rfloor,\qquad \operatorname{left}(i)=2i+1,\qquad \operatorname{right}(i)=2i+2. \]

完全性保证最后一个已占用数组槽位之前没有空缺，因此无需显式子引用，表示只使用 \(\Theta(n)\) 连续空间。

最小堆 ADT 提供：

操作 必须提供的行为 复杂度
peek_min() 返回根但不删除。 \(O(1)\)
push(x) 加入 x，向上筛选恢复堆序。 \(O(\log n)\)
pop_min() 删除根，把末项移到根，再向下筛选。 \(O(\log n)\)
heapify(values) 把所有值重排为有效堆。 自底向上 \(O(n)\)
search(x) 查找任意值。 \(O(n)\)
存储 保存全部堆元素。 \(\Theta(n)\)

插入把元素追加到唯一能保持完全性的槽位，再向上比较。取出最小值时，用末项填补根的空缺，再反复与较小子节点交换：

SIFT-DOWN(heap, i)
    while i has at least one child
        child <- index of the smaller child
        if heap[i] <= heap[child]
            stop
        swap heap[i] and heap[child]
        i <- child

BUILD-MIN-HEAP(values)
    for i from parent(last_index) down to 0
        SIFT-DOWN(values, i)

每次筛选最多沿一条根到叶路径前进，因此成本为 \(O(h)=O(\log n)\)。自底向上建堆是 \(O(n)\)，而不是 \(O(n\log n)\)。原因是绝大多数节点靠近叶层，移动很少：约 n/2 个叶节点无需工作，n/4 个节点最多移动一层，n/8 个最多移动两层，这个加权总和为线性。

Python 实现：数组支持的最小堆 
from collections.abc import Iterable


class MinHeap:
    def __init__(self, values: Iterable[int] = ()) -> None:
        self._data = list(values)
        # 叶节点本身已经是单元素堆，自底向上修复内部节点。
        for index in range(len(self._data) // 2 - 1, -1, -1):
            self._sift_down(index)

    def __len__(self) -> int:
        return len(self._data)

    def peek_min(self) -> int:
        if not self._data:
            raise IndexError("peek from empty heap")
        return self._data[0]

    def push(self, value: int) -> None:
        self._data.append(value)       # 保持完全树形状。
        self._sift_up(len(self._data) - 1)

    def pop_min(self) -> int:
        if not self._data:
            raise IndexError("pop from empty heap")

        minimum = self._data[0]
        last = self._data.pop()
        if self._data:
            self._data[0] = last       # 填补根的空缺。
            self._sift_down(0)
        return minimum

    def _sift_up(self, index: int) -> None:
        while index > 0:
            parent = (index - 1) // 2
            if self._data[parent] <= self._data[index]:
                break
            self._data[parent], self._data[index] = (
                self._data[index], self._data[parent]
            )
            index = parent

    def _sift_down(self, index: int) -> None:
        size = len(self._data)
        while True:
            left = 2 * index + 1
            right = left + 1
            smallest = index

            if left < size and self._data[left] < self._data[smallest]:
                smallest = left
            if right < size and self._data[right] < self._data[smallest]:
                smallest = right
            if smallest == index:
                return

            self._data[index], self._data[smallest] = (
                self._data[smallest], self._data[index]
            )
            index = smallest


heap = MinHeap([9, 4, 7, 1, 3, 6])
heap.push(2)
assert [heap.pop_min() for _ in range(len(heap))] == [1, 2, 3, 4, 6, 7, 9]

优先队列

优先队列（priority queue）是一种按优先级而不是到达时间或下标决定删除顺序的抽象数据类型。医院分诊是常见类比：后来到达但病情更紧急的患者可能先于早到的低紧急度患者接受处理。ADT 只规定行为，并不要求用堆实现；无序数组、有序数组、平衡搜索树与二叉堆都能实现同一契约，只是复杂度不同。

每个条目通常包含项目和可比较的优先级。最小优先队列删除最小优先级，最大优先队列删除最大优先级。相同优先级需要明确策略；稳定优先队列把插入顺序作为次关键字，使同优先级条目按 FIFO 顺序离开。

主要操作如下：

ADT 操作 必须提供的行为
insert(item, priority) 加入带优先级的项目。
peek_best() 返回但不删除最高优先级条目。
extract_best() 删除并返回最高优先级条目。
update_priority(item, p) 替换已有项目的优先级，同时保持队列契约。
is_empty() / size() 报告队列状态。

对于 n 个活动条目，常见实现对比如下：

表示 插入 查看最佳项 提取最佳项 搜索/更新任意项 结构优势
无序数组/列表 \(O(1)\) \(O(n)\) \(O(n)\) \(O(n)\) 插入最便宜
有序数组/列表 \(O(n)\) \(O(1)\) 在端点为 \(O(1)\) 搜索 \(O(\log n)\)，但移动 \(O(n)\) 连续读取/删除很快
平衡搜索树 \(O(\log n)\) \(O(\log n)\)；缓存极值时 \(O(1)\) \(O(\log n)\) \(O(\log n)\) 支持完整有序映射操作
二叉堆 \(O(\log n)\) \(O(1)\) \(O(\log n)\) 无下标映射时 \(O(n)\) 紧凑，适合反复访问最佳项

堆通常是默认选择，因为它在调度、图前沿、事件模拟和流式选择中取得良好平衡。若经常更新任意项目的优先级，可用项目到下标的辅助映射先以 \(O(1)\) 定位，再执行对数筛选。Python 的 heapq 不维护该映射，所以常见替代方式是惰性删除：把旧条目标记为失效，压入替代项，在失效项到达根时跳过。

Python 实现：稳定优先级与惰性更新 
import heapq
import itertools
from typing import Any


class StablePriorityQueue:
    """具有 FIFO 同优先级顺序与惰性更新的最小优先队列。"""

    _REMOVED = object()

    def __init__(self) -> None:
        self._heap: list[list[Any]] = []
        self._active: dict[str, list[Any]] = {}
        self._sequence = itertools.count()

    def __len__(self) -> int:
        return len(self._active)

    def put(self, item: str, priority: float) -> None:
        if item in self._active:
            self.remove(item)               # 使旧版本失效。

        entry: list[Any] = [priority, next(self._sequence), item]
        self._active[item] = entry
        heapq.heappush(self._heap, entry)

    def remove(self, item: str) -> None:
        entry = self._active.pop(item)
        entry[2] = self._REMOVED             # 留下无害的过期条目。

    def pop(self) -> tuple[str, float]:
        while self._heap:
            priority, _, item = heapq.heappop(self._heap)
            if item is not self._REMOVED:
                del self._active[item]
                return item, priority
        raise IndexError("pop from empty priority queue")


queue = StablePriorityQueue()
queue.put("write report", 3)
queue.put("fix production issue", 1)
queue.put("review notes", 3)                # 同优先级，但插入更晚。
queue.put("write report", 0)                # 惰性优先级更新。

assert queue.pop() == ("write report", 0)
assert queue.pop() == ("fix production issue", 1)
assert queue.pop() == ("review notes", 3)

堆插入与提取仍为 \(O(\log m)\)，其中 m 同时包含活动项和过期项。惰性删除具有良好摊还效率，但长期运行的系统应在过期项远多于活动项时定期重建堆。

基于优先队列的排序

优先队列带来一种简单排序策略：插入全部值，再反复提取最小值。用二叉堆实现时需要 \(O(n\log n)\) 时间和 \(O(n)\) 额外空间。堆排序（heapsort）进一步在输入数组内部建立最大堆，并把每个最大值直接移到最终位置，把辅助空间降为 \(O(1)\)。

未排序前缀被视为堆，有序后缀从右向左增长：

HEAPSORT(values)
    BUILD-MAX-HEAP(values)

    for end from length(values) - 1 down to 1
        swap values[0] and values[end]   // 最大值到达最终位置
        SIFT-DOWN(values, root=0, heap_size=end)

BUILD-MAX-HEAP(values)
    for i from parent(last_index) down to 0
        SIFT-DOWN(values, i, length(values))

自底向上建堆需要 \(O(n)\)。提取循环运行 n - 1 次，每次向下筛选最多 \(O(\log n)\)，所以最好、平均与最坏时间均为 \(O(n\log n)\)。数组表示让迭代实现成为原地算法，辅助空间为 \(O(1)\)。

堆排序提供普通快速排序在没有谨慎选择枢轴时不具备的最坏保证，并比标准归并排序使用更少额外内存。缺点是缓存局部性通常弱于快速排序，而且不稳定：远距离交换堆元素可能反转相等键的原始顺序。

Python 实现：原地升序堆排序 
def heapsort(values: list[int]) -> None:
    """使用原地最大堆把 values 按升序排序。"""

    def sift_down(root: int, heap_size: int) -> None:
        while True:
            left = 2 * root + 1
            right = left + 1
            largest = root

            if left < heap_size and values[left] > values[largest]:
                largest = left
            if right < heap_size and values[right] > values[largest]:
                largest = right
            if largest == root:
                return

            values[root], values[largest] = values[largest], values[root]
            root = largest

    # 在 O(n) 时间内把完整数组树转换为最大堆。
    for index in range(len(values) // 2 - 1, -1, -1):
        sift_down(index, len(values))

    # 把每个最大值移到末尾，再修复更短的堆前缀。
    for end in range(len(values) - 1, 0, -1):
        values[0], values[end] = values[end], values[0]
        sift_down(0, end)


numbers = [12, 11, 13, 5, 6, 7, 6]
heapsort(numbers)
assert numbers == [5, 6, 6, 7, 11, 12, 13]

在 Python 应用中，list.sort() 通常是更好的工程选择，因为 Timsort 稳定且高度优化。实现堆排序的价值在于理解 Priority Queue ADT 如何转化为完整的原地排序算法。

练习。 LeetCode 912 - 排序数组提供直接实现并比较 \(O(n\log n)\) 排序算法的场景。

Top-K 与 Merge-K 模式

两种常见堆模式都只保留大型搜索空间中仍可能影响答案的部分。两者都把堆作为紧凑的前沿（frontier），但维持不同不变量。

对于 Top-K，容量不超过 k 的最小堆保存目前见过的最大 k 个值。根是保留候选中最弱的一个。新值若不大于根，就不可能进入最终 Top-K，可以直接丢弃；更大的新值则替换根。

TOP-K-LARGEST(stream, k)
    candidates <- empty min-heap
    for value in stream
        if size(candidates) < k
            push(candidates, value)
        else if value > peek_min(candidates)
            replace_min(candidates, value)
    return candidates

对于 Merge-K，每个输入序列已经有序。只有各序列第一个尚未消费的值可能成为下一全局最小值，因此堆为每个非空序列保存一个前沿项。提取某项后，只有同一序列中的后继会新获得资格。

MERGE-K-SORTED(sequences)
    frontier <- empty min-heap
    push the first item of every non-empty sequence into frontier

    while frontier is not empty
        value, source, position <- extract_min(frontier)
        output value
        if source has an item at position + 1
            push that successor into frontier

对包含 n 个值的流，有界 Top-K 需要 \(O(n\log k)\) 时间和 \(O(k)\) 空间；最后排序保留候选另需 \(O(k\log k)\)。当 k 远小于 n 时，它优于对全部输入进行 \(O(n\log n)\) 排序，而且可以在线处理，无需保存完整数据流。

对于 k 个有序序列、总共 N 个值，Merge-K 需要 \(O(N\log k)\) 时间和 \(O(k)\) 堆空间。若每次输出都朴素扫描全部 k 个当前头部，则需要 \(O(Nk)\)。堆在不破坏有序前沿不变量的前提下加速了下一头部的选择。

Python 实现：有界 Top-K 与基于前沿的 Merge-K 
import heapq
from collections.abc import Iterable, Sequence


def top_k_largest(values: Iterable[int], k: int) -> list[int]:
    """按降序返回最大的 k 个值。"""
    if k < 0:
        raise ValueError("k must be non-negative")
    if k == 0:
        return []

    candidates: list[int] = []
    for value in values:
        if len(candidates) < k:
            heapq.heappush(candidates, value)
        elif value > candidates[0]:
            # 删除最弱的保留候选，并加入更好的候选。
            heapq.heapreplace(candidates, value)

    return sorted(candidates, reverse=True)


def merge_k_sorted(sequences: Sequence[Sequence[int]]) -> list[int]:
    """合并有序序列，同时只为每个来源保存一个前沿项。"""
    frontier: list[tuple[int, int, int]] = []

    for source, sequence in enumerate(sequences):
        if sequence:
            # 元组顺序用来源和位置打破相同值的平局。
            heapq.heappush(frontier, (sequence[0], source, 0))

    merged: list[int] = []
    while frontier:
        value, source, position = heapq.heappop(frontier)
        merged.append(value)

        next_position = position + 1
        if next_position < len(sequences[source]):
            next_value = sequences[source][next_position]
            heapq.heappush(frontier, (next_value, source, next_position))

    return merged


assert top_k_largest([5, 1, 9, 3, 14, 8], 3) == [14, 9, 8]
assert merge_k_sorted([[1, 4, 9], [2, 6], [3, 5, 7]]) == [1, 2, 3, 4, 5, 6, 7, 9]

对比与选择

本章结构不能互换。它们因为具有层级而图形相似，但每种不变量加速的是不同操作族。

需求 推荐起点 主要原因 重要限制
表示任意层级 子节点列表形式的一般树 直接表达可变分支结构 不自动提供搜索顺序
处理完整子树 DFS / 后序 子结果可自然合并 递归栈可能达到 \(O(n)\)
按深度处理或找最近无权结果 BFS / 层序 队列保持发现深度 前沿可能需要 \(O(n)\) 空间
有序搜索、范围查询、前驱/后继 平衡 BST 所有有序映射操作为 \(O(\log n)\) 更多链接和再平衡逻辑
反复只访问最小值或最大值 二叉堆 \(O(1)\) 查看，\(O(\log n)\) 更新 任意搜索与完整有序迭代较弱
暴露基于优先级的行为 Priority Queue ADT 将调度契约与表示分离 复杂度取决于实现
具有最坏保证的原地排序 堆排序 最坏 \(O(n\log n)\)，辅助空间 \(O(1)\) 不稳定，缓存友好性通常较差
从数据流保留少量最佳项 有界堆 \(O(n\log k)\) 时间与 \(O(k)\) 内存 最终排序前输出并非完全有序

实际选择时可以按以下顺序思考：

  1. 找出主导操作：层级遍历、有序查找，还是反复提取极值；
  2. 明确是什么不变量让该操作变得高效；
  3. 检查最坏形状。普通 BST 不能防止退化成链，而完全堆和 AVL 树可以；
  4. 计入表示成本。父引用、缓存高度、下标映射和稳定平局计数器能改善操作，但更新时必须维护；
  5. 选择正确分析参数：总节点数 n、根到叶路径 h、BFS 前沿宽度 w，以及有界候选/前沿堆大小 k。

核心结论是：树的形状本身不会自动带来效率。只有表示方式和不变量与应用必须回答的查询相匹配时，树才真正有用。
