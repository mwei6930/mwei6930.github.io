链表、栈、队列与双端队列

数组通过连续存储让按位置访问变得高效；链式结构则通过节点之间的引用保存顺序，让局部修改变得高效。栈、队列与双端队列进一步规定了元素可以从集合的哪些位置进入或离开。

这些概念彼此相关，但回答的是不同的设计问题：

  • 链表（linked list）决定一个序列在内存中如何表示；
  • 栈（stack）、队列（queue）与双端队列（deque）规定抽象数据类型（ADT）的访问策略；
  • 哑节点、快慢指针、反转、合并与环检测，是安全检查或修改链接关系的算法技巧；
  • 单调栈（monotonic stack）在普通栈上增加单调性不变量，使已经失去竞争力的候选项可以被永久丢弃。

处理链式结构时，最重要的习惯是先推理引用，再考虑节点值。修改 current.next 之前，必须判断结构的哪一部分可能因此不可达，并提前保存所需引用。声称插入或删除是 \(O(1)\) 之前，也要明确目标节点或它的前驱是否已经找到；寻找该位置本身仍可能需要 \(O(n)\) 时间。

链表基础

链表将有序序列表示为一组独立分配的节点，每个节点保存一个值以及一个或多个相邻节点的引用。可以把它类比为寻宝游戏：每条线索同时给出信息和下一条线索的位置。它不同于一排带编号的储物柜，仅仅知道第一个位置并不能直接得到第五个节点的地址，必须逐个沿链接向前寻找。

链表解决的问题与数组不同。当序列长度难以预知、节点需要保持稳定的内存位置，或者程序经常在已经找到的节点之后插入和删除时，链表很有价值。但链表并不会自动更快：它的下标访问和缓存局部性都较差，因为节点可能散布在内存的不同位置。

打开原始图片：Wikimedia Commons - Singly linked list。

常见表示方式有三种：

  • 单链表（singly linked list）只保存 next，遍历只能向前进行；
  • 双向链表（doubly linked list）同时保存 next 与 prev。已知某个节点时，删除和向后移动更容易，但每个节点需要多保存一个引用；
  • 循环链表（circular list）让最后一个节点指回第一个节点或哨兵节点。因为不存在表示末尾的空引用，遍历时必须定义明确的停止条件。

若单链表形式的 Sequence ADT 保存 head、tail 和 size，它的操作契约如下：

ADT 操作 前置条件 必须产生的效果或结果
length() 无 返回数据节点数量。
first() 链表非空 返回头节点的值，不修改链表。
prepend(x) 无 在原头节点之前加入 x。
append(x) 无 在原尾节点之后加入 x。
insert_after(node, x) node 属于该链表 在 node 之后立即链接一个新节点。
pop_front() 链表非空 删除并返回原头节点的值。
find(x) 无 返回匹配节点，或返回约定的未找到结果。

对于包含 n 个节点的链表，这种表示产生以下复杂度：

操作 单链表复杂度 原因
length、first \(O(1)\) 元数据与头引用被直接保存。
prepend \(O(1)\) 只需修改新节点与头引用。
append 保存尾引用时 \(O(1)\)；否则 \(O(n)\) 尾引用避免从头遍历。
insert_after 已知节点后为 \(O(1)\) 只需设置两个 next 引用。
pop_front \(O(1)\) 头引用只向前移动一次。
get(i)、find(x) 最坏 \(O(n)\) 必须按顺序沿链接前进。
pop_back \(O(n)\) 单链表必须找到尾节点的前驱。
遍历全部节点 \(\Theta(n)\) 每个节点恰好访问一次。

链表总空间为 \(\Theta(n)\)：每个值占一个节点，每个节点还保存一个 next 引用。双向链表仍为 \(\Theta(n)\)，但由于每个节点保存两个链接，其常数开销更大。

Python 实现：单链 Sequence ADT 
from dataclasses import dataclass
from typing import Generic, Iterator, TypeVar

T = TypeVar("T")


@dataclass
class Node(Generic[T]):
    value: T
    next: "Node[T] | None" = None


class SinglyLinkedList(Generic[T]):
    """保存头、尾和长度的单链表。"""

    def __init__(self) -> None:
        self._head: Node[T] | None = None
        self._tail: Node[T] | None = None
        self._size = 0

    def prepend(self, value: T) -> None:
        new_node = Node(value, self._head)
        self._head = new_node

        # 第一个插入的节点同时是头节点和尾节点。
        if self._tail is None:
            self._tail = new_node
        self._size += 1

    def append(self, value: T) -> None:
        new_node = Node(value)

        if self._tail is None:
            self._head = self._tail = new_node
        else:
            self._tail.next = new_node
            self._tail = new_node
        self._size += 1

    def pop_front(self) -> T:
        if self._head is None:
            raise IndexError("pop from an empty linked list")

        removed = self._head
        self._head = removed.next
        self._size -= 1

        # 删除唯一节点时还必须清空尾引用。
        if self._head is None:
            self._tail = None
        return removed.value

    def find(self, target: T) -> Node[T] | None:
        current = self._head
        while current is not None:
            if current.value == target:
                return current
            current = current.next
        return None

    def __len__(self) -> int:
        return self._size

    def __iter__(self) -> Iterator[T]:
        current = self._head
        while current is not None:
            yield current.value
            current = current.next


values = SinglyLinkedList[int]()
values.append(2)
values.append(3)
values.prepend(1)
assert list(values) == [1, 2, 3]
assert values.find(2) is not None
assert values.pop_front() == 1
assert list(values) == [2, 3]
assert len(values) == 2

当程序已经持有相关节点，并且经常进行局部链接修改时，链表比数组更合适。如果主要操作是 get(i)，数组通常是更好的表示方式。

练习。 LeetCode 2 - 两数相加训练逐节点遍历与构造，不依赖随机访问。

哑节点与指针操作

哑节点（dummy node）也称为哨兵节点（sentinel），是一种不代表普通数据项的结构节点。它可以放在第一个数据节点之前、最后一个数据节点之后，或同时放在两端。它的作用是消除指针算法中针对边界情况的特殊分支。

没有哑节点时，删除第一个数据节点需要修改 head，而删除之后的节点则修改 previous.next。在开头加入哑节点后，两种情况都可以统一为“删除 previous 之后的节点”。哑节点不会改善渐近复杂度，它的价值在于使不变量和实现更加统一。

若要删除所有值等于目标值的节点，让 previous 始终指向已经处理完的结果部分的最后一个节点。每轮检查 previous.next，而不能无条件地同时移动两个指针。

伪代码。

REMOVE-ALL(head, target)
    dummy.next <- head
    previous <- dummy

    while previous.next is not null
        if previous.next.value equals target
            previous.next <- previous.next.next
        else
            previous <- previous.next

    return dummy.next

删除节点时，previous 保持不动，因为它的新后继还没有被检查；保留节点时，previous 才向前移动。不变量是：previous.next 之前的所有节点都已经处理完毕，不含目标值，并保持原有相对顺序。

Python 实现：通过哑前驱删除指定值 
from dataclasses import dataclass


@dataclass
class ListNode:
    value: int
    next: "ListNode | None" = None


def remove_all(head: ListNode | None, target: int) -> ListNode | None:
    """删除所有值等于 target 的节点，并保持其余节点的顺序。"""
    dummy = ListNode(0, head)
    previous = dummy

    while previous.next is not None:
        if previous.next.value == target:
            # 绕过目标节点。此时不要移动 previous，
            # 因为新的后继仍可能等于 target。
            previous.next = previous.next.next
        else:
            previous = previous.next

    return dummy.next


def to_values(head: ListNode | None) -> list[int]:
    values: list[int] = []
    while head is not None:
        values.append(head.value)
        head = head.next
    return values


head = ListNode(2, ListNode(2, ListNode(5, ListNode(2))))
assert to_values(remove_all(head, 2)) == [5]
assert remove_all(None, 2) is None

每个节点只检查一次，因此时间为 \(O(n)\)，辅助空间为 \(O(1)\)。哑节点本身只增加一个常数大小的节点。删除、分区、链表合并以及构造头节点尚不确定的结果链表时，哑节点尤其有用。

练习。 LeetCode 19 - 删除链表的倒数第 N 个结点结合了哑前驱与保持固定间距的双指针。

快慢指针

快慢指针（fast and slow pointers）让两个指针以不同速度遍历同一个链式结构。慢指针通常每轮移动一条边，快指针每轮移动两条边。它利用指针位置之间的关系，替代原本可能需要长度计数器或已访问节点集合才能获得的信息。

寻找无环链表的中点时，慢指针每走一步，快指针就走两步。快指针走完整条链表时，慢指针大约走了一半。

伪代码。

MIDDLE(head)
    slow <- head
    fast <- head

    while fast is not null and fast.next is not null
        slow <- slow.next
        fast <- fast.next.next

    return slow

长度为 n 的链表会执行 \(\lfloor n/2 \rfloor\) 轮循环。对于偶数长度链表，这种初始化会返回两个中间节点中的第二个。让快指针预先领先一个节点，或改变循环条件，会得到不同的中点约定，因此指针初始化本身也是算法规格的一部分。

当算法要求单次遍历时，该技巧优于“先计数，再走到一半”的两遍方法，两者的辅助空间都是 \(O(1)\)。快慢指针还可以用于回文检查、为归并排序拆分链表、寻找距末尾固定距离的节点以及检测环。

Python 实现：定位第二个中间节点 
from dataclasses import dataclass


@dataclass
class ListNode:
    value: int
    next: "ListNode | None" = None


def middle_node(head: ListNode | None) -> ListNode | None:
    """返回中间节点；偶数长度时选择第二个中间节点。"""
    slow = head
    fast = head

    while fast is not None and fast.next is not None:
        slow = slow.next if slow is not None else None
        fast = fast.next.next

    return slow


odd = ListNode(1, ListNode(2, ListNode(3, ListNode(4, ListNode(5)))))
even = ListNode(1, ListNode(2, ListNode(3, ListNode(4))))
assert middle_node(odd).value == 3
assert middle_node(even).value == 3
assert middle_node(None) is None

时间为 \(O(n)\)，因为快指针最多经过 n 条边，慢指针最多经过约一半；只保存两个引用，因此辅助空间为 \(O(1)\)。

练习。 LeetCode 234 - 回文链表结合快慢指针寻找中点、反转后半部分与逐节点比较。

反转、合并与环检测

这三类算法是单链表最核心的指针变换：反转改变链接方向，合并从两个有序前端不断取出节点，而环检测则研究在可能永远遇不到空引用时，重复移动会产生什么关系。

反转链表

反转操作改变每个 next 引用，使原尾节点成为新头节点。最大的风险是丢失尚未处理的后缀。因此，在重定向 current.next 之前，必须先把原后继保存到 next_node。

伪代码。

REVERSE(head)
    previous <- null
    current <- head

    while current is not null
        next_node <- current.next
        current.next <- previous
        previous <- current
        current <- next_node

    return previous

循环不变量是：previous 指向已经正确反转的前缀，current 指向尚未修改的后缀。由于先保存了 next_node，每次重定向一条链接都能让反转前缀增长一个节点，同时不会失去剩余后缀。

Python 实现：原地迭代反转 
from dataclasses import dataclass


@dataclass
class ListNode:
    value: int
    next: "ListNode | None" = None


def reverse_list(head: ListNode | None) -> ListNode | None:
    previous: ListNode | None = None
    current = head

    while current is not None:
        # 重定向 current.next 前先保存未处理后缀。
        next_node = current.next
        current.next = previous

        # 向前移动已反转部分与未处理部分之间的边界。
        previous = current
        current = next_node

    return previous


head = ListNode(1, ListNode(2, ListNode(3)))
reversed_head = reverse_list(head)
assert reversed_head.value == 3
assert reversed_head.next.value == 2
assert reversed_head.next.next.value == 1
assert reversed_head.next.next.next is None

每个节点只处理一次，因此时间为 \(O(n)\)，辅助空间为 \(O(1)\)。递归反转同样需要 \(O(n)\) 时间，但会使用 \(O(n)\) 调用栈空间。

练习。 LeetCode 206 - 反转链表直接检验这组三引用不变量。

合并有序链表

合并算法利用输入的有序性。下一项只可能是两个当前头节点之一，因为每条链表后面的节点都不会小于自己的头节点。哑结果节点可以避免对第一个选中节点单独分支，tail 则始终标记已经合并好的前缀末端。

伪代码。

MERGE-SORTED(left, right)
    dummy <- new node
    tail <- dummy

    while left is not null and right is not null
        if left.value <= right.value
            tail.next <- left
            left <- left.next
        else
            tail.next <- right
            right <- right.next
        tail <- tail.next

    tail.next <- whichever list remains
    return dummy.next
Python 实现：复用原节点完成合并 
from dataclasses import dataclass


@dataclass
class ListNode:
    value: int
    next: "ListNode | None" = None


def merge_sorted(
    left: ListNode | None,
    right: ListNode | None,
) -> ListNode | None:
    """通过重新链接现有节点，合并两条升序链表。"""
    dummy = ListNode(0)
    tail = dummy

    while left is not None and right is not None:
        if left.value <= right.value:
            tail.next = left
            left = left.next
        else:
            tail.next = right
            right = right.next
        tail = tail.next

    # 剩余后缀本身已有序，可以一次性接到结果末尾。
    tail.next = left if left is not None else right
    return dummy.next


def values(head: ListNode | None) -> list[int]:
    result: list[int] = []
    while head is not None:
        result.append(head.value)
        head = head.next
    return result


left = ListNode(1, ListNode(4, ListNode(7)))
right = ListNode(2, ListNode(3, ListNode(8)))
assert values(merge_sorted(left, right)) == [1, 2, 3, 4, 7, 8]

若两条输入链表的长度分别为 n 和 m，每个节点只会被链接一次，因此时间为 \(O(n+m)\)。复用输入节点时辅助空间为 \(O(1)\)；若创建节点副本，则需要额外 \(O(n+m)\) 空间。

练习。 LeetCode 21 - 合并两个有序链表应用有序前缀不变量。

环检测

如果沿 next 前进最终返回先前节点，而不是到达空引用，链表中就存在环。用集合记录已访问节点的身份可以检测重复，但需要 \(O(n)\) 空间。Floyd 双指针算法能用 \(O(1)\) 空间得到相同结论。

伪代码。

HAS-CYCLE(head)
    slow <- head
    fast <- head

    while fast is not null and fast.next is not null
        slow <- slow.next
        fast <- fast.next.next
        if slow equals fast by node identity
            return true

    return false

令 \(\mu\) 表示头节点到环入口的边数，\(\lambda\) 表示环长。两个指针都进入环后，快指针每轮相对慢指针多前进一个节点。二者间距按 \(\lambda\) 取模；重复加一最终必然得到零，因此最多再经过 \(\lambda\) 轮就会相遇。

若要在相遇后定位环入口，将一个指针重置到 head，再让两个指针每轮各走一条边。相遇时的距离关系保证它们下一次重合的位置正是环入口。

Python 实现：检测环并返回入口 
from dataclasses import dataclass


@dataclass
class ListNode:
    value: int
    next: "ListNode | None" = None


def cycle_entry(head: ListNode | None) -> ListNode | None:
    """返回环入口节点；无环时返回 None。"""
    slow = head
    fast = head

    # 阶段 1：在环内寻找相遇点。
    while fast is not None and fast.next is not None:
        slow = slow.next if slow is not None else None
        fast = fast.next.next
        if slow is fast:
            break
    else:
        return None

    # 阶段 2：两个等速指针将在环入口相遇。
    seeker = head
    while seeker is not slow:
        seeker = seeker.next if seeker is not None else None
        slow = slow.next if slow is not None else None

    return seeker


first = ListNode(1)
entry = ListNode(2)
third = ListNode(3)
fourth = ListNode(4)
first.next = entry
entry.next = third
third.next = fourth
fourth.next = entry

assert cycle_entry(first) is entry
assert cycle_entry(ListNode(1, ListNode(2))) is None

时间为 \(O(n)\)，辅助空间为 \(O(1)\)。这里必须比较节点身份：两个不同节点即使保存相同的值，也不代表形成了环。

练习。 LeetCode 142 - 环形链表 II要求返回入口节点，而不仅是布尔结果。

栈与队列

栈与队列都是线性 ADT，它们由“允许从哪里删除元素”来定义，而不要求唯一的底层存储方式。两者都可以用数组或链式节点实现；ADT 契约不变，但操作成本取决于具体表示。

栈 ADT

栈遵循后进先出（last in, first out，LIFO），类似托盘只能从一摞的顶部放入和取出。当最近暂停的任务必须最先恢复时，就需要栈：函数调用、撤销历史、括号匹配、深度优先搜索和表达式求值都具有这一结构。

打开原始图片：Wikimedia Commons - Data stack。

ADT 操作 前置条件 必须产生的效果或结果
push(x) 无 让 x 成为新栈顶。
pop() 栈非空 删除并返回栈顶。
peek() 栈非空 返回栈顶但不删除。
is_empty() 无 判断栈中是否没有元素。
size() 无 返回元素数量。
操作 动态数组实现 链式实现
push 摊还 \(O(1)\)；扩容时最坏 \(O(n)\) 在头部最坏 \(O(1)\)
pop、peek 数组末端 \(O(1)\) 头部 \(O(1)\)
is_empty、size \(O(1)\) 保存长度时 \(O(1)\)
总空间 \(\Theta(n)\)，另有备用容量 \(\Theta(n)\)，另有节点链接

数组栈将最后一个已占用下标作为栈顶，这样压栈和出栈都不需要移动元素。若把 Python 列表的下标 0 当作栈顶，每次操作都会移动其余元素，成本变成 \(O(n)\)。

Python 实现：数组支持的栈 
from typing import Generic, TypeVar

T = TypeVar("T")


class ArrayStack(Generic[T]):
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        if self.is_empty():
            raise IndexError("pop from an empty stack")
        return self._items.pop()

    def peek(self) -> T:
        if self.is_empty():
            raise IndexError("peek at an empty stack")
        return self._items[-1]

    def is_empty(self) -> bool:
        return len(self._items) == 0

    def __len__(self) -> int:
        return len(self._items)


stack = ArrayStack[str]()
stack.push("parse (")
stack.push("parse [")
assert stack.peek() == "parse ["
assert stack.pop() == "parse ["
assert stack.pop() == "parse ("
assert stack.is_empty()

队列 ADT

队列遵循先进先出（first in, first out，FIFO），类似顾客按照到达顺序接受服务。调度、缓冲、广度优先搜索、事件处理，以及任何不允许较新的待办任务越过较早任务的工作流，都需要队列。

ADT 操作 前置条件 必须产生的效果或结果
enqueue(x) 无 在队尾加入 x。
dequeue() 队列非空 删除并返回队首。
front() 队列非空 返回队首但不删除。
is_empty() 无 判断队列是否为空。
size() 无 返回元素数量。
操作 保存 front/rear 的链式队列 循环数组队列
enqueue 通过 rear 实现 \(O(1)\) 可扩容时摊还 \(O(1)\)
dequeue 通过 front 实现 \(O(1)\) 移动 front，\(O(1)\)
front、size \(O(1)\) \(O(1)\)
总空间 \(\Theta(n)\)，另有链接 \(\Theta(n)\)，另有备用容量

从 Python 列表下标 0 删除元素不适合作为队列实现，因为它会移动所有剩余元素，成本为 \(O(n)\)。链式队列保存两端引用；循环数组通过移动下标而不是移动值完成操作。

Python 实现：链式 FIFO 队列 
from dataclasses import dataclass
from typing import Generic, TypeVar

T = TypeVar("T")


@dataclass
class QueueNode(Generic[T]):
    value: T
    next: "QueueNode[T] | None" = None


class LinkedQueue(Generic[T]):
    def __init__(self) -> None:
        self._front: QueueNode[T] | None = None
        self._rear: QueueNode[T] | None = None
        self._size = 0

    def enqueue(self, value: T) -> None:
        new_node = QueueNode(value)

        if self._rear is None:
            self._front = self._rear = new_node
        else:
            self._rear.next = new_node
            self._rear = new_node
        self._size += 1

    def dequeue(self) -> T:
        if self._front is None:
            raise IndexError("dequeue from an empty queue")

        removed = self._front
        self._front = removed.next
        self._size -= 1

        # 队列变空时不能保留已经失效的 rear 引用。
        if self._front is None:
            self._rear = None
        return removed.value

    def front(self) -> T:
        if self._front is None:
            raise IndexError("front of an empty queue")
        return self._front.value

    def is_empty(self) -> bool:
        return self._size == 0

    def __len__(self) -> int:
        return self._size


queue = LinkedQueue[str]()
queue.enqueue("first")
queue.enqueue("second")
assert queue.front() == "first"
assert queue.dequeue() == "first"
assert queue.dequeue() == "second"
assert queue.is_empty()

双端队列

双端队列（deque，double-ended queue）允许在两端插入和删除。它结合了栈与队列的访问策略：一端可以作为栈顶，而在相反两端操作则提供 FIFO 行为。双端队列适用于工作窃取调度器、撤销/重做缓冲区、广度优先搜索变体，以及维护移动窗口内的候选元素。

ADT 操作 前置条件 必须产生的效果或结果
append_left(x) 无 将 x 插入为新的最左元素。
append_right(x) 无 将 x 插入为新的最右元素。
pop_left() 双端队列非空 删除并返回最左元素。
pop_right() 双端队列非空 删除并返回最右元素。
peek_left() / peek_right() 双端队列非空 查看一端元素但不删除。
size() 无 返回元素数量。

双端队列可以用带哨兵的双向链表或循环数组实现。双向链表直接保存两端引用，可以在常数时间内断开端点节点。循环数组保存 front、size 和 capacity，物理下标通过取模运算环绕：

\[ \operatorname{physical}(i) = (\operatorname{front}+i) \bmod \operatorname{capacity}. \]

其中 i 是从左端开始计算的逻辑位置。取模会把越过最后一个数组槽位的位置映射回下标 0，因此移动任一端时都不需要平移元素。

操作 循环数组 双向链表
任一端追加 摊还 \(O(1)\)；扩容时最坏 \(O(n)\) 最坏 \(O(1)\)
任一端弹出或查看 \(O(1)\) \(O(1)\)
下标访问 若接口提供则为 \(O(1)\) \(O(n)\)
总空间 \(\Theta(n)\)，另有备用容量 \(\Theta(n)\)，每个节点另有两个链接

双端队列 ADT 通常不保证在中间高效插入。选择 deque 而不是普通列表，表达的是程序的重要修改集中在两端。

Python 实现：可扩容循环数组双端队列 
from typing import Generic, TypeVar, cast

T = TypeVar("T")


class CircularDeque(Generic[T]):
    """由循环数组支持的可扩容双端队列。"""

    def __init__(self) -> None:
        self._data: list[T | None] = [None] * 4
        self._front = 0
        self._size = 0

    def _index(self, logical_index: int) -> int:
        return (self._front + logical_index) % len(self._data)

    def _grow(self) -> None:
        new_data: list[T | None] = [None] * (2 * len(self._data))

        # 按逻辑上的从左到右顺序复制，再把 front 重置为 0。
        for logical_index in range(self._size):
            new_data[logical_index] = self._data[self._index(logical_index)]

        self._data = new_data
        self._front = 0

    def append_left(self, value: T) -> None:
        if self._size == len(self._data):
            self._grow()

        self._front = (self._front - 1) % len(self._data)
        self._data[self._front] = value
        self._size += 1

    def append_right(self, value: T) -> None:
        if self._size == len(self._data):
            self._grow()

        self._data[self._index(self._size)] = value
        self._size += 1

    def pop_left(self) -> T:
        if self._size == 0:
            raise IndexError("pop from an empty deque")

        value = cast(T, self._data[self._front])
        self._data[self._front] = None
        self._front = (self._front + 1) % len(self._data)
        self._size -= 1
        return value

    def pop_right(self) -> T:
        if self._size == 0:
            raise IndexError("pop from an empty deque")

        right_index = self._index(self._size - 1)
        value = cast(T, self._data[right_index])
        self._data[right_index] = None
        self._size -= 1
        return value

    def peek_left(self) -> T:
        if self._size == 0:
            raise IndexError("peek at an empty deque")
        return cast(T, self._data[self._front])

    def peek_right(self) -> T:
        if self._size == 0:
            raise IndexError("peek at an empty deque")
        return cast(T, self._data[self._index(self._size - 1)])

    def __len__(self) -> int:
        return self._size


deque = CircularDeque[int]()
deque.append_right(2)
deque.append_right(3)
deque.append_left(1)
deque.append_right(4)
deque.append_right(5)  # 触发扩容
assert deque.peek_left() == 1
assert deque.peek_right() == 5
assert deque.pop_left() == 1
assert deque.pop_right() == 5
assert len(deque) == 3

在生产环境的 Python 代码中，collections.deque 通常是实现快速端点操作的首选。普通 list 适合在右端实现栈，但不适合反复从左端删除。

单调栈

单调栈是始终按值递增或递减排列的普通栈。维持顺序本身并不是目的；栈中保存的是尚未遇到能够回答其查询的值的“未解决候选项”。

以寻找下一个更大元素为例，从左向右扫描，栈中保存尚未找到下一个更大值的下标。栈内对应值保持单调递减。当一个更大的当前值出现时，它会依次解决栈顶暴露出的所有更小下标。

伪代码。

NEXT-GREATER(values)
    answer <- array of -1 values
    stack <- empty stack of indices

    for i from 0 to length(values) - 1
        while stack is not empty and values[i] > values[stack.top]
            unresolved <- stack.pop()
            answer[unresolved] <- values[i]
        stack.push(i)

    return answer

两个不变量解释了该方法：

  1. 栈中下标按到达顺序排列，其对应值从栈底到栈顶递减；
  2. 栈中每个下标，从它自身位置到当前扫描位置之间都不存在更大值。

当前值大于栈顶时，它就是该栈顶下标遇到的第一个更大值。弹出是永久的：一个已经解决的下标再也不会被需要。保存下标而不只是值，还能保留距离和位置信息。

Python 实现：用递减栈寻找下一个更大值 
def next_greater_values(values: list[int]) -> list[int]:
    """返回右侧第一个严格更大的值；不存在时返回 -1。"""
    answer = [-1] * len(values)
    unresolved: list[int] = []

    for index, value in enumerate(values):
        # 当前值解决所有在栈顶暴露出来且更小的候选项。
        while unresolved and value > values[unresolved[-1]]:
            earlier_index = unresolved.pop()
            answer[earlier_index] = value

        # 当前下标开始等待属于自己的下一个更大值。
        unresolved.append(index)

    return answer


assert next_greater_values([2, 1, 5, 3]) == [5, 5, -1, -1]
assert next_greater_values([4, 3, 2, 1]) == [-1, -1, -1, -1]

虽然代码包含嵌套 while，它并不是平方时间。每个下标只压栈一次、最多弹出一次，因此栈操作总数不超过 2n。总时间为 \(O(n)\)，辅助空间为 \(O(n)\)；某一次外层迭代仍可能执行多次弹出。这是针对完整扫描过程的摊还分析。

递增或递减栈可以解决下一个/上一个更大或更小元素、股票跨度、柱状图最大矩形、接雨水边界，以及子数组最小值/最大值贡献等问题。所需的比较方向决定应维护哪一种单调不变量。

对比与选择

应根据程序反复执行的操作选择表示，而不是只看某一个示例的外观。

结构或模式 核心规则 擅长的操作 不擅长的操作 典型用途
单链表 每个节点向前指向下一个节点 已知节点后的插入、头部插入、顺序遍历 随机访问、寻找前驱 动态序列与指针算法
双向链表 节点同时指向前后 已知节点删除、两端修改 下标访问、节点内存开销 LRU 顺序与 deque 实现
栈 LIFO 在一端 push/pop/peek 访问最旧元素 撤销、解析、DFS
队列 FIFO 队尾入队、队首出队 删除最新元素 调度、缓冲、BFS
双端队列 两端都可修改 四种端点操作 任意中间修改 滑动窗口与工作队列
快慢指针 不同遍历速度 中点与环关系推理 随机访问 检查链表结构
单调栈 有序的未解决候选项 最近边界查询 任意搜索 最近更大/更小元素问题

实际选择时可以按以下顺序思考：

  1. 先判断需求是在选择表示、规定访问策略，还是在已有结构上运行算法；
  2. 选择存储方式之前，先写明 ADT 操作及其前置条件；
  3. 复杂度中要包含定位节点的成本，而不只是找到后修改链接的成本；
  4. 当头节点或结果的第一个节点需要特殊分支时，考虑使用哑节点；
  5. 修改前写清每个指针的含义，并先保存维持可达性所必需的引用；
  6. 当每个元素进入和离开栈或双端队列的次数有常数上界时，使用摊还分析。

需要频繁下标访问和紧凑遍历时，数组仍然更合适；稳定节点身份和局部重链接占主导时，链式节点更合适。在 Python 应用中，栈通常直接使用内置 list，队列和双端队列通常使用 collections.deque。自定义实现主要用于学习、特殊不变量或系统级控制。
