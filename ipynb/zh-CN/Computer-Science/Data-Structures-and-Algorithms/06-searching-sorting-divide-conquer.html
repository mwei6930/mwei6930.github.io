搜索、排序与分治

搜索和排序不只是库函数。它们集中体现了算法设计中的多种通用思想：维护不断缩小的候选集合、保持循环不变量、按照明确契约重排数据、把问题分解为更小实例，以及求解由此产生的递推式。

本章按以下逻辑连接这些思想：

  • 二分搜索利用有序性或单调谓词，以对数速度排除候选；
  • 排序算法揭示比较次数、写入次数、稳定性、辅助内存与最坏保证之间的取舍；
  • 归并排序、快速排序与堆排序通过不同结构不变量获得 \(O(n\log n)\) 行为；
  • 分治把递归子问题工作与划分、合并工作分开；
  • 递推展开与主定理解释递归何时高效；
  • Quickselect 说明寻找一个秩并不需要把两侧全部排序。

普通 Python 应用仍应优先使用内置 sorted 与 list.sort。这里的实现用于暴露库内部隐藏的不变量与成本，让相同推理可以迁移到不熟悉的问题。

二分搜索

二分搜索（binary search）在有序序列中定位目标：把目标与中间值比较，并丢弃不可能包含目标的那一半。它类似查字典：当前页能告诉你之前或之后的全部页面都可以忽略。

有序前置条件让这种排除变得安全。在无序数组中，观察到中间值小于目标，并不能说明左侧的值。只有当顺序已经存在、可以一次建立后重复使用，或问题天然提供顺序时，二分搜索才优于线性搜索。

使用闭区间候选范围 [low, high] 时，循环不变量是：

如果目标存在于序列中，那么至少一个目标仍位于包含端点的 low 与 high 之间。

BINARY-SEARCH(values, target)
    low <- 0
    high <- length(values) - 1

    while low <= high
        mid <- low + floor((high - low) / 2)
        if values[mid] equals target
            return mid
        if values[mid] < target
            low <- mid + 1
        else
            high <- mid - 1
    return not-found

中点表达式

\[ \operatorname{mid}=\operatorname{low}+\left\lfloor\frac{\operatorname{high}-\operatorname{low}}{2}\right\rfloor \]

选择较低的中间下标，并避免固定宽度语言中 (low + high) // 2 可能产生的整数溢出。Python 整数不会溢出，但这种写法能在不同语言中清楚表达不变量。

经过 k 次未成功比较后，最多还剩 \(n/2^k\) 个候选。该数量小于 1 时循环结束，因此 \(k=O(\log_2 n)\)。时间为 \(O(\log n)\)，迭代辅助空间为 \(O(1)\)；递归版本比较次数相同，但使用 \(O(\log n)\) 调用栈。

二分搜索适用于精确查找、字典索引、版本边界、阈值决策与答案空间优化。随机访问非常重要：在链表上使用按下标二分，会失去数组中 \(O(1)\) 获取中点的优势。

Python 实现：带不变量说明的精确二分搜索 
from collections.abc import Sequence


def binary_search(values: Sequence[int], target: int) -> int | None:
    """返回包含 target 的下标；不存在时返回 None。"""
    low = 0
    high = len(values) - 1

    while low <= high:
        mid = low + (high - low) // 2

        if values[mid] == target:
            return mid
        if values[mid] < target:
            # 有序性证明从开头到 mid 的所有值都太小。
            low = mid + 1
        else:
            # 有序性证明从 mid 到末尾的所有值都太大。
            high = mid - 1

    return None


numbers = [2, 5, 8, 12, 16, 23, 38]
assert binary_search(numbers, 23) == 5
assert binary_search(numbers, 2) == 0
assert binary_search(numbers, 40) is None
assert binary_search([], 7) is None

边界搜索模板

许多问题并不是询问某个精确值是否存在，而是寻找第一个满足条件的位置、重复值第一次出现的位置、插入点，或最小可行答案。这些都是在单调谓词上的边界搜索（boundary search）。

假设 predicate(i) 在前一段为假，从某个边界开始恒为真：

\[ F,F,\ldots,F,T,T,\ldots,T. \]

目标是找到第一个真下标。半开区间 [low, high) 很方便，因为长度恰为 high - low，空区间满足 low == high。其不变量是：

  • low 以下的下标都已知为假；
  • high 及以上的下标都已知为真；
  • 第一个真位置始终保留在 [low, high] 中。
FIRST-TRUE(low, high, predicate)       // 搜索 [low, high)
    while low < high
        mid <- low + floor((high - low) / 2)
        if predicate(mid) is true
            high <- mid                // mid 可能是第一个真位置
        else
            low <- mid + 1             // mid 确定太早
    return low

两种更新的不对称性至关重要。谓词为真时，mid 仍可能是答案，因此设 high = mid；为假时，mid 不可能是答案，因此设 low = mid + 1。两种更新都严格减小 high - low，从而证明算法终止。

在有序数组中，lower_bound(target) 是第一个值不小于目标的下标，upper_bound(target) 是第一个值大于目标的下标，二者之差就是重复次数。同一模板还能搜索答案域，例如使可行性测试首次为真的最小速度、容量或截止时间。

若候选域包含 R 个位置，搜索调用谓词 \(O(\log R)\) 次。一次谓词求值若需 \(P\) 时间，总时间是 \(O(P\log R)\)，而不只是 \(O(\log R)\)；迭代辅助空间仍为 \(O(1)\)。

Python 实现：first true、lower bound 与 upper bound 
from collections.abc import Callable, Sequence


def first_true(low: int, high: int, predicate: Callable[[int], bool]) -> int:
    """返回半开域 [low, high) 中第一个为真的下标。"""
    while low < high:
        mid = low + (high - low) // 2
        if predicate(mid):
            high = mid                 # 保留 mid 作为可能边界。
        else:
            low = mid + 1
    return low


def lower_bound(values: Sequence[int], target: int) -> int:
    return first_true(0, len(values), lambda i: values[i] >= target)


def upper_bound(values: Sequence[int], target: int) -> int:
    return first_true(0, len(values), lambda i: values[i] > target)


values = [1, 2, 2, 2, 5, 8]
assert lower_bound(values, 2) == 1
assert upper_bound(values, 2) == 4
assert upper_bound(values, 2) - lower_bound(values, 2) == 3
assert lower_bound(values, 7) == 5
assert lower_bound(values, 10) == len(values)

排序性质与下界

排序算法必须满足两个正确性条件：输出键按非递减顺序排列，并且输出是输入的一个排列（permutation），没有元素丢失、重复或凭空出现。实际应用常要求一些在所有值都不同时看不出来的额外性质。

  • 稳定排序（stable sort）保持相等键记录的原始相对顺序。稳定性支持多阶段排序：先按次关键字排序，再稳定地按主关键字排序，会在主键相同的组内保留次键顺序。
  • 原地排序（in-place sort）除输入数组外只使用常数或对数辅助空间；严格定义时应说明递归栈是否计入。
  • 自适应排序（adaptive sort）能利用输入中已有的顺序。插入排序与 Timsort 利用已有有序段；选择排序无论输入顺序如何都进行大致相同比较。
  • 在线排序（online sort）可以在项目到达时逐个纳入；离线算法则需要完整集合。
  • 最坏、平均与期望复杂度是不同承诺。随机快速排序的期望复杂度不等同于堆排序的最坏保证。

为什么任意互异键的比较排序都不能保证 \(o(n\log n)\) 次比较？输入共有 \(n!\) 种排列。确定性比较算法可以表示为二叉决策树：每次比较最多有两个结果，每种排列必须到达可区分的叶节点。高度为 h 的树最多有 \(2^h\) 个叶子，因此

\[ 2^h \ge n!,\qquad h\ge \log_2(n!). \]

由 Stirling 近似，\(\log_2(n!)=\Theta(n\log n)\)。所以任何比较排序最坏都需要 \(\Omega(n\log n)\) 次比较，归并排序与堆排序匹配这一渐近下界。

“基于比较”的限制很关键。计数排序与基数排序使用键结构，而不只做成对比较，可以达到 \(O(n+k)\) 或相关界，其中 k 表示键范围或位数。它们不违反决策树下界，因为一次操作可能揭示超过一个二元比较结果的信息。

Python 实现：验证顺序、排列与稳定性 
from collections import Counter, defaultdict
from dataclasses import dataclass


@dataclass(frozen=True)
class Record:
    key: int
    label: str                    # 区分键相等的记录。


def verify_stable_sort(original: list[Record], result: list[Record]) -> bool:
    """检查稳定排序契约的三个可观察部分。"""
    # 1. 结果必须恰好包含相同记录。
    if Counter(original) != Counter(result):
        return False

    # 2. 键必须非递减。
    if any(result[i - 1].key > result[i].key for i in range(1, len(result))):
        return False

    # 3. 每个相等键组内的标签必须保持输入顺序。
    original_groups: dict[int, list[str]] = defaultdict(list)
    result_groups: dict[int, list[str]] = defaultdict(list)
    for record in original:
        original_groups[record.key].append(record.label)
    for record in result:
        result_groups[record.key].append(record.label)
    return original_groups == result_groups


records = [Record(2, "A"), Record(1, "X"),
           Record(2, "B"), Record(1, "Y")]
stable_result = [Record(1, "X"), Record(1, "Y"),
                 Record(2, "A"), Record(2, "B")]
unstable_result = [Record(1, "Y"), Record(1, "X"),
                   Record(2, "A"), Record(2, "B")]

assert verify_stable_sort(records, stable_result)
assert not verify_stable_sort(records, unstable_result)

基础排序算法

选择排序、插入排序与冒泡排序最坏时间都为 \(O(n^2)\)，但它们执行的工作不同，适用约束也不同。

选择排序（selection sort）反复寻找未排序后缀的最小值，并交换到下一个输出位置。第 i 轮后，直到 i 的前缀包含全局最小的 i+1 个值，且已在最终位置。它总进行 \(\Theta(n^2)\) 次比较，但只做 \(O(n)\) 次交换，因此写入成本异常昂贵时有价值。

插入排序（insertion sort）维护有序前缀，通过把较大值右移，将下一个值插入正确位置。相等值不互相越过时算法稳定。其运行时间是 \(\Theta(n+I)\)，其中 I 为逆序对数量，因此几乎有序的输入可接近线性时间。

冒泡排序（bubble sort）反复交换相邻逆序对。一次完整的从左到右扫描会把剩余最大值移到末尾。提前停止标记使已排序输入的最好时间为 \(O(n)\)，但插入排序通常是更实用的自适应基础算法。

SELECTION-SORT(A)
    for boundary from 0 to n - 2
        minimum <- index of smallest item in A[boundary:n]
        swap A[boundary] and A[minimum]

INSERTION-SORT(A)
    for i from 1 to n - 1
        value <- A[i]
        shift larger prefix values one position right
        insert value into the created gap

BUBBLE-SORT(A)
    repeat passes over adjacent pairs
        swap every inverted pair
        stop if a pass made no swap

Python 实现：选择、插入与冒泡排序 
def selection_sort(values: list[int]) -> None:
    for boundary in range(len(values) - 1):
        minimum = boundary
        for index in range(boundary + 1, len(values)):
            if values[index] < values[minimum]:
                minimum = index
        values[boundary], values[minimum] = values[minimum], values[boundary]


def insertion_sort(values: list[int]) -> None:
    for index in range(1, len(values)):
        value = values[index]
        position = index

        # 只移动严格较大的值，从而保留相等元素的稳定顺序。
        while position > 0 and values[position - 1] > value:
            values[position] = values[position - 1]
            position -= 1
        values[position] = value


def bubble_sort(values: list[int]) -> None:
    for end in range(len(values) - 1, 0, -1):
        swapped = False
        for index in range(end):
            if values[index] > values[index + 1]:
                values[index], values[index + 1] = (
                    values[index + 1], values[index]
                )
                swapped = True
        if not swapped:                    # 剩余前缀已经有序。
            return


for algorithm in (selection_sort, insertion_sort, bubble_sort):
    sample = [5, 2, 4, 6, 1, 3, 2]
    algorithm(sample)
    assert sample == [1, 2, 2, 3, 4, 5, 6]

归并排序

归并排序（merge sort）按位置把数组分成两半，递归排序两半，再合并两个有序结果。它的主要优势是可预测性：任何输入排列都得到相同的 \(\Theta(n\log n)\) 渐近处理。

合并步骤维护两个下标，分别指向两个有序段。较小的当前值是尚未输出值中的最小值，因此可以安全复制到结果。值相等时优先取左侧，可以保持跨半区的原始顺序，使算法稳定。

MERGE-SORT(values)
    if length(values) <= 1
        return values
    split values into left and right halves
    left <- MERGE-SORT(left)
    right <- MERGE-SORT(right)
    return MERGE(left, right)

MERGE(left, right)
    repeatedly copy the smaller current value
    copy any remaining suffix after one side is exhausted

打开动画：Wikimedia Commons - Merge sort animation2.gif（CC BY-SA 2.5）。

对大小为 n 的输入，归并排序创建两个约为 n/2 的子问题，并执行 \(\Theta(n)\) 合并工作：

\[ T(n)=2T(n/2)+\Theta(n). \]

拆分层数为 \(\Theta(\log n)\)，每个合并层都处理全部 n 个值一次，因此最好、平均与最坏时间均为 \(\Theta(n\log n)\)。标准数组归并排序使用 \(\Theta(n)\) 辅助数组和 \(O(\log n)\) 递归栈；按通常工程定义，它不是原地算法。

归并排序特别适合链表，因为合并时只需修改链接而无需辅助值数组；也适合外部排序，因为顺序合并大型磁盘有序段比随机访问更高效。它还支持算法增强，例如在合并过程中累计逆序对和范围统计。

Python 实现：稳定的自顶向下归并排序 
from collections.abc import Sequence


def merge_sort(values: Sequence[int]) -> list[int]:
    """返回新的稳定有序列表。"""
    if len(values) <= 1:
        return list(values)

    middle = len(values) // 2
    left = merge_sort(values[:middle])
    right = merge_sort(values[middle:])

    merged: list[int] = []
    left_index = 0
    right_index = 0

    while left_index < len(left) and right_index < len(right):
        if left[left_index] <= right[right_index]:
            # 相等时选择左项可保持稳定性。
            merged.append(left[left_index])
            left_index += 1
        else:
            merged.append(right[right_index])
            right_index += 1

    # 两个后缀中恰有一个可能非空。
    merged.extend(left[left_index:])
    merged.extend(right[right_index:])
    return merged


assert merge_sort([8, 3, 2, 9, 7, 1, 5, 4]) == [1, 2, 3, 4, 5, 7, 8, 9]
assert merge_sort([]) == []

快速排序

快速排序（quicksort）选择一个枢轴（pivot），把较小键分到一侧、较大键分到另一侧，再递归排序两侧区域。与归并排序不同，它在递归前完成大部分结构工作，并且通常原地重排输入数组。

枢轴无需恰好是中位数才能保证正确性，但枢轴质量决定递归是否平衡，从而决定性能。接近中位数的枢轴产生两个约一半大小的子问题；反复选择极值会产生大小为 n-1 的单侧子问题，导致平方时间。

输入包含大量等于枢轴的值时，三路划分很稳健。扫描时维护：

  • [low, lt)：小于枢轴的值；
  • [lt, scan)：等于枢轴的值；
  • [scan, gt]：尚未分类；
  • (gt, high]：大于枢轴的值。
THREE-WAY-PARTITION(A, low, high, pivot)
    lt <- low; scan <- low; gt <- high
    while scan <= gt
        if A[scan] < pivot
            swap A[lt] and A[scan]; increment lt and scan
        else if A[scan] > pivot
            swap A[scan] and A[gt]; decrement gt
        else
            increment scan
    return lt, gt

QUICKSORT(A, low, high)
    choose a pivot
    lt, gt <- THREE-WAY-PARTITION(A, low, high, pivot)
    QUICKSORT(A, low, lt - 1)
    QUICKSORT(A, gt + 1, high)

打开动画：Wikimedia Commons - Sorting quicksort anim.gif（CC BY-SA / GFDL）。

平衡划分满足 \(T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)\)；极端划分满足 \(T(n)=T(n-1)+\Theta(n)=\Theta(n^2)\)。均匀随机选择枢轴时，对固定输入顺序的期望时间为 \(\Theta(n\log n)\)，理论最坏仍为 \(\Theta(n^2)\)。

原地划分只用 \(O(1)\) 本地空间。平衡随机行为下递归栈期望为 \(O(\log n)\)，最坏可达 \(O(n)\)。快速排序通常不稳定，因为交换可能反转相等键记录。尽管最坏保证较弱，良好的缓存局部性和小常数使它在数组上经常很快。

Python 实现：随机原地三路快速排序 
from random import Random


def quicksort(values: list[int], seed: int = 0) -> None:
    """用随机枢轴和三路划分原地排序。"""
    random = Random(seed)

    def sort(low: int, high: int) -> None:
        if low >= high:
            return

        pivot = values[random.randrange(low, high + 1)]
        less = low
        scan = low
        greater = high

        while scan <= greater:
            if values[scan] < pivot:
                values[less], values[scan] = values[scan], values[less]
                less += 1
                scan += 1
            elif values[scan] > pivot:
                values[scan], values[greater] = values[greater], values[scan]
                greater -= 1
                # 交换到 scan 的新值尚未分类，不能移动 scan。
            else:
                scan += 1

        sort(low, less - 1)
        sort(greater + 1, high)

    sort(0, len(values) - 1)


sample = [7, 2, 5, 3, 9, 5, 1, 5]
quicksort(sample, seed=42)
assert sample == [1, 2, 3, 5, 5, 5, 7, 9]

堆排序

堆排序（heapsort）把输入数组视为最大堆，最大值位于下标 0 的根。把根与最后元素交换，就把一个值放到永久有序位置；缩小逻辑堆大小以排除有序后缀，再向下筛选修复剩余堆前缀。

本节关注堆排序的排序契约。完全树表示、下标公式、筛选操作与自底向上的 \(O(n)\) 建堆已在二叉堆与建堆中详细说明。

HEAPSORT(A)
    build a max-heap across the full array
    for end from length(A) - 1 down to 1
        swap A[0] and A[end]
        reduce logical heap size to end
        sift the new root downward inside the heap prefix

自底向上建堆为 \(O(n)\)。随后执行 n-1 次根提取，每次最多需要 \(O(\log n)\) 筛选，因此最好、平均与最坏时间均为 \(O(n\log n)\)。迭代堆排序使用 \(O(1)\) 辅助存储，在最坏内存和时间上比普通快速排序提供更强保证。

取舍在于实际局部性与稳定性。向下筛选会在父子下标之间跳跃，而不是扫描连续有序段，所以内存数组上通常比精心实现的快速排序慢。长距离交换使算法不稳定。最坏 \(O(n\log n)\) 与原地存储比稳定性和常数因素更重要时，堆排序很合适。

Python 实现：原地最大堆排序 
def heapsort(values: list[int]) -> None:
    def sift_down(root: int, heap_size: int) -> None:
        while True:
            left = 2 * root + 1
            right = left + 1
            largest = root

            if left < heap_size and values[left] > values[largest]:
                largest = left
            if right < heap_size and values[right] > values[largest]:
                largest = right
            if largest == root:
                return

            values[root], values[largest] = values[largest], values[root]
            root = largest

    # 自底向上建堆：叶节点已经满足堆性质。
    for root in range(len(values) // 2 - 1, -1, -1):
        sift_down(root, len(values))

    # 把每个最大值移入已排除的有序后缀。
    for end in range(len(values) - 1, 0, -1):
        values[0], values[end] = values[end], values[0]
        sift_down(0, end)


sample = [12, 11, 13, 5, 6, 7, 6]
heapsort(sample)
assert sample == [5, 6, 6, 7, 11, 12, 13]

分治设计

分治（divide-and-conquer）把问题划分为同一问题的更小实例，递归解决，再合并答案。当子问题显著缩小，且其结果包含足够信息以高效组合时，该模式很有价值。

SOLVE(problem of size n)
    if n is small enough
        return direct base-case answer
    subproblems <- DIVIDE(problem)
    partial_answers <- recursively SOLVE each required subproblem
    return COMBINE(partial_answers)

若问题产生 a 个大小为 n/b 的子问题，划分与合并成本为 \(f(n)\)，递推式通常为

\[ T(n)=aT(n/b)+f(n). \]

其中 a 是递归分支数，b 是缩小因子，\(f(n)\) 包含递归调用之外的工作。二分搜索为 a=1、b=2、\(f(n)=\Theta(1)\)；归并排序为 a=2、b=2、\(f(n)=\Theta(n)\)。

分治不会自动高效。重叠子问题可能重复大量工作，此时需要记忆化或动态规划；高度不平衡的子问题可能造成深递归；昂贵的合并步骤可能压过递归节省。因此设计时应写出基本情况、证明每次都向其推进、判断子问题是否重叠，并分析合并成本。

以最大子数组为例，可以在中点拆分。最佳子数组要么完全位于左半区，要么完全位于右半区，要么跨越中点。跨越答案由左半区最佳后缀与右半区最佳前缀构成。

Python 实现：分治最大子数组 
def maximum_subarray_divide_conquer(values: list[int]) -> int:
    """返回非空连续子数组的最大和。"""
    if not values:
        raise ValueError("values must be nonempty")

    def solve(low: int, high: int) -> int:
        if high - low == 1:
            return values[low]

        middle = low + (high - low) // 2
        best_left = solve(low, middle)
        best_right = solve(middle, high)

        # 恰好在中点之前结束的最佳后缀。
        running = 0
        best_suffix = float("-inf")
        for index in range(middle - 1, low - 1, -1):
            running += values[index]
            best_suffix = max(best_suffix, running)

        # 恰好从中点开始的最佳前缀。
        running = 0
        best_prefix = float("-inf")
        for index in range(middle, high):
            running += values[index]
            best_prefix = max(best_prefix, running)

        best_crossing = int(best_suffix + best_prefix)
        return max(best_left, best_right, best_crossing)

    return solve(0, len(values))


assert maximum_subarray_divide_conquer(
    [-2, 1, -3, 4, -1, 2, 1, -5, 4]
) == 6  # [4, -1, 2, 1]
assert maximum_subarray_divide_conquer([-4, -2, -7]) == -2

递推式为 \(T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)\)。Kadane 算法能用 \(\Theta(n)\) 时间解决同一问题，因此这个例子主要用于展示分治设计，而不是最佳专用解法。

递推式分析

递推式（recurrence）用更小输入的成本定义大小为 n 的算法成本。它应由递归代码推导，而不是先看到期望答案后随意选择。每个递推式都应明确：

  • 基本情况成本；
  • 递归调用的数量与大小；
  • 非递归的划分、分区或合并工作；
  • 向下取整、向上取整或不等大小是否会影响渐近结果。

本章例子为：

\[ \begin{aligned} \text{二分搜索： } &T(n)=T(n/2)+\Theta(1),\\ \text{归并排序： } &T(n)=2T(n/2)+\Theta(n),\\ \text{平衡快速排序： } &T(n)=2T(n/2)+\Theta(n),\\ \text{极端快速排序： } &T(n)=T(n-1)+\Theta(n). \end{aligned} \]

第一个系数表示递归调用数，参数表示每个子问题大小，最后一项计算当前调用在递归之外执行的工作。

重复代入也称为展开（unrolling），会不断展开较小项直到出现基本情况。递归树按层展示同一展开过程，通常更容易观察工作集中在哪里。

对归并排序：

\[ T(n)=2T(n/2)+n =4T(n/4)+2n =8T(n/8)+3n. \]

展开 j 次后，有 \(2^j\) 个大小为 \(n/2^j\) 的子问题，累计合并工作为 \(jn\)。当 \(n/2^j=1\) 时停止，所以 \(j=\log_2 n\)。叶节点贡献 \(\Theta(n)\)，内部层贡献 \(\Theta(n\log n)\)，最终 \(T(n)=\Theta(n\log n)\)。

代入法还可以用归纳证明猜测的界。要证明 \(T(n)=O(n\log n)\)，假设较小实例满足所提出的不等式，把假设代回递推式，再选择使结果成立的常数。递归树用于发现可能的界，归纳用于严格验证。

Python 实现：直接测量归并排序递推工作量 
import math


def merge_recurrence_work(size: int) -> int:
    """计算单位基本工作与每次合并调用的 size 单位工作。"""
    if size <= 1:
        return 1

    left_size = size // 2
    right_size = size - left_size
    return (
        merge_recurrence_work(left_size)
        + merge_recurrence_work(right_size)
        + size
    )


# 对 2 的幂，若 T(1)=1 且合并成本为 n：
# T(n) = n + n log2(n)。
for size in (1, 2, 4, 8, 16, 32):
    expected = size * (1 + int(math.log2(size)))
    assert merge_recurrence_work(size) == expected

这个递归测量用于教学，而不是高效分析器；它镜像调用树，使统计工作可以与代数对应。

练习。 LeetCode 50 - Pow(x, n)通过指数折半得到 \(T(n)=T(n/2)+\Theta(1)=\Theta(\log n)\)，前提是只计算一次半次幂并复用。

递归树与主定理

对于形如

\[ T(n)=aT(n/b)+f(n) \]

的递推式，主定理（Master Theorem）比较当前调用的非递归工作 \(f(n)\) 与递归阈值

\[ n^{\log_b a}. \]

参数 a 是子问题数，b 是每个子问题的缩小因子，\(p=\log_b a\) 描述递归树叶节点数量如何增长。定理判断工作集中在叶层、各层均衡，还是集中在根附近。

令 \(p=\log_b a\)，\(\varepsilon\) 为正常数：

  1. 若 \(f(n)=O(n^{p-\varepsilon})\)，递归叶层占主导，\(T(n)=\Theta(n^p)\)；
  2. 若 \(f(n)=\Theta(n^p\log^k n)\) 且 \(k\ge 0\)，各层均衡，\(T(n)=\Theta(n^p\log^{k+1}n)\)；
  3. 若 \(f(n)=\Omega(n^{p+\varepsilon})\)，且对某个 \(c<1\) 满足正则条件 \(af(n/b)\le c f(n)\)，根侧工作占主导，\(T(n)=\Theta(f(n))\)。

例如：

递推式 比较 情况 界
\(T(n)=8T(n/2)+n^2\) \(p=3\)，\(n^2\) 多项式级更小 1 \(\Theta(n^3)\)
\(T(n)=2T(n/2)+n\) \(p=1\)，\(f(n)=\Theta(n^p)\) 2 \(\Theta(n\log n)\)
\(T(n)=2T(n/2)+n^2\) \(p=1\)，\(n^2\) 多项式级更大 3 \(\Theta(n^2)\)

主定理并非万能。它不能直接处理 \(T(n)=T(n/3)+T(2n/3)+n\)、子问题数随 n 变化的情况，或极端快速排序的 \(T(n)=T(n-1)+n\)。不满足标准形式或附加条件时，需要递归树、代入法、Akra-Bazzi 或其他方法。

Python 实现：分类多项式形式的主定理情况 
import math


def polynomial_master_case(a: float, b: float, degree: float) -> tuple[int, str]:
    """分类 T(n)=aT(n/b)+Theta(n^degree)，不含对数因子。"""
    if a < 1 or b <= 1:
        raise ValueError("require a >= 1 and b > 1")

    threshold = math.log(a, b)          # p = log_b(a)
    tolerance = 1e-12

    if degree < threshold - tolerance:
        return 1, f"Theta(n^{threshold:g})"
    if degree > threshold + tolerance:
        # 多项式 f(n)=n^degree 在此满足正则条件。
        return 3, f"Theta(n^{degree:g})"
    return 2, f"Theta(n^{threshold:g} log n)"


assert polynomial_master_case(8, 2, 2) == (1, "Theta(n^3)")
assert polynomial_master_case(2, 2, 1) == (2, "Theta(n^1 log n)")
assert polynomial_master_case(2, 2, 2) == (3, "Theta(n^2)")

该辅助函数有意只处理 \(f(n)=\Theta(n^d)\)。把它误当成通用递推求解器，会隐藏对数因子和必要正则条件。

Quickselect 与随机枢轴

顺序统计量（order statistic）是指定秩的元素，例如最小值、中位数或第 k 小值。完整排序可以在 \(O(n\log n)\) 时间得到答案，但它计算了寻找单个秩并不需要的更多顺序信息。

Quickselect 使用与快速排序相同的划分步骤。划分后，枢轴或等枢轴区域已经处于最终秩范围。把 k 与该范围比较，就能判断答案已经找到，或完全位于一侧；另一侧无需排序即可丢弃。

QUICKSELECT(A, k)
    low <- 0; high <- length(A) - 1
    while low <= high
        choose a random pivot from A[low:high+1]
        lt, gt <- three-way partition around pivot
        if k < lt
            high <- lt - 1
        else if k > gt
            low <- gt + 1
        else
            return A[k]

一次划分用 \(\Theta(n)\) 时间扫描活动区间。若随机枢轴使期望区间大小按几何级数缩小，总期望工作类似

\[ n+\frac{n}{2}+\frac{n}{4}+\cdots=O(n). \]

严格期望分析会考虑所有枢轴秩，但几何级数给出核心直觉。若反复选中极端枢轴，则工作为 \(n+(n-1)+\cdots+1=\Theta(n^2)\)。随机枢轴使固定输入顺序触发该行为的概率很低，但不会消除理论最坏情况。

迭代原地实现使用 \(O(1)\) 辅助空间。大量重复值时，三路划分特别有用，因为整个相等区域都能一次终止搜索。

Python 实现：随机原地 Quickselect 
from random import Random


def quickselect(values: list[int], k: int, seed: int = 0) -> int:
    """返回从零开始的第 k 小值，并原地重排 values。"""
    if k < 0 or k >= len(values):
        raise IndexError("rank k is outside the array")

    random = Random(seed)
    low = 0
    high = len(values) - 1

    while low <= high:
        pivot = values[random.randrange(low, high + 1)]
        less = low
        scan = low
        greater = high

        while scan <= greater:
            if values[scan] < pivot:
                values[less], values[scan] = values[scan], values[less]
                less += 1
                scan += 1
            elif values[scan] > pivot:
                values[scan], values[greater] = values[greater], values[scan]
                greater -= 1
            else:
                scan += 1

        if k < less:
            high = less - 1              # 丢弃枢轴及更大区域。
        elif k > greater:
            low = greater + 1            # 丢弃枢轴及更小区域。
        else:
            return values[k]

    raise RuntimeError("unreachable for a valid rank")


sample = [9, 1, 8, 2, 7, 3, 6, 4, 5, 5]
assert quickselect(sample.copy(), 0, seed=7) == 1
assert quickselect(sample.copy(), 4, seed=7) == 5
assert quickselect(sample.copy(), 9, seed=7) == 9

对比与选择

合适技术取决于需要多少顺序信息，以及应用重视哪些保证。

严谨的工作流程是：

  1. 明确输入是否已经有序，或是否存在单调谓词；
  2. 判断输出需要一个元素、一个边界、部分顺序还是完整顺序；
  3. 选择排序前先规定稳定性、是否允许修改、内存与最坏要求；
  4. 对递归算法写出基本情况，并把每个递推项对应到代码；
  5. 引用复杂度前检查定理假设；不等大小的快速排序子问题不符合基础主定理；
  6. 测试空输入、单元素、重复项、已排序、逆序，以及高度不平衡的划分。

贯穿本章的统一思想是安全排除：二分搜索删除不可能的下标，排序逐步固定更多顺序，分治总结已经完成的子问题，而 Quickselect 丢弃不可能包含请求答案的秩。
